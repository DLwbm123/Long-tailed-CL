# 医学长尾增量研究：已交付结果总结（2026-10-15）

本文件整理本日聊天中的结果总结，仅依据已公开交付的匿名聚合。医学分类结果、合成CPU验证、真实GPU零更新预检与正式轮启动分别陈述；不新增实验，不改变健康运行源码，不读取部分val指标。正式守卫轮尚无纳入本总结的完整效果结果。

**主要结论：PMT在ISIC上改善旧类和尾类，但明显损害新类；HK上收益很弱。动态锚定没有形成有效贡献。新快照守卫已通过生产CPU和四条真实GPU零更新预检，但能否解决医学分类中的旧新类权衡，仍待正式轮检验。**

## 2. 动态锚定：没有支持有效贡献

## 3. 快照守卫：可解性和生产接线已验证，分类效用尚未证明

- 完整非负dual求解从开始保留全部约束，不依赖扩大active cap；maxcor10仅为优化历史。ISIC最大阶段9434个fit支持、1536维满支持秩、66038条约束，可以通过固定KKT门并保持非identity更新。HK最大旧bank的guard支持为1038点／rank1038／22836约束；另一个PMT合成probe才是输入满rank1536。
- 生产CPU八项全PASS：关闭Core/LT及PMT时参数、bank、head等精确回归；epoch/boundary时点、每次更新后的证书失效、guard-aware checkpoint/eval、封存屏障、预算及全部高维Session检查。
- 正式生产CPU六个高维合成案例相对同状态ON无约束proposal的救回／破坏全部0／0。可行非identity、头范数变化和约99.98%的二次目标收益保留，不能替代分类改善。未单列错误储量，不能区分分类饱和与没有跨越边界。
- 保护仅限固定encoder/frame、epoch初始化和boundary最终头上的完整current-fit true-vs-all margin，参考为同状态OFF。optimizer更新后证书失效；投影detach，中间原loss/梯度不变。它不保证整个训练过程中持续保护、独立控制轨迹无损或val新类无损。
- checkpoint保留force/reference/proposal/head和证书标量；没有完整支持，加载时只能核对重建、stationarity与当时凭据，不能独立重验全部点margin。
