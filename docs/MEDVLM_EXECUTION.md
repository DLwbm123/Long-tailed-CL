# NB2-MedVLM execution

The user authorized the supplied medical-VLM plan on 2026-09-26 and explicitly
removed its wall-clock limits. The frozen method matrix, no-training rule, original
two-class Task1 parents, dataset split/order locks, and test/reserved exclusions remain.
`medvlm_protocol.json` fixes all remaining routine choices before any new validation.

The primary comparison is BiomedCLIP joint ridge B.J versus Generic G.J. Both use
lambda 0.0005. F uses lambda 0.001; the second matched scale is J1=0.001 versus F2=0.002.
R, and its three fixed prior ablations, use J's lambda in the solve and spectral
operator. Its semantic-scale denominator also uses 0.0005; the original reliability
formula and gamma prefactor 0.001 remain fixed. V uses 0.001. No parameter is selected
using validation. Generic R1 A2 corresponds to G.J1, not the new G.J.

BiomedCLIP's official local configuration is used with its native PubMedBERT
architecture, tokenizer and 256-token context. Only configuration paths are localized.
The old serialized `position_ids` buffer is removed after verifying equality with
the deterministic buffer generated by Transformers, matching the official OpenCLIP
compatibility rule. Every learned tensor is loaded strictly. Runtime connections
are rejected, in addition to Hugging Face offline flags.

Generic fitting reuses the original locked per-stage aggregate banks. B extracts
only the current class of its parent/order, then retains class/component aggregates.
Independent B workers use available separate GPUs and disjoint parent/order assignments.
All G/B core states precede fixed ablations; every state is locked before new val
access. Private APART val features are reused per parent across models, and each
medical VLM's val features are shared across parents only in the evaluation phase.
All physical image accesses are charged, including qualification.

DermLIP is conditional. The official repository now requires access approval.

The model-card metadata says CC BY-NC 4.0, while its body and access terms say

Run `tests/test_medvlm_math.py` in the experiment environment to check the direct
ridge/prior equations and a complete synthetic reporting matrix with a deliberately
zero-gain primary candidate. The live qualification then restores all six real
parents and checks native BiomedCLIP outputs using Task1 fit samples only.

The launcher supplies `MED_CONFIG`, `MED_ENTRY`, CUDA device visibility and offline
flags through environment variables. Scientific process arguments contain only
neutral entry paths. Every stage is atomic; an incomplete transaction raises an
error instead of being mistaken for a completed stage. Child failure creates a
failure receipt, and the coordinator stops before validation/reporting.

Successful execution writes `completion_receipts.json` only after final reports
and resource accounting. A positive result concerns this fixed development matrix;
it does not establish independent generalization or continual adaptation. The final
decision is always STOP. Public Git contains source and aggregate results only.
