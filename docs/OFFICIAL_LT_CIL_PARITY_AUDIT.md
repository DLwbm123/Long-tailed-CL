source inspected from GitHub on 2026-06-15. The current reproduction target is
GPA-style CIFAR-100-LT with rho=0.01, 50 base classes, and 5 incremental tasks.

## Key Findings

1. `original_id` is the closest match to `xialeiliu/Long-Tailed-CIL` count binding.
   `shuffled_rank` is a useful diagnostic but does not match that official code path.
2. Current class order does not match the official fixed `cifar100_lt` order. This is a
   protocol mismatch independent of count assignment.
3. The official CIFAR100-LT script enables exemplar memory, while the current repo is
   intentionally exemplar-free. This can make official LT-CIL baseline numbers
   incomparable to the current no-replay reproduction.
4. The current default training schedule is much shorter and different from the
   official CIFAR100-LT script: official uses 160 epochs and step decay.
5. Normalization std differs from official LT-CIL. This should be checked before
   concluding that base underfit is caused by GPA.
