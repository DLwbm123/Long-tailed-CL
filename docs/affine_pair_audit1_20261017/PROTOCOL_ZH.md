# 已封存岭头的配对预测与补偿关系诊断

## 问题与固定检验

联合仿射岭相对完整无截距岭仅两个Qgate略升，ISIC Qfit旧类受损、HK Qfit逐类正确数不变。另一方面，联合截距约为条件截距的350/376倍，不能仅看截距大小解释最终预测。本轮只诊断这两项未解决的问题，不新增候选方法、参数、训练或部署选择。

固定原完整头W₀、联合仿射头W₁及其未缩放截距b、条件截距b₀，以及同支持类平衡均值m。所有输入均来自已交付模型，来源提交详见LOCK inputs。首先从现有头差重构g=−(W₁−W₀)bᵀ/(bbᵀ)，核对W₁−W₀=−g b和(1−mg)b=b₀。g是由封存头重构的方向，不声称独立求解了A⁻¹m，也不声称进行了新的因果干预。

随后在原Qfit/Qgate共享同一次raw特征前向，计算两模型原分数及直接预测。对每个查询检查Δscore=8(1−zg)b，记α=1−zg；报告每类α的min/median/mean/max、负值计数、平均绝对值，及逐样本最大绝对logit变化的类内均值/最大值。中位数用0.5分位数线性插值。不以这些统计拟合、筛选样本、调整截距或挑选后续参数。

## 配对输出

每类和all/old/new组报告rescued（原错现对）、harmed（原对现错）、both_correct、both_wrong、changed、wrong_to_other_wrong。核对总数、changed分解及rescued−harmed与正确数净差一致。公开按真实类/原预测/新预测/转移类型聚合的切换次数，不公开个体标识、文件名、原始特征、逐样本logit或患者信息。

重新计算两封存模型逐类BA/CE和错误流向，必须复现上一轮已公开的count/correct/errors_to_old/errors_to_new（整数完全相同）及CE（绝对误差<1e−10）。仅复现这两个固定模型供配对诊断，历史17参考已有报告不重跑。没有新的候选门槛或选优。本轮检查通过仅表示代数和结果复现正确，不表示方法有效。

## 数据、来源与访问

沿用seed74002/类别顺序/既定Qfit/Qgate，ISIC旧4新2、HK旧13新2。允许读取已封存完整岭、联合仿射岭、条件截距及中心artifact和各DELIVERY来源收据。核对源码和交付提交，头1536×6/15 float64 finite、全零adapter及形状一致、条件截距的W与完整W完全相同，center finite1536。中心artifact附带head只用于形状检查，不参与预测。

先完成固定几何重构并记录seal，再允许读取Qfit/Qgate和仿射轮聚合；访问守卫提前测试禁止支持/query/ref读取。无H、新旧S、teacher状态、E、原图、新标签、GPU，不拷贝banks，不改原模型。查询有限1536、标签范围和每类非空检查保留。

b范数须>1e−12，1−mg须>1e−12，否则停止，不改问题或回退。头差相对重构误差<=1e−7，条件截距恒等式相对误差<=1e−7，逐查询score恒等式最大绝对误差<=1e−9。相对范数分母使用1e−15下限，仅用于诊断误差，不修改模型。失败保留日志，不自动重跑科学阶段或放宽阈值。

## 实现与预算

新增小入口run_affine_pair_diagnostic.py，沿用已有诊断的共享features、load/save、聚合配对和历史结果一致性模式，以及既有CPU队列。工程断言检验二维秩一头差可精确重构、zg=1时权重项与截距抵消、其他行的score恒等式、拒绝零b，以及人工五样本覆盖获益/损害/正确保持/错误保持/错到另一错的计数分解。

0新头/截距/center拟合、0矩阵解、0梯度及adapter/teacher/encoder/memory更新。两数据集合计2155共享特征前向、4310模型logit和决策样本评估、2155诊断差值重构评估；未保存新预测模型。重构向量、矩阵乘法、softmax、聚合和读取有CPU成本，历史成本不重计，客户端准备null。
