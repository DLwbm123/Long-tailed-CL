# 联合仿射岭：权重与不正则化截距共同求解

## 依据、假设及唯一改动

固定W的支持截距轮已交付：截距很小、仅ISIC Qgate单片通过主参考，HK逐类计数均不变。它没有允许W随截距共同改变，不能排除联合仿射目标的影响。当前唯一目标变化是在原类平衡岭中加入不受正则惩罚的截距b，并联合求解W、b。

目标为(1/K)Σ_c mean_i ||z_ci W+b−e_c||² + λ||W||²，λ固定0.001；raw z先沿用原单位特征，不再对中心化后的样本或头列做单位化。设μ为类均值矩阵，S=Σ_c mean_i zzᵀ，m=mean_c μ_c，G=S/K，B=μᵀ/K。精确解满足：

(G−mmᵀ+λI)W=(μ−m)ᵀ/K，b=1/K·1−mW。

推理仍为8(zW+b)，保存给metrics的bias=8b。所有类等质量、类内均匀权重、λ和BETA固定，不扫λ/截距正则/温度/强度，不改变新旧权重或重采样。此为标准仿射岭基线，不宣称新方法或必然分类改善。它不是前一轮固定W的条件截距，W方向和长度现在由同一个联合目标确定；不在query上拟合。

## 实现与工程检查

复用tools/run_raw_ridge_head.py，新增affine_intercept=true，与六个旧second-moment消融标志互斥，默认旧分支保留。affine_ridge使用既有analytic.move对所有类施加同一−m位移，得到S−Kmmᵀ和μ−m；再调用analytic.ridge，推导b。原bank不改。只修改此入口、对应配置、队列调用和中性包装，其他调用方无变更。

原支持数据形状finite1536/非空/均匀权重检查保留，输出1536×6/15 float64头finite。除中心化岭方程相对残差<=1e−7，还验证原联合正规方程(G+λI)W+mb=B与mW+b=1/K的合并相对残差<=1e−7。记录center_norm、两残差、每类head_norm、unscaled_intercept和logit_bias。原始支持散布诊断仍基于未中心化的原moments，不把它们当成新目标的中心化协方差指标。数值失败停止，不clip、改λ或科学重试。

每数据集三个小矩阵解：单位二维两类的闭式仿射解；三样本不等类计数、类等质量权重的中心化解；同例直接增广特征[ x,1 ]、正则diag(λ,λ,0)的3×3联合解。后两者W/b须在1e−12内一致。另检查原bank不改、复制一个类全部样本后类平衡S和μ不变、特征共同平移配套b改变后分数不变；这些检查不增加矩阵解或梯度。
