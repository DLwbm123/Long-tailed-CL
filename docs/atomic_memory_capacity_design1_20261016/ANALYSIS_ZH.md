下一步机制假说：不要把整类分布永远压成同一组有限原子，而用原矩匹配中心加一个由当前类二阶迹残差确定的随机残差分布，在每次使用时生成新的16个合成潜特征。用满秩随机残差减少永久固定子空间；不增加中心数、节点优化步数或查询训练。仅凭这个想法没有效果保证：各向同性残差可能错误，归一化会改变均值，随机小批有方差，仍需新前瞻CPU配对验证。

关键限定：新查询需先确定、然后独立采样新记忆批；这可研究对解码分布的条件期望/梯度估计，不承诺对观察当次样本后再选择的所有查询uniform准确。单次采样仍受有限原子限制。不能把多次采样平均偷偷当16点部署表现，不能把生成分布的无偏估计误当对真实旧分布无偏。下一协议需报告每个16点批次的全部误差与波动、归一化对照及真实资源，全部旧结果保留。
