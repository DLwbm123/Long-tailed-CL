# 有限原子记忆容量反例：前瞻CPU协议

前轮序列设计已完整交付f2ab201，两个高维完整门失败，旧记忆/固定查询/接口精确。现在不继续调Adam、权重、节点数、更新预算或门槛，而先审计固定16原子的方向容量限制。本轮不优化任何记忆，不设计新医学方法，不重跑或读取旧轮节点。

## 解析对象与推导

参考分布P为d维正负坐标基的均匀分布（2d个单位点），均值0、Q=I/d。参考是新的显式合成反例，不是旧非高斯类条件fixture或医学分布。允许查询家族的子集取A=B=0（identity adapter），v=2q且||q||=1，原beta=8，因此b=16。保留原features归一化：所有非零节点在查询时先归一化，零节点映为0。单位球内只缩短非零节点不能逃离本子家族的方向限制。

有限记忆为最多M=16节点的正概率分布。记忆Q_M的秩<=M，trace为tau；最大特征值lambda>=tau/M。取对应单位方向q。实际枚举四个固定构造：16正交单位节点（非零均值控制）、16顶点零均值正则单纯形(rank15)、8对正负轴(rank8)、16零节点（trace0退化负控制）。均匀权重，不增加seed/节点档位，维数只32和1536。

令h(t)=(softplus(bt)+softplus(-bt))/2=log2+logcosh(bt/2)。对|t|<=1，有

    log2 + logcosh(b/2)*t^2 <= h(t) <= log2 + b^2*t^2/8。

上界来自logcosh(u)<=u^2/2；下界来自f(s)=logcosh(b*sqrt(s)/2)在[0,1]凹且f(0)=0，所以f(s)>=s*f(1)。凹性由tanh(u)/u递减得到（sinh(2u)>2u）。这是一条解析推导，网格检查只查算术实现，不代替证明。

因此记忆对称查询均值减参考至少为

    L_spectrum = logcosh(b/2)*lambda - b^2/(8*d)
                >= logcosh(b/2)*tau/M - b^2/(8*d) = L_trace。

+q和-q中至少一个signed gap不小于该均值，正下界同时是绝对误差的存在性下界。负下界原样报告为无信息，不能填0当成功。单位球面tau=1，但不保证任意分布/实际分类误差都有此下界。它仅证明在本允许查询族、此各向同性参考下，单靠优化16个固定原子不能任意消除最坏方向差距。
