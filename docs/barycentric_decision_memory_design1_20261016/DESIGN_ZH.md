# 类支持凸组合判别记忆：前瞻 CPU 协议

上一轮 ec46abe 全部正常结束但两个高维门均失败，判别记忆最大误差 ISIC 12.5322、HK 15.2235，显著高于矩匹配。移动训练查询误差也增长；有效节点数没有塌缩成单点。节点仅限单位球可能离开类支持，但此前未保存轨迹，不能把此假说当因果结论。

本轮唯一结构改动：每类每个合成节点 z_m = sum_i a_mi x_i，a_mi 非负且和为 1。a 从与原 random/free-decision 相同的样本 one-hot 初始化，沿用 Adam .02 后作欧氏 simplex 投影；logit 权重训练不变。节点始终在当前类支持凸包内，可能过度收缩、欠拟合，或者仍然不稳定。不是提高 cap、节点数或更新步数。

依赖旧 helper 的纯合成 fixture/损失函数，新 run_scale 加一条结构候选；旧 helper 与旧轮不改不重跑。新轮 mean/random/moment/free-decision/barycentric 五方法重做同轮配对，共用评价查询；因为 stress 查询由五方法共同产生，不能与旧轮四方法查询数值直接作配对比较。临时系数与支持只用于当前任务构造，部署只保留 16 合成节点/类与权重；本轮全合成，无医学特征。未来序列必须在任务结束丢弃当前真实支持，不能倒读旧类支持。

四个独立 CPU case：新 simplex 可行性/投影 KKT/幂等/相同初始化/系数有限差分/排列检查；32 维 N512 K4；1536 维 N9434 K8；1536 维 N1038 K23。沿用第一轮非高斯单位样本、公开比例最大余数分配和 seed263/264/265，不冒充医学 fit。16节点、48记忆更新、每步2查询更新、rank8、8查询、4组未见随机查询与2组共同stress查询，每组8方向，全部超参数见 DESIGN_LOCK。没有 val/test。

两个高维各自必须 barycentric 最大绝对损失误差 <= .9×moment/random 的各自最大误差，且平均误差不大于两者，才是完整有限查询信号；与 free-decision 的正负差另列。查询只作为新优化训练之外的有限见证，不是 uniform/sup 证书，也不是分类改善。不得按结果增加步数、节点或挑查询。
