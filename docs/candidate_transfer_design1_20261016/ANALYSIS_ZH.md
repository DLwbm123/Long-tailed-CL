# Candidate机制诊断：结果分析与停止

本轮的直接结论是：未经逐类筛选的candidate没有补回整体分类收益。四个固定场景中，它的整体BA点估计均低于moment，也均低于selected；两个场景新组相对moment下降1.35pp，超过冻结的1pp点估计代价上限。因此，本轮不支持“取消逐类筛选即可恢复收益”，也没有形成应立即开发联合选择器的分类证据。

更有价值的机制信息是：candidate在教师和moment终点两个共同参数状态下的完整训练目标梯度误差都小于moment及selected，然而下游分类净收益未出现。这里的目标包含实际加权CE与保持项，而不再只看创新梯度。

## 1. 完整分类结果

两次固定状态的描述性整体均值：ISIC相对moment−0.250000pp、相对selected−0.175000pp；HK分别−0.106667pp、−0.043333pp。所有8个整体比较区间仍跨零，因此不能把“4/4负点估计”表述为已证明总体稳定负收益或selected具有普遍显著优势。它足以否定本轮预期的正向观察，但不支持无限外推。

ISIC200264、HK200265新组相对moment都下降1.35pp，区间分别[−2.20,−0.50]和[−1.95,−0.75]；相对selected都下降1.05pp。两者均按冻结规则判COST_EXCEEDS_LIMIT。两个区间没有完全落在−1pp以下，所以不能再声称总体损失已被证明超过1pp；超限标签依据的是冻结的点估计与区间保护规则。其他两个场景点代价和区间代价通过，但整体收益非正。

## 2. 筛选并未在这些状态中损失整体BA

前轮发现candidate在固定教师处的聚合创新梯度比selected更好，提供了局部组合缺口的线索。本轮直接把同一candidate用于同样48步训练后，4个整体点估计均未优于selected。特别是两个第二种子，新组比selected再下降1.05pp。

因此，“梯度筛选损失了某些近似优势”与“筛选损失了分类净收益”必须分开。前者仍有固定教师原始诊断支持，后者在本轮没有出现。不能由此证明原13项筛选最优，也不能排除其他联合选择方法；但立即设计joint selector的优先级应下降，不能再把它作为已经定位的修复方案。

候选仍产生了实际分类变化，而非数值恒等：相对moment，四场景的救回/伤害分别54/70、86/100、116/141、108/115，净正确数−16、−14、−25、−7。相对selected则27/30、59/77、72/84、100/101。评估每类等样本，BA和该均衡bank的样本准确率数值相同。

分组正收益完整保留：ISIC200264和HK200265旧组改善；HK100265新组改善0.95pp，区间[+0.35,+1.55]。不过它们没有抵消对应其他组损失。接纳旧类/原回退旧类和逐类变化全部保留在SUMMARY/PAIRED_PREDICTIONS；这些组共享适配器，不能按类归属直接解释因果。

## 3. 总梯度优势减弱，但在第二共同状态没有反转

以下是candidate相对moment的完整目标梯度绝对误差降幅，包含旧/新CE与原教师固定的保持项。

|场景|教师状态误差降低|moment终点误差降低|
|---|---:|---:|
|ISIC100264|24.592827%|9.029436%|
|ISIC200264|15.752045%|5.734687%|
|HK100265|14.317910%|4.318109%|
|HK200265|13.537271%|8.202243%|

candidate在这8个共同状态比较中总梯度绝对误差都更小，而且都小于selected。不同状态梯度范数、参照和几何本身不同；表中降幅是各状态内部相对moment的比较，不能把两列当成同一误差随时间单调变化。

这不支持把当前问题简单归结为“离开教师后，全部梯度优势消失”。优势在观察的第二状态仍存在，但最终BA没有改善。两个固定查询并非整个训练轨迹，也没有查询candidate自身终点，不能排除未观察路径上的失配。

保持项并非处处更好：moment终点处，candidate保持梯度误差在ISIC200264增加12.293905%、HK200265增加2.692644%，另外两场景下降2.473316%、4.432653%。但四场景的总梯度误差仍都下降。因此不能把两个新类损失简单归因为“保持梯度更差”；需要保留分量和总量的区别，且本轮没有干预保持系数来识别因果。

## 4. 当前证据支持的路线判断

最强的有限结论是：对原有限训练支持的更好梯度近似，包括两个共同状态下的完整训练目标，仍不足以推出这批场景的分类净收益。

full_support只是少量长尾合成训练支持，不是总体分布，也不是经过证明的分类最优目标。当前结果不能单独区分：有限支持的泛化偏差、未观察训练路径、梯度L2目标与决策边界变化之间的差异。也没有证据证明固定节点16点的最优性、表达上限或整个记忆方向无效。

当前停止继续扩展这个固定教师权重修正版本；moment保留主对照。若以后重新授权研究，应先证明所匹配的训练参照/目标为何能够提供可迁移的分类收益，再决定是否优化筛选或轨迹。此处只是证据解释，不启动任何下一轮、oracle训练、真实医学或多阶段扩展。
