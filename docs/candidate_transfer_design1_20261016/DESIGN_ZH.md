# 未筛选 candidate 的机制诊断：冻结协议

授权范围：复用上一轮四个新增种子的现有教师、moment、candidate、selected和两条已保存终点，仅为candidate各补48步下一阶段训练；在共同状态作零更新梯度诊断。结果用于机制解释，不是新的独立确认。基础结果提交c6a799eecaf10b04f2092a07e48ccb094d432c3e。

## 1. 唯一训练干预

ISIC100264/200264、HK100265/200265固定不变。载入既有第一阶段教师、固定ETF、16节点概率记忆和接受记录，直接使用未经13项逐类筛选的candidate全部类别权重。moment和selected不重训；教师、记忆和历史终点不写回、不覆盖。

candidate与既有两臂相同：48步全批SGD，学习率1/16，类别均衡扩展类别CE + 系数1的旧类teacher-correct中心化logits保持；教师正确掩码只依据原旧类竞争集合。调用原train函数，参数和数据不变。总新增192 adapter更新、0 memory更新、0 teacher更新。没有joint selector、修改接受条件、调参、加步数、补种子、科学失败重试或下一轮。

## 2. 共同状态梯度诊断

每场景只用两个预定状态：共同教师theta0、已保存moment的48步终点thetaM。针对full_support、moment、candidate、selected四种旧类表示，在同一个theta计算以下五个分量：旧类扩展CE、新类CE、完整CE、旧类保持项、CE+保持总目标。teacher-correct掩码及保持目标始终由原theta0在各自表示上计算，不能在thetaM重新定义教师。

CE按实际训练每类1/Kseen加权；保持按旧类1/Kold加权并乘冻结的教师正确掩码。新类训练支持各表示完全共用。full_support为原来的有限旧类合成训练支持，仅用于诊断参考，不参与candidate训练、不代表总体真值或分类上限。重现生成器只为恢复完全相同的训练支持，不新增样本或改变种子。

公开各分量目标值、梯度范数、参照范数、绝对/相对误差和余弦；参照或自身零范数时相对量/余弦按原comparison规则记NA。梯度向量仅瞬时计算，不公开私有模型。检查梯度可加性、不同表示的新类梯度一致及教师处保持项/梯度为0。零更新单元检查用小合成fixture验证总目标与原训练表达式一致、非零保持项下的梯度有限差分，不执行优化器或train。

诊断不用于选择记忆或中间停止；不读candidate中间分类结果。只在两个既有状态查询，不能冒充观察了整个48步轨迹。结果涉及总梯度更好/更差的机制证据，不将创新梯度单一分量变化当作BA因果证明。

## 3. 封存后分类评估和门槛

四条candidate终点全部封存后统一评估，复用上一轮固定bank：ISIC310264、HK310265；所有已见类各1000样本。重现样本不扩充评估集，既有moment/selected的每类正确数必须复现上一轮公开记录，否则停止解释并报告异常。

主比较candidate−moment，次比较candidate−selected。公开42条逐类三臂正确数，84条两种成对比较的完整正确性四格与错误去向，40个整体/旧/新/接纳旧/回退旧分组结果，24个整体/旧/新条件区间，8个场景比较判定；空组为NA。旧接纳与回退分组仅使用原selected规则，不依candidate分类重分组。

维持原规则：整体BA差>1e-12；旧、新组点差均>=−0.01−1e-12；旧、新组条件95%区间下界均>=−0.01−1e-12；整体区间下界>1e-12才给SUPPORTED标签。超组点限为COST_EXCEEDS_LIMIT；整体点非正为NO_POSITIVE_GAIN；其余INCONCLUSIVE。所有布尔分量保留。两规模分别报告两个固定种子的符号、均值/范围和是否同时满足；不合并抵消，不以逐类退化一票否决。

类别内成对四格multinomial bootstrap10000次，线性百分位95%区间；种子953000..953007按锁文件依次固定。区间仅描述固定模型的评估采样不确定性，非种子总体区间、非多重比较同时覆盖、非独立确认。已有状态和评估集均已查看，本轮SUPPORTED也只能是机制诊断中的算术标签，不覆盖前轮失败。

## 4. 结果解释与停止

candidate优于selected且优于moment：支持进一步研究筛选的下游影响，但不能单独归因于创新梯度或证明joint selector有效。优于selected却不优于moment：筛选可能损失近似优势，但修正使用价值未建立。教师优势在thetaM减弱/反转：支持跨状态失配假设，但没有完整轨迹。共同状态近似改善而BA不改善：固定参照梯度不足以支持分类净收益；有限训练支持与泛化的差距仍需区分。完整正、负、零结果都报告，无事后挑场景。
