## 模型与估计

每个患者 s 在某类内的所有图像 patch 共 T_s 个，模型为 x_sp = mu + b_s + e_sp，b_s~N(0,B)，e_sp~N(0,W)。重复图像的 patch 共用患者效应；R=I，未覆盖全部空间/跨图像条件相关性。

以患者为等权单位。记 m_s 为患者 patch 均值，Q_s 为其中心散度。

- W_hat = mean_s Q_s/(T_s-1)。
- B_hat = PSD[Cov_unbiased_s(m_s) - W_hat * mean_s(1/T_s)]。
- 每类 mu 为患者均值的等权平均。分别对 W、B 向基类各类对应矩阵的平均收缩，beta=n_patients/(n_patients+20)。仅一患者时 B 不可识别，直接使用基类 B 先验，不称其为估计结果。
- W 统一加 .001×基类等患者边际协方差平均对角方差的单位矩阵；不对均值作先验收缩。
- 另保留等图像和等患者的普通 patch 边际协方差，用于基线。PSD 截断数量公开记录，不因数量/验证结果调整估计器。

单张图像 P=196，均值 m、残差 r_p=x_p-m 的精确联合 log-density：

`log N(m;mu,B+W/P) - d/2 log P - 1/2 sum_p r_p'W^-1 r_p - (P-1)/2 [log|W|+d log(2pi)]`。

这是 `11' ⊗ B + I ⊗ W` 的联合高斯，不是用有效样本数缩放独立分数。小维度下与完整稠密协方差的独立实现核对；B=0 必须还原独立 patch 乘积。

患者的 T、sum x、sum xx' 可按块合并；仅活跃患者暂存，完成后归并到类级固定统计量，不缓存全部训练 patch 或全部患者矩阵。每类需要 O(d²) 但矩阵数量大于单高斯；不声称与16个历史特征等预算。先验只使用基类类内矩阵；不把类间差异混入患者间方差。

## 固定对照与报告

八臂全部报告，不择优：image_uniform、patchbell_adapted_entropy（等图像无收缩）、patient_uniform（等患者无收缩）、patient_shrunk（边际协方差收缩）、hierarchical_no_shared（同一 W 但 B=0）、hierarchical_independent（同一 W+B 的独立 patch 似然）、hierarchical（主方法）、ridge_historical（历史分数直接复用）。

主要机制比较：hierarchical 对 hierarchical_independent，二者使用完全相同的参数与内存，只有联合/独立似然变化。报告六阶段 BA、微准确率、每类正确数/召回率/混淆矩阵、最终 BA 与平均阶段 BA；对所有固定对照记录负结果。主方法对同参数对照、patient_shrunk、熵对照与 ridge 记录救回/损害。记录旧类分数漂移；固定模型旧分数不变不等于没有新类竞争遗忘。

一次已有开发集运行仅判断该机制是否值得继续。改进不成立、效果差或失败都保留，不自动调参、换种子或扩大模型。
