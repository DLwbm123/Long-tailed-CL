# 病例层联合 patch 证据：固定开发实验

结论：固定病例层联合模型未获得收益。与使用完全相同 mu/W/B 的独立patch评分相比，最终BA由18.333%降至17.000%（55/300→51/300，−1.333个百分点），平均阶段BA由23.087%降至20.869%（−2.218个百分点）。最终救回4张、损害8张，改变52张预测。

加入共享效应相对B=0的15.00%确有改善，但仍低于同参数边际独立评分，不能由此宣称病例联合建模成功。普通等图像高斯19.333%、等患者高斯18.333%、历史ridge25.333%；患者等权是本轮协议选择，不自动带来准确率收益。

独立重算六阶段共10,800个方法–图像预测，核对每类正确数、混淆、BA及救回/损害，并确认等患者普通高斯在全部阶段复现历史预测。小维度联合密度oracle与B=0还原检查也已通过；实现正确性不等于随机效应假设符合诊断任务。

联合模型只表示跨patch共享的加性患者偏移，条件残差R=I；没有证据表明所有患者间差异都是无关噪声，或所有空间依赖均已建模。本轮结果不能否定所有病例层模型，也不能将现象定位为某一似然分项主导。接下来的同条件表示/读出控制已另行授权并独立冻结，不依据本轮结果修改该模型或DENO。
