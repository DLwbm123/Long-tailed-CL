# 类平衡共享中心变换：固定单因素开发检验

依据[旧新块消融](../centroid_block_factorial1_20261017/REPORT_ZH.md)，旧块改为中位数在两种新块条件下均损伤旧类，不能靠中位数混搭解决；不继续分位数网格。原始支持类均值范数约0.79–0.93（单点类1），说明类内聚集较强但不证明跨类公共偏移。本轮检验一个不同假设：同一冻结表示中的共享偏移可能干扰余弦类中心判别；同时记录几何以检验这个前提，不预设有效或新颖。

## 唯一主要改动

对每个seen类c，用相同支持（旧H、新S）和原类内权重p计算原始单位特征均值μ_c。共享中心g=(1/K)Σμ_c，每类等权，避免新类样本数量直接主导中心。对所有支持及随后查询统一使用z'=normalize(z−g)，再从支持z'按原p构造normalize(Σp z')的算术均值头。固定BETA8、无bias，无强度系数、白化、特征筛选、种子或温度搜索。g不单位化；诊断用其方向不改变变换。g和头必须在读查询前封存，查询不得更新中心。

仍用原H64/169、新S2290/95、seed74002/类序/划分/冻结原始特征；两套数据各拟合一个共享中心和一个头。相同均值聚合规则，主要干预是所有特征共享的去中心化归一化。该变换会改变角度、范数以及有效分数尺度，CE也报告；不能将它简化为只减所有类相同的logit常数。

## 判定和必要参考

本轮主要单因素参考为raw_centroid原始均值余弦头。每数据集Qfit与Qgate均须总体BA严格提高且旧/新各下降不超过1pp；任一不满足则该数据集不通过。该规则在运行前冻结，历史轮的MM主要门槛不改。完整报告raw_centroid、MM、HH、identity_ETF、teacher_centroid、teacher_ETF、coordinate_median共七参考的全seen逐类/组BA和CE、所有正负差值及相同门槛。MM/HH表示不同，不能用于本轮单因素归因。七参考只读上一中位数轮完整聚合，不重推理；每查询只评价本轮候选。

记录g范数、各原始均值头沿g方向余弦（g接近零则null）、去中心化前后类头两两余弦min/mean/max、原始与变换后类均值范数、逐类支持残差范数min/mean/max。几何扩张不等于分类改善，不根据诊断选方向或调整参数。

## 边界和检查

只读既有teacher文件用于零残差模型与形状、同一H和新S；禁止旧S、E、原图、新标签及GPU。先构造并封存center/head后才读Qfit/Qgate与参考聚合。残差范数或类均值范数<=1e−12直接停止，不加epsilon、回退原特征、换算法或重试；共享中心本身允许为零。数据finite、权重非负且和为1、形状、查询标签范围检查保留。

合成自检：正交样本减共享中心后为反向单位向量、零中心为恒等、复制单一类别样本不改变类平衡中心、零残差拒绝。0工程反向。使用原centroid校验与既有监督器，两个CPU任务ISIC_centered/HK_centered，各900秒、总3600秒；不重置预算、不自动重跑。
