# 固定均值/中位数头的旧新块2×2开发诊断

依据已交付[中位数结果](../coordinate_median_head1_20261017/REPORT_ZH.md)：相对原始均值，旧类BA在四切片均下降，旧类CE均上升；整体只ISIC Qgate提高。仅凭聚合无法识别旧类损伤来自旧类中心变化还是新类竞争。

固定两个因子：旧类块选均值/中位数、新类块选均值/中位数。四组合mean_mean、median_mean、mean_median、median_median的前半名称指旧类块，后半指新类块。两个端点沿用封存头，另两混合头直接拼接列，所有组合在读查询前固定。唯一干预为块来源；表示、类序、seed74002、划分、BETA8及无偏置余弦评分不变。无训练、支持访问、类别筛选、超参数或最优模型选择。

报告每组合Qfit/Qgate全部seen逐类recall/CE、错误去旧/新，以及all/old/new宏BA和完整seen竞争CE。对每组每指标记A=mean_mean、B=median_mean、C=mean_median、D=median_median：旧块效应为B−A和D−C，新块为C−A和D−B，交互D−B−C+A，总变化D−A。BA差值按pp解释，CE按原值；恒等式逐项核对。不预设方向、不设置事后择优门槛，不将准确率交互当作参数层独立可加贡献。

三个非基线组合均与mean_mean配对，报告逐真实类获救、受损、都正确、都错误、预测切换及错到另一错；按真实类、源预测、目标预测聚合去向，并标注旧新组。核对净正确变化=获救−损害、切换=获救+损害+错到另一错。两端点逐类正确数、计数、CE、错向必须与已发布中位数轮聚合一致，否则停止；不为匹配结果改模型。
