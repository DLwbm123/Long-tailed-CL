## Frozen model
Existing ImageNet ViT-B/16, no backbone updates. RGB Resize224 bicubic/antialias, mean/std .5, original author20 train68058/devval300, original seed/order/tasks. Feature = raw final CLS768 concat mean196patch768, per-image L2 normalized. Shared support encoder 1536->128 SiLU->64, output L2; comparator concatenates query64, mean/diagonal variance128 of c and d (320 total), MLP320->128 SiLU->1. Pair a_cd=tanh(h(q,M_c,M_d)-h(q,M_d,M_c)), diag0; score_c=8/(K-1)*sum_d a_cd. No label-id/count/frequency/intercept per class; all arms same parameters and initialization. Nonlinear support encoder is learned, not an affine head reparameterization. Antisymmetry does not guarantee correct or transitive decisions.

## Actual access and patient isolation
Only actual Task1/base10=60129 images may contribute to meta-training. Deterministically partition their patients globally into support/query training pools, preserving at least one independent patient/class on both sides; infeasibility stops before image loading. Greedy rare-class-first query witness selection then deterministic 20% query fill, never from validation. This query pool is training supervision, NOT independent evaluation. Within each episode select up to4 distinct support patients/class and up to2 distinct query patients/class, one image/patient/class. Fixed cap=min(requested,available), recorded; no duplication as extra patients. Support/query patients globally disjoint across classes; full author train/val patients also disjoint. No future class rows/features in actual base training, no test/Etest, no original A Task1 or deleted static packs/caches restored.

Pseudo order is a deterministic permutation of the ten actually available base classes each episode, pseudo prefixes4/6/8/10. Three support allocations are fixed in config, using nested subsets of the same selected support patients; identical queries/order across paired allocations and identical episodes across arms. Actual future classes are never used as pseudo-classes.

## Objectives
Let L[v,t,c] be mean query CE for class c when pseudo-prefix t contains c. R[v,c] is the average over its containing prefixes (class-normalized visit count). META=mean_v,c R; WORST=max_c mean_v R; PAIRED=max_v,c R. Thus ordinary WORST cannot exploit the worst individual support assignment by changing its definition after results. The three arms see/compute every allocation and every prefix; same support/query examples, same 3000 AdamW steps, lr3e-4/wd1e-4/clip5; no schedules/best checkpoints/val tuning. Every episode, including allocation maxima, is deterministic under seed74002+episode. Class losses, selected worst conditions, exposure and clipping summarized. Generic worst-risk benefits are explicitly controlled; no assertion this objective is first-of-kind or TMI-ready.
