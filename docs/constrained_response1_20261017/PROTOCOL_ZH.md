# 在旧 H 更新空间内直接优化响应保护 CE

q403投影后 ISIC 新支持宏 CE 从full的0.364620退到0.433999（ridge0.430760），两片新类救回31例中丢失30例，同时修复旧类8/10例伤害。它不能区分空间表达限制与事后投影未重新拟合。本轮只检验后者：将空间约束放入优化过程，数据、原目标及正则不变。q403是已曝光开发依据，不能冒充独立验证。

## 唯一主要改动

令原ridge头为W0，旧H的固定数值秩正交basis为Q，直接优化W=W0+QA，从A=0开始。Q同q403由旧H归一化特征thinSVD确定，阈值max(H.shape)*float64eps*smax，不扫描秩或混合强度。空间外保持原ridge，但空间内响应可变化，因此不要求保持q401或q403的旧H响应。

目标沿用class-balanced CE(8zW)+.064/2 Rnorm(W−W0)，p_i=1/(K*n_yi)，Rnorm=1536/(2∑p||z||²) ∑_i p_i∑_j[z_i(Δw_yi−Δw_j)]²。仍包含全部H+newS和全部竞争列；scale由原1536维z算，不对zQ重新归一化或以rank替换1536。该归一化是沿用原目标，不声称受限空间与全空间等平均曲率。

使用已有Newton-CG，在受限Gram Gq=(zQ)ᵀdiag(p)(zQ)上以L Lᵀ=Gq+.001I作坐标变换。V=LᵀA，Ztilde=zQ L⁻ᵀ，CE固定offset=8zW0；响应项只作用于Ztilde V。此.001是坐标预条件，不新增目标项。共享objective/newton_steps只增加缺省0的offset参数，旧调用不变；复用解析HVP与预算计数，不复制求解器。

## 判定与预算

原ridge唯一主对照，冻结q403投影头为次对照。两组各仅一次正式拟合，最多200外步、每步50CG、20次Armijo回退；目标+梯度、HVP、线搜索目标、曲率概率缓存合计每组≤300，另外终点两次梯度（受限坐标与原全空间）用于恒等式和收敛检查。每组900秒、全轮3600秒、2线程CPU、0GPU。一次二维工程fit/组，所有工程运算与成本另列；无续跑、调参、自动重试或预算扩展。

约束收敛要求原W坐标的切空间梯度max|QQᵀ∇W F|≤1e−6。优化器内部仍以变换坐标梯度≤1e−8停止；不得拿它替换最终标准。另报完整∇W F，不称全空间已收敛。该约束主门需要约束收敛且两片BA_all严格提高、BA_old/new各下降≤1pp；它是开发判据，不是完整医学方法或独立验证成功。q401的全空间收敛失败不被追改。

## 输入与检查

旧H原herding直接读取，新S仍ISIC2290/HK95，合计2354/264；1536维double，无新增encoder/adapter/teacher/memory更新和标签。先校验centroid/ridge和q403 DELIVERY绑定，q403私有头与结果必须在候选保存seal后才读。query亦seal后，禁止原旧S、teacher、E、raw图像。守卫主动自测，模型/维度/finite/全零adapter和逐类count检查保持。

二维非零offset例子验证原/受限目标、解析HVP与自动微分二阶导、缺省offset=0原目标，以及80步二分固定标量最优解和空间外保持。正式拟合验证Cholesky、feature映回、原/受限目标、QQᵀ原梯度与QL变换梯度的恒等式误差≤1e−10，更新空间外残差≤1e−10。不要求full和受限梯度相同。ridge和冻结投影头全部逐类query计数精确、CE1e−10匹配q403，支持逐类亦复核。

输出三头全部支持/逐类CE、BA、margin/rank、所有竞争者，ridge→candidate与projection→candidate真实配对、全类转换及零事件；完整fit计数、trace、约束与全梯度、来源与成本。正式2SVD/2Cholesky/4三角solve；工程2Cholesky/4solve和2个显式HVP检查。支持特征2618、三头logit7854；共享query2155、三头logit6465，优化内算术另外计数，不能声称等FLOPs。2新头32,256个double（258,048bytes），无新增Q推理模块，Q仅工作内存。

## 后续边界

先完成结果公开交付，再据证据决定下一步。即使在空间内重新拟合，也可能破坏旧query或仍学不好新类；若失败，不自动扫描空间混合系数或延长预算。若约束目标改善但query无稳定收益，应承认当前固定信息和读出假设的瓶颈，不能凭小样本宏变化宣称方法成功。当前会话不接管独立新方法研究会话。
