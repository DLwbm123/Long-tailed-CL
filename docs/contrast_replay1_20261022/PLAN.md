# 实际阶段判别式特征重放：冻结三臂迁移实验

本协议在读取本轮验证影像、正式训练或资格编码前冻结。主比较为 SUPERVISED 对 ER、INSTANCE；不选择其中最高分作为主方法。

## 问题、依据与贡献边界

此前独立类密度、基类伪增量比较器及保守覆盖上界未建立可用的医学增量判别能力。本轮转向真实阶段监督：保留明确有限的历史输入特征，让共享非线性表示继续学习。有限特征记忆是新的实验权限/预算，与 A/B 的统计记忆协议不同；不能将性能差值归因为新损失。

[SCR 原论文](https://arxiv.org/html/2103.13885v3)把监督对比学习用于重放，并使用 NCM 分类；[SupCon 原论文](https://arxiv.org/html/2004.11362v5)给出平均正样本对数概率目标。本轮复用该已知损失，而非声称发明它。实际适配使用冻结影像特征、输入特征 dropout、共享残差网络及共同 CE 余弦头；不称忠实 SCR 复现、端到端影像增强或新 TMI 核心贡献。科学问题仅为：相同实际阶段与记忆预算下，类别关系监督是否优于普通 CE 与实例关系监督。

此前 ICLR27 目录匹配的 TSR 作者 arXiv 稿已定点阅读，但其共享词表梯度路由不能直接移植为医学 disjoint-label CIL 结论；本轮不采用该路由或其 teacher。未获得 OpenReview 原 PDF，不声称投稿版本完全一致。

## 数据访问与有限状态

现有 NIH author20 train 68058，开发 val 300，每类15；原固定顺序与六阶段 10+2+2+2+2+2 见 config。训练/验证患者交集必须为0。可读取全局标签/患者元数据作隔离审计，只有类别实际到达才读取其训练影像；不读 test/Etest，不下载新数据。

每图仅编码一次为现有 ImageNet ViT 的 CLS768 拼接 FP32 patchmean768，然后 L2。encoder FP16、冻结，TF32 off、确定性。资格另20张训练编码，正式68058、val300一次，均计费。当前阶段全部输入特征只保留在 RAM，阶段末释放；不保存完整历史特征、不恢复旧 pack/cache、不借其他实验的逐图特征。

每类最多32个患者、每患者一幅影像的输入特征作为显式重放记忆。患者及其影像分别按固定 seed 的元数据排序选择，与模型和验证成绩无关。三臂共享相同记忆。旧患者只通过这些保留特征参加未来训练；其标签/身份/输入特征、全部阶段模型、分数留私有并计费。不同类可含同一训练患者，不将它们称独立患者证据。输入重复采样计为曝光，不算新图/新患者。

## 模型与目标

三臂完全相同：

\[
h(x)=\operatorname{norm}(\operatorname{norm}(x)+U\,\operatorname{SiLU}(V\operatorname{norm}(x))),\quad
s_c(x)=25h(x)^T\operatorname{norm}(w_c).
\]

V 为1536→128含bias，U 为128→1536含bias。U 零初始化，保存原输入通路；各类 head 行在实际到达时初始化为该类患者等权输入特征均值方向。旧 head 和残差网络跨阶段继续训练，不重置；优化器各阶段统一重置。仅分配 seen head 行，未到达类没有参数/初始化/梯度。参数每臂为394880+1536K：初始410240、最终425600。

每步从 seen 类无放回选8类，每类患者等概率、患者内影像等概率抽8次（有放回，共64逻辑行）。旧类仅从有限记忆取样，新类从当前全部训练数据取样。对相同64行生成两份独立输入 dropout p=.1，三臂用完全相同的128行、mask和标签。该特征扰动不是新的影像编码，也没有医学增强有效性保证。

设 z 为 h 的输出，A(i) 为除自身外所有 batch 行，

\[
L(P)=-\frac1N\sum_i\frac1{|P(i)|}\sum_{p\in P(i)}\log\frac{\exp(z_i^Tz_p/.1)}{\sum_{a\in A(i)}\exp(z_i^Tz_a/.1)}.
\]

ER：仅 CE。INSTANCE：CE+L，P 为同一原始影像的其他 view/重复抽样行。SUPERVISED：CE+L，P 为同类其他行。均排除自身，辅助权重固定1。重复采样的原影像在 INSTANCE 中仍是正样本，避免把完全相同输入误作负样本。所有监督对比正样本都来自训练标签，不构造未证实的疾病局部真值。

每臂基类2000步，后续每阶段500步，总4500步，三臂13500正式更新。AdamW lr3e-4/wd1e-4、clip5、FP32，无scheduler/早停/验证选参。每臂288000逻辑影像行、576000 view映射；两对比臂各73728000相似矩阵元素，ER 无对比矩阵。相同参数/曝光/更新不等于相同 FLOPs，实际时间/资源分列。固定步数不保证收敛。

所有18阶段模型封存后才开放 val，一次编码；仅真实 seen 前缀评分。推理不 dropout，FP64。每臂验证模型行数1350，总4050；无额外 NCM/温度/路由/融合选择。

## 停止门与独立验收

主方法固定全部门：final≥91/300、mean≥36.005291005291%、tail7≥25/105、later10≥41/150、initial10≥44/150；分别对 ER、INSTANCE 要 final≥+4、mean≥+1pp、tail4≥+2/60、later10 不降。tail4=[7,14,15,16]，tail7=train n<250；不混两者。任何门失败关闭固定配方，不扫容量/记忆数/温度/dropout/lr/步数/seed/损失权重/门槛救分。

数学资格独立 NumPy 目标与有限差分梯度、batch置换；20真实训练编码及每臂1丢弃工程步，score差≤2e-6、梯度有限非零。资格不是正式吞吐/性能。正式阶段不可触及 future/val；非有限 loss/梯度或隔离/资源违约立即失败。所有准备/失败/工程/正式/验收成本保留。

run0后独立 CPU NumPy 进程重新实现残差、归一化、余弦头，重构18组分数，绝对误差≤2e-6且预测全同；从元数据独立重建各阶段记忆选择、旧记忆不变、阶段/患者/覆盖/计数/资源。0重编码/新优化。不以训练loss或数值PASS替代方法门。
