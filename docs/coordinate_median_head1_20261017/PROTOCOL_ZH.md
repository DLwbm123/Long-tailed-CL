# 固定逐坐标中位数头：启动前协议

依据[实际删一查询诊断](../centroid_delete_query1_20261017/REPORT_ZH.md)，ISIC约31%、HK约17%的查询存在至少一种单点删除会改变预测，HK关注类别既有修正也有新增错误。这不是单模型错误率，也未证明异常样本；提示可以检验一个不同中心估计。

唯一主要改变：在相同原始冻结单位特征上，将每类加权算术均值（既有类内权重均匀）替换为逐坐标中位数，随后L2归一化。torch.quantile(.5)使偶数样本取中间两值平均；所有类别统一使用，不按查询择类混合。原H64/169、新S2290/95、seed74002、类顺序、划分、BETA8及余弦评分不变。无温度/偏置/强度拟合或样本筛选，没有新超参数搜索。

该中心依赖坐标系，不具旋转不变性；中位数对个别坐标数值的性质不能直接推出高维方向稳定或准确率改善。本轮首先检验查询BA/CE，不用这些准确率结果冒充删一稳健性证据。不是新颖性论证。

主要仍为候选vs历史MM：每数据集两查询总体BA严格提高，旧新各下降不超过1pp。原始均值余弦头raw_centroid是必要单因素次要参考，报告同样门槛；另完整报告HH/identity_ETF/teacher_centroid/teacher_ETF以及MM共六参考的组/逐类BA、完整seen竞争CE与所有正负差值。不以通过较弱MM代替相对原始均值的改进。MM/HH表示不同，不作头单因素归因。

每类一次支持特征变换，计算中位数并封存头后才读取Qfit/Qgate和历史聚合。既有原始/教师参考与MM/HH从聚合复用，不重推理；每查询只评价新头。2个数据拟合头，共21向量，1536×6/15、32256个float64元素、258048字节（252KiB），无偏置。辅助记录原均值范数mean_norm和中位中心范数location_norm，避免混淆。0梯度（含工程）、0适配器/教师/编码器/记忆更新，不能称零拟合。

数据边界沿用头实验：构造只读原teacher文件（用于零残差形状/ETF形状）、新S和同一H；禁止旧S、E、原图、新标签/GPU。查询与历史参考只能在新头封存后读。中位中心范数<=1e−12时停止，不回退均值或换算法。自检偶数正交样本中央插值、奇数中位数、单样本归一化、零中位数拒绝；原权重均值/恒等映射自检与finite/权重均匀/shape/访问守卫保留，0工程反向。

两个CPU任务ISIC_median/HK_median，各900秒、总3600秒；预计2618支持+2155查询=4773样本前向。只评价此一个中心估计，不扫描种子、坐标变换或其他分位数。不自动重跑或重置预算，历史H/模型成本只计一次、客户端准备null。
