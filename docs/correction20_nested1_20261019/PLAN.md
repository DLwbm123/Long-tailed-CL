# 最终20类：训练内部嵌套判别修正最小对照

状态：协议冻结，准备启动。仅使用已有训练特征缓存。不得扩展至六阶段，不新增编码、不使用原验证集或E/test、不搜索超参。研究目标是判断直接分类纠正损失是否比普通判别修正更有用；本轮不是临床独立测试或最终泛化结论。

## 五臂与公平比较

1. CLS768 ridge：复用既有最终阶段三折外层头。
2. scale_joint：复用相同三折尺度归一化CLS＋patch-mean联合头。
3. df_matched_joint：仅在各外层训练部分重新拟合自由度匹配联合头。
4. plain_correction：以对应scale_joint为固定锚点，加入1537×20线性残差，优化普通交叉熵＋L2。
5. utility_correction：与plain共用锚点、输入、参数规模、初始值、正则、优化器与预算，只增加修复加权与保留项。

两种修正均可合并为单一线性头，无门控或附加模块。768维CLS和768维patch-mean加偏置，与既有强联合头一致；不改骨干、类别顺序或原始样本。不得以本轮结果选择新超参或新版本。

## 训练内部隔离

沿用原三折患者稳定散列。每次留一折作外层核验；其余两折内部互换训练／预测，生成每张训练图片的内层CLS、joint分数。不能用旧三折OOF直接训练修正再称外层独立。

仅拟合三组单折教师（每组CLS、joint，共6头），在两个允许使用它的外层轮次复用。某外层核验折的样本不进入该轮教师、修复/保留标记、归一化、锚点拟合、残差拟合或自由度匹配。外层CLS/joint旧头须用对应训练子集重算正规方程残差和尺度验收，才允许复用。另拟合3个外层df头。所有外层修正头封存后，才统一生成、比较外层核验预测。

输入白名单：旧训练缓存train768、训练索引labels/groups/folds/weights/bounds、三个fold_head_5头、旧运行COMPLETE回执及旧配置中的seed/order身份字段。不加载图片、原验证预测、病例外数据、E/test，也不使用历史验证成绩选参数。所有外层折均包含20类。本轮患者分组只用于防止训练内泄漏，不引入新病例实验。

## 固定目标

设z为按对应外层训练数据固定尺度的联合向量；J为该外层训练得到的联合锚点；R为待拟合线性残差。内层预测生成：

- repair_i：CLS正确、joint错误。
- keep_i：joint正确，包括双方正确及joint独有纠正。
- T：内层joint分数去除逐图类别均值后，按类别/患者权重计算的RMS尺度。
- m_i：keep样本的内层joint真类对最大错类margin，除以T；用keep组加权中位数封顶。其余样本置零。

所有权重只在该外层训练子集中计算：每类总质量相等，类内每患者总质量相等，患者同类图片均分。再使总权重为1。温度和margin目标只由内层训练预测决定，不作搜索。

分数s_i=z_i(J/T+R)。普通方案：

`L_plain = sum_i w_i CE(s_i,y_i) + 0.05 ||R||²`

修复＋保留方案：

`L_utility = sum_i w_i (1+repair_i) CE(s_i,y_i)`

`+ sum_i w_i keep_i mean_{j!=y_i} softplus(m_i-(s_iy-s_ij)) + 0.05 ||R||²`

修复、保留系数均固定为1。keep为软损失，不承诺逐样本零损害。该损失不是0–1收益的无偏估计，也不是负翻转保护的新颖性证明；本轮只检验其增量实用性。均为光滑凸目标；优化成功不冒充精确全局最优证书。

使用训练侧Gram对角线进行优化坐标预条件，`R=diag(p)U`，正则始终作用于R，因此不改变原目标或线性族。零残差初始化。L-BFGS-B maxiter500/maxfun15000/maxls30/maxcor20/ftol1e-10/gtol1e-6。必须success、参数/梯度有限、目标不高于初始值；失败即保留现场，不自动重试、换容差或续跑。

## 封存与判读

只有完成3个外层模型封存后才计算外层指标；这不是只留一个全局完全未见的测试集，而是标准嵌套交叉核验。各折独立拟合，汇总每图唯一的外层预测；不将三个最终阶段结果解读为六阶段持续学习结果。

报告五臂BA、同类别/患者权重正确率、每类/头中尾指标，以及相对CLS、两个强联合头和普通修正的救回/损害。按CLS与joint正确性交叉分组，报告joint独有纠正保留、CLS独有正确损害、共同错误纠正。逐折结果一并保留，不只报告合并涨点。若utility未超过普通修正与两个强联合头，或尾类、CLS损害变差，直接记负结果，不调整机制追分。超越三者并减少损害才支持继续讨论，但本轮不自动扩展。

独立验收读取缓存、内层头、冻结残差和私有预测，不做拟合：重算内层预测/信号、正规方程残差、最终目标/梯度、所有外层预测和分组指标、封存顺序和累计成本。数值并列均argmax小索引。保存原始分数以暴露数值边界。
