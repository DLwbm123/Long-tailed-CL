# 最终20类五臂实验总结

**结论：判别修正提高总体BA，但修复＋保留项尚未实现尾类和CLS正确预测的等权保护。** 本轮已完成并通过独立核验，所有失败与成本均保留。

## 实验设置

固定最终20类、原种子与类别顺序；复用768维CLS及768维patch-mean缓存。三折训练内部嵌套核验，外层隔离，模型全部封存后统一评价。新增编码0，不访问原验证集或E/test，不扩展六阶段。以下结果来自68058张训练图片的外层预测，不能与此前300张原验证集的结果直接比较。

## 主要结果

单位为%。PP正确率为类别等权、类内患者等权的图片正确率。

| 方法 | BA | PP正确率 | 头类BA | 中类BA | 尾类BA |
|---|---:|---:|---:|---:|---:|
| CLS768 ridge | 16.2860 | 15.7318 | 12.5159 | 24.1717 | 13.2970 |
| 尺度联合头 | 17.7507 | 17.1753 | 14.3642 | 25.5971 | 14.4118 |
| df匹配联合头 | 17.8081 | 17.2396 | 13.9243 | 25.7525 | 14.8826 |
| 普通判别修正 | 18.8287 | 18.0557 | 21.7147 | 27.2081 | 8.7603 |
| 修复＋保留修正 | **18.9944** | **18.2438** | **21.9025** | **27.8433** | **8.5014** |

- 修复＋保留相对两个强联合头的BA提高1.2436／1.1862个百分点；相对普通修正只提高0.1657个百分点，三折中两折提高、一折下降。
- 尾类明显回退：相对两个强联合头下降5.9103／6.3811个百分点，相对普通修正也下降0.2589个百分点。主要总体收益伴随头类、中类改善。
- CLS正确图片损害数从尺度联合头的1211张降到706张，但类别等权损害由2.1777升至3.6706个百分点，PP等权损害由2.1001升至3.6700个百分点。不能只看图片数就判断保护成功。
- 尺度联合独有的2119张正确样本，修复＋保留保留1914张（90.3256%）；类别等权保留率仅62.7496%，PP等权保留率61.8456%，尾类增益没有充分保留。

普通判别修正已贡献大部分总体涨点，额外修复＋保留项的增量较小且没有解决尾类失衡。平均交叉熵和margin保护仍可能在类别／纠正群体之间交换收益，但本轮没有证明具体因果机制。尚缺CLS-only同损失残差对照，不能将相对ridge的全部收益归于patch；当前结果也不足以证明完整保护机制成功或六阶段有效。

## 验收、失败与资源

独立重算340290条预测，指标误差0，最大分数误差2.31×10⁻¹⁴。首次500次迭代上限失败永久保留；随后等价坐标修复不改目标和容差，六头均通过验收。验收器的尺度逐位相等误判及其修复也已记录。

本轮科学尝试2次、科学失败1次；唯一ridge头9个、实际求解10次（含1次未落盘产物重建）；残差优化调用7次（含旧失败），成功6头。续跑峰值RSS约3.66GiB、GPU保留显存约1.61GiB；旧失败峰值未知。远程新增文件约115.23MB，计入100MB本地预留后约215.23MB上界，低于20GB。累计成本及未计量开销均在成本说明中列明。

本轮已结束，监测已暂停；没有依据外层成绩修改目标追分，没有新增科学实验或扩展六阶段。
