# 固定子空间对照：方向选择带来折中，尚未实现全面提升

本轮按固定协议完成两个子空间各三折、六个新头。主要结果是：**原头分数子空间部分恢复小类，但损失总体BA；同维PCA几乎没有恢复尾类。** 当前支持方向选择值得研究，不支持“仅减少参数数量即可解决尾类泛化”，两个候选均未达到原定全面提升目标。

## 固定设置与主要结果

复用既有训练缓存与原三折患者外层划分，新编码0、新ridge拟合0。固定联合锚点、温度、类别/患者权重、CE及0.05原残差L2；不加repair/keep。两个基均只用对应外层训练部分构造，均保留独立偏置，六头全部封存后才生成新候选外层预测。没有原验证集/Etest、秩网格、新种子或六阶段扩展。

各折原头基均为39维，PCA也为39维；每头名义参数780个，相比完整残差30740个。Q正交保证||QA||²=||A||²。PCA中心化仅用于选方向，前向仍用原坐标。相同维数与参数数量不代表相同有效统计自由度。

## 原头子空间：部分尾类恢复，但不是全面成功

相对完整普通修正，原头子空间BA下降0.4499个百分点，尾类提高2.7980个百分点。三折均呈总体下降、尾类改善的同向折中。

它的BA仍比尺度联合头高0.6281个百分点、比df联合头高0.5707个百分点，但尾类分别低2.8535和3.3242个百分点；总体也低于原保护18.9944%。因此不能宣布超过现有方法或达到进入六阶段的全面性能门。

原头子空间恢复了类14、16的非零召回，但没有回到强联合头水平；部分其他类别仍有代价。类15在两种新候选中仍为零，它在强联合头中本来就是零，不能算作新增零召回。

## PCA：减少名义维数本身不够

PCA39维的合并BA18.8280%，与完整普通修正18.8287%几乎相同，尾类8.7400%也没有改善。但各折并非预测或表现等价：PCA第0折BA低约0.4561个百分点，第1、2折分别高约0.2672、0.3230个百分点，合并净值存在抵消。

原头子空间与PCA同维、同正则范数却给出不同尾类取舍，说明不能把结果简化为“把参数从三万降到几百就会好”。更准确的证据是：这个原头方向选择相对这个PCA对照更偏向保留部分小类能力。仍不能排除特征协方差、有效自由度和方向性正则作用，也未证明高维参数数量就是病因。

## 全部样本的训练—外层差距

这次统计覆盖每类全部训练样本，不局限于repair/keep子集。类7、14、16、15的联合锚点和完整普通修正，在三个外层训练部分均为100%正确。类14、16完整普通外层正确数却为0；类15连原锚点外层也为0。

因此，明显训练—外层差距在锚点阶段就已存在；普通修正没有进一步提高这些类的训练正确率，却损害了其中部分外层正确性。这支持检查训练支持以外的竞争边界变化，不能仅凭训练100%就宣布新修正独有的高维过拟合已被证明。

中类3表现不同：锚点训练正确率约87.5%–89.9%，完整普通修正约80.9%–82.4%，外层也从258/435降至209/435。这里训练正确性本身也被交换，不能把所有类别都归为同一种泛化失败。类12也有部分训练正确性损失。逐折全量正确率和margin分位数见training_outer_gap.csv。

完整的最大竞争margin变化还包含锚点竞争类切换项，已在逐样本恒等式中检查并在聚合审计中另报；各部分不各自重新选竞争类。事后使用外层标签分组仅用于解释，未参与基选择或训练保护对象生成。该分解不是因果干预证明。

## 当前研究决定

两候选均未同时超过完整普通修正与强联合头并恢复尾类，未达到原定全面提升目标；原头方案提供了有价值的风险—收益折中，而非成功主方法。PCA结果也不支持只靠减少名义自由度解决问题。

按冻结停止分支，本轮不继续加第三个子空间、秩网格、margin项、置信度门或按类系数，不扩展六阶段。保留原头方向的部分保护证据，以及空间外方向同时带来收益与损害这一机制线索；如果以后另开研究，应重新明确如何获得可迁移的小类决策证据，不能因两个候选未成功就宣称表示无信息或整个线性函数族不可行。
