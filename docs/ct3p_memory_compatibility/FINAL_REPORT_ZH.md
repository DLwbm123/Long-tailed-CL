## 归因结论与限制

**已观察事实：** ISIC主比较C3−C1为+5.584pp，三个配对都改善BA，但old平均提高13.819pp、current下降10.883pp。C3相对P提高2.993pp；C2为63.794，C3为63.523，公共平移没有带来额外平均提升。HK主比较+1.686pp的条件性区间跨零，old提高8.745pp而current下降12.432pp，HM还下降约2.193pp。两数据上单独T−A的平均BA均为负。不存在“全面修复”的依据。

**强参照与逐类：** HK的P/C2/C3在Task3对三个seed的609/399/516张val图像预测完全相同；审计确认分数、W哈希不同，C2/C3来自F轨迹，并未复用P的分数。不能把“与P预测相同”写成模型相同或FD没有更新。ISIC的C3最差seed为56.909，相对C1最差seed51.314有改善。终端tail平均HK为P/C3 61.310、C0 58.036、C1 53.274；ISIC为P71.207、C0 71.154、C1 67.735、C2/C3 75.321。唯一终端零召回为HK seed1995 original_label5：各方法均0/1且仅一个component，不能据此推断该类别总体效果。逐类分母、component数、错误分解和遗忘见结果CSV。

**机制支持：** 每数据集60个epoch级首batch探针中，main/few FD各54次非零；每个任务第1epoch的教师与学生起点相同，6次零值是预期。所有任务adapter均有变化，教师保持固定。seed1993旧均值误差均值，HK A:0.08573→0.00739、T:0.09584→0.00768；ISIC A:0.08000→0.01244、T:0.08212→0.01300。支持FD减小这两个预定末态的记忆空间失配。但HK在线–Q11差距收敛到0，ISIC T的差距反而从0.167增到0.407pp；“所有差距均缩小”不成立。Q11在HK从85.842降到85.435，在ISIC从66.682升到69.007。仅seed1993诊断不能代表其他顺序。

**梯度与塑性：** 部分记录的weighted FD/real梯度比极大，是real梯度接近零时比值不稳定，不等于数值发散，也不能据此本轮调整beta。与当前类召回下降、HK强参照无增益一并看，FD的保持作用可能限制塑性；仍需独立控制区别“有益的持续适配”与“接近冻结编码器的效果”。

**未验证问题：** 尚未证明完整8/23类长期有效、尚未证明FD优于仅冻结正常Task1末编码器、尚未获得独立holdout确认。三seed同时改变顺序和训练随机性；条件性bootstrap固定三个模型并保留共享样本相关性，不代表训练总体置信区间。val已多轮用于开发；Q11使用27584次旧fit读取，仅是隔离离线诊断，绝非合法在线成绩。
