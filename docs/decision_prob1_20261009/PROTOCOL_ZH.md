# DECISION-PROB1：冻结的分类效用选择验证

用户已授权尽快执行上一轮方案。本轮只验证固定普通训练之后的终端头选择，不增加编码器、适配器或策略训练。

## 状态与范围

固定5个状态：ISIC/HK上一轮任务2的零动作分支（缓存特征，原一个epoch）；另选ISIC最后任务3、HK中间任务4和最后任务6，使用既有static_pc完整两epoch轨迹checkpoint。位置按任务序列固定，不按效果选取。两种来源分别报告，不把缓存短分支当作完整任务训练。所有这些开发数据已被研究者查看，本轮不是独立确认。

新增状态只抽取当前任务训练影像在任务前/后的特征，以及选择完成后的已见类开发特征；不读取旧训练影像、不读取医学test或CIFAR。原身份fit/meta划分不变，meta与fit及历史训练身份隔离。旧bank仍包含历史meta。

每个状态保留原17个边竞争候选（零动作与8维正负单位扰动）。另加17个列范数对照：对同一零动作头各列除以其L2范数的tau次方，tau=i/16、i=0..16，范数数值下限1e−12。两个家族共享零头，合计33个唯一头；两个refit版本共330个头×状态读出。对照不使用开发标签调参。

## 构建、概率近似与选择

正常训练后的编码器固定。主比较使用fit-only统计和分类头，当前meta不进入旧类运输或新类统计。每个候选的实际预测使用float32头；概率积分用该头转换为float64。

每类协方差为保存的Q−mu mu^T。假设候选头的联合分数服从对应高斯分布，保留类别分数间相关性；不把两两胜出概率相乘。仅截断浮点舍入导致的负特征值，最小特征值低于−1e−8则失败；不添加收缩参数、不调分布。高斯近似可能不适用于多峰、稀少、漂移或单位球面特征，不把它解释成真实旧类分布。

固定积分种子74002及各状态公开偏移。每类8批×4096=32768个标准正态向量，只生成联合分数用于积分，不生成旧影像或执行特征回放训练。各候选共享同一随机积分输入，成对比较。积分批次标准误仅衡量所假设分布下的数值误差，不代表患者采样误差、统计估计误差或分布漂移置信度。图像数不能当作独立身份数；当前类同时报告两种支持量。

混合分类效用为：旧类高斯正确率与新类留出meta准确率的类别等权平均。选择要求旧类、新类、尾类组的平均估计变化均≥−1e−12；总体估计改善必须超过max(1e−8,两倍成对积分标准误)。在合格候选中按总体效用最大选择，平局索引小者优先；没有合格候选则保持零动作。这是代理保护，不宣称逐类或逐样本真实无损。

比较四条选择结果：零动作、原平方奖励在同一17个终端fit-only头上的选择、分类效用在边竞争家族上的选择、相同分类效用在列范数家族上的选择。原奖励保留原归一化、负收益惩罚、KL和1e−8执行门。原奖励基线也在当前正常训练后的状态上计算，不能混用上一轮训练前奖励。

## 训练侧模型检查与开发屏障

另将当前新类当作只有fit统计可用的类，比较其高斯预测正确率与真实留出meta召回，包括候选改善方向、误差和支持量。该项检验不证明旧类运输可靠；不按结果重新拟合、调积分量或改规则，也不将同一meta同时选择与诊断的结果当作独立泛化。

五个状态的选择结果先写入并锁定。三个worker全部SELECT_COMPLETE后，才读取开发特征/指标。任何worker失败均关闭其他worker的开发读出，不自动补跑或扩大科学范围。

all-refit仅作固定迁移对照：将fit阶段选定的竞争系数或tau应用于all-refit，不能重新选择；其meta已参与拟合，不再作为留出评价。全部候选开发结果仅用于事后诊断上界、保护口径与选择差距，不用于本轮选择。校正头不反馈到后续训练、蒸馏、统计更新或控制器。

## 检查、报告与停止

重现每个状态的原零动作all-refit保存头，allclose atol=1e−6/rtol=1e−5；求解残差≤1e−8。保留任何失败、原输入、已消耗成本与异常，不覆盖旧实验。报告实际选择相对零动作的总体/旧新/尾类BA、逐类变化、helped/hurt、原奖励对照、归一化对照，以及有限候选事后上界。相关系数只作描述。

若统计模型与当前留出决策变化也不对应，关闭时优先建议改信息或模型假设；若候选根本没有尾类收益，不能宣称解决长尾问题；若简单范数校正相当，则不保留不必要复杂性。不论结果如何，本轮不自动恢复RL或启动新训练。
