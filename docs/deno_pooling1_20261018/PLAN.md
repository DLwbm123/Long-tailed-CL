# 固定 DENO 聚合迁移：一次 NIH 开发对照

用户在本聊天明确要求按文献分析建议立即执行。本轮只增加同特征聚合对照；不改动并行病例层实验，不串联新模块，不恢复旧监测。

本轮新增编码只用于标定：每个基类最多8名患者，按现有患者ID排序后用固定种子无放回抽样，每名患者选路径排序第一张图像。最多80张，等类、等患者聚合。支持标定是训练集内标定，不是独立验证。全部标定参数封存后才读取任何验证特征或历史验证分数。

## 固定机制

类patch分数 l_pc 为历史等患者无收缩高斯的完整 logpdf（包含 logdet），参考 l_p0 为原固定基类参考高斯的 logpdf，沿用原协方差地板。定义 e_raw=(l_pc-l_p0)/s，e=clip(e_raw,-8,8)。

共享尺度 s 为上述基类标定图像上所有patch、所有基类的 e未缩放 比值的等类 RMS；不按类别分别归一化、不减验证集均值。相似性使用归一化patch特征；带宽平方为每张标定图像非对角patch平方距离中位数的一半，再对图像按类平均、对类平均。若该值<=1e-12直接失败，不改带宽重试。

K_ij=exp(-||m_i-m_j||²/(2l²))，L=D^(-1/2)KD^(-1/2)。A=2[logdet(I+D+LD+)-logdet(I+D-LD-)]，D±=diag(exp(±e/4))。完整混合分数 z=.5 A + .5 mean(e)，即固定 beta=.5、tau=1。其值采用论文初始化，但本轮不优化它们；带宽与尺度只由训练支持确定。主张仅为此单一固定迁移方案的开发表现，不能以其失败判定 DENO 方法族无效。

公共参考在非线性聚合中不会自动抵消，本轮独立记录这种假设；该分数是类相对证据的判别聚合，不称为完整联合后验密度。没有跨当前所有类别softmax的前置归一化；新增类别不改变旧类的固定参考、核参数和类密度。

## 八个固定对照

1. uniform_raw：原高斯patch均值。
2. patchbell_entropy：相同密度，按PatchBELL附录A4计算权重，最终聚合原始密度。
3. reference_mean_raw：参考比值均值，预测应与uniform_raw完全一致。
4. reference_mean_clipped：与DENO相同的尺度、参考和截断，均值聚合。
5. deno_determinant：只有A，去掉均值支路。
6. deno_mixture：固定完整混合，主方法。
7. identity_mixture：L=I时的解析分数；其预测应与截断均值一致。
8. ridge_historical：既有历史分数，不重新拟合。

主要机制比较为 deno_mixture 对 reference_mean_clipped；同时必须报告相对熵聚合、原高斯均值及ridge的全部正负差异。六阶段宏召回/准确率、最终与平均阶段BA、逐类正确数、混淆、救回/损害及旧类分数漂移全部报告。不选择最好一臂代替主方法。

## 验证和资源

先用非医学小矩阵对独立slogdet oracle、L=I加性还原、符号反转、排列不变及均匀全袋复制不变做断言。选择性复制不要求不变。正式阶段在每个首次出现类的开发首图上将所有patch重复一遍，按相同标定重算，记录DENO分数误差；这只是20张图的数值性质核验，不是新的临床性能实验。所有截断比例公开记录。

新资源上限：独立GPU1、1小时墙钟硬限（含失败与清理）、GPU保留内存4GiB、新增训练图像编码<=80、零优化更新、输出<=256MiB。推理batch=4，float64行列式，workers=0。一次固定运行；失败保留成本后停止，不自动科学重试。主子进程使用中性入口。先检查目标存储挂载、可用容量、读写探针和GPU空余；不触碰已有进程。原病例层实验的费用与本轮新增费用分开记录。
