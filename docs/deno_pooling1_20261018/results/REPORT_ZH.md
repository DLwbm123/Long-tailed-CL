# 固定 DENO 聚合迁移：NIH 开发结果

结论：本次固定迁移未获得相关性聚合收益。最终 BA 相对同证据均值下降 **3.00 个百分点**（55/300 → 46/300），平均阶段 BA 下降 **0.833 个百分点**。虽然高于熵聚合，但低于均值及 ridge，不能据此宣称改进成功。

相对均值的 96 次预测变化中，救回3张、损害12张。无截断参考均值与原均值、截断参考均值与单位核混合，在全部六阶段的预测分别一致；本轮也未观察到截断改变预测。因此当前直接证据支持“这种固定几何/参考/权重下的 DENO 替换不成立”，不能归因于已观测的截断预测改变。

独立核对已重算六阶段共10,800个方法–图像预测，逐项确认每类正确数、混淆矩阵、BA及救回/损害；合成矩阵 oracle 和20个全袋均匀复制核验通过。上述验证确认实现与报告一致，不证明模型假设符合真实病灶证据。

DENO 原文学习 evidence、相似性表征及聚合参数；本轮固定通用 patch 几何和高斯相对证据。性能差不能否定原方法或所有可训练迁移版本，也不足以定位失败究竟来自几何、类证据定义还是固定权重。没有为此自动追加训练或调参。
