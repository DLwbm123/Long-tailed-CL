## 2. 最大残差目标产生了可直接观测的分支失衡

S对两项相同，因此max(||e_old||²,||e_delta||²)/S的分支取决于未分别归一的平方残差。非最大分支在严格不等时不直接贡献目标对记忆变量的梯度。旧分支更新仍可能间接改变新增竞争误差，不能说后者完全不受参数变化影响。

|规模|类×步骤总数|旧分支主导|新增竞争分支主导|相等|
|---|---:|---:|---:|---:|
|small|96|56|40|0|
|ISIC|192|191|1|0|
|HK|624|624|0|0|

HK全部13类的48步都由旧分支主导；ISIC只有一次新增竞争分支主导。这不是根据最终误差猜测，而是构造时逐步记录的实际比较结果。上轮审计发现HK的新增竞争梯度量级较小，本方案为避免单独放大它而使用共同尺度，再配合max，结果使它在本次预算内没有直接优化压力。

第0步到第47步更新前，ISIC旧误差平方均值2.679192→1.672036，但新增竞争误差平方0.267295→0.698117；HK分别5.134375→3.509027、0.015163→0.036521。总目标下降与新增竞争误差上升同时发生。因此，“把两个残差写入max”没有在本次运行中实现双目标共同改善。

small则相反：新增竞争误差平方8.275474→2.843310，旧误差平方3.092831→3.305904。它说明分支确实切换，但也不保证每项单调改善。这些是0/47更新前记录；最终结果单独用第48次更新后的诊断梯度计算。

这暴露了所提目标在有限步数下的局限；不能用“已经包含扩展查询”来掩盖。也不能由分支记录定量推断每种误差对后续分类损害的因果贡献，因为本轮没有后续训练。
