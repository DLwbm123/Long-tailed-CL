固定教师T，O为第一任务slots，N为下一任务预定slots。gO=完整当前类合成支持在O上的CE参数梯度；g+=相同支持在O∪N上的梯度；gΔ=g+−gO。记忆对应误差eO和eΔ。S=max(||gO||²+||gΔ||²,1e-12)为固定完整支持尺度。目标为各类max(||eO||²,||eΔ||²)/S的等权平均。每类每步只计算旧/扩展两次梯度；创新项相减得到。不分别归一化小的新增竞争梯度，不加入可调系数。torch.maximum相等点使用默认对称次梯度。

训练前快照梯度项和响应W1项均移出优化；响应仅封存后诊断。新类别样本不进入构造，下一查询只使用已有ETF方向。所有参考梯度和分母stop-gradient；仅节点与权重更新。原teacher、moment、旧判别记忆保持只读。
