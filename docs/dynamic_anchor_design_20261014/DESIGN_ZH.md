# Core 动态原生几何锚定：CPU 设计与待授权贡献协议

状态：CPU_DESIGN_ONLY。没有接入医学生产训练入口，没有新医学实验、图像推理、GPU 预检或正式更新。固定定义见 DESIGN_LOCK.json，合成检查见 CPU_CHECK.json。本文是 GPA 启发的解析头适配设计，不是 GPA 作者实现，也没有效果结论。

## 为什么不用单位原型直接锚定

Core 的分类器是类别均衡二阶矩、原型先验和有向类竞争共同决定的解析解。单位原始均值不是这个目标的最优分类器方向。现有最终阶段的中心化分类器与协方差感知的非竞争 ridge 方向余弦约 .997–.999，而与原始均值方向余弦明显较低。强行对齐原始均值或 ETF 可能破坏已经合理的判别几何和尺度。

这也不是“已有头就是完美分类器”：均值、二阶矩和 ridge 都来自同一统计银行，接近只证明内部一致。旧类真实分布可能已变化，训练内正确也不能解释为独立泛化证据。

## 冻结的时间参考与同类旋转

记全头为 W，维度 d×K。每个任务开始时，用原生统计和类竞争建立包含当前新类的完整参考 W0；当前新类只用 fit 训练统计进行原生 bootstrap，不用 val。旧类仍使用既定运输统计，不额外估计旧类图像漂移。

冻结任务起点曲率 G0=ΣQ0/K + .001R0，R0 是该臂原生先验；local_transport 臂保留原来的区域先验。G0 含现有已知类统计，不是独立 Fisher 或真实总体协方差。

对起点与块边界均值分别中心化，得到 b0_c=G0^{-1}(μ0_c−平均类均值0)、bt_c=G0^{-1}(μt_c−平均类均值t)。从 b0_c 到 bt_c 建立最小二维平面旋转；对中心化 W0 列做相同方向的部分旋转，再加回 W0 的公共分量。每列只沿自己的参考方向改变，保留原生权重相对该方向的偏角，不借其他类别的均值、身份或 ETF 列。

旋转角度乘以 ρ_c=n_c/(n_c+16)/(1+age_c)，age 为引入后经过的任务数。16 是本次设计前瞻固定的平滑常数，未根据 val 选择。ρ 是支持度和陈旧程度启发式，不是可靠性概率或真实漂移置信区间；少样本可能被压得过弱，必须在未来贡献对照中披露。

零向量及反平行但平面不可辨认时，ρ=0，该列精确保留参考。无方向改变时目标列精确复制 W0。旋转只保证加回公共分量前各列的判别向量范数；类中心化投影和最后求解不保证各列范数或类别间隔不变。

全局共同平移由类别中心化去除，避免把现有 global/local transport 的共同位移重复施加一次。旧银行的共同平移本身不能提供真实旧类方向变化；当旧、新均值仅同移时，动态部分会退化为任务起点稳定项。新类的相对变化也可能改变旧类相对全类中心的方向，不能把这种变化叫作观测到的旧类真实漂移。

## 解析头目标与训练梯度一致

令 Π=I−11ᵀ/K，H=Π diag(ρ) Π，A 为上述时间参考目标。加入

\[
J_{anchor}(W)=\frac{\lambda}{2}\operatorname{tr}[(W-A)H(W-A)^T],\quad
\lambda=0.1\operatorname{tr}(G_0)/d.
\]

H 半正定且 H1=0，锚定仅作用于类别判别部分。原生方程变为 native_operator(W)+λWH=native_rhs+λAH。原生二阶统计、区域先验、竞争项和训练时 .01 proximal 原封保留；边界 refit 原生 proximal=0。λ=0 或全部ρ=0 精确调用原生 solve。CPU 实现使用稠密 Cholesky 预条件；生产 Woodbury 接口与速度尚未接入，不能称 production-ready。

与用当前解析解当锚点不同，任务起点 W0、G0 固定，A/ρ/λ 在优化块内 detach 并冻结。训练保留原始 fit、old moment、pair、ridge、proximal、FD10 损失，并使用含同一 anchor 的解析头。固定块内可使用 envelope gradient：anchor 本身不直接反传到 encoder，但改变解析头，因而改变原生 fit/pair 的特征梯度。块边界更新目标并不等于对整个目标生成过程求导。

原方案刷新频率冻结为每个 epoch 边界，用 fit 统计估计；meta 只在既定全当前训练封存边界加入，不作为独立校准集。目标刷新和原统计更新必须有明确的 before/current 顺序，避免把同一状态与自身比较；若已有两个 epoch 提供的方向变化过少，应如实披露，不靠追加 epoch 弥补。

## 与 local_transport 的互补和新类保护

local_transport 更新局部区域统计并改变 R；本设计保持“全局分类器相对于同类原生方向”的时间关系，不添加第二套区域中心，不重复运输旧统计。它是训练过程稳定机制，而不是又一套后处理概率准入或协方差供体借用。

对新类采用自身任务起点参考，保留类别均衡 fit/pair 竞争和原 FD/proximal，避免直接用旧类或供体方向覆盖新类身份。公共 logit 分量不受新正则改变。以上都是结构性限制，**不是新类正确率或间隔保证**：类对比 H 仍耦合各列，encoder 更新和统计误差仍可能伤害新类；少样本新类的ρ也可能过弱。

额外锚定有可能与原 .01 proximal、FD10 重复，尤其当前头/原型已内部一致时。未来必须报告 λ 相对 native/proximal 曲率、每列旋转角、目标差距、实际头变化、anchor/native 梯度比例、旧新类间隔与纠正/破坏；非零损失、非零旋转或数值 PASS 均不算净贡献。
