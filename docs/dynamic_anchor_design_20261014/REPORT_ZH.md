# Core 几何核对与动态锚定 CPU 设计报告

## 结论

没有发现 HK 稀少类权重范数明显缩小/坍缩的证据。分类器与原始均值方向不一致，但与考虑同一统计银行二阶矩和原生先验的 ridge 方向高度一致；因此不能把原始权重—均值夹角当作需要修复的错误。

可以确认旧银行运输后的均值与当前 encoder 下的旧训练图像均值在**现有头的 score 投影**上仍存在残差。不能由此恢复完整特征空间的真实漂移方向，也不能证明区域统计真实保真。动态原生几何锚定作为训练稳定假设已设计并通过 CPU 检查，尚无医学效果或因果证据。

## 范围和证据

只读18个原控制阶段 checkpoint 的解析头、统计银行、区域中心，以及18份已有训练侧统计 sidecar；复用36条 epoch 数值诊断。NAS 上计算匿名标量，不导出权重/矩阵，不运行 encoder。0新医学影像读取、0val manifest、0test、0GPU、0optimizer更新，不修改已冻结训练源码或历史结果。

252条逐类阶段行、18条阶段行与全部36条 epoch 标量见 CLASS_GEOMETRY.csv / STAGE_GEOMETRY.csv / EPOCH_DIAGNOSTICS.csv。缺失字段保持空值，见 EVIDENCE_COVERAGE.json。checkpoint 元数据、来源、阶段/order/count/steps 与已有来源核对；仅按已知字节/mtime检查未修改，不声称哈希或逐字节验证。

当前训练侧 score 分布来自既往诊断，不是新校准集；统计 bank 的旧类均值来自估计运输，新类边界均值来自当前全train，故新类 score 残差近0属于构造内一致。不得把它与独立正确率混为一谈。

## 区域统计与时间覆盖

local_transport 中区域先验张成空间的秩为4K：ISIC阶段16/24/32，HK52/60/68/76/84/92。HK最终判别头在该空间的能量比例，稀少旧类约.217、其他旧类.224、新类.246；ISIC旧类约.111、新类.168。这不是区域模块的因果贡献，也不是应该再添加一套局部约束的证据。

HK六任务epoch2区域位移范数依次 .00288955/.00268483/.00212945/.00218484/.00327284/.00164309；保存旧区域中心跨阶段余弦非常接近1。epoch1位移0是任务起点 before/current 相同的构造结果。共同运输的小变化只能说明存储的估计接近，不能说明真实旧图像局部区域没有漂移。

区域向量是 CLS 条件下的 patch 区域中心；全局分类器作用于 concatenated global feature。两者的余弦不能直接当成同一分布下的几何对齐目标。当前缺少旧图像真实区域均值/协方差及各epoch逐类几何。

36条epoch保存loss/求解残差/prototype count/区域位移幅度，但没有逐类角度、范数或epoch checkpoint。本轮只能核对stage边界，不能声称已证明训练中不断发生某种失配。

## 动态锚定与 local_transport

完整数学定义及待授权主四格见 DESIGN_ZH.md / DESIGN_LOCK.json。机制使用任务起点原生头和冻结曲率，按同类协方差感知方向变化做有限旋转，再用类中心化的PSD二次项锚定解析头。它保持原生方向偏角，避免生硬拉向单位均值；与 local_transport 的区域先验更新作用在不同层面，不再重复运输或添加区域列。

新类使用自身参考、不借供体身份，保留原class-balanced竞争、FD和proximal；但**不保证新类间隔或正确率**。支持度/年龄权重可能把稀少类压弱，原FD/proximal可能与锚定重复。必要贡献对照是相同强度/权重的静态任务起点锚定，不能把普通正则增益叫动态几何收益。

当前头/原型的内部一致性较高，所以动态锚定是否值得训练验证仍是待检验假设。它不自动修复稀少类混淆，不取代旧类漂移可信度证据。
