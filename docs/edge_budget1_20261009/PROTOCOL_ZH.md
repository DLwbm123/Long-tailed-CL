## 问题与唯一主要候选

历史PCRL把竞争压缩成旧→新、新→旧、组内三组，固定动作已复现其预测；这不证明细粒度动作有用。本轮检验：同组内不同类别对的冲突信息，能否让竞争预算分配优于三组统一调节和固定竞争？唯一主要候选为edge_rl。进一步与同动作空间的非RL搜索比较，避免将搜索或动作空间的收益全部归给策略梯度。

本轮只细化有向**类别对**；每条边的证据来自多原型和类级一二阶矩。没有声称逐原型对独立优化，也不新增推理非线性边界、图神经网络或旧图像回放。

## 四臂共享的分类目标

保留多原型证据形成的正定岭正则矩阵R、原生闭式/近端头、均匀类内样本权重。所有臂新增同一个prototype-directed quadratic class competition，beta=0.5，从Task1开始生效。原竞争矩阵a0每行质量1、对角0，等于半均匀加半原型混淆分配。四臂同样通过闭式头和真实适配器梯度使用竞争项，推理仍为单线性头。

头目标为原生平方拟合、旧类统计平方拟合、0.001的原型矩阵岭正则，加0.5倍有向类对平方间隔项；minibatch保留0.01近端项。PCG目标相对残差1e-9，验收≤1e-8、最多128次，失败保留并停止，不放松数值门槛。为保持原始多原型先验，扩展求解器显式接受R；旧调用默认单位阵，既有实验源码不覆盖。

## 细粒度动作

每条有向边c→j的8维描述为：旧→新、新→旧、组内三个指示；相对本行均值的多原型混淆强度；基于完整二阶矩的标准化负margin；类均值余弦相似度；目标/源训练计数的对数比；margin标准差与绝对均值的比值。连续量使用代码中预固定的tanh/归一化，不含类别ID embedding、val/test信息。粗粒度仅使用前三维。

一个动作是共享系数向量u（coarse为3维，edge为8维），它为每条边生成log-odds：`log(2)*tanh(f_cj dot u)`。竞争质量为

`a = 0.5*a0 + 0.5*sum(a0)*softmax_over_offdiagonal(log(a0)+log_odds)`。

总竞争质量固定；每条边至少保留0.5倍原质量；所有边保持非负、对角严格零，凸二次头不变。u=0精确返回a0。coarse同组边缩放相同；edge可以在同组内区分不同边。edge前5个新增系数置零时包含coarse动作族；新增维数本身是表达能力变化，不能伪称参数量完全相等。

## 奖励、优化及执行

每epoch固定当前特征、原型正则与基准a0，以static_pc头为参考。当前类风险为meta上的半平方预测损失，旧类为共同平移统计的同形式期望平方损失。相对收益按参考风险clamp_min(0.1)归一化；奖励为所有类平均收益，减旧类、新类、已见尾类各组的负收益均值，再减0.01倍归一化竞争质量相对a0的KL。尾类为原训练计数后半类；空组不计。共享平方风险减少量纲差别，但不保证真实旧类或召回排序可靠。

coarse_rl/edge_rl：零初始化可学习均值参数，Gaussian潜在系数均值`2*tanh(theta/2)`、固定sigma0.5；每epoch4组×4候选，每组2次策略更新，共8次。Adam0.05、概率比clip[0.8,1.2]、均值相对任务起点的每维平均Gaussian KL系数0.01、策略梯度裁剪1。优势以static_pc的零回报为基线，用候选奖励RMS缩放，**不减组均值**，避免负收益仅因其他候选更差而成为正优势。每任务重建Adam，策略参数跨任务保留。

edge_search：相同8维动作、4组×4候选和sigma，每组围绕当前最优系数搜索并保留已见最好者；不进行策略梯度。下一epoch搜索中心保留在同样有界均值范围[-2,2]内。两种RL与搜索均为16候选+参考+最终提议，共18次控制器头评估/epoch；static_pc只计算参考。全部额外求解时间计费，等评估次数不等于逐秒相同成本。

RL执行最终策略均值，search执行搜索提议。最终提议奖励必须>1e-8才执行，否则使用a0；这只是代理目标的正收益门，**不是逐类安全保证**。原逐类新/旧风险无恶化条件另行诊断，不控制执行。四臂共同的奖励、执行规则与历史PCRL不同，因果归因只在本轮配对臂内进行，不能直接对照旧轮数值宣称仅细化动作的收益。

每个动作持续一个epoch。任务末按原协议用全部当前训练样本重建统计、基准边和描述，应用最后执行的系数，不重新优化策略、不访问验证集。边界动作可能因描述变化而改变；控制期正奖励不保证refit后收益。策略只优化固定表示下的即时头代理，不声称长期credit assignment或真实短分支训练收益。
