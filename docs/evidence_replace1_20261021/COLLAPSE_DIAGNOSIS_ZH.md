# class19 塌缩原因定位：训练目标、分数可比性与整图主导

结论：**未发现能够解释本次塌缩的 log-det 符号、类别索引、漏加参考项或源码漂移问题；失败出在这套固定生成目标与长尾训练预算下得到的跨类评分，以及 E 的整图退化。** 数学归一化和独立数值复现均成立，不代表学到了可区分病种的证据。不能把“没有发现这些计算错误”扩大成实现绝无其他问题，也不能从一轮结果唯一分离优化进度、样本支持及类分布的贡献。

本次只读已有代码、配置、训练 scalar、300张已保存 query 分数/特征及共同参考矩；CPU4，无模型 forward、无新预测方案、无训练图逐样本读取、无新图像编码、无求解/重拟合/优化。没有重开科学运行或调参救分。

## 1. 训练的究竟是什么

`run.py:100–123` 对每个类别单独新建 flow，仅用该类正样本最大化 log likelihood ratio，固定5epoch；不包含其他类别负样本、分类CE或“真类分数高于竞争类”的目标。G最大化全patch生成似然，E最大化共同背景替换后的区域边缘似然。它们并不是直接训练分类margin。

每类 patient 权重之和为1，代码将其乘该类图像数 n 再取 minibatch mean：自然均匀抽样时，目标期望仍是该类患者等权风险。**没有在推理偷偷乘 n_c、没有加经验类别先验；也不是患者数多直接给该类推理分数加常数。** 但固定epoch导致优化步数非常不同：

| 类别 | 训练图像 | 每臂更新 | 第5epoch G记录NLL/patch | 保存query G平均score/patch |
|---|---:|---:|---:|---:|
| 19 | 45,439 | 7,100 | −256.1740 | 252.2011 |
| 8 | 6,941 | 1,085 | −193.2933 | 197.1212 |
| 13 | 1,485 | 235 | −118.7149 | 125.4542 |
| 16 | 32 | 5 | −3.0637 | 3.0701 |
| 15 | 7 | 5 | −2.8359 | 0.3142 |

class19与最小类别的更新数相差1420倍。三臂之间预算匹配不意味着各类专家处于相同拟合程度。实际保存query的类别分数均值排序，三臂完全相同且近乎随更新数排序；log更新次数与分数均值的Pearson约0.980，完整的ties修正Spearman见JSON。这是强描述证据，但样本数、优化次数与病种分布共同变化，**不能断言仅更新数就造成全部塌缩，也不能用此结果推出加步数必能救回尾类。**

训练曲线是每epoch沿途 minibatch loss 的等批次平均，不是固定终点重新评价的完整患者加权风险；末批不足32时也按一批计。它能确认训练在更新、相对q的似然收益增长，不能认证各类已收敛或直接跨类比较病种难度。缺失的逐样本训练终点证据不再重建。

## 2. 跨类密度分数：形式可比，经验分类失败

令共同白化坐标 `u=(z−mu_q(g))/sigma_q`，flow输出 `T_c(u)`，则 `core.py:24–26` 实际计算

`r_c = (||u||²−||T_c(u)||²)/2 + log|det dT_c/du|`。

这是 `log(p_c(z|g,j)/q_j(z|g))`，符号与仿射逆变换一致；共同白化Jacobian在比值中抵消。G的整图 `sum r_c` 与 `sum log p_c` 只差同一张图、所有类共享的 `sum log q`。E也可以补回相同的整图q乘积，得到其区域混合模型。因此没有漏掉一个类专属归一化常数；给已存分数补回解析共同q后，三臂argmax变化均0。该核对没有产生新模型预测或用于挑选新评分。

可比性的严格范围是：固定同一观察条件g/位置、同一特征空间、同一参考的归一化**条件**密度。CLS只是条件，未建模类条件 `p(g|c)`；不是完整图像联合密度的实证保证。归一化不保证有限样本、模型失配和不同拟合进度下的经验校准，更不保证学到的通用patch统计改善是病种特异信息。

现有分数说明 class19 不只在真class19上高，而是在全部20类、全部300张图上都压过其他专家：E最小第一/第二差距为4664.373764，总预测全部class19。G中class19平均每patch252.201，次高class8为197.121；class19模型对自身15张相对其他285张的平均分差仅5.287/patch。**跨模型总体偏移约55/patch，远大于该模型自身/他类均值差，现有分类主要被专家整体似然抬升压住。** 这不是分数只有微小舍入差导致的翻转；独立复算误差仅5.821e−11。

共同q本身没有出现除以近零variance floor或非有限值：sigma最小0.324064，150,528个方差坐标中floor触发0，参考权重质量约1；训练参考矩给出的加权白化能量为768/patch，保存query平均898.065/patch，全部有限。平均能量差不能证明q整体失效，也不能排除相关结构、高阶分布或条件模型失配。**不同专家对共同分布结构的拟合收益可污染分类**与现象一致，但没有保存能把该收益和病种特异收益唯一拆开的训练反事实，不能编造因果比例。

## 3. 为什么整图主导，E为何接近普通G

区域R的项是 `a_R=log pi_R+sum_(j in R) r_j`。本实现每个尺度总先验质量1/5，尺度内N_s个位置均分；整图尺度只有一个位置。因此任一非整图窗口与整图的**精确项差**为

`a_full−a_R = sum_(j outside R) r_j + log N_s`。

这里没有面积平均，也没有额外背景patch惩罚。整图本身先验质量0.2；单patch窗口只有1/980。若区域外证据之和为正，就更奖励扩张；即便没有病灶语义、只是多数patch的共同似然改善，也可能把区域后验推向整图。这个性质符合冻结的替换生成模型，不是softmax维度写错或意外把sum当mean。条件归一化模型中允许这种解，不意味着该解具有预期医学机制。

**不能由全图总score为正推出所有patch证据均为正；本次没有保存逐patch ratio，不补跑模型来作该断言。** 实际是否整图主导，以已有区域后验摘要为证：18/20个E专家的query平均面积比例约1、global-like比例1。类15平均0.680049，类16为0.983733。因其他最大窗面积只有49/196=1/4，`E[area]>=a`蕴含`E[posterior_full]>=(a−1/4)/(3/4)`；因此这18个专家的平均整图后验也近1，不能把它们解释为发现局部病灶。

其后果可直接由公式确定：

- 整图后验趋近1时，`S_E≈sum_j r_j−log5`；对同一个flow，退化为G减一个所有类共同的常数。
- 梯度 `dS_E/dr_j=sum_R posterior(R)*1[j in R]` 此时趋近1，也接近G的训练梯度。
- 整图之和对置换不变，因此shuffle几乎无法干预主导项。**当前实际预测差异0，而不是三臂所有分数逐值完全相同。** 三臂各有独立优化的flow，不能直接把不同模型的分差都归于常数−log5。

由此可以确认本轮的空间机制没有有效发挥；E-shuffle平局在这种退化状态下不是“空间无关也能证明证据有效”，而是未形成所宣称的局部空间证据。

首次资格中的全正大数fixture已经出现整图主导，后来改为局部正岛/负背景，只证明算子在某些输入下会响应置换，**并未排除真实训练进入整图退化**。这属于资格覆盖不足；不能把那个通过用作现实空间机制的成功证据。本次保留该失败及全部费用，不修改旧记录。

## 4. 实现问题与方法失败的边界

| 问题 | 当前证据/结论 |
|---|---|
| 远端运行了不同模型或配置 | neutral入口core/run/verify与封存源逐文件文本相同，公开冻结配置字段无差异 |
| 类别索引串位、argmax/seen前缀错误 | 保存order/labels、原独立全分数复算及前缀评价一致；未发现该问题 |
| flow logdet符号/共同q漏项 | 公式吻合逆变换；共同q补回不改变任何argmax；不支持该解释 |
| variance floor/NaN/微小数值差 | floor0、全部有限、分差数千、数值复算误差1e−11量级；不支持该解释 |
| 训练目标不直接保证类间竞争 | 确认，只有各类正似然目标；经验归一化不等分类校准 |
| 尾类与头类拟合进度悬殊 | 固定epoch下确认；与均值分数强相关，但不能唯一因果归因 |
| E整图退化、空间机制未发生 | 公式+保存后验确认，是目标允许且可能奖励的退化，不是计算复现通过能排除的问题 |
| 训练收敛与精确密度 | 没有足够记录认证，不将固定5epoch视为收敛或精确Bayes模型 |

原来的科学结论不变：三臂15/300、tail0/later0，E未胜同容量G、空间门失败，关闭这套**模型+目标+固定训练预算**。这次不足以否定所有生成分类或所有背景替换理论，但足以否定本配方作为有效病种空间证据方法。没有调参、补训练、重新编码、改分数救分或放宽门槛。
