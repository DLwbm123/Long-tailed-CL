## 2. 已经学到什么

1. **元比较/最坏风险未形成有效判别。** PAIRED最终15/300、近均匀输出，META全预测class16，WORST/PAIRED全class15。PAIRED对WORST的支持压力仅低0.000025509nat，未达0.02；原始CE还混有伪到达位置的机会基线。没有唯一塌缩原因证据，不能靠压力标量降低宣布成功。
2. **监督对比辅助不支持本轮假说。** SUPERVISED45低于ER51和INSTANCE60；tail4为8，later29。并非单类塌缩，但不能据末batch梯度改步数、温度或换主臂救分。这不否定所有SupCon/SCR。
3. **冻结局部分支不足以固定完整判别函数。** FROZEN_PAST相对匹配控制final+6、mean+2.390212pp，但tail4无增益、initial仅11/150；拼接归一化、head和新增类竞争仍变化。不是零遗忘，也不是完整DER复现。
4. **保存出生功能信息仍只有微小收益。** MARGIN相对ER final+1、mean+0.345459pp、tail4持平；对LOGIT final+8而mean只+0.509480pp。出生teacher可重建、真实probe目标正确、辅助确实执行；这些不能证明辅助权重合适、已经收敛或机制有效。
5. **有限记忆风险受控不等于兼顾新类。** FEASIBLE相对ER整体+15、初始类多27，但later少12、tail4少7；相对PROJECT整体只+3。主臂五次到达两新类当期正确数0/1/0/0/0（每次30val），而ER13/14/15/12/6；主拒绝474次，占旧记忆阶段18.96%。支持本协议保护与可塑性失衡，不唯一归因投影、bias、lr或memory，也不意味着后来永远识别不了这些类。

上述固定科学配方均关闭，不通过扫权重/风险预算/lr/steps/容量/记忆/seed、改门、NCM/refit/融合或换主臂救分。跨轮SGD+共同bias的ER36与AdamW ER51不是同配置，不能据此投入baseline追分。主线按研究用途界定，成熟方法的合理适配仍可服务主线，但不包装为已证明创新。

## 3. 工程失败与修复必须单列

- **loss_cover：部分实验。** POINT38步/48评估，梯度1.379001822e-7通过；CLASS5步/10评估，梯度1.876277271e-5未过1e-5。CELL未开始，future7929未读、val0，没有三臂效能结果。独立NumPy只核对两个保存头的目标/梯度，属于部分失败记录验收。
- **functional_margin：首次CuBLAS环境遗漏。** 60129基类+20资格编码后首次正式GPU FP32前向失败，正式更新0、val0，但部分前向不是0计算。一次环境修复后在原4h/2GB同钟重试并完整验收；两次重复编码全部保留，未延截止。
- **feasible_replay：首次投影KKT门失败。** 原失败QP/arm信息未保存，不能唯一诊断。人工要求解决后，改为同一QP主动集NNLS、不加ridge、不放宽KKT/方向门；真实GPU全链通过后从stage1精确封存恢复，原钟/原预算不变。丢失当期3348图重新编码计费，原部分报告未改，最终完整验收通过而科学门仍失败。额外ARMS导出和入口环境检查失败也保留。
- **native_token_replay：真实数据前的数学预检失败。** 原生两块/token记忆方案已冻结源1f1cc1e，但首次合成NumPy入口期待blocks.0/1，PyTorch切片保留10/11，报KeyError。CPU合成2行前反向后被拦截，真实train/资格/val编码与优化均0；未取得真实GPU全链PASS、没有科学指标。32.351秒后全组退役，无重试。本次只公开失败记录，不以源PLAN交付冒充启动成功或科学完成。

下一研究方向原本是保留稳定下层空间token、实际学习原生上层attention/MLP，改变可塑表示与历史信息权限；目前仅有冻结实现和预检失败证据，不声称其有效。任何继续执行都须保留工程失败和原钟，先完成必要正确性检查与真实GPU全链，才允许bulk；本次汇总不启动新进程。
