# FDRL3：仿射统计搬运，先验证奖励再检验策略

用户于2026-10-08在FDRL2阴性关闭后授权本轮，限定四张A100。FDRL2的20个校准、1040步和1.1321 GPU小时成本保持原样，本轮单独记账，不覆盖旧失败或修改旧结论。

## 唯一方法改动

当前fit图像同时通过任务起点教师和当前编码器，获得成对特征x/y。按类别等质量权重w，拟合带恒等先验的仿射映射：

`min_(A,b) sum_i w_i ||A x_i + b - y_i||² + 0.001 ||A-I||_F²`。

b不惩罚，先按加权均值中心化；按样本数/特征维度选等价的原始或对偶岭回归求解，避免固定构造大样本Gram。没有搜索岭系数、秩、学习率或奖励权重。未变化输入精确退化为恒等映射。

历史类均值、完整原始二阶矩及原型中心使用同一A/b搬运；fit和meta矩永久隔离。Q更新为`A Q Aᵀ + (A μ)bᵀ + b(A μ)ᵀ + bbᵀ`，等价于协方差`A Σ Aᵀ`。训练解析头、奖励读出、epoch起点及最终边界一致使用该规则；中间读出总从任务起点历史bank出发，避免累积重复搬运。

这些矩公式对给定仿射变换精确；A/b对真实旧类变化仍是外推近似。更新后不额外逐样本归一化映射，否则矩封闭性不再成立。历史组件没有完整协方差，标量radius保留并标记未使用；本轮原型证据强度0、无竞争项，不在分类头/奖励/动作中使用旧radius，不声称恢复组件形状。

借鉴[LDC, ECCV 2024](https://arxiv.org/abs/2407.08536)从当前数据学习漂移映射的思想；本轮是恒等先验岭回归和类级一二阶矩版本，不声称完整复现或新增理论遗忘保证。

## 数据准入与20个校准

上轮T1尾类的40个meta身份组均被旧校准覆盖，换随机种子不能构成独立身份复核。本轮校准放在T2起点，使用当前到达的原始类3/7；T1前缀仅见过4/0。不是访问未来任务或真实旧类原图。3/7在旧FDRL2成功校准中从未被读取，但可能曾用于历史正式训练；本轮仍是开发诊断，不声称外部独立确认。

校准专用划分从正式永久划分派生：类7原meta只有5个单身份图像，固定种子82007对其fit身份组排序打乱，移出3个身份组共3张图像，使该类fit/meta为19/8；类3维持1057/249。按完整身份组划分，无身份交叉。该前缀未训练过任何3/7图像；meta既不训练编码器，也不拟合搬运、原型或分类头。正式15122/3596划分完全不变，诊断meta不冒充正式独立验证。

固定五个采样种子82000–82004 × 伪旧/新两个方向 × 0/8步起点，共20个场景。每类至多128fit/64meta，实际类7为19fit/8meta；这些重复共享稀有类meta，不能当作20次独立复现。保持16步FD5/10/20同状态分支，合计1040次真实适配器更新，无保留校准模型。

A/b仅用伪新fit配对特征拟合；伪旧meta只为诊断真实风险。每个分支同时读取共同平移对照的聚合风险/召回，复用相同真实适配器轨迹，无额外适配器更新。该配对读出仅用于归因，不允许根据它重选候选或参数。

冻结门槛沿用上轮且必须全部通过：至少20个差值≥1e-4的有效动作对；代理/真实奖励排序一致率≥2/3；预测旧损失改善≥1e-4但真实旧召回下降≥1pp的分支比例≤10%；选择动作相对三动作最佳BA的平均差距≤1pp；至少5个场景三动作BA范围≥1pp。稀有类只有8个meta，召回分辨率粗，应保留这个局限。任一门槛未过或证据不足，停止正式训练并交付阴性结果；不降低阈值或自动更换方法。

## 条件正式训练

校准通过才启动8臂：仿射R(固定10)、FD5、FD20、RANDOM、GREEDY、FDRL、SHUFFLED，以及共同平移LEGACY(固定10)。所有臂底座无竞争项，保留5/10/20动作、原奖励公式、16次多样化预热及完整任务回报。LEGACY用于区分搬运变化与策略贡献；共同平移不接收仿射更新。

主候选唯一为FDRL。主筛相对匹配仿射R：最终BA≥+1pp、尾类≥−0.5pp、遗忘增加≤1pp、新类≥−1pp，并且BA严格超过其余6种控制及满足相对LEGACY的尾类/遗忘/新类保护。训练全部封存后才访问官方开发val，test始终封存。

主筛通过才运行74003/74004两个新种子的R/FD5/FD20/FDRL，共8臂；每个新种子对R的BA>0并满足保护，三种子平均BA差≥1pp且超过固定5/20才算本开发协议复核通过。没有额外消融、HK迁移、自动方法修订或失败重试。
