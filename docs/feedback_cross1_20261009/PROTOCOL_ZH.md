# FEEDBACK-CROSS1 冻结协议

用户授权按上一轮分析执行下一步。复用 ACTION-TRACE1 的固定状态与全部候选，仅做奖励审计和最终分类头交叉读出。沿用原始截止与累计成本，不追加适配器或策略更新。

## 范围与比较

ISIC、HK 各17个原候选，含零动作；保留 ISIC 跨 GPU 零动作重复，共35条实际记录、34个唯一候选。分片及 GPU 沿用上一轮。读取保存的当前训练特征、开发特征、旧 bank 和逐类聚合结果；训练清单仅用于复现原尾类定义。不加载影像、不提取新特征，不访问医学 test 或 CIFAR。

两个读出版本均预先保留：all-refit 是原流程终端读出，fit-refit 是当前 meta 不参与拟合的诊断。对每个候选 a，在零动作训练后的编码器 θ0 与动作训练后的编码器 θa 上，分别重建零动作头和动作 a 头：B00、B01、B10、B11。每个头必须用相应编码器的当前特征重新计算统计、旧类运输、原型与边描述，不能交换不匹配的头。共有280个逻辑读出（共享零动作单元不重复解释为独立实验）。不新增训练随机性。

报告 B11−B00 总收益、B01−B00 基线表征上的读出收益、B10−B00 零动作读出下的训练路径差异、B11−B10 动作表征上的读出收益，以及 B11−B10−B01+B00 交互项。均同时报告全部/旧类/新类 BA 与同定义平方风险，逐类变化与 helped/hurt。这里的训练路径差异包含相应统计重建，不宣称是纯表征因果效应。

## 反馈审计

对所有原候选分解初始奖励：平均归一化风险收益、旧类/新类/尾类负收益惩罚、0.01 allocation KL。保持原归一化下限0.1与执行门1e−8不变。核对分项重组与原奖励一致。

对最终反馈明确区分：原 post_feedback 比较 B11 与 B10（同候选编码器）；整条分支的风险变化比较 B11 与 B00。后者只报告风险收益和保护项，不引入未经定义的跨编码器 KL，不据此训练新的终端奖励。逐类比较旧 bank 代理风险、开发样本同头平方风险与 BA；训练/开发差距不能单独识别运输误差。只允许把代理变化与开发变化的偏差称为反馈失配。

all-refit 使用当前 meta 拟合，因此其 meta 表现不是留出反馈；fit-refit 的当前 meta 保持排除，但旧 bank 含历史 meta，且开发样本已被研究者查看。两者都不是独立确认。

## 预先固定的保护口径与解释

同时报告四层口径，不按结果事后挑选：总体 BA 正收益；旧/新组平均 BA 均不下降；每个类别净召回均不下降；没有原正确样本被伤害。后三层均在当前开发样本上定义，不外推为总体安全保证。few 类零召回不再下降不能解释为保护成功。

所有候选一并输出。有限集最佳和门槛反事实只作特权诊断，绝不部署或作为方法成绩。相关系数仅为同一有限集合的描述性统计；不计算显著性，不把候选数当作独立重复。

若基线编码器上的头调整已保留主要正收益，可提出后续简化读出验证；若训练路径与交互不可忽略，则保留训练控制问题。不给“主要”设事后分类阈值，完整报告各项绝对值，避免在总收益接近零时报告不稳定比例。上述发现都不自动授权下一轮训练。
