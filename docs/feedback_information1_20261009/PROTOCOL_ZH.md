# FEEDBACK-INFORMATION1：基线读出强度与反馈误差诊断

用户已授权按照上一轮分析继续实验。本轮固定DECISION-PROB1的五个状态与编码器，比较分类头的静态改进空间、反馈辨别和有限候选可达性；不追加RL、适配器或编码器训练。

## 固定范围与基线

沿用ISIC/HK缓存任务2的一个epoch零动作分支，以及ISIC任务3、HK任务4和任务6的完整两epochstatic_pc轨迹。两种来源分别报告，不将五个状态当作独立重复。

只用原fit-only版本，保留原33个头配置（17边候选与17列范数候选共享零头）。增加两个预定终端读出：去掉原型先验与竞争项的线性ridge，以及保留原型先验、去掉竞争项的prototype ridge，正则系数仍为.001。固定现有强基线为主比较，不按本轮结果更换基线，不预设消融一定更弱。新增两个头只作消融，不加入选择候选。

这些消融使用同一个已按static_pc训练的编码器，检验终端读出组成，不检验预训练编码器强弱，也不代表分别训练后的完整线性/原型方法。报告共同候选库相对各基线的空间时，必须拆开静态基线差异与额外选择收益，不能将静态改进计成RL收益。

复用原始当前任务特征、开发特征和33头缓存。仅为三个完整轨迹状态重新抽取当前训练图像在任务前编码器下的特征，预期13895个图像特征次数；任务后表示复用缓存，两个任务2的前表示也复用缓存。无旧训练图像、医学test、CIFAR访问。原模型初始化种子、身份fit/meta划分保持不变；重建fit零头必须通过原allclose阈值，不放宽科学检查。

## 一次身份隔离的A/B诊断

开发特征已被历史研究查看，本轮将其作为明确的特权诊断材料。使用固定拆分种子93003，逐类排序身份后以seed+label×2003打乱，前floor(n/2)身份给B、其余给A。同一身份不能跨两边，出现跨类别身份时停止而不改分法。只拆一次，不增加种子、不反复重分。

数据清点仅查看支持量，发现HK类别5/6各只有一个开发身份，类别19只有两个。因此预先规定：至少四个身份的类别进入A/B诊断，两边各至少两个身份。ISIC均可覆盖；HK固定缺少5/6/19。缺少类别仍留在完整开发评价和全部分类头输出中；不得填零、视为安全或把其余类别结果当作完整旧类/尾类保护。两个身份每边的类仍然支持很弱，全部公开聚合支持量，不将“达到可计算下限”理解成足以泛化。

对同一A特征、同一33候选，计算真实经验召回和由这些分数的经验均值/总体协方差产生的联合高斯召回。比较同样本经验收益与高斯收益，定位矩压缩加高斯假设的近似差异；再比较真实A反馈与B效果，观察样本间差异。该分解不把不同样本之间的误差全部归到高斯假设。

每个来源分别在原17边候选和17范数候选中选择。保护口径与上一轮一致：可覆盖类别上的旧/新/尾组平均预测变化不降，总体改善超过max(1e−8,两倍成对数值积分标准误)，平局索引小者优先，否则零动作。经验A反馈积分误差为零，但不意味着采样误差为零。高斯保留类别输出和候选之间的相关性；每类固定8批×4096个标准正态积分样本。使用经验总体协方差除以n的精确低秩分解，或等价的分数协方差特征分解；不调收缩、不增加积分预算。

五个状态的A选择先写入，全部完成后才计算B与完整开发指标。分层拆分所需的标签/身份以及完整缓存文件可能已经加载；屏障约束的是B指标计算，不宣称历史数据未被看过。原DECISION-PROB1的训练侧选择也原样评价，不能利用本轮B反馈修改它。

## 条件化运输诊断

对每个当前类别，用其原fit样本比较：任务后直接表示的高斯正确率；任务前表示经其他当前类别拟合的平均位移平移后的高斯正确率；同一fit样本的经验正确率；原meta样本的经验正确率。目标类别完全排除于位移拟合。两种高斯使用相同预算和成对标准正态输入。

目标类别已参与当前编码器训练，因此这项实验仅检验给定编码器变化下的类别排除运输。不能把它等同于真正未被重访旧类的泛化，也不能据此证明历史bank运输可靠。旧bank可能包含历史meta，本轮不会把历史meta改名为独立留出集。
