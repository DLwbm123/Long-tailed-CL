# 读出目标与访问预算审查

结论：存在相同NIH冻结表示上的完整头CE配方缺口，但它只能作为最终20类的离线能力参照，不能充当原统计记忆预算下的CIL新方法。现有缓存可只读复用，无重建需求。

当前检查了缓存header、逐行索引与当前清单/患者/类边界、现有20类生成parity回执；没有重做全量哈希或编码。配置/实现表明旧类标签在缓存中按固定类顺序映射0..19，不能直接当原医学类ID。

为什么不能从Gram直接拟合精确CE：一维A取±1各1/2，B取±sqrt2各1/4、0取1/2。两者质量1、均值0、二阶矩1，附加常数后的Gram和固定标签target均相同。在w=1时logistic风险分别0.8132616875与0.8089378417，相差0.0043238459。因此二阶统计不决定精确logistic风险。这里是解析反例，非医疗实验或性能结果。

旧NIH plain correction虽含CE，却是围绕校准锚点的受罚残差；ISIC/HK完整支持CE又有不同数据、特征单位和访问预算；静态NIH frozen LA改变了增强/头/训练日程。不能据这些名字说本同表示完整头配方已完成，也不能忽略其负证据或拿它们与新结果直接相减。
