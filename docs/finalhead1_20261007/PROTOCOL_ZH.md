# FINALHEAD1：任务末重拟合一致的动作选择

本轮依据 PCRL2 完成后的分析及用户继续实施的授权，单独验证分类头选择能否超过固定动作1。PCRL2 已封闭；旧预算与负结果不重置。本轮不是新 RL 方法，也不是独立种子复现。

## 唯一候选与数据边界

- `FINALHEAD` 复用 PCRL2 `FIXED1`、seed74002 的四阶段编码器和历史统计。顺序 `[4,0,3,7,5,6,2,1]`、两类增量、FD10、完整二阶矩、prototype competition、beta0.5、ridge0.001、七动作及质量保留下限0.5均不变。新增编码器、分支和策略优化器更新均为0；已完成的476次编码器更新只记为复用。
- 第一阶段直接复用既有结果。在第2/3/4阶段，当前 fit 图像由上一阶段和当前阶段编码器分别提取特征；只用 fit 计算共同平移、原型划分、当前类均值和二阶矩。历史类仅使用已保存统计；不读取历史图像。
- 对 fit 候选统计执行与任务末一致的 `bank_head` 求解，遍历七个动作。当前 meta 图像仅用于候选评分，不参与这次候选拟合、原型划分或共同平移。meta 属于训练来源，不能称独立验证集。读取 manifest 时可检查 val 的身份组边界，但选择过程中不读取 val 图像或预测。
- 旧类使用原有标准化边际 softplus 代理，新类使用 meta 上逐类平均 CE。相对于动作1计算原有收益：各类相对风险改善均值，减旧类、新类、尾类各自负改善的平均惩罚；分母至少0.1。改变的是参考动作和评分头，收益公式不另行调优。
- 冻结512次按类分层、身份组为块的配对重采样；每次保留抽中身份组的全部 meta 图像，同一重采样同时评分七动作。种子 `74002 + task*100003 + 511`。对六个替代动作，以 `max_a(point_reward[a]-bootstrap_reward[a])` 的95%分位数（higher）作为共同扣减量，且扣减量不小于0。选择代理下界最高且严格大于1e-8的动作；并列选较小编号。无合格候选或任一新类 meta 身份组不足2个时回退动作1。动作1代理下界固定为0。
- 此重采样仅描述当前 meta 的采样变化，不覆盖历史统计漂移、拟合统计变化、动作选择偏差或开发集复用，不能作真实召回/泛化的95%保证。fit-only 候选与 full-train refit 结构一致、数据不同，仍可能发生排名改变。
- 选定动作后，按原协议用包含当前 meta 的完整训练统计重新拟合最终头。复用 FIXED1 已保存的完整统计，而不重复编码全训练数据。每阶段重建动作1头须与既有头在 float32 下 allclose(atol=rtol=2e-6)；所有求解相对残差须≤1e-8。失败不回退绕过检查。
- 下一阶段编码器继续复用 FIXED1 轨迹，候选读出不反馈编码器训练。只保存唯一所选头用于正式评价；不在 val 上评价七个头后择优。

## 封存评价与判定

全部三个决策和最终 refit 完成，`SELECTION_SEALED` 后，才执行四阶段 val 评价。复用 PCRL1 R/PC/GREEDY/RL 和 PCRL2 FIXED1/RESPONSE0/RL_RESPONSE 现有指标及配对预测，旧训练和评估成本不重复计入。test 始终封存；val 已多轮使用，结论仅为开发集探索。

初筛要求 FINALHEAD 相对 R 最终 BA≥+1pp、尾类召回差≥−0.5pp、遗忘增加≤1pp、最后两新类召回差≥−1pp，最终 BA 严格高于 FIXED1 和 PC；相对 FIXED1 还须通过同样的尾类、遗忘、新类保护。完整四阶段及全部计算检查通过、无失败才可能通过。记录动作序列、候选代理收益/下界、求解残差、全部阶段/类别指标以及配对预测汇总。

本波只包含一个正式候选。若失败，完整交付负结果并停止本波，不重采样种子、不调阈值或奖励、不换候选重评。若通过，先交付主波，再冻结 seed74003/74004 的匹配 FIXED1、R、PC 与 FINALHEAD 复核及其预算；本波不会自动启动新种子、消融、RL 或 HK。
