# 第一阶段固定状态审计：结果与机制判断

本轮完成冻结范围：每规模一次第一阶段48步教师训练、各一次48步moment/decision构造；无第二阶段更新。四个独立CPU case正常退出，无科学失败、超时或重试。算术检查通过，六组逐类覆盖复现最大差1.11e-16；只证明该标量诊断复现，不声称模型逐字节等价。

核心结论：当前问题不能统一归结为“保持不足”或“新增竞争”。small直接出现旧查询优势在扩展查询中反转；ISIC/HK在原旧查询上就已有更大的梯度误差。19个旧类的新增竞争项梯度误差全部是decision更大。HK同时提供重要反例：decision的响应分布和覆盖更接近完整支持，梯度却更差，因此提高教师覆盖或匹配少数分数间隔都不能单独保证有效回放。

## 1. small给出查询迁移缺口的直接固定状态证据

在完全相同的第一阶段教师下，decision旧查询逐类平均相对梯度误差0.224187，优于moment的0.607424，两个类都更好。扩展查询后，decision误差0.710963，差于moment的0.325672，两个类全部反转。绝对误差也从旧查询0.428236对1.160397，变成扩展查询3.077645对1.284783；这不是仅由相对误差分母变化产生的假象。

扩展减旧的新增竞争项，decision绝对梯度误差3.026791，moment0.873102。说明两个快照上的原查询梯度拟合，确实未自动保留下一任务激活方向所需的信息。没有模型训练漂移、新类样本或保持项作用参与这一固定状态比较。它仍不能量化上一轮最终分类退化中有多少由该缺口导致。

正结果也完整保留：small的decision在旧查询的梯度近似明显较好，不应笼统宣布判别压缩“什么都没学到”。但旧查询已见间隔W1反而0.973720对0.470556，更说明当前两个目标并不相互保证。

## 3. 覆盖率应与原支持比较，不能追求越高越好

以下完整支持是第一任务的合成训练支持，不是上一轮独立评价集；因此HK的66.13%不能与上一轮第一阶段独立评价BA38.29%混用。

HK则必须修正此前只盯“判别覆盖低”的解释：decision宏覆盖离原支持仅5.91个百分点，moment相差24.63个百分点。进一步从已冻结逐类记录派生、避免宏平均抵消后，逐类覆盖绝对误差平均分别为12.96和24.63个百分点；decision仍更接近。其已见间隔W1在8/13类更好，平均0.919603优于1.109914，预留间隔W1也更小。这里是确实存在的响应保真收益，而非只挑一个宏覆盖数字。

然而HK旧/扩展查询梯度都更差。数学上CE参数梯度还依赖每个节点的参数Jacobian和完整softmax竞争关系；少数最大间隔的分布并不能决定这些量。本轮支持“响应保真不足以保证梯度保真”，没有测量节点几何偏离或逐项优化方向，不将这些未测机制写成已证实原因。

## 4. 宏梯度与逐类结果必须一起看

全部逐类梯度及U/V分块保存在GRADIENTS；宏梯度及抵消比在AGGREGATES。HK扩展查询的完整旧回放宏梯度方向，moment余弦为+0.728934，decision为-0.164340；相对宏梯度误差分别0.881714和1.845484。旧查询也有类似差异。不能只用某些类相互抵消后的误差评价记忆质量。

这里的负余弦只描述旧类回放分量相对完整旧支持的方向；未加入新类数据梯度，也没有执行第二阶段第一步，所以不能据此声称实际总训练更新方向为反向，或已经证明一次更新造成分类损害。

## 5. 方法判断与停止边界

现在优先级应按证据分开：small首先暴露查询迁移问题；ISIC首先暴露原查询/响应构造不足；HK说明即使响应分布较真，也未保留有用梯度。当前继续扩大保持范围缺乏依据。moment仍应保留为强对照，但不应把高教师覆盖直接变成压缩目标。

本轮不给出新的模块、权重、参数或迭代数，不切换原四臂主门，不宣称医学有效性。若以后另行授权修改，必须分别说明准备修复哪一类缺口；不能把三种情况合并成一个确定因果机制。
