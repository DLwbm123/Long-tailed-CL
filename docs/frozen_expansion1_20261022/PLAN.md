# 等增长容量的旧分支冻结实验：运行前冻结

本轮固定比较 ALL_TRAINABLE 与主方法 FROZEN_PAST。两臂每阶段具有完全相同的增长网络、全seen分类器和有限输入特征记忆；处理差异仅为主臂冻结旧分支、对照持续训练全部分支。相同总参数不等于相同可训练参数/FLOPs，后者正是处理差异，必须另报。

依据为 [DER 作者 arXiv v1](https://arxiv.org/pdf/2103.16788) 的3.2–3.4节：冻结旧特征、追加新分支、拼接后统一分类；原文还使用辅助分类、剪枝和均衡头再训练。本轮不移植后三项，不称完整 DER 复现或新 TMI 方法。此前对比重放三臂失败不唯一证明表示漂移，本轮只检验冻结旧分支局部函数这一结构处理能否改善可观察表现。旧生成/元比较/覆盖及对比固定配方保持关闭。

## 数据与记忆

现有NIH author20 train68058、开发val300，每类15；顺序/六实际阶段10+2×5见config。全局元数据仅作访问/患者隔离审计；训练影像仅类别到达时读，不读test/Etest，不借未来权重或外部新数据。

同原ImageNet ViT-B/16冻结encoder，FP16编码、FP32 CLS768+patchmean768后L2，TF32 off、确定性，batch32。资格20基类训练图额外编码、正式68058、最后val300一次。当前阶段完整输入仅RAM用后释放；不恢复已删pack/cache或借此前实验的逐图特征。

显式持久记忆为每类最多32患者、每患者一幅影像的冻结输入特征。固定seed元数据哈希先选患者再选影像，不使用模型或val成绩。两臂完全共享该记忆；不同类可共享训练患者，不冒称独立患者数。此权限不同于A/B旧统计记忆，不作预算同构或差值因果宣称；也不是旧DualTrack统计运输，不从旧Gram推新非线性矩。

## 模型与优化

第t阶段（从1起）有t个分支，每个分支

\[
f_j(x)=\operatorname{norm}\{\operatorname{norm}(x)+U_j\operatorname{SiLU}(V_j\operatorname{norm}(x))\},\quad
z_t=\operatorname{norm}[f_1(x),\ldots,f_t(x)].
\]

V=1536→128含bias，U=128→1536含bias，第一分支U零初始化。每次实际到达后，新分支复制本臂上一已训练分支。主臂只训练最新分支；对照训练全部分支。每个输入统一通过所有分支，无task-id路由、无融合选模型。余弦分类器score=25*z*norm(W)^T，始终对所有seen类统一CE训练。

增长时旧head权重补全零新列；在增加新类、继续优化前，旧类内部排序不变（整体尺度可变），资格检查该性质。新类head行仅从实际到达当前训练患者等权嵌入均值初始化；后续类head初始化映射7929行/臂，另计。全局head之后可以改变，新类竞争也仍可能伤害旧类；不称零遗忘。旧分支局部函数固定不等于完整归一化拼接向量或分类器固定。

两臂每阶段总参数t*394880+K*1536*t，初始410240、最终2553600；主臂可训练参数394880+K*1536*t，最终579200，对照全部可训练。相同增长容量避免把对照输赢直接归因参数数量；仍不能据一次实验唯一归因所有机制。

两臂相同采样、dropout mask、初始化规则、更新预算。每步seen中选8类（无放回），每类患者均匀/患者内影像均匀有放回抽8行，旧类只从有限记忆抽，新类从当前完整训练数据抽。64逻辑行生成2份独立inputdropout.1，共128views，均用于CE；无对比矩阵或teacher。基类2000步、后来每阶段500，共4500/臂=9000正式更新，AdamW3e-4/wd1e-4/clip5，每实际阶段统一重置optimizer但不重置已有网络/head。FP32训练、FP64推理。每臂288000逻辑影像行/576000views，重复抽样不是新图/患者；分支映射数与全模型映射行数区分。固定步数不保证收敛，不根据训练曲线追加步数。

全部12阶段模型和记忆先封存，之后val编码一次；仅六actual seen前缀评分，每臂1350 query映射。无温度选择/路由/NCM/融合/验证梯度或成绩调参。
