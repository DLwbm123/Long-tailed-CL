# 本轮结论：覆盖缺口已观测，全槽保持未救回判别记忆

四个CPU case正常，原旧保持一步精确回归/覆盖率检查/全槽保持FD与盲区反例通过。D相对B主门和联合门均false，无运行失败/超时/科学重试。540类recall及540条类贡献、全部正负与费用公开。

## 1. 第二阶段开始前，压缩已改变教师保持覆盖

第一阶段四臂没有旧memory，模型逐tensor精确相同。第二阶段A/B覆盖逐类精确相同，C/D也相同。此时比较moment与判别memory，排除了教师模型不同这一混杂因素：ISIC旧正确质量98.395181%对29.508754%，HK90.764874%对60.217536%。判别memory对应约70.49%/39.78%的概率质量未进入教师保持项，仍进入回放CE，不能说这些点没有参与训练。

small则为87.568262%对90.605917%，判别memory覆盖更高仍未获得分类收益。所以“覆盖低”是高维早期失败的重要直接观测，不能作为所有失败的唯一原因，也不证明提高覆盖本身足够。

高维第二阶段开始前旧覆盖与全槽覆盖相同，不能用“未激活槽抢走了本来旧正确的记忆点”解释这个初始高维覆盖缺口。small全槽覆盖仅47.937329%/46.415143%，该潜在冲突确实存在但不同规模不能混为一谈。所有值是在合成memory上，不是医学或真实旧样本准确率。

## 2. 压缩总目标下降掩盖了分项退化

ISIC第一阶段判别压缩：总目标1.701984→1.164784，但响应项0.204271→0.564848变坏；训练前快照梯度项1.047981→0.194679改善，训练后快照项0.449733→0.405256改善很小。HK总目标0.898798→0.398778，响应项0.109825→0.114474略坏，训练后快照梯度项0.176801→0.196817也坏，主要下降来自训练前项0.612171→0.087486。

这证明“总目标下降”不能当作每个判别目标都被保留。它与过分迁就训练前快照的解释相容，但尚未单独干预该项，不能宣布唯一因果。目标只记录0/47步更新前，不冒充最后更新后收敛值。

全部140条参考梯度分母没有触及1e-12下限；平方范数最小small1.257666、ISIC1.635021、HK8.157138。因此本轮没有支持“近零分母触底导致数值爆炸”的证据。缺最优性证书，不认定额外迭代必能解决。

## 3. 全槽保持把部分问题转成了新类学习受限

B−A在ISIC第二阶段旧BA+12.401259pp、新BA−24.690419pp，总BA仅+0.037367pp；末阶段旧+10.048696pp、新−44.197804pp、BA−3.512929pp。small末阶段新BA−54.285714pp。HK第二阶段新BA−36.538462pp，旧也−1.558040pp。

D−C在ISIC第二阶段BA+1.206359pp，但旧+3.806223pp、新−3.993367pp；末阶段BA−2.436917pp、旧−4.333848pp、新+3.253877pp。HK所有非首阶段D−C的BA都更低，末阶段新类BA由12.334315%降到0。故“全槽保持修复判别记忆”被本轮冻结门否定。

D仍在所有非首阶段低于B。ISIC末阶段D−B：BA−10.043776pp、旧−29.307097pp、新+47.746187pp；HK末阶段BA−14.941961pp、旧−16.365005pp、新均0。不能把新类回升包装成全面改进，也不能把B保旧伤新当成安全保护。

第47步更新前ISIC第二阶段：B的全槽MSE较A由0.667438降到0.125189，但旧中心化MSE由0.023254升到0.037686；D旧中心化MSE较C由1.831459升到3.458032。统计对全部旧memory，实际loss只教师正确部分，不能混同。更小的全槽MSE不意味着旧旧结构或真实旧样本保护更好。

## 4. 可以排除与仍不能排除的解释

A/C对应上一轮固定分配两臂的24个stage公共Acc/BA/oldBA/newBA/间隔指标全部精确一致，仅本地公开聚合比较，未读旧NAS或重评旧模型。原旧保持一步参数精确回归通过。本轮全槽改动未污染这两个控制。

全槽均方按K平均，旧保持按O平均：MSE_all=(O/K)MSE_old+(R/K)MSE_other+(OR/K²)(meanδold−meanδother)²。新增方向约束和旧旧子空间权重稀释并存；系数1不代表相同方向梯度强度。本轮不事后补权重，也未用额外消融分离两者。

当前应停止把“更强/更广的保持”视为默认修复。更值得先分析的是：压缩过程如何在总目标下降时破坏响应分布和教师正确概率质量，以及为何训练前快照拟合收益没有转化为训练后可用记忆。先保留moment为强对照；这不是新增实验授权，不调参数/节点/步骤追门。
