# 有限历史功能记忆：跨新增类别的间隔保持

冻结目标：检验仅约束出生时已有输出的函数匹配是否遗漏后来竞争类别，以及在出生时判断正确的有限旧样本上保持全seen决策间隔是否优于普通重放与历史logit匹配。不是旧冻结扩展加补丁；本实验单共享网络、无分支增长。不把已有负结果唯一归因为该遗漏；也不声称新TMI、临床保证或必有正结果。

## 一手依据与区别

已读取 Buzzega等《Dark Experience for General Continual Learning: a Strong, Simple Baseline》arXiv:2004.07211v2，第3节、算法1/2及3.1相关工作（不是全附录）。[一手PDF](https://arxiv.org/pdf/2004.07211)。DER/DER++使用历史logit记忆，FDR在任务边界保存响应；本实验LOGIT是边界记忆的特征级受控适配，**不是忠实DER++复现**，也不是ICLR27对应投稿。

三臂ER/LOGIT/MARGIN。同一冻结ImageNetCLS+patchmean1536/L2输入，同一1536→128SiLU→1536残差（up初始0）及统一seen余弦头25。只真实到达时追加head，患者等权当期inputmean初始化。每阶段持续训练整个单共享模型；容量410240→425600，所有臂一致。无task-id、NCM、旧分支冻结、对比、生成、融合。

持久记忆：每类最多32患者、一患者一影像的输入特征，以及每个样本在本类到达阶段末本臂模型输出的seen前缀logits。每行固定20个FP64槽+prefix mask，未到达槽为0且不参与历史匹配。目标一旦存储永不刷新；各臂都分配、计算并审计相同格式（ER不使用目标）。历史功能信息是新状态，非A/B moment-only权限同构。出生目标以当前封存FP32模型的CPU FP64 forward生成。当前全特征仅RAM、阶段末释放；不借旧实验缓存/pack/历史全图。三臂自己的教师值会随本臂学习自然不同，目标容量、选择和封存时刻一致。

## 目标

共享seen类别患者均匀采样CE。记s为当前score，z为样本出生score、V为出生有效前缀，y为真类，S=25。

- ER：CE。
- LOGIT：CE + mean_old[mean_{j∈V}(s_j-z_j)^2]/S²。只已有历史坐标，不发明未来logit。
- MARGIN：出生间隔m=z_y−max_{j∈V,j≠y}z_j，仅m>0且为旧记忆行时生效；CE + mean_eligible relu(m−[s_y−max_{j∈all_seen,j≠y}s_j])²/S²。空eligible辅助为0。它保留正确出生决策的最低间隔，允许间隔改善，错误/平局教师不施加保持约束；新类别也进入当前竞争项。

辅助权重1，除S²为两辅助统一固定尺度，无clip半径、温度、置信阈值搜索。该目标可能牺牲塑性，有限记忆不能保证非记忆样本保持，不把成熟间隔/蒸馏思想换名为创新。出生间隔只在有限样本上正确，不代表医学诊断正确。

数学资格需独立NumPy目标/有限差分/批置换及一个明确反例：旧输出[2,0]完全匹配而新增输出4时，LOGIT损失0但主方法非0且梯度压低新增竞争项；出生错误教师不保持。不是新NIH结果，也不是旧失败唯一因果证明。
