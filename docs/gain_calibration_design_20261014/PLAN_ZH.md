# 训练侧校准与旧类漂移凭据：现有证据审计和最小方案

本次仅源码/匿名训练统计核对、方案设计和合成CPU检查。未打开医学checkpoint、train/val/test影像或原始逐样本记录；不启动推理、训练或监测。方向、四步长和7552e56冻结的RISK准入参数都未修改。

## 现有统计能否补齐

结论：不能直接补齐独立校准和旧类真实漂移凭据。审计依据是两个控制各自科学冻结commit的实际保存代码，以及本地已公开训练聚合；不是声称对NAS所有未声明私有文件做过完整盘点。

|所需凭据|现有信息|能否用于独立准入|
|---|---|---|
|源/task/order/支持数及解析头|checkpoint保存schema和冻结协议有|可核对来源，不能证明独立性|
|从encoder/head/bank/方向拟合全链路排除的训练留出|原20%meta在task末加入bank/head重估|不能|
|目标类在独立数据上的四候选配对救回/破坏|训练diagnostics保存loss、步骤、求解/激活聚合|没有所需计数|
|旧类在各次真实encoder更新前后的配对残差|原bank只按共同位移运输；before/current临时存在，未保存配对cross-moment|不能从单独旧/新moments恢复|
|逐旧类、逐边界的转移可信度|漂移轮保存当前类残差诊断/可选矩阵；是另一次训练轨迹|不能嫁接到原base/local_transport并称同状态凭据|
|患者级独立单位和历史曝光账本|identity_component分组不等于已验证患者独立|不能写成IID患者保证|

static_pc不更新policy，不应说成meta在本控制里用于RL调参；但最终meta加入解析统计这件事已经足以使它不能成为独立最终头校准集。仅重分训练数据、仅head-only交叉拟合或只把校准器做交叉验证，都不能消除已有encoder/bank/方向的样本曝光。

二阶矩缺失是信息不可识别问题：E[(f_after-f_before)(f_after-f_before)^T]需要E[f_after f_before^T]。单独mu/Q相同的两组配对，可产生零漂移或非零漂移；合成CPU反例已验证。trace/Frobenius范数也不能恢复竞争边界方向。

## 必须先解决样本量可行性

RISK v3的逐类损失上限为tau=.01*n_train/(n_train+16)。即便观察到零破坏，独立二元事件计数所需的最乐观样本数至少为：

    n_cal >= ceil(log(2E/alpha) / -log(1-tau))

使用上一版固定alpha=.01、E=3656448；不放宽参数。还没有加数值/漂移/供体罚项，因此这只是所需样本量下限。

|HK目标train支持|固定破坏上限|理想零破坏所需独立n_cal|
|---:|---:|---:|
|3|0.1579%|12917|
|6|0.2727%|7474|
|23|0.5897%|3451|
|25|0.6098%|3338|
|34|0.6800%|2992|
|736|0.9787%|2076|

最终HK全部21旧类，即使乐观地把所有原train图片当独立校准样本，支持也不足。原20%留出更不可能解决这一点。这里不能用重复增强、多个stage同一图片或供体数量冒充新的独立样本。

因此，仅补统计并保留当前严格逐类证书门，不能承诺摆脱identity。这是上一版设计的样本量瓶颈。没有独立校准、旧类转移证据或理想样本量都不够时，不应启动一轮可预知全拒绝的医学主评价。设计已加启动前可行性检查，拒绝原因单列，不把“未运行”当效果负结果。

## 最小、保留现有数值方向的下一项工作

建议先做训练侧辨识诊断，而不是直接跑严格证书主四格；本次只设计，不执行。它解决“模型在哪些边界高估救回/低估破坏”，不假冒独立校准。

1. 仍用原18阶段状态及四个已冻结delta。每个样本一次current encoder特征抽取，同时计算OFF和四候选guarded ON；不选步长、不按诊断调参数。
2. 对已有训练数据采用seed74002、按identity/group划分的固定两fold。校准器的拟合组与检查组互斥；但原分类器已见这些数据，所以只能报告“校准器层面的交叉检查、分类器训练内诊断”。患者信息缺失单列，不升级成患者独立。
3. 旧类漂移使用同一批目标类图像在相邻两个冻结encoder下的成对分数差；当前任务common global displacement在相同全局坐标中重建并扣除。保持local_transport的原W/R条件，不把不同维度区域位移直接减到全局特征上。
4. 保存计数、均值、[W,ray]投影下46维配对残差二阶矩和阶段/类/边界来源；四步长通过同一冻结ray的量化映射计算。旧特征和逐样本分数在任务内使用后丢弃，矩阵/原样本引用留NAS私有。只公开匿名计数/标量。
5. 比较预测与实际训练内救回/破坏、旧类内部混淆、供体误差、各步长排序，以及哪些收益在按组检查后不稳定。分析独立于val，不把训练内观察用于填充RISK的independent=true字段。

这是单次信息获取方案：候选共享同一特征批，不为四个候选重抽四次；旧类配对需要额外旧训练图像访问（纯推理诊断，不是optimizer回放），这仍属于新权限，当前没有执行授权。若未来仍禁止访问旧训练图像，就无法直接识别旧类真实漂移，只能保留当前类转移代理及其未知项。

旧common shift向量没有被原控制完整保存时，还需相邻encoder对当前新类的成对抽取来重建它，不能只看shift_norm。预计曝光上限按原全部训练引用计算，见RESOURCE_PLAN.json；没有实测推理时间，不能据合成CPU给出GPU时长。

## 真正独立校准的两条路径及约束

**保留旧checkpoint和数值方向：**只能采用从未参与任一encoder/head/bank/方向/policy的、另行确认来源与单位独立的train-only校准池。已有冻结协议未声明这样的池；val/test/reserved不能被改名充当它。目标类真实独立新样本的n_cal与历史n_train分开记录，不能把供体样本算成目标n；v3设计辅助器的n_cal<=n_train限制需在这种来源真实存在后由新适配器明确处理，而不是隐式绕过。严格门所需大量样本目前没有得到满足，不建议为过严证书盲目收集上万稀少类样本。

**使用现有train预先永久留出：**按既有20%分组规则，在任何encoder训练/解析统计/方向/模型选择之前永久排除校准组；所有后续task和boundary refit也不得把它加入。旧类校准组只用于冻结状态下的推理/漂移观测，不参加梯度、FD、bank、teacher构造或方向拟合。此法能形成新的独立谱系，但需新控制训练，数值方向/checkpoint必然变化，不能同时声称复用当前18个原状态。20%支持仍不足以满足上述严格逐类门，故不是本次推荐的自动下一轮。

## 不自动执行的决策

当前可交付的是：证据缺口、样本量反证、最小训练内辨识方案和CPU检查。主风险门不改，不用val校准，不启动医学实验。

完成未来训练侧辨识后，若继续研发，可以单独设计“条件预测风险/排序准入”，将它与严格逐类统计证书分开，完整披露假设和不确定性。这需要用户明确授权新的准入目标，不能在本次通过放宽1%上限、降低alpha要求、虚增n或把训练内误差写成独立置信范围来达成。
