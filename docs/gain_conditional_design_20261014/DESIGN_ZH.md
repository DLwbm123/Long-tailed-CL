# GAIN 条件风险与稀少旧类边界保护 v4

状态：独立设计与合成 CPU 原型。现有数值方向和 .125/.25/.5/1 保留；0 为严格 identity。旧 RISK v3 证书文件和已交付结果不修改。本设计将未来目标明确改为条件预测风险与边界保护，不声称独立校准、分布无关保证或医学可接受的损失上限。

## OFF 错误储量与两种条件事件

每类 c 记录 n、OFF 正确数 C、错误数 E=n−C、救回 R≤E、破坏 H≤C。q=P(OFF错误|c)，r=P(ON正确|OFF错误,c)，h=P(ON错误|OFF正确,c)。无条件救回为 q r，破坏为 (1−q) h；同一个 q 同时用于两项。不能用总 n 冒充 r 的 E 个支持或 h 的 C 个支持，也不能将积分节点、供体或重复stage计作独立样本。

主 q 以固定状态的 train-only 事件计数锚定：Beta(E+.5,C+.5)。r、h 分别采用条件似然：Beta(R+.5+t r_M,E−R+.5+t(1−r_M)) 和 Beta(H+.5+t h_M,C−H+.5+t(1−h_M))，t=2 n/(n+16)。.5 是 Jeffreys 形式的固定建模选择；模型伪计数至多2，和真实支持分别报告，不宣称增加独立信息。模型 q_M 只作为失配诊断；主 q 不由供体替换。零次观察不等于零概率，E=0/C=0 的条件事件没有观察支持，先验作用与不确定性单列。

模型概率来自原联合 OFF/ON 节点并应用原新类守卫，须额外保存 OFF错误/正确概率再计算 r_M、h_M。不能只用现有无条件救回/破坏推回条件概率：旧公开摘要缺少模型 OFF错误概率。分母为0时，相应条件概率不可识别，必须保留标记；无条件零事件不能冒充可靠条件零概率。

各类使用4096固定后验模拟节点、seed1074005。同类四候选的 q 流相同；不声称 r/h 的不同 Beta 采样构成严格共享分位数耦合。一个样本化 q 同时用于救回和破坏，得到等类平均净效用的10%分位数，作为选择分数；不把各类救回最小值减破坏最大值替代这一耦合计算。跨类独立后验是计算假设，不是患者独立结论，有限模拟的排名误差须单列。

## 真实漂移与统计借用的可信度

使用当前状态直接观察的训练侧计数后，不再给这些计数加一次历史均值漂移，以免重复修正。bank到当前状态的累计残差、相邻encoder去共同位移后的配对残差分开记录，不能将后者当作完整累计误差。风险模型可以使用只读的当前训练分布，不写回原bank/head。local_transport区域位移不能被减到不同维度全局特征中。

对 P=[W,ray]，配对二阶矩投影给出各分数的 RMS 敏感范围。固定 RMS 系数1，通过原联合节点、原守卫及tie规则的分数区间传播，得到 q、r、h 的条件模型敏感宽度 s_q/s_r/s_h；RMS范围不是置信区间。条件分母跨0的范围不能默认取0，必须标记不可识别并保留范围。没有正确来源的投影凭据和传播结果，主方法 NOT_READY，不能用 shift_norm 代替。

效用采用同一不利储量 q'=max(0,q−s_q)，r'=max(0,r−s_r)，h'=min(1,h+s_h)，计算 q'r'−(1−q')h'。这是给定敏感盒下的保守预测目标，不是已校准概率上界。q减少对净值单调不利，因此此角点与同一个储量约束一致。新类的 h 与敏感修正严格为0，由原新列不变和旧类max不增加守卫给出；旧类校准证据不能自动转移给新类救回。

供体始终重新以目标中心为中心，不借标签、均值、目标 q 或质量。由目标所有竞争边的 [W_c−W_j,ray_c−ray_j] 投影构造形状差异 z_b；直接配对漂移投影 RMS 相对目标边界散度给出 z_d。固定 rho=[n_d/(n_d+16)]/(1+age_d)/(1+z_b²+z_d²)。rho 是可信度评分，不是转移置信概率；缺失配对/边界凭据 rho=0。多次运输年龄与当前观察来源必须分开，不能用年龄替代漂移测量。

使用冻结供体提案权重归一化后，以 .4×weight×rho 混合目标 r_M/h_M 的条件先验；剩余权重留给目标。这是条件概率先验混合，不冒充特征分布混合或完整共轭后验。目标支持仍只有自己的 n/E/C；供体的高 n 和多供体不降低目标 q 的支持不确定性。总先验伪计数仍不超过2。目标与供体的边界相似度如何预测真实事件迁移，必须在未来报告检验，不能由CPU PASS宣称有效。

## 稀少旧类边界保护

只对每类原本 OFF 正确的训练行，计算所有竞争类 j 的正间隔 g_off=fᵀ(W_c−W_j) 和守卫后 g_on。每行侵蚀 e=max_j clip((g_off−g_on)/max(g_off,相对机器精度地板),0,1)。不只看类平均残差，不只看已经发生的破坏；完全不动的tie为0，失去tie为最大侵蚀。

冻结评分 B_c=mean(e)+sqrt(Var(e)/C)，截到[0,1]；预算 b_c=.25 n/(n+16)。所有旧类逐一检查 B_c≤b_c，n越小预算越紧，没有按HK类号或事后val结果指定保护对象。预算为工程上的相对间隔侵蚀偏好，不是1%错误率上限或临床标准。C=0时没有原正确边界可保护，单列支持缺失，不伪造计数。

本版只通过准入选择完整原候选或identity，不做类别列拼接、按真实标签的部署路由或逐图增补纠正。完整全头/判别范数和固定竞争间隔仍报告；score保护条件只用训练侧带标签统计离线选择，部署推理使用冻结候选及原新类守卫，不读取val标签。未来若需要逐图保护，将是另一个设计，不属于本版。

四候选中，仅在条件净效用>1e−12且全部旧类边界检查通过时，选择效用最高者；精确平局选较小步长。证据齐全但全拒绝为identity；缺凭据为NOT_READY且禁止生成医学sidecar，两者不混作方法负结果。首task原ray严格零，直接identity，不能给零候选加先验破坏。

## 与解析头和 local_transport 的关系

原 W、Q、R、n、pairs、encoder和native解析目标全部保持。候选必须精确为 (scale×原ray).float().double()，新列为0，旧列和保持原浮点容差。选择器不重求原头，也不将观测到的漂移写回统计。与 local_transport 的互补目标是控制其参考头附近残余旧类边界重排风险，而非第二次局部统计运输。

## 当前证据缺口与范围

已有训练侧诊断可以提供 n/C/E/R/H、配对投影矩阵的私有来源及粗略间隔变化，但不能从公开聚合重建逐行相对侵蚀的联合间隔统计，也不能补出模型 q_M和供体重居中后的条件概率。CPU原型接受严格来源的显式输入，不实现医学凭据生成器、loader、launcher或collector。

因此当前 medical_evidence_NOT_READY=true，independent_calibration_ready=false。不存在真实零更新预检或GPU启动。未来生产接线和缺失统计获取须另行授权；不能偷偷用val补齐输入。训练内证据即使齐全也仍只支持条件预测诊断。此设计受此前公开development诊断启发，新增数值按本文冻结，不按val优化；将来再次使用同一val不构成全新独立评估。
