# GAIN 联合概率与净收益准入重设计

本文件是设计与合成 CPU 验收，不是医学评价结果。现有 GAIN 已交付结果、方向提案和四个步长保留。主控制固定 local_transport；base 为机制对照。不读取医学 checkpoint、影像或 val，不启动 GPU、推理或训练，test/reserved 封存。

## 为什么替换估计和门

上一轮主 GAIN 56 个非零候选的救回下界全部为 0；方向范数非零、能量帽未激活，但最终全部 identity。该结果不能区分候选方向无效与准入界无判别力。旧联合赢家事件用 2(K−1) 个边际失败概率的并集界，下界忽略强相关；旧式 min(救回)−max(破坏) 还可能组合不同情景。三个协方差情景相加形成 envelope，先验几乎为零时也可能膨胀到近 3 倍。单样本恰零散度才判不可识别，会对浮点残差敏感。

## 保留的对象

方向仍严格调用冻结版本 d258fff32b804717ee17b81d4985f0920fbf843b 的统计借用、proposal、原解析曲率 PCG、旧类对比子空间和 native 半径 1。新 helper 复制冻结生产方向链并与原函数捕获的 ray 做位级对照。四个非零候选为 .125/.25/.5/1，继续按原 float32 量化再转 double；另保留 0 锚点。Q、R、竞争图、原头、均值、支持量不更新。修正识别规则只作用于新概率准入，不回流改变方向。

## 联合估计

把每个统计组件投影到 `[W, Δ]` 的 2K 维分数空间，K≤23，因此最大 46 维。生成固定 65536 个 IID 伪随机数值积分节点，batch4096/seed1074005；这些节点只用于概率积分，不是旧图、旧特征或训练样本。OFF/ON 使用同一节点、完整相关协方差、原新类守卫与确定性 argmax，直接累计救回、破坏及其差。不会把旧类内部边际事件当作相互独立，也不会先算两个最坏值再相减。

组件质量权重 w=组件 mass/K。条件于模型及 IID 数值节点，净值 ∈[−1,1]，使用加权分层 Hoeffding 数值半宽：sqrt(2 log(2M/α) Σw²/N)，α=.01、M=432。M=18stage×4scale×3借用情景×2估计方式；确定性组件不增加数值误差。各候选共享随机流减少比较噪声；不同组件使用不同流。它只控制数值积分误差，**不是训练统计覆盖率，也不是临床置信区间**。特征模型误差、独立患者假设均未验证。PSD 特征值在声明的浮点容差内裁剪，额外记录舍弃 trace；此近似的决策边界偏差不被 Hoeffding 覆盖。

## 统计不确定性与不可识别质量

JOINT_POINT 只积分固定 Gaussian，作为定位联合界问题的诊断。JOINT_PRED 使用共享标量 Student-t：df=n−1，scale=(n+1)/(n−1)×当前情景的 ML 协方差。OFF/ON/所有类别边界共享一次 χ² 扰动，不逐坐标拼接最坏均值和方差。n=2/3 可有无限预测方差，但类别事件概率仍有限。

该 Student-t 是固定/借用协方差形状下的**前瞻模型选择**；既有 pooled/isotropic/借用统计并不构成其完整共轭后验，不能声称精确后验、覆盖全部均值/协方差形状不确定性或更宽泛的分布鲁棒证书。三个借用情景保留原 η 和 0/.5/1 借用比例，各自评估，不求和。报告同情景中心净值与数值区间、跨情景敏感范围，并单列最坏情景上界，避免把“可能模型范围”误当最坏风险目标的区间。

n<2 始终数据不可识别；n≥2 但经验 trace≤64 eps64×max(1,||center||²) 同样拒绝可识别散度。先验可用与目标数据可识别分别记录；借用不增加 n、mass 或 ESS。不可识别旧组件贡献区间 [−mass,+mass]，新组件由原守卫得到 [0,+mass]，不能把未估计部分当 0。只有 Δ=0 时净变化精确 0。

## 净收益准入

每个候选先在**同一个情景、同一节点**计算 net=救回−破坏，再加数值半宽及未知质量区间。准入分数为三个情景 net_lower 的最小值。仅当分数 >1e−12 才选择；四步长中取下界最大者，精确平局按升序小步长。全部不过则 identity，如实记录是未知质量、数值误差、预测尾部还是估计净值造成拒绝。主选择 JOINT_PRED_SELECTED；JOINT_POINT_SELECTED 是贡献诊断，绝不按 val 切换主方法。

## 与 local_transport、解析头与新类的关系

local_transport 已决定 R 和参考头；本次仅沿原 R 的曲率方向评价同一候选，不新增协方差借用或运输、不替换原 ridge 目标。验证包括 base/LT 两个 R、原方向及四量化候选位级一致、原 bank/Q/R/pairs 不变。新概率逻辑不能使原解析头成为另一个优化解，也不据此声称方向就是净收益梯度。

原守卫固定新类列，限制 ON 的旧类最大分数不超过 OFF 旧类最大分数，因此保留原已正确新类赢家，并使新类相对旧类的间隔不减。它不能修复新新混淆，也可能阻止旧类从新类赢家中救回。后续同状态诊断必须列守卫阻止的救回及 RAW→GUARDED 的变化；现阶段不放松守卫、不调能量或步长。
