# GAIN 联合估计准备报告

设计和合成 CPU 检查已完成；当前没有新医学实验、checkpoint/val 读取或 GPU 启动，也没有医学性能结果。保留原 ray、四步长与新类守卫，仅重新设计后续概率与准入。详见 DESIGN_ZH.md、PROTOCOL_ZH.md、PROTOCOL_LOCK.json。

联合估计直接保留 OFF/ON 全类别分数相关性，救回与破坏来自同一情景、同一数值节点。新增 Gaussian 点模型与共享尺度 Student-t 预测模型两个读数；前者诊断旧并集界损失，后者为固定主准入。三个借用情景独立评估并取最小净下界，不叠加协方差、不从不同情景拼救回和破坏。单样本/零散度数据不可识别，旧类未知质量保留正负范围，先验不提高支持量。

## 工程与费用

首次 CPU 在相关重复坐标产生理论平局的 fixture 上失败，发现协方差分解舍入可破坏精确分数平局；积分器显式保持相同协方差行的相同随机噪声。该错误和私有日志保留，0医学/0GPU。第二次检查 PASS；随后代码审阅把秩阈值改为协方差相对尺度，补充分数缩放不变性与组件审计，第三次最终检查 PASS。

三次 CPU 进程驻留依次 11.042072727、10.039169033、8.386824161 秒，总计 **29.468065921秒**。最后成功 pipeline5.133128332秒包含于8.386824161驻留，不另外相加。首次失败 pipeline未单测，留null。数据准备/正式GPU/optimizer/policy均0；既有 GAIN 和其他轮成本只引用，不重收费。

## 冻结后的同状态诊断

未来另经授权后，18stage同一状态、72个固定候选，八读数 OFF/四固定候选/旧选择/JOINT_POINT选择/JOINT_PRED选择；逐stage和31类保留全量纠正、破坏、净类均衡收益、旧新混淆、AIR差距、新类间隔与守卫挡住的救回。模型与实际效果分开比较，以判断方向是否有益、估计是否排序正确及准入是否仍过弱；不能只评价被接受的头，也不能按val更换主选择。当前无生产入口或真实预检。

数值 Hoeffding半宽不等于统计置信度；Student-t只是共享协方差形状的前瞻近似，借用三情景不覆盖全部形状不确定性。极少支持可能仍迫使全部 identity，不能通过删除未知质量保证模块出手。保留这一失败可能，是本次冻结协议的一部分。
