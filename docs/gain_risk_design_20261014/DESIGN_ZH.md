## 保留的科学主体

方向仍使用固定 GAIN 作者项目内启发式及原解析算子预条件、原能量约束；不重新拟合方向，不改变其平滑、R、Q、竞争矩阵、原 readout 或编码器。固定候选为 0.125/0.25/0.5/1，另有严格零 identity。候选仍用原 float32 量化路径；选择只能返回原候选之一，不插值、不放大、不换步长。

## 1. 三种误差分别记录

数值误差：联合 OFF/ON 的同一个随机分数节点，精确施加原守卫，再计算救回与破坏。节点数65536、批4096、随机seed1074005保留。分别对救回下界事件和破坏上界事件进行单侧 KL-Chernoff 反演；不再用一个对称数值误差给零次破坏制造大于全部破坏上限的固定误差地板。

有限支持/模型误差：需要独立校准集上的匿名救回与破坏计数，模型/方向/步长必须在读取这些计数前冻结。对 n 个独立同域二元事件，以 n KL(q||p)=log(2E/alpha) 反演，得到救回频率下界和破坏频率上界。模型预测相对这些界的单侧偏差，分别成为救回高估和破坏低估罚项。alpha=.01，E=18×4候选×4模式×3情景×23类×4成分×23混合分支×2事件=3656448，固定保守分配，不根据结果调整。

以上只在独立 IID、同域条件下有事件频率解释，不是对历史医学样本的无条件保证。没有独立性、没有校准集或 n=0，误差保留1；校准支持数不得超过目标类实际支持，供体不能补足目标类样本数。n=1成分继续不识别。现有 checkpoint moments 和本轮重复development val不能提供这项独立校准，不能把 synthetic PASS 或患者独立性未知改写成已有医学证据。

漂移误差：单独保存每次运输的成对特征残差二阶矩以及适用域、统计来源、校准来源、类的运输年龄。全局特征残差先扣除已有 common global displacement；区域统计只在其原区域坐标系内扣除 local displacement，不能直接把不同维度的区域位移减到1536维全局特征上。当前风险条件已经使用各自控制的 W/ray，local_transport 的区域几何作用不再另加一项修正。当前类残差只能是转移代理，不能宣称观测到旧类真实漂移。

## 2. 旧类漂移范围

不悄悄改均值或解析头。对联合投影 P=[W,delta]，各次运输残差二阶矩 D_t 给出分数 RMS 范围：

    radius_i = sum_t sqrt(max(0, P_i^T D_t P_i))

逐次相加，不假设误差独立，不假设多次运输抵消。这个范围是模型敏感性范围，不自动是旧类置信区间；范围外概率及向旧类的转移误差需有独立依据，另外记 uncovered_upper。没有依据的旧类设置 uncovered_upper=1。不能由 shift_norm、旧类历史 n 或供体数推导一个小的 uncovered_upper。

在每个联合分数节点，构造 OFF 和 change 的分数区间，并通过守卫的区间上包络，判断真类“必然赢/可能赢”。救回下界要求 OFF 必然不赢且 ON 必然赢；破坏上界要求 OFF 可能赢且 ON 不保证赢。保留 argmax 最小索引的 tie 规则。此矩形包络可能较保守，但不会把若干选定漂移方向的敏感性值当作整个范围的最坏情形。

现有 checkpoint 没有完整转移校准凭据时，主规则会返回 identity。这是缺失证据回退，不是证实方向无效。首次任务没有旧类，候选本身为零，严格 identity 不产生不确定性罚项。

## 3. 边界可信度借用

对目标类 c，每个竞争类 j 同时使用 W_c-W_j 和 ray_c-ray_j，组成固定边界投影。供体在这个投影下的协方差形状匹配，区别于全头通用形状匹配。权重保留原 n/(n+16) 与 exp(-distance/.1)，新增按统计年龄的1/(1+age)折扣；这些都是先验选择，不是置信度。

原最大借用比例 .4、支持伪计数16、情景0/半/全保留。目标均值、类标签和成分质量始终不借用；donor 不增加目标 n。借用使用“目标经验分布与多个重新以目标中心为中心的供体形状分布的混合”，不把混合协方差直接当成混合分布。这样借用比例可以明确对应概率质量。

每个供体必须另有适用于该重新居中边界分布的转移误差上界 b_j；未知 b_j=1。借用罚项为 eta×fraction×sum(weight_j*b_j)，不能用 shape distance 直接替代 b_j。信任范围、校准统计及类支持单独报告。实际生产前仍需精确绑定 control/stage/class/candidate/estimator/scenario/source 和校准来源；当前辅助函数不实现医学凭据读取。

## 4. 净收益与稀少旧类保护

每个类分别得到救回下界 R_c 和破坏上界 H_c；分别扣除数值、有限支持/模型、漂移与借用误差。先对每类跨三情景取最坏，再等类平均 sum(R_c-H_c)/K，不能让对不同类有利的情景互相抵消。

必须同时满足：宏平均净收益下界>1e-12，且每个旧类 H_c <= .01*n_c/(n_c+16)。上限1%是本次新增、前瞻固定的工程风险偏好，不由 val 优化，不宣称医学可接受标准。所有旧类都检查；稀少类上限更紧，没有基于本轮结果硬编码HK类0/17，也没有事后确定tail分界。

identity净收益为严格0；相同正下界优先最小固定步长。不得以“平均收益为正”绕过逐类破坏约束。新类继续使用原“新列不变、旧类最大logit不增加”守卫，因此保持原本正确的新类预测。该性质不保护旧类内部混淆，也不保证所有固定竞争类归一化间隔不降。

CPU 检查覆盖两个控制的完整1536×23原解析解与原方向、候选精确量化、统计不变；不把合成高维检查当医学checkpoint或真实零更新预检。
