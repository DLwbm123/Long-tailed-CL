# 冻结四格分类头分块诊断

2026-10-18 用户授权。复用已交付 A（H+新S岭头）与 B（新增离线完整旧统计量+新S岭头），不重新拟合、不调参、不扩种子、不打开 E。混合头仅是诊断干预，仍包含 B 的新增历史信息，不是原 H 记忆预算方法，不作等预算、性能上界或已验证新方法宣称。

## 固定四格与输入

| 读出 | 旧类列 | 新类列 |
|---|---|---|
| A | A | A |
| old_B_new_A（O） | B | A |
| old_A_new_B（N） | A | B |
| B | B | B |

只拼接原列，不归一化、不加bias、不调列尺度或混合系数；固定logits=8zW。ISIC/HK各原首转移、seed74002、原类序、原Qfit/Qgate及冻结1536维float64坐标、同一零适配器归一化。两份原头的来源交付和源码提交绑定见JSON。四格在读取查询前组装封存；只允许原头、必要交付记录和随后Qfit/Qgate及A/B聚合参考。禁止所有S、H、完整统计矩、teacher、原图、E、test/reserved与其他实验输入。

两CPU角色按ISIC、HK顺序执行，各先做固定小张量工程检查。两套原头的模型/维度/有限性/零适配器必须一致；A/B查询逐类计数、正确数、错误方向复核原公开值，CE误差<1e-10。每次查询特征归一化一次，再评估4个头；原始分数与逐样本预测不公开。

## 完整报告

1. 每数据集、查询、头的全类别混淆矩阵，包含零单元格；逐类及旧/新/总体BA、macro CE、全部差值。
2. 四格全部6组两两比较，固定方向A→O、A→N、A→B、O→N、O→B、N→B；报告逐类/组救回、伤害、共同正确、共同错误、错误间转换、变化总数，以及全部非零预测转移。
3. 每类每头正确类分数、最大非正确竞争类分数、最大旧/新非正确竞争分数、相应margin与rank的min/median/mean/max；竞争类别分布及并列情况。旧/新竞争最大值均排除正确类本身。
4. 每对读出每类按all/rescued/harmed/both_correct/both_wrong分别汇总分数与margin变化、竞争者切换次数。空子集不伪造统计量，配对表保留其零计数。

令源头最大非正确竞争者为j_A，目标最大竞争者为j_B。逐样本验证：

Δmargin_actual = Δscore_true − Δscore_jA − [score_target(j_B)−score_target(j_A)]。

方括号项非负，单列报告；同时报告固定原竞争者的margin变化、最大旧/新竞争分数及margin变化。数值恒等式误差<1e-10。四格分数恒等式B−O−N+A=0；BA的同式只用来描述argmax后的非加性，不当作线性可加贡献或总体因果效应。

## 预先固定的解释边界

重点检查ISIC class4与class3，但不排除其他类别或HK。这些重点来自上一轮结果，不是事先未见数据的独立检验。比较单独替换旧列、新列及在另一块已替换时的条件效应：单独新列明显损伤支持关注新头变化；单独旧列明显损伤支持关注竞争分数；单独替换与共同替换不同提示相对分数匹配/非线性交互。必须结合完整混淆、配对伤害与margin，不以单个BA或均值判定全部样本来源，也不预设class4一定被class3吸收。

保留原新列不保证新类预测不变。混合头不保证是某个共同岭目标的解。本轮不能分离旧均值与二阶矩对B的影响，不能证明任何伤害在所有可行方法中不可避免。对O/N/B均报告原门槛（两个查询总体BA严格提高，旧/新各下降不超过1pp，数值容差沿用），门槛仅供描述，不据此选择/部署头。
