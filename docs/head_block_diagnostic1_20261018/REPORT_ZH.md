## 诊断结论与保留的负结果

O是三个非参考读出中唯一在两数据集、两查询上均通过预设描述门槛的组合。ISIC总体BA相对A在Qfit/Qgate为+0.183/+2.737pp，HK为+5.792/+0.341pp。这是冻结四格的观察，不据此将O升级为正式方法；HK Qgate的O增益还小于B的+0.598pp。

ISIC class4的正确数按A/O/N/B依次为Qfit 184/188/153/152、Qgate 175/183/133/145。仅换B新类列就分别净损失31/42个正确预测；仅换B旧类列则净增加4/8个。换入B新类列使class4正确分数均值下降0.692/0.647，而A→B最大旧竞争分数均值只变化+0.055/−0.009。当前头分块干预支持“新类列改变是class4大幅退化的重要通道”；不能将其概括为旧类竞争普遍变强。O同时增加class3与class4正确数，说明二者的净精度交换并非本轮四格中必然出现的结果。

完整混淆也不支持把class3当作唯一或主要伤害去向：A→B的class4伤害样本中，Qfit/Qgate分别有23/18个转到class0，8/5个转到class3。O仍会伤害class4的9/7个原本正确样本，分别由13/15个救回抵消。O在Qfit的class4平均margin下降但正确数增加，因此均值变化不能替代配对判别分析。

所有退化均保留：O的ISIC class0正确数在Qfit从19降至17、Qgate从19降至18；HK Qfit旧class4/9/10各少对1个，Qgate旧class3从7/8降到5/8、class5从35/40降到33/40。组级门槛通过不等于保护每个类别。HK的O在Qfit救回class13的2个样本（0/3→2/3），单此项贡献总体BA +4.444pp，占+5.792pp增益的大部；Qgate该类仍为1/3，不能宣称稳定尾类学习。N在HK Qgate则把该类从1/3降到0/3，并使总体BA下降1.853pp。

四格没有分离B内旧类均值与二阶矩的作用，BA差值也不可作线性可加归因。下面保留全部四格、六组配对、各类混淆与分数分布；其解释限于当前复用的开发查询。
