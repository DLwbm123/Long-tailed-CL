# 三个固定分类头的竞争关系诊断

## 依据与问题

上一轮配对诊断已验证仿射权重补偿，HK Qfit全399个预测不变；不重复拟合或重做该补偿审计。进一步核对历史逐类计数发现：ISIC完整岭两片BA差的98.3%来自每片仅2例的class1；HK完整岭相对均值Qgate增益的86.9%来自单样本class12。同时，HK class11两片均受损（14→7/26、12→10/26）；class13支持有28例，Qfit的0/3是查询计数，Qgate仍1/3。类平衡不等于统计可靠，现有结果不足以认定表示不可分或压缩破坏二阶结构。

因此暂不增加二次核或其他候选，优先回答均值→完整岭的收益和伤害由哪些竞争类/边界产生。三个模型均已冻结：原始均值余弦、完整岭、联合仿射岭。重点解释ISIC类0/2/4、HK类11/13，但所有类完整报告，明确重点类由先前结果选择，属于开发诊断。

## 固定输出与检查

每query同一次raw features前向用于三头。逐类count/correct/errors_to_old/new须复现仿射报告整数完全一致，CE误差<1e−10。报告每类真实类margin=s_y−max_{j≠y}s_j的min/median/mean/max；最强非真实竞争类计数及错误数；真实类排名摘要与top1/2/3计数。排名采用1+严格更高分数数目+同分且类别索引更小的数目，与torch.argmax首索引规则一致。另列真实分数并列样本和零margin样本，避免把零margin等同于正确。

均值→完整岭、均值→仿射两组配对输出每类救回/伤害/均对/均错/改变/错到另错以及真实类、原预测、新预测的汇总转移。核对总数、净正确数变化和转移分解。每类×四种正确性结果，报告两模型各自margin摘要、固定原始均值最强竞争类下的margin变化摘要、最强竞争类变化计数。后者防止两个模型各选不同竞争类后误解差值。全岭→仿射配对计数已有公开诊断，不另做新配对表或补偿重构。

所有摘要为计数或min/median/mean/max，不保存或公开个体标识、逐样本预测/logit、文件名或原始特征。中位数torch.quantile(.5)线性插值。三头分数尺度不同；margin幅度不能直接当作跨模型可比置信度、校准或因果证据。不根据margin筛样本、改阈值、调参或选择部署模型。没有成功/失败方法门槛；只有工程复现与诊断完整性检查。
