# 面向 NIH 的结构化原型方法：改造后组合的完整母体 v0

状态：**方法结构已明确，尚未冻结实验配方、实现、GPU资格或启动新实验**。这不是对现有非对称重放改loss，也不是重启旧token/Spatial/ProtoTail条件分支。来源组件经过任务化改造；新组合没有NIH效果证据，不冒称论文原方法或已具TMI创新性。先建立可复现、可消融的完整方法，再处理创新论证。

## 1. 任务目标决定怎样改，而不是按论文名字拼

NIH当前协议是长尾20类、实际10+2×5到达、患者隔离和有限历史记忆，不是每新类固定5-shot，也没有组学、分割标注或任务ID。此前结果既显示基阶段判别不足，也显示新类全seen竞争和有限记忆泛化问题。因此母体必须同时学习图像局部证据、估计尾类分布、完成统一新旧类判别。只换CE、加一个原型均值或事后融合旧分数不够。

采用三个互相依赖的主体：**固定坐标下的局部部件表示 → 可靠性校准的类条件多原型分布 → 全seen判别组合**。闭环特征生成暂作独立扩展，不在第一轮全加上。

## 2. 主体A：基阶段学习共享局部证据坐标，之后保持历史记忆有效

借鉴PDAM的部件发现、OGPCMIL的原型引导局部取证，但不假定胸片病灶是鸟类部件或拥有组学先验。

- 冻结现有ViT，保留原始patch空间与CLS。只在真实基类阶段训练共享的patch映射、竞争式局部query字典和重建decoder；用图像级类别监督约束判别，用patch-feature重建约束信息覆盖。空间位置仅作为软先验，不需要肺野/病灶标注。
- query产生一组局部描述符，而不是把所有patch先平均成一个向量。权重依据当前图像内容，不把第m个slot直接命名为某个器官或病灶，也不假定跨图slot天然语义对齐。
- 完成基阶段后冻结整个描述符生成映射，decoder不参与推理。新类学习发生在类条件原型组成与全seen判别层。

这样旧图的局部描述符、均值和方差始终处于同一坐标，不需要伪造非线性矩运输。若以后决定让映射继续变化，就必须保留足以重新提取旧表示的输入并重新计费，不能把旧统计原样当真。

## 3. 主体B：保留类内异质性，把头类知识用于方差而非吞掉尾类均值

每类保存局部描述符的少量模式、各模式患者权重、均值及对角方差，以及受硬字节限额约束的真实患者描述符。模式数受该类实际患者数限制，样本不足时退化为单模式。模式不是新增独立病例。

用实际患者数而非影像数估计可靠性。对某类/局部模式，保持其自身均值 `mu_hat = mu_empirical`，只对方差做分层收缩：

`Sigma_hat = rho_c * Sigma_empirical + (1-rho_c) * Sigma_prior + epsilon*I`。

`Sigma_prior`从已经到达且统计可靠的类获得；先验权重/收缩强度只能用训练患者估计并在val前冻结。未到达类别的特征、均值、计数不得参与早期参数选择。只借鉴DAP的可靠分布先验，不直接照搬把尾均值推向头类的校准。

查询时用带归一化项的混合分布证据，例如：

`e_c,m(x) = log sum_k pi_c,m,k * N(z_m(x); mu_c,m,k, Sigma_hat_c,m,k)`。

要保留混合权重归一化和方差体积项，防止组件更多、方差更宽或随意增加切向参考就获得不公平分数。BASIL保留均值并补充局部参考的思想可借鉴，但其max-reference会提升错误类分数；本方案不把随机切向点当真实标签或独立样本。

**兼容性改造：不对每张图做同类特征塌缩。** 若采用长尾几何均衡，只施加于可学习的全局判别类锚点或类间关系，保留每类的多个局部模式。这样不能继承FBCL原有的最优几何定理，需重新检查目标与实际效果。

## 4. 主体C：把局部证据接入统一全seen决策，不留新旧类偏移空缺

CLS提供全局判别，局部分布提供类条件证据。二者在同一训练目标中学习组合/尺度，不是从旧实验成绩挑一组分数融合。

- 全seen分类损失必须同时见到已经到达的新旧类正例，采用患者类平衡风险。当前完整数据与历史有限描述符的权限、抽样和实际曝光需明确。
- 全局余弦类锚点可接受可靠性加权的经验中心对齐；类间几何项约束判别锚点，而不是改写保存的经验分布。
- 局部证据的门控依据描述符内容和训练估计的统计可靠性。组合尺度在训练患者上学习并在val前封存，不给每阶段手工加bias，不用val找融合权重，不用test时任务ID。
- 用所有已见类别的最终完整分数做预测。冻结局部映射/旧分布不等于完整判别函数不变，也不承诺零遗忘。

CAFÉ的“生成后还要用真实数据验证用途”可以成为后续完整扩展：只允许训练患者支持集评价候选的虚拟更新收益，限定真实/合成容量，并与纯真实记忆强控制比较。第一轮不默认启用，避免额外阈值与合成误差掩盖主体是否有效。这是可改造组件，不能因旧生成路线失败就逻辑上认定所有生成机制无效，也不能借新名复活原evidence_replace配方。

## 5. 方法体量必须对应可检验的贡献

第一轮拟比较的不是弱均值头：

1. 同预训练、数据权限、患者记忆字节、更新机会的强全局判别重放；为容量差异提供匹配参数量的控制，并披露FLOPs。
2. 完整局部表示与多原型，但去掉可靠性收缩/校准：区分新表示收益与估计收益。
3. 完整母体：局部表示、多模态分布与全seen判别组成。

必要消融：相同数量的固定区域池化 vs 学习字典；一个原型 vs 多模式；不收缩 vs 训练患者估计的收缩；去掉全seen组合。采用阶段化最小消融安排，先证明主体有效再增加扩展，不把所有组合做成无边界网格。

初步内存可行性举例（**不是冻结超参**）：每患者8×128局部描述符加128全局描述符，FP32为4608B；615患者约2.83MB。若每类2×8个模式、128维均值+对角方差，另约0.33MB，加计数/权重/字典仍须精确审计。不能只报向量数、把统计或可训练参数藏在记忆预算外；真实冻结方案按同字节限额匹配强控制。

## 6. 下一步执行边界

继续补读首批机制的实验/实现细节及全量候选中的其他强相关全文，再决定最小可实施母体。当前非对称实验按冻结协议继续，结果仍独立验收交付；新母体不得作为它的中途调参或救分。所有后继继续共享12h窗口累计30GB新增存储，实验各自原钟与更严预算、真实GPU全链资格、患者隔离/test/future/val禁令、源码聚合交付保持。

不因增加模块就宣称TMI级；本阶段交付标准是完整机制、实际训练、清晰权限、强对照与可复现正向证据。
