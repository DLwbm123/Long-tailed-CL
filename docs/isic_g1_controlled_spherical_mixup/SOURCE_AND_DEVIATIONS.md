# G1 来源与偏离说明

本轮依据用户提供的 Tran 等论文附件（29页），首页标记 arXiv:2607.22931v1，2026-07-24。已读取 PDF 第7–9页的式(8)/(9)/Algorithm 1及第27页Appendix C.3；未用新版替换附件。公开版本入口：[arXiv v1](https://arxiv.org/abs/2607.22931v1)。附件SHA256：`33980d677ee90b19c7d14619041a83b37ced66fcddc7ed0f1b33d6515049455c`。PDF本身不进入公开仓库。

论文运算是同类特征凸混合后L2归一化；频次参数 α=0.6+0.4exp(-0.005N)，增强系数β=1。算法更新真实与合成的Gram及标签交叉统计。附录给出DINO正则0.01、MoCo正则0.001。G1仅借鉴这些明确运算，不将其称为恒角速度SLERP。

| 要素 | G1固定选择及来源边界 |
|---|---|
| 配额 | 每类M=N是本项目新增规定，不声称原文明确该固定配额；不枚举N²对。 |
| 配对 | PCG64随机环、两端各覆盖一次是本项目新增规定；不视为独立患者对。 |

| 固定α | B2/B3取0.6是本轮基于α_base的预先选择；不声称是论文Table 3固定α消融的已知值。 |

G1 是 GSR-inspired controlled analytic experiment，full_GSR_reproduction=false。B3−B2包含能量变化，不识别纯方向因果；数值秩阈值变化不等于真实秩增加。未对论文的理论/数值疑问作实现“修复”。

参考代码/结果：R1 `2ab2c2690953cc34128d4b702df0a4e920e54d44`；V3 `cda1b371225de3568f7f07a8fc1658ec5f03fa3d`，原 `tools/frozen_medical_v3.py`。复用R1的纯CPU指标函数及component bootstrap函数，明确将输出split标为val；未调用R1 complete/test读取入口。基线兼容测试仅执行原solve_stats函数AST，不导入其编码器模块。

工程选择：单worker、4个BLAS线程，统计和求解用既有NumPy/SciPy。合成特征只在内存中形成当前类数组并立即归约，最大类仍低于RSS预算，不将全量合成数组持久化；归约统计只在该类到达时进入学习器。保存11份去重最终状态（B1引用B0）和一个活跃状态；各阶段W与validation分数私有。没有候选、随机规则、损失、阈值或数据协议偏离。

保护：原source-only工作区不转为Git；历史含5份未提交CSV修改的工作树保持原状；新分支独立于main。未删除历史文件、未恢复定时监测。原训练缓存/清单/权重/checkpoint/预测不覆盖。
