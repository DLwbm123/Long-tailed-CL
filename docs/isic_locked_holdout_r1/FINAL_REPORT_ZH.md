## 事实、推断与未验证问题

已观察事实：以上完整矩阵、预设对比、原门槛检查、尾类和最差 seed 均来自相同 test 布局，没有按结果删除方法。K−C 是一组既有改动的系统效果；K−H 是既有方差规则对照；K−ridge 同时改变 S0 适配、特征和分类器，不能单独归因于 Gaussian 或 ridge。

仍未验证：外部队列、患者级独立性、预训练暴露、训练 seed 总体和临床有效性。295 张 val 的重复开发使用及 V2 的既有 test 暴露仍限制结论。Bootstrap 不能消除这些限制。
