# Fixed S0 features with the original replay objective

This is a separate follow-up authorized by the user's request for autonomous, evidence-based iterations after V3. V2 and V3 source, checkpoint, prediction and result artifacts remain unchanged. V3 E did not meet the agreed success criterion.

V3 E recovered current recall by 78.907 pp but reduced old recall by 48.526 pp relative to V2 C. Final synthetic replay losses were below 0.00054, and synthetic old margins favored old classes while 87.44–96.00% of real old validation images were assigned to current classes. Frozen AugReg CBRidge reached 55.497% BA, above V2 C's 41.848%. These observations motivate a feature/statistics mismatch hypothesis; they do not prove it or justify sweeping replay weights.

**F:** inherit each corresponding V2 C S0 state and its original statistics, use V3 all-seen real CE and ConCM-lite with weight 0.05, and freeze every network parameter except the existing main/few head weights and biases. This is the sole training intervention versus E. All loss terms, reductions, /3, sampling, theta, augmentation, pull/assignment terms, batchwise routing and replay statistics rules remain the same. Assignment/pull terms become constants when their parameters are frozen; no replacement loss is introduced. The pretrained trunk was already frozen; this also freezes learned adapters, pools and assigner.

Use the exact V2 manifests, 18,718 train / 295 val / 764 sealed test, actual 389.96:1, and the same 1993/1994/1995 orders. Only current-class train images arrive at each session. Three trajectories, S1 and S2, 10 epochs each: 60 new epochs and 6 final checkpoints, no S0 retraining, no early stop or best-epoch selection. AdamW retains its original two groups and settings (.0003 empty pool group, .003 head group; weight decay .01, betas .9/.999, eps 1e-8). No hyperparameter search, extra encoder, head-norm or new module.

Main comparison F−V2 C; mechanism comparison F−V3 E. Use identical sorted-ID, batch-48 seen-class validation layout and report all three heads, stages/classes, tails, old/current errors, margins and component losses. Compare real-input stream fingerprints against E. Success requires final mean BA > C, current recall at least +10 pp, old recall no worse than −5 pp, at least 2/3 paired BA/current improvements, and no added current-class zero recall at either incremental stage. A frozen reference passing numerical thresholds does not relabel V3 E as successful. New test predictions remain zero.

The server has only about 2.6 GiB free. New F checkpoints store the four mutable head tensors, original optimizer state, current class statistics, RNG/loader/synthesis states and every normal restore contract field, plus an immutable exact S0 parent reference. The full network is reconstructed from this parent, and then the same ordinary restore validation is applied. No reduced precision or lossy compression. Test wrong-parent/seed rejection, bitwise frozen-parameter equality, exact restore and next-update equivalence before launch. Retain all original parents and all new session checkpoints/resumes. The delta format is dependent on its recorded parent and must not be distributed alone as a standalone model.

Engineering runs on a disposable copy, followed by the first formal epoch as a throughput pilot. Record measured peak memory, disk, throughput, projected and actual GPU time. Up to two compatible workers if memory permits; otherwise one. No post-V3 total GPU budget cap, and no purchases/expansion. Reserve 128 MiB for new outputs plus 1 GiB spare capacity before the matrix. Use neutral launcher names. Freeze source/config before the formal pilot; integrity/numerical/storage failures preserve completed work and stop dependent launches.

This experiment tests whether stationary features help replay statistics remain relevant, not whether they eliminate augmentation, Gaussian approximation or batch-context mismatch. Repeated validation use creates adaptive selection bias; results are development evidence, not independent test generalization. After this fixed matrix, audit and publish all results before selecting another evidence-based intervention.
