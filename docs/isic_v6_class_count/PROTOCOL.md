# Task-derived old/current group-count replay coefficient

V5 G completed all three seeds and 60 epochs, with average final BA 51.017%, old recall 43.779%, and current recall 72.729%. It improved BA and current recall over V2 C in all three runs. However, old recall remained 11.056 pp below C, failing the permitted 5 pp deficit. The G−F replay-weight contrast improved old recall by 5.920 pp without an average current-recall loss. These are observed validation results; neither monotonicity nor success is assumed.

H keeps the stationary C S0 feature extractor and every other G setting, but uses the fixed rule **replay coefficient = number of old classes / number of current classes**. The immutable 4+2+2 protocol therefore gives **S1: 4/2 = 2; S2: 6/2 = 3**. This is the sole new training change. It is determined by task class counts, not by validation scores, image class frequencies, a parameter grid or an adaptive controller.

Rationale: unit weights allocate equal coefficients to the old and new class groups despite the old group containing twice/three times as many classes. The next contrast tests whether a group-count prior helps retention. It is **not** an exactly class-balanced or gradient-balanced loss: real sampling remains naturally imbalanced, and all three real loss components retain their original reductions and /3. Final G fixed-train-probe real gradients still exceeded weighted replay gradients, but these probes are local evidence, not dataset-wide proof. Synthetic approximation and main/few objective asymmetry can still limit the result.

Same locked train/val/test, actual 389.96:1, 8 classes, 4+2+2; only current-class train arrivals. S1 and S2 each run exactly 10 epochs, 60 total new epochs, six final delta checkpoints. No S0 retraining, early stop, best epoch, split change or new test inference.
