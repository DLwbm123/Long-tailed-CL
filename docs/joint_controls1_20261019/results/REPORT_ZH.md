# 联合头尺度与有效自由度控制：算法归因结果

## 主要结论

两个控制均保留收益：scale_joint与df_matched_joint最终BA均为27.333%，CLS为25.333%，净增6/300张；平均阶段分别34.058%、34.005%，比CLS高2.053和2.000个百分点。该固定算法的补充预测价值证据增强，不能仅用本次控制的基类总能量增加或更高标量有效自由度解释。但没有匹配全部特征方向、谱形状、秩与正则几何，不能把结果写成严格独有信息证明。

用户只关注算法，本轮未新增独立病例、数据集或种子，也不把独立病例作为后续动作要求。不增加病例层、相关性或其他模块。

## 冻结控制与训练审计

只使用基类10类训练Gram，CLS平均平方范数Ec=7384.408367826，patch Em=4987.066808921，s=sqrt(Ec/Em)=1.216844993882。输入为[C/sqrt(2),s*M/sqrt(2),1]，不中心化、不逐维白化。基类等类平均总特征能量精确匹配CLS；后续阶段固定s不更新，因此总能量不保证逐阶段完全一致。

## 算法含义与剩余边界

现有证据链是：768→128原投影有明显损失；768维patch单头接近CLS；联合后有小幅净收益；等基类总能量及等训练df后收益没有消失。本轮因此支持保留768维的简单联合判别头，并将patch看作当前线性算法可利用的补充表示，而不是先增加密度、病例或相关性复杂度。
排查的是两个具体替代解释：总体尺度与标量有效自由度。标量df相同不代表相同特征秩、相同谱逐方向收缩、相同参数维度或相同假设空间。结果也可能来自不同表示改善线性可读性，不能严格证明patch包含CLS完全没有的条件信息或病灶证据。
按预定规则不挑赢家：尺度头平均阶段略高于df匹配头，但两者都报告，不将这一小差值用作新的调参或自动升级理由。本轮仅验证当前固定基准的算法行为，没有启动下一轮、没有恢复监测。
