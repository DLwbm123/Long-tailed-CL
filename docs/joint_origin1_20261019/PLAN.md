# 联合收益来源及增量竞争：固定最小实验

用户授权按此前分析继续实验并每30分钟监测。只复用已有统计、query和预测，不提取图像、不新增病例、种子或数据，不加入门控/病例/相关性模块，不调DENO。

## 主要对象与两个新增对照

主要对象为上一轮df_matched_joint；scale_joint和原始joint作为描述参照，均保留，不能挑赢家。
A cls_same_block：第t阶段采用原始坐标惩罚diag(2*lambda_J*I768,lambda_J)，lambda_J固定取上一轮匹配头的训练侧系数，求解CLS+截距头。不搜索正则。
同时精确分解原df匹配联合预测：Q=G_UU+Lambda_U，P=Q^-1 G_UM，fJ=U Q^-1 B_U+(M−UP)WM，WM是原始坐标patch系数；检查分数重构最大误差<1e-8。残差非零不证明条件独有信息。
B predicted_patch_joint：仅基类训练数据拟合A=(G_UU_base+I)^-1 G_UM_base，包含受罚截距，rho=1固定；训练及验证均使用Mhat=UA，之后不更新A。
仅用基类统计令shat=sqrt(E_C/E_Mhat)，输入[C/sqrt2,shat*Mhat/sqrt2,1]；各阶段只根据训练Gram匹配CLS alpha1有效自由度（包含截距），使用上一轮同一谱阈值和df根规则。所有头/尺度/lambda拟合封存后才读取验证。新增两臂共12个阶段读出。
B并非训练时未使用patch，而是测试时不需要patch的线性替代。B差不能证明所有CLS预测器不可替代，基类映射对新类失配也是可能解释。A参照变化与patch补充项的准确率不能线性分配为因果贡献。

## 零新增训练诊断（所有九臂六阶段全部报告）

四组：由原CLS768和原patchmean768硬预测定义both_correct/CLS_only/patch_only/both_wrong，报告各臂组内正确数。硬预测择优oracle不是联合特征分类器上限。
旧类竞争分解：同一批旧类图像，计算前阶段全旧类BA、当前仅旧输出BA、当前全输出BA，检查总变化=旧类内部变化−新类竞争损失；新类夺走只能解释该评价限制下的竞争，不能当因果机制证明。
逐类出生轨迹：报告出生BA、最终BA、各阶段相对CLS优势及最终优势−出生优势，不能当独立重复或直接称为保持机制。
类别频次：仅描述，以全20类训练图像数/病例数分别排序，尾7/中6/头7，平局按类索引；固定分组只用于诊断，不进入拟合或选择。报告最终各组BA和每类计数，不能将新类当尾类。
能量：各阶段等类分布的总平方范数拆为全局均值能量、类间均值变化、类内变化；用原充分统计计算。每类总权重1，已见K类总质量K，固定lambda对应平均风险lambda/K，明确记录。
