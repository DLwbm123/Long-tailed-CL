# 联合收益来源、替代patch及增量竞争：完成报告

## 核心判断

真实patch的固定联合头收益未被两个新增对照复现：df匹配联合头最终27.333%，同块正则CLS与CLS预测patch均25.000%，原CLS25.333%。相对两个新增对照真实联合头各多7/300张。这削弱了本次同块正则和固定基类线性替代器两个解释，支持当前算法利用真实patch的样本相关修正；仍不是对一切CLS变换不可替代或严格条件信息的证明。
增量和长尾定位则得到负面/混合证据：新类竞争损失五次转移仅一次减轻、其余持平；基类10类最终净+7张，后加入10类净−1张；尾7类净−2张，中6类+5张、头7类+3张。因此当前收益更接近表示和边界补充，不能称为已解决增量竞争或长尾识别。

## 固定对照与复用范围

沿用NIH author20单标签协议、68058训练/300验证、768维冻结CLS与patch均值、seed74002、六阶段和原权重。新增两臂各六个阶段读出，无图像提取、无独立病例、无新种子/数据、不加门控/病例/相关性模块、不调DENO、不访问E/test。原七臂保存分数直接复用。
A cls_same_block：原始CLS坐标特征罚2*lambda_J、截距罚lambda_J，lambda_J取已冻结df匹配联合头。Q=G_UU+Lambda_U，P=Q^-1 G_UM，精确重构fJ=U Q^-1 B_U+(M−UP)WM。该分解是代数诊断，残差非零不证明CLS不可表达。
B predicted_patch_joint：仅基类训练统计拟合A=(G_UU_base+I)^-1 G_UM_base，包含受罚截距、rho=1固定，此后冻结。输入[C/sqrt2,shat*UA/sqrt2,1]；shat由基类训练平方范数确定，各阶段lambda只匹配CLS alpha1训练df。不看验证挑尺度/正则。B训练时使用了patch统计，测试时不需要真实patch；B失败只否定这一固定线性替代方案，可能包含基类映射对新类失配影响。
替代映射shat=1.222334526725。最终替代头lambda=0.552540435，df=537.080891，与CLS目标一致。最终same-block CLS特征罚3.074747872、截距罚1.537373936。所有头拟合封存后才打开query/历史分数。

## 权重与能量诊断

每类总权重1，K类总质量K，目标是按类风险求和加ridge，而非平均类风险加同数值ridge。原alpha1对应平均类风险正则1/K：从基类.1到最终.05。此规则各臂同阶段保持一致，但跨阶段解释需纳入；本轮没有改成按类平均或重新调参。

能量按等类混合分布分解为全局均值平方范数、类间均值变化、类内变化。均值能量大不自动说明无判别信息，较小的变化方向可能很重要。

## 下一步研究定位（未执行新轮次）

本轮加强真实patch相对当前CLS-only/替代表示的判别补充证据，但不支持把它直接命名为长尾改善或普遍增量竞争保护。最清楚的可测失败是：有用补充与仅CLS正确样本的损害并存，同时收益偏向基类及中头类。是否能用训练侧量识别这些方向并改善权衡仍未成立。
本轮没有训练门控、残差保护或任何新机制；不能利用验证四组真值来选择修正。未来若另获授权，应以当前强联合头而非128维弱基线为主要比较对象，并明确检查尾类与增量类代价。不能仅凭再多一两张正确宣告机制成立。
