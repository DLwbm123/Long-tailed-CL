## 三个问题与四个读出

1. 初始识别：逐类报告原始fit、meta和开发集的样本/身份组数、正确数、真实类排名、top3、真实类分数、最大竞争类margin分位数、错误流向与平方风险。保留全部类别，few子组只是解释重点；few不等于按训练计数后半类定义的tail。报告原型数量及样本支持，不公开原型向量。原meta已参与历史任务末refit，不能当作独立验证。
2. 同状态头部干预：保存头(saved)、不加竞争但保留原型正则的原生头(native)、当前bank重建的固定竞争头(static_pc)、当前bank和保存边权重重建的动作头(action_replay)。四种读出共用冻结编码器、bank和原型正则；native/static/action均只在既有bank上求解，不用新增提取的特征拟合头。native不是从头不加竞争训练的结果。
3. 统计运输诊断：使用历史训练图像在当前冻结编码器下的均值/完整二阶矩，与保存bank比较均值和二阶矩相对误差、保存头下的平方风险。历史图像只用于事后观察，不回流到分类头或控制器，不构成所评方法的旧图像回放。新类也作为同状态核对。该部分使用了方法运行时不可用的信息，不能算在线可用方法或独立评估。

每个split报告native/static/action相对saved的逐类helped/hurt及预测改变数，避免把净正确数当作唯一改变图像数。纯分数变化与argmax变化分别报告。

- checkpoint类别顺序与原阶段一致；编码器所有参数requires_grad=False。
- 重建动作头与保存头allclose(atol1e-6,rtol1e-5)，训练及开发预测一致；保存头的开发逐类分母和召回必须重现原报告。
