# 同一可行性问题的工程修复

首个完整模型已触发SCIP memlimit：812.206364秒，0搜索节点、0候选；本轮仍未决。完整失败记录见ATTEMPT1.json。求解后密集模型清理持续消耗CPU，写出结果后仅终止本轮worker，supervisor完整记录退出码和成本。worker驻留1700.565696秒，峰值RSS40467.199219MiB；求解器20000的内存预算并未构成操作系统RSS硬上限，这一异常不隐去。工程检查另驻留13.056614秒。

修复不改变特征、配额、无偏置函数族、自由二元选择与并列规则。令每个样本的五个非基准类得分s_ic=z_i^T w_c，用等式连接权重；竞争指示只比较两个得分变量。消去辅助得分变量即还原原约束，故是同一可行域的扩展表述。此处不作正确样本集合固定、特征降维、权重界或有限big-M。

关闭对称性处理，禁止聚合把稀疏比较重新展开为密集系数；这些是算法工程设置，不是目标调参。依据SCIP参数文档：https://www.scipopt.org/doc/html/PARAMETERS.php 。增加父进程每0.5秒检查worker RSS，超过20000MiB即终止，仅作用本轮新worker；求解器内存阈值仍为20000，不增加。日志与wait4峰值均保留，瞬时峰值可能在采样间隔超限。

结果显式写出、刷新后进程退出，由OS回收模型，避免昂贵析构；模型引用保留至退出，防止函数返回前隐式触发析构。三项小型工程求解验证矛盾标签、允许不选正确样本和三类可行见证。

工程续行使用原始启动时刻起11700秒的同一个总elapsed期限；首次所有成本、等待、修复时间均不清零。新增求解器时间最多9000秒，且两次实际求解器时间合计不超过10500秒；建模/验证另受原总期限。REPAIR_LOCK中的总时长还要与绝对原期限取最小值。仅一次紧凑表述续行，不据失败自动增加内存或反复更换设置。
