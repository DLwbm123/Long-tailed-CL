## 不能跳过的下一步

各类anchor=2normalize(各类mean)，不是一个共享头的共同anchor。真实同一个二元head方向v在多类上的loss必须使用同一个v；要同时调用这些局部记忆，v需要落在相应有效球的交集。任意两anchor距离大于2r即证明交集为空。尚未检查这个条件，也没有共享多类训练、类别增长、encoder变化/重压缩/生产budget证据。

因此下一步是独立前瞻CPU参数域兼容性审计：只重新生成同一确定性合成fixture，计算anchor几何必要条件，不重跑旧loss拟合/评价，不重读旧NAS。证明兼容或不兼容都完整交付；不会为了让局部法可用扩大半径、加anchor、加存储或放宽原门。若交集为空，需要改变表示/共享参数机制，而非直接上医学GPU。
