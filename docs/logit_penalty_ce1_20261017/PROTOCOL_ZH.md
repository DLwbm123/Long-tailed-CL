# 固定logit坐标正则的线性CE对照

## 假设及唯一改动

上一轮q396类平衡CE已收敛，却在ISIC/HK均未通过双查询规则，支持CE下降、W范数增长，ISIC新类收益伴随旧类损伤。不能据此排除所有CE读出，也不能排他断言过拟合原因。

因为实际logit系数U=8W，q396的CE(8zW)+.001/2||W||²严格等价于CE(zU)+(.001/64)/2||U||²。本轮只采用另一固定约定CE(zU)+.001/2||U||²，在原W变量中实现为CE(8zW)+.064/2||W||²。倍数64来自原冻结beta²，不由查询挑选。这是正则强度对照，上一轮实现没有bug；也不是声称CE和ridge的正则完全等效或该lambda最优。

其他设置、W变量中的初始化及优化器完全不变。仅在既有run_linear_ce_head.py中显式传入罚项系数；缺少新字段的旧协议仍按原W罚项.001。原冻结源码与结果不修改，不增其他lambda、温度或插值搜索。

## 固定数据、训练、判定

原生1536维归一化特征、零适配器、相同H+新S，ISIC2354条、HK264条。类质量1/K、类内均匀。从封存完整岭W开始，优化无偏置W，不列归一化，无retention项。来源DELIVERY三重绑定、count/DT/有限性、完整均值重构和完整岭正规方程检查同q396。

固定L-BFGS lr1、max_iter200、max_eval250、history20、strong_wolfe、tolerance_grad1e−8、tolerance_change1e−14，每正式fit closure硬上限300。终点梯度max_abs<=1e−6才标为收敛；预算终点不收敛保留并报告，不延长或重试。记录完整目标/梯度轨迹、初末支持CE与头范数。

先保存头再读取Qfit/Qgate与历史参考，两个查询均早已用于开发。完整岭为唯一主要参考：收敛且每片总体BA严格提高、旧/新BA下降均不超过1pp，两片同时满足才记该数据集通过。均值为次要参考。三个头共享查询特征，逐类准确/CE、rank/margin/Top2/3/ties、竞争者、两对逐类救回伤害全保存。两个历史基线计数精确复现，CE容差1e−10。

交付时额外从q396已发布结果比较两个CE约定的全部逐类和总体BA/CE/错误去向计数；不重新训练q396，不访问其私有模型。历史聚合比较没有逐样本配对，不能称两CE之间的救回/伤害数。原主对照仍是完整岭，不因次要改善切换判定。

禁止原旧S、teacher状态、保留E、原图和新标签；H、新S和源头合法读取。没有患者分组、独立临床或完整CL证据，不承接另一个会话的新方法路线。

## 工程检查与预算

新增自检精确验证W/U两种坐标目标相同且梯度满足链式关系gW=8gU，并验证默认旧目标不变。原有CE解析梯度、类内复制不变和二维对称解对照保留；二维解使用当前.064罚项的标量二分根。所有这些都在正式拟合前执行，不用开发查询。

两个CPU任务各900秒、总3600秒、2线程，无GPU。2正式fit+2二维工程fit，正式closure最多600加2终点梯度；工程梯度按unitclosure+3计，新增坐标检查使用解析表达式不增加反传。2完整支持矩重构，0基线重拟合或正式线性solve。共享支持2618条、查询2155条、三头logit计算6465次；两个新头32256个float64元素、258048字节。峰值工作内存与持续头存储分列，0适配器/教师/编码器/记忆更新。原数据/模型均保留，全部失败、负结果与费用公开汇总。
