## Mechanism and memory

For a class arriving now, keep at most32 image feature centers, no more than one center/patient, class-normalized patient-equal cell masses, and the maximum distance of every assigned current-class feature from its center. Greedy center selection starts closest to the patient-equal mean, then picks the farthest eligible patient's image; ties follow immutable manifest order. Every current image is assigned to its nearest retained center. Whole feature rows are retained as exemplars: this is a different memory permission/setting from the original A/B moment-only learners. The new memory is explicitly counted, private, and is not a clinical privacy guarantee. No old images are replayed; no existing static pack/cache is restored. Current-class full features are temporary RAM only and discarded after its actual stage; old raw vectors are represented only by the small sealed cover, not a full-history cache. Old covers never change when new classes arrive.

Frozen existing ImageNet ViT-B/16 encoder (FP16, TF32off, deterministic), RGB224 bicubic/antialias and .5 normalization as earlier. Features are CLS768 concat FP32 mean of196 patch768, then per-image L2. No encoder update. All arms use the SAME centers, masses, initialization, ridge, solver and fitting limits. No learned comparator, density, transport, meta-episodes, class-specific temperature or routing.

`logsumexp_j[(w_j-w_c)^T u+b_j-b_c+r*||w_j-w_c||_2]`.

This is an empirical deletion/coverage bound in the frozen coordinate system, NOT a bound on clinical population risk, unseen patients, feature drift, or accuracy. No assumption of NIH label noise.
