# 两份固定旧记忆子集上的匹配读出压力测试

## 问题和唯一扰动

三头竞争诊断显示HK旧11在Qfit被完整岭伤害7例，全部改判旧9/10；新13三例也输给旧9/10，其中两例真实类第二。尚不知道这些边界是否对有限旧记忆敏感。本轮不增加核、偏置或校正候选，只检验合法记忆稀疏化后的固定读出变化。

保留原始冻结表示、旧记忆H、全部当前新类S、seed74002/类别顺序、class-balanced目标、lambda=.001和logit scale8。唯一主改动为按每旧类H的既有顺序构造两个子集：零基索引0/2/4…为A，1/3/5…为B。n>1两份互斥且覆盖原H；n=1时唯一项在两份均保留，明确该类未扰动。对所有旧类同时操作，不根据query、特征、标签损益或类名决定保留项；无重排/重选记忆。新类支持完全不变。

每份子集都拟合原始均值余弦与完整岭，构成匹配两读出压力测试。类内权重重新均匀、类间仍等权；岭无bias、不做头列单位化。两个子集都报告，不选优、不挑某个结果继续、不将变体部署。原完整支持的两个模型从已交付artifact复用，不重新拟合。

ISIC每旧类16→8+8，H64→每份32，新S2290保留，每份总2322；HK旧类16→8+8、4→2+2、单例→两份各1，H169→每份85，新S95保留，每份总180。HK旧class1没有记忆扰动；它的最终预测仍可能因其他类别头变化而改变，不能将该类自身统计称作被检验。

## 检查和输出

先核对三个来源DELIVERY与LOCK源码/交付提交；旧H从原均值头发布根读取，原始旧S禁止。用完整合法H+新S重建类均值和二阶矩，验证单位均值头与封存头最大abs误差<1e−12、封存完整岭满足相同正规方程相对残差≤1e−7。该过程重构统计并检查来源一致性，不新解完整参考头。来源不一致停止，无替代输入。

A/B各调用既有analytic.append和analytic.ridge求完整头，并由同一批类均值归一化得到均值余弦头。记录每类原/A/B数量、单例标记、两矩阵解残差、整体二阶矩/类均值相对变化、每类均值变化与两方法头范数/头变化范数。零类均值或非有限量停止。四个诊断头保存并seal后才读取Qfit/Qgate及原仿射报告的参考聚合。

每query共享特征前向一次，评估full/A/B×均值/岭共六头。全支持参考两头的逐类count/correct/errors_to_old/new必须精确复现历史、CE误差<1e−10。全类正确数/BA/CE、margin和真实类排名摘要、最强竞争类计数、每方法full→A/full→B/A→B配对救回/伤害/改变/错到另错都报告。

主要敏感性量是每类在full/A/B任意两者预测不一致的比例，分别对两方法计算，再报告其类宏平均之差（岭−均值），每query以及all/old/new组完整列出。同时报告A/B直接不一致、两半均伤害原正确和两半均救回原错误的计数。只解释这两次固定扰动，符号不作为方法成功或部署门槛；两查询/类结果不一致时如实报告。重点HK9/10/11/13来自先前结果，全类不能省略。margin跨方法尺度不同，不当可比置信度。

## 数据边界、实现和预算

允许读取现有H和新S用于拟合，不读取原始旧S、teacher状态、E、原图或新增标签。源码不修改既有helper和参考模型。访问守卫先拒绝未seal query/ref及旧S/teacher/E；头1536×6/15 float64 finite，adapter全零且两参考一致，所有支持计数与LOCK一致。无banks复制，不改原H或S。四诊断头只存于本轮NAS私有artifact。

自检覆盖n=1/2/5/16的分组、互斥/并集/非空及单例保留，复用既有二维class-balanced ridge闭式值与同类重复样本不变性检查（每数据集2次工程小求解）。排名/配对复用上一轮已测试helper。仅新增一个诊断入口，沿用原CPU队列与发布流程。

两个CPU任务各900秒，总3600秒、2线程；4正式1536矩阵求解+4工程小矩阵求解，4均值头+4岭头拟合。两个完整参考统计重构、0完整参考头拟合。2618共享支持特征样本前向、2155共享query前向、12930模型logit样本评估；四诊断头每数据集，共129024个double、1032192字节（不含零adapter）。0梯度、adapter/teacher/encoder/memory更新，0GPU；记忆分组是诊断子集，不修改已有memory artifact。所有成本计CPU，复用成本不重计，客户端准备null。失败/超时保留且停止，不科学重试、补种子或放宽阈值。

## 解释边界

本实验同时改变旧记忆数量和组成，是固定稀疏化压力测试，不是同预算记忆选择比较，不是jackknife置信区间或统计可靠性估计。敏感不证明herding丢失二阶信息；稳定也不证明完整旧统计可靠。不能据此声称原旧数据压缩损失、患者层级/跨种子泛化或完整持续学习改进。Qfit/Qgate已用于设计，任何结果都是开发证据。该轮完成后先交付完整正负结果，再决定是否有必要的下一检验，不自动增加分组/随机划分/核或收缩搜索。
