# 两种子稳定性验证：分析与停止结论

本轮正常完成全部既定构造、训练和评估，但没有获得稳定整体BA收益的支持。四个新增场景中3个整体BA点估计为负、1个略正，所有整体差的条件95%区间都跨零。两个规模各自的两次新增重复均未满足“整体BA都为正”；这项结果不依赖逐类分类门槛，本轮逐类分类只作诊断。

ISIC两个新增种子的整体差均值−0.075000pp，范围[−0.216667,+0.066667]；HK均值−0.063333pp，范围[−0.086667,−0.040000]。这只是两次重复的描述，不计算种子总体置信区间。当前数据不支持稳定正收益，也不能依据这些跨零区间断言稳定负收益。

四个场景的旧/新组点估计都在允许的−1pp下限以内。ISIC100264的新组区间下界为−1.10pp，因此该场景的代价尚不能按冻结规则确认为可接受。其余3个新增场景的旧/新区间下界均在上限内，其中ISIC200264的新组下界恰好−1pp，依照预先规定的包含边界规则通过代价项；但整体收益区间仍跨零。

DECISIONS同时保留正收益、点估计代价、区间代价与区间收益四个布尔量，场景标签不掩盖同时存在的问题。没有把某类下降作为本轮否决条件，也没有为得到通过而改用跨种子平均值。

## 2. 原有种子在更均衡评估上的表现

原ISIC264与HK265终点没有重训，仅在同一新评估bank上作development参照。ISIC整体差为+0.366667pp，区间[−0.066667,+0.816667]；旧组+0.750000pp、新组−0.400000pp，新组区间下界−1.15pp，因此INCONCLUSIVE。原HK整体差+0.240000pp，区间[+0.086667,+0.393333]；旧组+0.315385pp、新组−0.250000pp且代价区间在上限内，故该开发场景SUPPORTED。

旧ISIC在此前稀疏长尾评估上的+1.335475pp，换到每类1000个新样本后为+0.366667pp；此前只有14个样本的回退类获得7.142857pp recall增益，现在1000个样本上为−0.2pp。这提示此前大幅BA收益受有限样本估计影响，但本轮同时改变了样本数量和具体评估样本，不能把差异唯一归因于某个因素。

原HK的正收益在当前评估仍存在，而两个新训练种子未复现正向整体差。因此当前更准确的定位是“原有训练状态存在局部收益，跨完整训练/构造随机状态的重复性未建立”。新seed同时改变数据噪声、ETF、初始化及构造状态，本轮不能拆分哪个随机来源导致变化。原有种子不进入确认性通过率，也不抵消新种子的失败。
