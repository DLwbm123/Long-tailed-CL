## 不确定性与判定

每个场景独立计算同一评估样本上moment与selected的四格正确性计数（共同正确、救回、伤害、共同错误）。类别内成对非参数bootstrap：每类按这四格经验概率Multinomial(1000,p)重采样10000次，类别等权平均形成整体/旧/新BA差分布；两侧95%百分位区间，numpy quantile(method=linear)。bootstrap种子清单见LOCK。此方法等价于对每类成对正确性样本重采样，不独立打乱两组配对。

区间是单个训练场景条件下、评估样本的不确定性；不是跨训练种子总体区间。共享评估样本不计作独立新种子；不把三个训练种子的样本合并扩大统计样本数。区间逐项报告，不声称同时95%覆盖。只以两个新增种子的点估计均值/范围及符号重复性描述训练变化，不用2个种子构造总体稳定性置信结论。

整体收益主目标：每规模两个新增种子的整体BA差均>1e-12。旧、新组允许代价均为最多1个百分点，即每场景两组差均>=−.01−1e-12。逐类下降只诊断，不进入本轮分类主门槛。

每场景标签冻结如下：若任一旧/新组点估计小于−.01−1e-12，为COST_EXCEEDS_LIMIT；否则整体差<=1e-12为NO_POSITIVE_GAIN；否则若整体95%下界>1e-12且旧/新组95%下界都>=−.01−1e-12，为SUPPORTED；其余INCONCLUSIVE。分别保留所有布尔分量，不让标签掩盖同时存在的问题。每规模两新增场景均SUPPORTED才得到初步支持；两规模均支持才联合支持。原种子不覆盖新增失败，缺失为NA，不填0、不补跑。
