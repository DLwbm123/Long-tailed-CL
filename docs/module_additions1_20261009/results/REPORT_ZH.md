## 结论与可区分的后续假设

本轮没有模块同时通过 ISIC/HK。local 仅在 ISIC 达门：BA +1.2900、tail +3.3125、forgetting -1.1168、old +1.7579、new -0.1136。HK local 为 BA +0.0133、tail 0，不能称双数据集成功。层级两数据集 BA 仅 +0.3171/+0.0264；paced 为 -0.0253/-0.0685。ISIC fusion 旧类 +4.6606、遗忘 -5.0229、tail +6.9909，但新类 -12.2727，体现保留/可塑性取舍；HK fusion BA -0.0178。

局部/层级先验确实激活（ISIC local 最终 32 列、prior delta 1.122；HK 92 列、1.714），所以 HK 近零效果不能归结为代码未执行。paced 在 ISIC 第3任务、HK 第5/6任务确实降低学习率；fusion 在所有任务末（首任务除外）确实改变 adapter。触发不是贡献证据。

HK 极少类匿名 ID 5/6/19/21 的最终验证分母分别 1/1/2/4；base、local、fusion 的这些类 recall 都为0。极小分母限制判断，不能据此宣称局部信息无效。ISIC local 部分旧类改善，表明值得对局部路径进行一次机制实验，而不是组合所有模块。

下一假设：当前局部信息仅改变全局头的二次先验，推理仍只用全局 CLS；且旧局部中心复用了全局 CLS 的共同位移。这两处近似可能使 HK 的局部判别信息不起作用。下一独立轮将比较“每区域类均衡位移运输、保留 prior-only”控制与“相同运输/先验 + 固定幅度局部 cosine 读出”候选，以分离运输修正和局部信息进入预测的效应。幅度不按 val 搜索，所有选择启动前冻结；现有 base 严格复用。

限制：四象限 CLS 池化不是 COMPOSE 原文槽位/路由/Chamfer；参数历史秩不是 PaLoRA LoRA 有效秩；batch 梯度平方不是逐样本 Fisher；名称分组不是经医学验证的层级。本轮及后续新训练 seed 都只能提供重复使用开发集上的开发证据，不是患者独立泛化或临床验证。

本轮GPU子进程驻留 19493.178 秒（5.4148 小时），其中预检、训练、评价各计一次；并行墙钟 8068.507 秒单列，不重复相加。历史 83019.614 秒，累计 102512.791 秒。
