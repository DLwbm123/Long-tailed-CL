# 局部模块第二轮：区域运输与直接读出

前轮完整结果已公开交付（ecd783f）。用户授权负结果后的自主增量研究。保持 static_pc 主体：同一 ViT/adapter、全局充分统计、竞争解析头、两 epoch、FD10、训练预算、74002 seed/split seed、shuffled order 和 fit/meta 划分。不重启 RL、不引入新数据、不回放旧图像或逐样本旧特征。医学 test/reserved 和 CIFAR 封存。

## 证据、假设与贡献对照

前轮 local 在 ISIC 通过所有开发门，HK 未通过。局部先验均激活；推理只用全局 CLS，旧局部中心运输复用全局位移。本轮检验局部通道是否因运输近似和只作为正则先验而未进入最终判别。不是完整 COMPOSE 复现。

两个新臂各跑 ISIC/HK，共4条、1288 adapter 更新、0策略更新；原匹配 base 完全复用前轮，每阶段每类 recall 已验证与更早 static_pc 相同，避免重复训练。前轮 local 作为历史运输对照，仅作为描述，不据结果选幅度。

- local_transport 控制：原局部 prior 不变，但旧局部统计使用每区域共同位移。令 L_i,r 为当前图像四象限局部向量（原 CLS 条件池化、减图像四区域均值并归一化）。δ_r = mean_c mean_{i:y_i=c}(L_after,i,r − L_before,i,r)。每 epoch 用当前 fit 的类均衡位移；任务末用当前全部训练样本，meta 按原协议加入。旧中心 m_c,r ← m_c,r + δ_r，新类中心为当前区域均值。全局 bank 仍使用原全局位移，先验 R=(I+[P,M][P,M]^T)^−1，区域权重1/2不变。控制推理保留全局解析 logits。
- local_readout 候选：训练与控制相同。s_local,c(x)=1/4 Σ_r cosine(L_x,r,m_c,r)，s_final,c=s_global,c+0.25*s_local,c。固定0.25是预注册四区域平均读出的幅度，未根据 val 拟合，不做幅度扫描。零中心依照 normalize eps 输出0，无新学习参数/支持集/旧图像。记录 local RMS 和改变预测数量；候选各阶段未加局部项的每类 recall 必须等于控制，协调器 fail-closed。

局部运输仍是当前数据驱动的共同平移近似，不证明旧类真实分布已运输正确。空间四象限固定，对视角/翻转敏感；无槽位对应或匹配。局部 cosine 可能压低新类或放大少量样本噪声，保护门保持不变。

## 冻结与评价

两数据集各一个零更新真实 readout 预检，CPU数学/工程检查。预检 PASS 后按 local_transport→local_readout 固定队列用 GPU0/1/2；4条全部 TRAINED 且更新一致才打开开发评价，不因阶段切换重启。候选/控制全局预测等价检查通过才算 COMPLETE。没有正式失败重跑，失败保留并计成本。每轮墙钟24小时，历史驻留102512.791203秒单列不重置。

两数据集各自所有门均满足才进入额外种子确认：ΔBA≥+1pp、Δtail≥−0.5pp、Δforgetting≤+1pp、Δold/new≥−1pp。单种子、旧开发集不能叫成功确认或临床有效。若候选双数据集通过，再一次预注册两个新训练 seed×两数据集×原static_pc/冻结候选8条确认，每个配对同门；不挑 seed 补成功。普通后续开发轮最多6条且先独立预注册，禁止 val 网格、放宽门或仅报告正类。

实际结束后匿名 metrics、模块标量、全类分母、审计、失败和成本完整公开 GitHub，经代理推送并核实匿名访问，保存 NAS 回执。影像/身份/权重/特征/局部中心向量/边矩阵/私有路径配置/原始日志不公开。每小时健康无变化保持安静。
