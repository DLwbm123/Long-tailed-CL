# 第八轮：只移除与原目标冲突的局部梯度

第七轮完整交付后独立预注册。加强局部监督后，ISIC/HK相对原基线最终BA−1.4269/−0.6006pp，ISIC新类−2.2727pp；局部梯度真实增强但没有净效用。既不能断言梯度冲突已被证明，也不能继续把更大梯度当成功。本轮检验一个不同机制：保留单位辅助质量和全部局部信息，只移除与原训练目标梯度负内积的分量。

## 冻结机制

保留现有ViT/adapter、全局统计与竞争解析头、FD10、四区域局部先验及共同区域运输。原目标L0包含原fit/pair/old/ridge/proximal/10FD全部项，局部Ll完全沿第七轮当前类归一化CE，温度1/系数1。每batch同一次encoder前向，分别对全部requires_grad参数求g0=∇L0和gl=∇Ll，令d=<g0,gl>。

当d<0且||g0||²>0时，gl'=gl−d/||g0||²*g0；否则gl'=gl。使用g0+gl'，原clip5/AdamW/调度/预算不变。两个梯度都None时参数grad保持None，仅一方有梯度则缺项为0。原目标为0时保留局部梯度。内积/范数累计float64，修正及相加保持参数梯度dtype；有限值和方向检查失败即停止。固定容差为dot(g0,gl')≥−1e−6*max(||g0||*||gl||,1e−12)。不存在val选幅度或新增权重/头/推理分数。

在精确算术中<g0,gl'>≥0，因此组合原始梯度对原目标的内积至少||g0||²。这只是原始梯度的代数性质；AdamW预条件、动量、权重衰减和有限步长使实际参数更新不具备此下降保证，训练损失下降也不保证开发召回/新类安全。局部特征梯度标量记录的是原Ll的梯度，不是投影后参数梯度；投影另记录参数空间冲突比例、移除量、前后内积与两种范数。投影不触发也按冻结协议评价，不强制制造触发。
