证据：前三个解析残差/条件化/平方风险保护读出都比原static_pc差；第五轮ISIC逐类训练平方风险全下降，约束不触发却仍损伤开发新类。HK约束触发但未达效果门。原局部先验ISIC有正向开发信号、HK几乎无增益。因此本轮检验局部特征的类别判别性，而不继续调整末端分数幅度。

## 数学与贡献控制

每个epoch使用原流程中当前fit及旧类中心形成的local_candidate，中心在本epoch冻结且detach。当前增强图像通过同一次encoder前向，捕获两支norm输出，得到可微四区域p。s_ic = (1/4) sum_r cosine(p_ir, center_cr)，所有已见类均为竞争类别。局部损失为 sum_i alpha_i CE(s_i, y_i)，alpha=N_fit*w_i/(K_seen*batch_n)，w沿用原静态每类单位权重。温度1、系数1冻结，不按验证集选择。此目标的尺度包含当前类数/已见类数，与原拟合样本权重一致。总损失L_original + L_local，原FD10、优化器、裁剪和每epoch原全局解析头拟合不变。

控制local_detached对p停止梯度，计算同样局部CE；候选local_supervised允许局部CE反向到同一adapter。两臂前向、损失标量、中心、数据及预算一致，只差局部梯度路径。控制每阶段类召回必须精确复现第二轮运输控制，否则fail closed。候选故意改变adapter，不能要求它的全局召回等于控制。CPU检查同值局部损失、双支局部梯度有限非零、detach后全局梯度完全一致；真实GPU预检核对同一梯度路径。无额外可训练头参数、无额外optimizer更新、无旧样本回放。

分类CE比平方分数误差更直接训练类别竞争，但当前类监督仍可能破坏旧类/新类泛化；FD10不是召回无损证明，区域运输也仍近似。本轮是可区分假设，不是承诺成功或论文复现。
