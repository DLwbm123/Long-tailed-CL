## 证据分析与下一可区分问题

没有发现工程不等价：梯度阻断控制所有阶段每类召回精确复现第二轮区域运输。新局部监督在HK仅提供微小最终增益，ISIC还略损伤已有局部先验；当前证据不支持宣称局部类别监督解决HK。局部CE的目标中心仍是同一训练图像局部均值，空间对齐和区域运输只是近似，信息质量/泛化可能受限。

本轮损失权重沿用全局拟合alpha=N_fit*w/(K_seen*B)。当前fit的每类w总和1，因此对随机batch取期望，局部CE总权重为K_current/K_seen：HK由首任务1降至末任务2/23，ISIC末任务2/8。HK候选局部特征梯度范数首任务约0.105，末任务约0.0031；这一降低还受中心/类别/样本差异影响，不能全部归因于归一化，也不能与全局adapter梯度直接比较。可独立检验辅助目标是否因seen类数归一化被系统稀释：只把辅助CE归一化分母改为K_current，使当前任务期望单位类均衡质量恒为1；全局原alpha/损失/FD10和温度不变，严格复用本轮未归一化候选作机制控制。首任务两公式一致，必须类级复现控制；后续梯度可能更强并损伤ISIC/旧类，冻结门不放宽。这是按任务结构归一化的单次机制试验，不是val幅度网格或自动挑选系数。先完成本轮公开交付，再独立协议、数学检查和源码冻结；方案描述不是启动回执。
