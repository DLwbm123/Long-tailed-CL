## 机制解释与边界

局部类别监督后的固定读出仍没有形成双数据集增益：ISIC新增读出主要损伤旧类，HK有微小贡献，但不够达到+1门。类别关系存在、读出RMS/改预测激活均不足以证明净收益。保留完整负结果，不扫描读出幅度、不挑类或seed补成功。既有局部先验/区域运输比这一组合更稳健，可作为用户另行授权的CIFAR辅助验证候选；该辅助验证不替代医学双数据集门。
