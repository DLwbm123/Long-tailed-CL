# NIH 真实数据工程试跑（2026-10-05）

用户授权按数据特性自行划分并启动。该轮用于验证真实图像上的两阶段训练、六条件可执行性及资源开销，不能作为正式类别增量方法有效性的结论。

患者划分、标签顺序、样本数、随机种子、比较条件和预算见 PROTOCOL.json。官方测试集不打开；从官方 train_val 中随机预留 10% 患者，剩余患者随机分入两个互斥训练阶段。从各阶段均匀抽取 128 张图像，验证抽取 64 张。训练池频次用于交错安排两组各七标签，阶段一开放第一组，阶段二累积开放全部十四标签；这是累积标签开放协议，不是只标注新标签的协议。所有条件使用同一划分与固定种子 74002，单条件每阶段 1 epoch、batch size 8。

按 A、R05、R01、P01、EP01、F_S 顺序串行执行，总墙钟预算 3600 秒（包含各条件初始化、训练、统计量求解和验证），独立监督进程负责到时停止本轮子进程。任何条件失败就停止，不自动重试、不自动扩大。阶段 checkpoint 可保留，批次中途不能精确恢复。进程使用中性入口，代码和数据路径经环境变量/stdin 传递。

样本保持未经阳性富集的随机抽样：第一阶段部分标签无阳性，两个训练阶段均无 Hernia 阳性，64 张验证图像中 Edema、Emphysema 和 Pleural_Thickening 无阳性。这些限制不通过重抽修饰；AP/AUROC 不可估计项为 null，并报告各标签分母，不做调阈值或模型选择。

私有图像名/患者划分表、原图、逐样本数据和 checkpoint 不公开。该目录保存不含身份信息的协议与后续结果摘要；启动不代表实验完成。
