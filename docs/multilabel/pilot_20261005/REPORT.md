## 结论与范围

本轮证明该实现能够在真实 NIH 图像上完成累积标签开放、六条件训练及验证流程。第一阶段六条件的逐标签指标完全一致；全部更新均记录一次 clip 和一次 optimizer step。随机奖励和投影均未产生足以支持方法有效性的证据。单种子、小样本结果不能用于正式优劣判断或选定最佳条件。

同一患者互斥划分、同一初始化和种子、每阶段 128 张训练图与 64 张固定验证图，阶段一开放七标签、阶段二开放全部十四标签。A 为匹配基线；F_S 在阶段一后冻结编码器，因此其第二阶段无参数更新。官方测试集未打开，阈值固定为 0.5。
