# 原生MLP隐藏特征：投影前/后固定配对

## 机制与去重

借鉴已全文核读的InnerCIL（OpenReview RoJiIFcc1v）在MLP输出投影W2合成前读取原生隐藏激活的机制。这里只测试原ViT最后一个block的一份全局CLS hidden，不迁移全层/局部attention/多view/跨阶段Fisher重选整套算法，不宣称原论文复现或TMI充分性。

现有NIH对照是最终post-norm CLS、patch均值、尺度/df、原样/校准重复、同块CLS正则及基类线性预测patch；same-block CLS对照改变的是读出正则，不是MLP fc2贡献。已确认Spatial p3未过门，不能继续调聚合阶数、后验融合或启动附条件ProtoTail。原生MLP数据依赖特征不是128维随机投影或source3弱头原型。ISIC/HK的线性CE/响应/协方差对照保留其负结果，不能当作NIH已做配对，也不能直接换名重复。

假说：冻结编码器末MLP的GELU hidden中，存在经fc2压缩/残差合成后较难线性读出的监督信号；固定基类选择后应能改善原强联合，而不是只靠新增同块支路和不同正则。两臂结果最多支持这些固定读出的可利用性，不严格证明W2零空间包含不可恢复的条件信息。

## 两个新增臂，一个原图编码pass

共享原冻结augreg ViT-B/16，最后block固定为索引11。
- native_pre：最终post-norm CLS768 + 原生mlp.act的CLS位置3072维中固定选出的768维。
- native_post：最终post-norm CLS768 + 同一MLP的fc2输出CLS768。

两臂均1536+单个受罚偏置，保持原类/患者/图像权重、基类能量缩放和逐阶段匹配CLS(alpha1)自由度。两臂均为新机制所必需，主参照直接复用df_matched_joint，scale_joint及其他旧臂全量报告，不重新编码/拟合旧对照。

原生hidden坐标只由最初10类训练统计选择一次，之后永久冻结。对每个hidden坐标，等类平均均值记mu_c，类内方差记v_c；Fisher分数为Var_c(mu_c)/mean_c(v_c)。保留固定768坐标，分数同分按原索引取早，不扫描维数/层号/正则/温度。类内方差的负值只有相对二阶矩1e-10以内可视为舍入并截0，否则资格失败；分母0且分子正记正无穷，二者0记0，不引入可调地板。原每类统计已等患者、患者内等图，不新增患者模型。

编码时形成只读原生字典[CLS768,fc2_CLS768,hidden_CLS3072,1]，按类累计float64 Gram和标签和，共4609维。先完成基类10类并封存选择，才处理后来类；部署特征选择/尺度不含未来类。保存原生充分统计供独立重建，不保存逐图训练特征/全token或重建pack。各阶段头只用已见类统计。全部12头封存后才打开300val；所有监督选择只看train。

## 数据、工程资格和核验

沿用NIH author20 train68058/val300、seed74002、10+5×2同类顺序、原Resize224/bicubic RGB .5/.5、batch64/workers0、FP16编码、TF32关闭、float64统计求解。不读test/Etest，不下载新数据，不用静态微调权重、不重启CLIP。

资格仅32训练图：确认原模型12blocks和3072/768 hidden/output尺寸、只读hooks不改模型；全CLS与历史值/逐类Gram按原2e-5门核对。fc2重构需在同一dtype/整批形状下核对，不能以更换GEMM形状造成的误差放宽原CLS门。合成小矩阵核对Fisher次序、同分、零方差、负舍入处理和显式子Gram/基类能量/df恒等式。没有资格通过前不得编码完整train或访问val指标。

独立进程从20类原生统计重算base Fisher选择、两臂所有六阶段头（Cholesky对一般解）、训练覆盖/患者隔离、df、封存时序、300图每类15图及全部指标/成对救回损害/资源/失败成本。hook位置与投影前/后含义一并核对，不把形状正确当机制正确。

## 继续门和停止条件

native_pre需同时满足：最终>=86/300、平均六阶段比旧df_matched_joint>=1pp、尾7>=22/105、后来10类>=38/150；另要求基阶段至少旧A0的66/150，以防只提高最终端点而重复早期损害。

要支持“投影前额外价值”，native_pre还须最终正确数严格高于native_post，且平均阶段BA不低于native_post。若仅post改善，或pre只在挑选分组上好，不称pre机制成功、不按val换主臂；全结果保留再提出不同假说。任一主门失败关闭这套固定迁移，不扫层、Fisher维数、M、种子、温度、融合或白化救分。不是统计显著性门，300val反复开发非独立test。
