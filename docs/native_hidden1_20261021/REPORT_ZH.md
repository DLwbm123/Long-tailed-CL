## 后继研究边界

本轮负结果显示，换成同块全局MLP支路没有稳定替代原CLS/patch互补性，且基阶段损害不能靠漂移约束解释。下一步先依据已经保存的分组与阶段分数、论文笔记和全部旧对照，定位原方法的可利用互补与损害来源，再提出不同且可证伪的假说；不为保持GPU忙而重跑已关闭路线，不以本轮结束暂停持续研究。新实验须另行冻结协议与硬守卫。
