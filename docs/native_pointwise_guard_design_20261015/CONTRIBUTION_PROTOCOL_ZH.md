# 后续贡献协议的准入条件

当前只冻结上述 CPU 算术与证伪范围，不冻结正式轨迹数/新预算，不启动实验。

候选应与 local_transport 的区域先验互补：PMT 更新旧全局/区域统计的坐标，LT 保留原区域 prior，逐点约束只限制当前训练支持上的边界伤害，不二次运输当前新类。禁止把借用的旧均值当成真实旧错误概率。

若后续满足完整生产 CPU、Wref 时序/梯度、全 fit 支持资源和非 identity 可行性、封存及真实零更新预检，才另行前瞻冻结最小主四格：复用 Core/LT，新增守卫运输单独/组合；唯一必要无守卫运输贡献对照必须匹配状态与预算。原训练数据/order/seed/每臂预算参数不变，不增加强度网格或 val 校准。当前不以旧训练结果替代未来随机轨迹，也不把合成 KKT PASS 当性能。

未来完整报告六指标/Acc/F1可用项、每类 stage n/recall、旧新混淆、救回/破坏/错误换错误及 margin、AIR差距、可行性/活跃集/判别与公共 head 范数、全部失败和费用。missing不补0，全部正零负保留，不能只报旧类改善。若仅 identity 或资源不足，公开失败而不机械启动。
