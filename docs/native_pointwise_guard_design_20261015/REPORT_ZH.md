## 算子、约束和梯度

实现独立 helper，复用原 `core1_competition.pcg/laplacians/moments` 与 Core/LT metric、proximal Woodbury。完整类二阶矩参与 competition，未退化成均值近似。小规模显式样本损失的 Hessian/线性项与算子一致，原 native 解差异 ≤3.6840e−10，Woodbury/direct 差异 ≤1.533e−15。关闭守卫逐元素精确返回原无约束输入头；这只是 helper 的关闭检查，尚非生产全参数/bank 回归。

约束每个已观察 current-fit 点的真类−所有竞争类 margin，不低于块内冻结 Wref。matrix-free 分离扫描 N×K 分数，缓存活跃逆方向，解非负 dual，检查原始可行性、dual 非负、互补与 stationarity。无 dK×dK Hessian 或全部约束张量。64 atom 上限到达或数值失败会显式报错，不静默放松或返回 identity。

## 高维与 identity 两面证据

1536×23、21旧类、Core/LT 原 metric、原 proximal/Woodbury 的高维检查均通过。但约束支持仅两个点、秩2，共44条边；压力参考由预先固定的无约束头加 .02 边方向生成，**不是医学 OFF 头**。

| 高维压力项 | Core | LT |
|---|---:|---:|
| 分离/正 dual 活跃边 | 23/23 | 23/23 |
| stationarity | 1.0491e−14 | 1.0427e−14 |
| 互补误差 | 4.5169e−19 | 5.0167e−19 |
| 非公共 head 更新范数 | .00351992 | .00352256 |
| H逆总 PCG 迭代 | 161 | 161 |
| 最大 H逆相对残差 | 1.1548e−12 | 1.1519e−12 |

每个高维例的旧 Q 张量396,361,728 bytes，23条逆方向缓存6,500,352 bytes；同大小 atom 也需存储，另有当前/全类矩、metric、工作数组和小 Gram。以上是张量计数，**不是测得进程峰值**。64条 cap 时逆方向加 atom 上界36,175,872 bytes（不含 Gram/基础矩/其他工作空间）；更大的活跃集不在已验证范围。不能由74秒 CPU 驻留估计医学全 fit 训练成本。

另一个预先声明的4维全支持压力例，把正负坐标和全部类别配对（对抗性支持，不是医学分布），48条约束中8条活跃，非公共变化仅9.3611e−17，退为判别 identity。这保留了反例：Wref 可行不等于存在有用更新；全头变化不能代替判别作用。也不能由这个构造认定所有真实高维支持必 identity。

类别排列、正交坐标、公共 logit 规范、约束 adjoint、合成 checkpoint roundtrip、非法历史/未来标签拒绝均通过。这里的 checkpoint 是内存合成 state，不是医学 checkpoint。
