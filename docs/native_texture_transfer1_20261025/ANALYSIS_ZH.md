# 为什么多轮机制没有稳定超过 Native：已有证据与独立后继

这不是“Native永远最好”的结论，也不是因为训练次数不够就应该继续加预算。更准确的观察是：**若干控制能提高最终或平均准确率，但没有一条已验收的主机制同时保住尾部、后续类和绝对门；反复替换表示／重估同一特征并未产生稳定新增诊断信息。** 当前选择保留Native并补充原始像素纹理信号，进行一次可否证的独立检验，不再扫适配器、随机投影、空间分区、损失或学习率。

## 能支持的原因

1. **基类优化的判别目标与未来类别迁移不一致。** 监督控制80相对Native75，初始42对34、后续38对41、尾7为17对28；SSF主臂初始37对34，但后续29对41、尾7为17对28。多个不同机制都表现出初始类收益与未见类／尾部收益脱节。它支持“基类特化可能牺牲可迁移性”，并不证明唯一原因是灾难性遗忘。Frame/LoRA连初始类也严重退步，不能强行纳入同一个解释。

2. **固定表示下的读出重构没有创造新的观测信号。** 四象限74、随机分区70、Native75；RP在原生表示上65对75，SSF后RP66对线性65。更复杂、更多维度并非有效信息更多。对同一描述符做确定性变换不能增加其关于标签的总体信息，但可以改善有限样本可线性分性；因此信息论不能证明这些变换必败，实际负结果才是当前不继续的依据。

3. **尾部类的复杂分布估计比均值／共享判别更脆弱。** FULL最终21、尾7为0；SHARED69、尾7为6。现有125患者纹理文献不能替代本数据的稀少患者证据；本数据某基类仅7患者，不能用图像数冒充独立患者数。协方差／密度复杂度与稀疏样本的失配是合理风险，但现有比较同时改变多个部分，不能唯一归因为logdet、体积、条件数或某个floor，不应继续调这些参数。

4. **这里很多下降并非后续SGD造成。** 多轮表示在base后永久冻结，随后仅更新全seen患者／类等质量解析系统。固定特征的充分统计量加和本身不依赖类到达顺序；新类列竞争与类别数增加仍可降低原类准确率。这不同于权重更新造成的遗忘。加“防遗忘”损失、重放或新的reference，未必作用于实际瓶颈。

5. **Native具有可解释的工程和统计优势。** 它保留大规模预训练形成的通用表示，不受只见过base标签的再次特化；全部实际到达数据参与患者等质量的联合ridge，正则解唯一、旧矩坐标固定。因此后继机制必须证明相对于这个强锚的互补，而不能依赖弱分类头、弱对照或更多拟合容量制造优势。

## 不能从现有结果推出什么

- 数值验收通过只证明实现与所冻结方程一致，不保证医学假说正确。MIL、完整score增长、masked和visual-word等没有完成科学实验的失败，仅是工程／资源／配额记录，不能拿来证明其医学机制无效。
- 尚未有病灶定位、独立新test、全量表示充分性证书或严格单因子因果诊断，不能断言Native已保留全部信息、网络只看背景、图像标签有多大噪声，或者某一物理机制就是全部失败根因。
- author20当前协议是明确single-label CSV；不把它私自改成共病或多标签任务，也不靠新增数据、换医学预训练权重改写比较。
- 反复查看同一300val已经构成开发使用，不能把小幅涨点当独立外部验证。下一轮仍只作开发筛查，门和报告口径不变。

## 选择的独立方向：保留 Native 的原始纹理互补表示

旧路线大多替换／压缩Native或重新映射同一份特征；本轮改变**可用观测信号**：Native完整1537维仿射坐标原样保留，追加原始像素中多尺度局部灰度排列的固定28维测量。没有base训练、没有新权重或数据下载、不加随机核或空间token池化，也不靠调整Native正则。

采用七级正交Haar四子带相对能量，输入为现有canonical224的RGB均值，去均值／除总体标准差。奇数边长只反射补一行／列，28维向量L2单位化后除sqrt2，追加到原Native向量；不对整体再归一化。保留Native意味着原线性函数仍可由扩展头的零纹理系数表示，但有限样本下ridge可能仍变差，**不是不退步保证**。全图纹理还可能反映设备／曝光／背景，所以不把它称作肺野或病灶特征，不声称恢复了224缩放丢失的高分辨率信息。

四臂：Native；Native＋28个灰度分位数；Native＋保留精确直方图但打乱空间排列后的同28维Haar；主Native＋真实Haar。后三臂同维度、同数据、同患者／类质量、同ridge1e-4，无融合权重搜索。主臂须通过原17门，尤其必须超过灰度控制与打乱控制。若只比Native好却不能超过保留灰度的打乱对照，不能声称捕获医学纹理结构；若尾部／后续类退步，同样失败关闭。

医学依据边界：一项[125受试者尘肺胸片研究](https://pubmed.ncbi.nlm.nih.gov/23836078/)使用肺野28个小波能量特征，支持胸片纹理可测的动机；此处仅实读其摘要与方法图注，全文访问受限，不能声称读完全方法或忠实复现。另已读[NIH14小波预处理研究](https://arxiv.org/pdf/2002.00625)方法与结果，但其随机图像划分及比例描述有问题，不把其性能当可信增益保证。本轮的保留Native、灰度／空间破坏对照和患者级协议是独立设计，是否有用由单次冻结实验决定。
