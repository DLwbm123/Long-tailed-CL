# 原生上层注意力的潜在 token 重放：实现草稿，未冻结、未启动

## 直接服务主线的问题

上一轮有限记忆风险确实受控，但主臂五次新类到达仅 0/1/0/0/0，最终后来类与尾类均不足。该证据不足以唯一归因求解器、初始化或记忆，也不支持继续收紧约束。本候选取消风险约束/功能目标，改变可学习表示与历史信息保留的位置：冻结预训练 ViT 下十层，保存该位置的完整空间 token，让原生最后两层注意力和 MLP 在真实阶段标签上继续学习。

此前 native_hidden/spatial 使用冻结网络输出或统计量，没有更新这两层原生注意力；此前静态全量微调不是六阶段持续学习。本候选不恢复这些已关闭配方、静态图片包或旧 feature cache。

## 完整机制与强对照

两臂 FROZEN_UPPER、PLASTIC_UPPER 从同一预训练最后两块和最终 LayerNorm 开始，均接同一个 CLS 与 patch 均值拼接、L2 归一、固定 scale25 余弦分类头。第一臂只学习头；主臂学习两块原生 Transformer、最终 LayerNorm 与头。使用相同实际阶段、患者记忆选择、初始化输入、类别患者均衡抽样、更新机会与 token 缓冲。

这是相同总模型容量与历史信息权限下，是否开放原生上层学习的干预；可训练参数数、反向计算和优化状态明确不同，不能称等可训练容量或等 FLOPs。冻结臂是固定预训练表示重放的控制，不另行调优；不引入随机初始化弱对照。两臂都保存 token，不让主臂额外访问旧原图。

下十块和 patch/position embedding 全冻结并 eval，输出每图 197×768 FP16 token。每类至多32患者、每患者一个不可变 token；当期所有 token 只在 RAM，阶段末释放。新头仅用实际已到达的当前患者等权表示初始化。统一全 seen 分类，不路由、蒸馏、对比、风险投影、融合或后置重拟合。主臂保留上层参数跨阶段继续学习。

这是成熟 latent replay 思想的 ViT 适配，不声称原论文忠实复现或新 TMI 贡献。参考 Pellegrini 等《Latent Replay for Real-Time Continual Learning》，arXiv:1912.01100v2，第3/4节及5.1相关讨论；未声称读完附录。原文 MobileNet/AR1*/CWR*、批归一化和记忆规则不等于本方案。冻结下层消除历史 token 的表示老化；FP16量化仍须单列误差，不能声称所有精度下与原图重放逐位相同。
