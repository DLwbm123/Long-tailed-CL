# NB-RL-A4：中间学习率的单因素开发实验

状态：方案和实现已准备，未启动 GPU。累计 GPU 预算仍待用户明确答复；不把建议值或预选项视为授权。
本方案来自 A3 完整结果，属于适应性开发，不是独立确认。原 A3 结果、协议和服务器源码保持原样。

## 证据与假设

A3 在三个顺序、两个训练种子下，C(1e-4)−A(3e-4)最终 BA 为-0.375 pp，条件区间[-1.490,+0.680]，
六个配对仅两个正向；当前类召回六个配对全部下降，均值-5.792 pp、条件区间[-8.297,-3.357]。
旧类仅增加1.431 pp。C−F_S最终BA为-0.026 pp，不能支持持续更新已有稳定净收益。
因此，不把 A2 的+2.065 pp作为已复现收益，也不继续增加奖励或直接采用强FD。

待检验假设：固定3 epoch时，1e-4的更新幅度过小，当前类学习代价超过保持收益；
中间学习率2e-4可能提供更合适的折中。这是待验证解释，不是已证明的收敛或因果结论。
只选择这一个预定中间点，不进行连续搜索，不同时修改FD、统计迁移、训练轮数或奖励。

|条件|Task2–4 FD|Task2–4 学习率|辅助奖励|
|---|---:|---:|---|
|A|10|3e-4|无|
|M|10|2e-4|无|
|F_S|冻结特征|无更新|无|

所有训练轨迹从外部 AugReg 和未训练特征模块重新开始；Task1统一CE、3e-4、3 epoch。
F_S来自对应本轮A的Task1。重新运行本轮A/F_S，避免在实现验证前混用跨轮 checkpoint 或预测。
三个类别顺序1993/1994/1995与训练种子73001/73002组成六个配对，种子角色保持解耦。
复用这些种子是为了控制本次单因素比较；它们已在A3评价，不作为新的独立复验样本。
每任务3 epoch、batch48、FP32、AdamW/余弦/clip以及其余训练、统计迁移和W_final主头全部沿用A3。
12条训练轨迹，14100次更新；6条冻结参照，总计72阶段/360逐类。禁止旧/未来fit图像和test/reserved；全状态封存后统一验证。

## 预定比较与判定

主比较M−A，冻结参照M−F_S，补充A−F_S。A3的C结果仅作历史背景，不混入本轮主配对或bootstrap。
沿用效用门槛：平均Final BA至少+1 pp，至少2/3顺序的两种子均值正向，AvgBA_inc(Task2–4)不下降。
沿用安全门槛：相对A的平均old/current至少-2 pp、tail不下降，每个配对Final BA至少-2 pp；
不得新增相对A或F_S、n>=20类的最终零召回。逐顺序×种子的old/current/tail差距全部报告。
即使通过上述门槛，也单独判断对冻结模型是否存在稳定净收益，不把一个最高均值当作成功。
2000次共享类别/身份component bootstrap、seed64201，仅估计固定模型条件区间；保留全部正负结果，不将训练种子当作独立患者。
若该唯一中间点仍无净收益，后续优先分析表示与统计迁移接口，不自动添加更多学习率点。
