# NB-RL-A5：强蒸馏基线上的采样奖励

本轮为用户要求继续测试 RL 后的单轮开发性实验。A4 未启动；不恢复自动监测或后续轮次。唯一主要比较 R−A，所有正负结果均交付。

四组 A/G/R/E：共同 FD=10、学习率 3e-4、3 epoch、batch48、FP32；Task1 完全相同的 CE 训练，不更新奖励尺度或动作 RNG。从 Task2 开始，A 无奖励；G 仅准确率奖励；R 为准确率加 0.5 保持奖励；E 为与 R 相同奖励的精确期望。奖励项外系数固定 0.5，八次独立分类动作采样、leave-one-out baseline、sigma EMA=.999、下限 .05。保持奖励 exp(-20 relu(log p-log q)) 使用当前图像与冻结任务起点教师，奖励 stop-gradient。该量是保持代理，不能视为真实旧类性能奖励。

A1 奖励梯度偏小，本轮预先选择单一 0.5 系数，不做系数搜索；因此不得把与 A1 的跨轮变化单独归因于 FD。E 与 R 同系数，使采样对照公平。该实现是分类 contextual bandit 辅助目标，不是生成式长程 RL 或原论文复现。

顺序 1993/1994/1995，训练随机种子统一 74001；四组配对初始化、批次和增强。新预训练起点重新训练，不能加载历史训练 checkpoint。12 条训练轨迹 14100 更新；F_S 从本轮 A 的 Task1 冻结得到，3 条参照；60 阶段、300 逐类行。冻结参照用于判断学习是否带来净收益。

主头仅 W_final。R−A 最终 BA 至少 +1 pp、至少 2/3 顺序正向且 AvgBA_inc 不下降为效用门槛；安全要求 old/current 不低于 -2 pp、tail 不下降、各顺序 BA 不低于 -2 pp，且不能新增相对 A 或 F_S 的 n>=20 最终零召回。净收益还要求 R−F_S 均值>0 且至少2/3顺序正向。采样证据要求 R−E >=.5 pp、至少2/3正向且条件区间下界>0；保持项证据要求 R−G >=.5 pp、至少2/3正向且 current/tail 不下降。这些只支持开发性证据，不能证明独立泛化或顶会水平。

沿用类别/身份 component 配对 bootstrap 2000 次、seed64201；区间条件于三个固定顺序和单一训练种子，不替代多训练种子或独立数据验证。所有逐顺序、逐类分母、零召回、梯度、奖励、混淆流向及头重拟合诊断保留。

只读当前任务训练图像；全部训练与冻结状态封存后统一验证。禁用旧/未来训练图像和 test/reserved。GPU0/2/3；16墙钟小时、累计16 GPU小时、16GiB含备份；工程至多2.5小时和180更新，计划32更新；12.5小时停止训练、14.5小时停止图像前向。T0 固定为本次用户请求时间。预算预测使用实测进程驻留及1.3余量，不通过则不启动冻结矩阵，不缩减矩阵凑预算。
