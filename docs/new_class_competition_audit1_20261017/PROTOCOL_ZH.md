# 固定端点的新类训练支持与类别竞争诊断

依据[总质量匹配结果](../real_retention_mass_control1_20261017/REPORT_ZH.md)（交付 `7448dec`），ISIC 在总质量匹配后仍通过，HK 新类损失保持。继续试系数的信息价值有限。本轮不改变模型，固定原 MM 与未缩放 HH，检查新类损失发生在哪里；全部分析均是开发诊断。

## 固定输入与主要诊断

仅使用已封存的原 baseline/MM 和上一轮 herding/HH 两个端点，不使用随机记忆或质量缩放端点，不重训、不选模型。每数据集检查原 S_new、Qfit、Qgate 中的新类样本；查询旧类样本虽在原缓存中，但本轮不推理它们。

新类数量固定为 ISIC S_new=2290、Qfit=299、Qgate=290；HK 为 95、11、11。两模型合计 5992 个样本推理。原始图像、旧 S、E 和保留测试集禁止读取；无新标签。

主要诊断是三个角色上的 HH−MM 新类宏召回率变化，预先分别标记是否下降超过 1pp。若训练支持也下降，说明问题在已见支持上已存在；若训练支持未下降而查询下降，只描述为查询侧的损失，不据此断言分布漂移、患者泛化或单一因果机制。这里没有新候选或新的性能通过门槛，不修改此前任何结果。

## 次要诊断与限制

每个新类、角色和模型报告样本量、正确数、召回、CE、错分旧类/另一个新类数量，以及两个 logit 边际：真实类减最佳旧类、真实类减其他新类。边际只公开均值和 10/50/90 分位数，不公开逐样本记录或身份。

另报告只在新类 logits 中 argmax 的正确率，以及因此恢复的正确数。该指标使用“样本属于新类”的标签条件，属于 oracle 诊断，不能当成可部署路由器、真实分类性能或替代 BA 门槛。正确数必须不小于全类预测；原正确/错分旧类/错分新类三类计数必须穷尽样本。

同一批样本上报告 MM→HH 的三类预测状态转移表，逐新类聚合，不发布身份。所有查询的原正确数/样本数必须与已交付 HH 2×2 汇总完全一致，否则停止并报告工程异常。该检查复用同一次推理结果，不额外重跑。

## 有限运行与交付

两个 CPU 任务 ISIC_audit/HK_audit，每项 900 秒、总限 3600 秒；训练、梯度、教师、编码器、记忆更新均为零，无 GPU。运行内置三样本自检，验证旧类竞争、新类内部错误、正确预测和 oracle 计数；另检查访问边界、固定样本数和查询聚合一致性。

不读写既有模型或修改冻结协议，不搜索参数/种子、不重建记忆、不根据结果续加模型。记录实际样本推理次数、CPU 驻留/user/system/RSS 和监督器墙钟，失败与缺失均保留。累计沿用此前成本。
