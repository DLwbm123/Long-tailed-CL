# 固定对角与均值，仅恢复新类跨维协方差

## 证据和唯一问题

保留全部边际类内方差、删除全部类内跨维项后，四切片总体BA仍低于完整岭9.5711/3.9450/3.2267/9.3396pp，相对各向同性方案变化很小。类内跨维项来自旧类记忆H和新类S两个来源。本轮检验：只恢复新类跨维项，能否保留完整岭表现，或在当前协议下仍需要旧类记忆的跨维相关性。

## 唯一主要改动

K为seen总类数，G_between=μᵀμ/K。C_old=(1/K)Σ_old [mean zzᵀ−μ_c μ_cᵀ]，C_new=(1/K)Σ_new [mean zzᵀ−μ_c μ_cᵀ]，仍使用完整K归一化，不能分别按旧/新类数重归一化。

固定G_next=G_between+diag(diag(C_old))+C_new；W=(G_next+0.001I)^−1(μᵀ/K)，评分8zW。全部均值、完整G每个对角和trace保持不变。相对完整岭仅移除旧类跨维项，相对上一轮仅恢复新类跨维项；旧类均值和边际方差仍保留，不能解释为旧记忆可删除。

无λ/强度/秩/温度/类质量/坐标旋转选择扫描，μ不额外单位化，无bias、无列归一化。此为固定机制消融，非原逐样本最小二乘等价解，非新方法；对角操作依赖既有特征坐标。

## 复用实现与工程检查

复用run_raw_ridge_head.py、analytic.append/ridge。完整支持特征只计算一次，另用其中新类部分累计S_new和μ_new；新矩阵为μᵀμ+S_new−μ_newᵀμ_new，再把对角替换为原S对角，旧bank不改。new_class_cross_covariance_only=true与之前四标志互斥，旧默认分支保留。原参考聚合来自已交付within-diagonal轮，不重跑历史。

每数据集3个二维工程矩阵解：无类内散布时解析解、复制新类样本不改变类平衡解、已知旧/新跨维协方差的闭式解，验证只保留新类跨维项且原S不变、候选不满足完整方程。共6工程+2正式矩阵解，0逐元素正式解、0梯度（含工程）。

原1536维/非空/finite/类内均匀权重/合法标签/1536×6或15头/相对残差<=1e−7检查保留。旧类边际方差必须有限非负，不裁剪、不改λ/回退或自动重跑。支持拟合并保存封存后才允许query/ref访问。
