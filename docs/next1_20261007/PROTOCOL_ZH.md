# NEXT1：训练预算与表示保持的瓶颈诊断

状态：实验计划，未执行。本文件不代表新增训练已获授权；不得自动续用上一周期已耗尽的正式轨迹名额。

## 1. 目标与基本判断

本轮不增加 RL 奖励版本，不增加原型正则强度搜索，不增加图融合或新 backbone。先回答三个问题：

1. 保持 Task 1 完全一致后，把后续训练机会从大任务转给小任务，是否改善最终性能？
2. 分类目标按类平衡、特征保持却按图像频数加权，是否造成不必要的学习—保持冲突？
3. 在同一个闭式头和数据协议下，Task 1 后继续适配是否真的优于冻结表示？

这些是实验假设，不是已经成立的根因。更多小任务更新可能过拟合；类平衡 FD 可能更强地限制尾类；冻结可能降低新类学习能力。负结果同样有信息量。

### 4.2 工程验收

应核验：旧原生路径不变；统一 FD 的常数损失尺度正确；采样与权重索引一致；两块步数和学习率更新次数正确；新增循环拥有不同但可复现的增强；跨臂诊断不扰动训练 RNG；任务边界状态可恢复；F 臂所有编码器权重和缓冲区保持不变。

若原生 R 的配置、数据或计算路径发生非预期变化，停止其它臂先审计。若仅为有记录的硬件/数值非确定性，不反复追逐历史 56.8150%；使用本轮 R 作所有本轮比较的基线，并清楚报告偏差。

### 5.1 共享 Task 1 前缀

优先在本轮 R 任务 1 结束时保存完整任务边界状态，作为 F/U/CB/UCB 的公共起点。包括完整编码器权重和缓冲区、适配器、头、统计 bank、seen 标签、配置和 RNG 状态；任务入口优化器按原实现重置。

### 5.2 U 的步数与取样

保留 T1 的 276 次更新；后续总量固定为 200，按三个任务分配为 66、66、68。

两块分别为：T1 138/138，T2 33/33，T3 33/33，T4 34/34。R/CB 对应 T2 17/17、T3 4/4、T4 79/79。

保持按图像均匀打乱，不引入类别平衡 sampler。每块耗尽当前 fit 数据后，以新随机排列进入新 cycle，直到达到该块指定更新数。尾 batch 保留；每次循环使用新的、可复现的增强。每个块第一个 cycle 兼容旧增强种子，后续 cycle 加入独立循环编号。不要重播同一批增强张量。

循环次数不触发额外 canonical 提取、头全量重拟合或搬运刷新；这些仍按两个块和任务末的原时点执行。

记录 SGD 总抽样次数、唯一图像/身份组覆盖、每类重复次数、实际 batch 大小及 GPU 成本。“总更新数相同”不宣传为“总图像数/FLOPs/GPU 时间完全相同”。U 的干预是训练机会重分配，不是仅对 T3 凭空增加计算；T4 的少训练及其风险必须报告。

### 5.3 CB 的唯一改动

令当前任务 K=2 个类别，当前 fit 总数为 N，类别 c 的 fit 图像数为 n_c，样本特征保持损失 d_i=||z_i-z_i_teacher||^2。

原 FD：

    FD_nat = (1/b) * sum_i d_i

新 FD（按当前均匀图像采样）：

    FD_cb = (1/b) * sum_i [N/(K*n_{y_i})] * d_i

这是当前类宏平均 FD 的无偏小批量估计；外部系数仍为 10。n_c 是整份当前 fit 的计数，不是 batch 内计数。不要只对 batch 中出现的类别归一化，不做自归一化权重，不再改分类损失或采样器。

U/CB/UCB 仍保留原来的分类损失权重和闭式拟合过程。CB 与 UCB 不引入类自适应超参数。

### 5.4 F 的冻结定义

Task 1 后停止所有编码器/适配器参数更新及可变缓冲区更新；仍在各任务到达时提取全部当前 train 特征，追加均匀类统计，并求解同一个 gamma=0 分类头。

固定编码器不搬运旧统计（delta=0），不冻结分类头，不使用未来任务图像。逐任务审计完整特征映射状态哈希。F 是冻结表示参照，不宣称具有新的方法创新。

## 6. 随主实验记录的机制诊断

所有主臂、所有任务边界均按预先冻结的字段记录；训练中的诊断不得改变损失、学习率、步数或 checkpoint 选择。

### 6.1 学习与保持分开

每类记录：首次任务完成时召回、最终召回、后续下降、正式遗忘；尤其检查 U 是否提升类别 5/7 的初始学习，以及是否牺牲 T4 新类或更早旧类。

训练日志记录每类 fit 损失、当前 meta 诊断损失和间隙。meta 仅是未用于 adapter SGD 的训练来源切片，不是独立验证集。

每个 T2-T4 训练块的首/末 batch 额外记录 g_fit 与 10*g_FD 的范数、夹角余弦和该 batch 类别组成。不根据诊断自动调权；额外反向开销计入诊断预算。

### 6.2 搬运假设检查

仅在数据仍为当前任务时，使用任务入口教师与当前模型的成对 canonical 特征。用 fit 估计实际共同平移 delta_fit，在当前 meta 上计算类宏平均：

    E0 = mean_c mean_{i in meta_c} ||z_after_i-z_before_i||^2
    Eshift = mean_c mean_{i in meta_c} ||z_after_i-z_before_i-delta_fit||^2

输出原始 E0、Eshift 及在 E0 足够非零时的比值。Eshift<E0 表示该平移在这个当前类切片上解释了一部分变化，不能升级为真实旧类保护证明。

额外输出各当前类协方差变化、投影到任务入口旧头方向上的残差、fit 类 a 估计平移迁移到 meta 类 b 的双向检查。T1 没有旧头的相应字段记 NA；F 的近零变化避免除零制造好结果。

不读取过去任务训练图像来补诊断，不存旧逐样本特征。成对当前特征只在任务内使用，任务结束删除，只保存允许的聚合统计。这些诊断不拟合新的实际搬运模型。

## 7. 对比、筛查和停止规则

### 7.1 预先指定的机制对比

- U-R：后续更新重分配的作用。
- CB-R：原始更新预算下，类平衡 FD 的作用。
- UCB-U：重分配更新预算下，类平衡 FD 的作用。
- UCB-CB：类平衡 FD 下，更新重分配的作用。
- (UCB-U)-(CB-R)：两个改动的交互。
- F-R：同一个 Task 1 起点后，持续适配相对冻结的净收益。

不把历史其它训练路径的 BA 当作本轮单模块对照。机制支持需要与预期的逐类首次学习/遗忘或梯度变化一致，不能只用最终 BA 推断机制。

### 7.2 效果初筛

主实验全部结束后统一打开本轮官方 val 评估，禁止途中查看 val 结果选择臂或改变配置。沿用原有三条件，全部以本轮 R 为匹配基线、单位为百分点：

    delta_final_BA >= +1.0
    delta_tail_recall >= -0.5
    delta_forgetting <= +1.0

三个条件全部满足才是通过初筛。历史 56.8150% 只用于复核，不取代本轮 R。

没有臂通过：结束本轮，不启动稳健性四条，不继续调学习率/FD 系数/更新分配，不自动转回 RL。

多个臂通过：按预先指定的简洁性顺序 F -> U -> CB -> UCB 选择一个候选确认，不按第三/第四位小数追逐最高 BA。该顺序是本轮资源分配规则，不是方法优劣的普遍排序。
