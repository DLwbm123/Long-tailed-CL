## 局部正向信号与代价

F 的尾类召回提高2.7249pp、平均正式遗忘减少3.4792pp，平均阶段BA也提高0.1110pp；但最终BA下降0.6596pp。冻结并未成为全面优胜方案。F对旧类4的最终召回提高9.7561pp，而T4新类2/1宏召回比R下降9.2244pp，说明本次保持收益伴随新类学习代价。

U使类别5首次学习召回从48.6486%（18/37）升至56.7568%（21/37），最终召回从17/37升至18/37；UCB首次升至25/37，最终19/37。类别7首次召回U没有改善（仍13/24），CB/UCB降为12/24；各臂最终均12/24。不能概括为所有小类均获益。UCB的最终BA提高0.3310pp，但未达到1pp门槛，且遗忘增加3.6539pp超出保护上限。UCB中旧类4最终正确数从20/41降至16/41；类别5从首次25/37降至最终19/37，体现早期学习提升仍会丢失。

U/UCB在T4仅训练68更新，对比R/CB158更新，当前新类2/1宏召回均下降2.1739pp。两个改动的描述性交互BA为+1.2706pp；这是单设置差分，不能称已确认协同、统计显著或独立泛化收益。
