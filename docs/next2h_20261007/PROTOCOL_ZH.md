## 1. 决策摘要

本轮仅复用 NEXT1 的冻结 Task1 编码器 F、已保存的逐阶段类统计量，以及既有 R/F checkpoint 和开发验证结果。新增神经网络参数更新为 0，不重跑 Task1，不读取旧训练图像，不回放旧逐样本训练特征。

## 5. 阶段 A：实现一致性与归因审计

### A0. 输入及闭式头审计

检查四阶段 F checkpoint 的 model/head/bank/seen、原类号与 seen 列映射、数据清单和预处理哈希。逐样本配对需要私有样本键或可证明一致的清单行顺序；不能仅凭标签数组相同就认定样本已对齐。

设 K 为已见类别数，d 为特征维度，mu_c 与 Q_c 来自当前 stage bank。原生 cf_linear 在任务边界的精确形式为：

A = (sum_c Q_c) / K + 0.001 I
B = [mu_1, ..., mu_K] / K
W = solve(A, B)
s(z) = z^T W

这里 Q 已经按类内样本权重归一化。不能再除 n_c，不能改成按 n_c 池化，也不能省略 1/K 却保留相同 ridge。任务边界不加入训练批内使用的 proximal 0.01；gamma 固定为 0。

复用原生 FP64 求解路径，并按原代码转为 FP32 头进行部署评分。预检先完成不需要新验证特征的参数/数值一致性检查；若没有缓存验证特征，逐样本预测一致性检查延后至全部新头冻结且统一特征提取完成之后，并且必须先于 C1/C2 效果评价通过。拟合残差 ||AW-B||_F / max(||B||_F, 1e-12) 应 ≤ 1e-8；重构头与原存储 FP32 头比较采用 atol=1e-6、rtol=1e-5。同一缓存特征上的原头与 C0 预测必须完全一致，并逐阶段核对原 R/F 指标及分母。

如果重提取特征导致与历史预测不一致，必须先区分样本对齐、预处理、状态恢复和浮点近并列差异。候选评价暂停；不反复重跑追逐历史数字、不自动放宽容差、不将差异默认为随机波动。不能确认基线有效时终止为 BLOCKED_BASELINE。

### A1. 旧类退化分解

对每次转换 t=2,3,4，令 O_t 为此前已见类。在同一批旧类验证样本、同一类别集合上，逐类记录：

r_prev(c)：t-1 模型在 O_t 上的召回。
r_restricted(c)：t 模型分数仅保留 O_t 后的召回。
r_all(c)：t 模型在全部已见类上的召回。

D_internal(t) = mean_{c in O_t}[r_prev(c) - r_restricted(c)]
D_competition(t) = mean_{c in O_t}[r_restricted(c) - r_all(c)]
D_total(t) = D_internal(t) + D_competition(t)

以 pp 输出，保留负 D_internal，不截断。掩码保持原 seen 列顺序和一致 tie-breaking；同一打分器下的 D_competition 不应为负。

对新类同时计算当前新类候选集内召回与全已见类召回之间的差。每个方向输出混淆分组、正确数、分母和类宏平均；不能用整体准确率代替 BA。

F 的 D_internal 可用于描述固定表示下的读出变化。R 的该项同时包含表示、统计搬运和分类头变化，不命名为“纯表示遗忘”。此分解与 max(previous)-final 标准遗忘不同，必须分开报告。

对 C1，T2 同时发生 cf_linear→NCM 的切换，不能把该次 D_internal 都解释为新增类的影响。T3/T4 才检查 NCM 在固定旧类均值下的旧类内部排序不变性。即使此排序不变，新增类仍可夺走旧样本，故不宣称“零遗忘”。

## 6. 阶段 B：固定三个读出轨迹

| 臂 | T1 | T2—T4 | 是否新候选 |
|---|---|---|---|
| F-C0 | 原 cf_linear | 原 cf_linear 重构 | 否，匹配参照 |
| F-C1 | 原 cf_linear | 欧氏最近类均值 NCM | 是 |
| F-C2 | 原 cf_linear | 类平衡固定收缩共享协方差 LDA | 是 |

R-ref 是既有持续适配 cf_linear 轨迹，只作性能比较，不在本轮重训。

### C1：欧氏 NCM

s_c(z) = z^T mu_c - 0.5 ||mu_c||^2

等价于 argmin_c ||z-mu_c||^2。沿用原 encoder 输出的逐样本归一化，但不把 mu_c 再归一化，不转成 cosine-NCM，不增加类别先验、温度或任务偏置。

C0 与 C1 同时改变了度量/头的构造与类别偏置形式。若 C1 更好，只能说“读出形式改变有效”，不能仅据此断言共享逆矩阵或无偏置头就是唯一根因。

### C2：类平衡收缩 LDA

Q_c 是非中心矩，因此先计算：

C = (1/K) sum_c (Q_c - mu_c mu_c^T)
C = (C + C^T) / 2
tau = max(trace(C)/d, 1e-12)
Sigma = 0.9 C + (0.1 + 1e-6) tau I

每类等权；本轮使用二阶中心矩形式，不添加 n/(n-1) 校正，也不按 n_c 对类协方差加权。固定收缩 rho=0.1，1e-6 项为预先规定的数值稳定项。0.1 是本次预注册的工程选择，不声称是最优值或由 NEXT1 效果推得；不扫描 0.01/0.05/0.2 等变体。

v_c = solve(Sigma, mu_c)
b_c = -0.5 mu_c^T v_c
s_c(z) = z^T v_c + b_c

使用均匀类先验。共享协方差的 log-determinant 对所有类相同，评分中无需加入。实现使用 FP64 Cholesky/线性求解，不显式求逆，头和偏置转 FP32 后与 C0/C1 采用相同推理精度。

不引入类特异协方差、FeCAM 的额外变换、Tukey、PCA、原型搬运、图模块、伪特征采样、融合或校准集拟合。本臂是受共享协方差判别启发的机制基线，不是完整 FeCAM/SLDA 复现，也不是新方法创新结论。

### 合成测试与异常处置

只在合成 CPU 数据上做：原生 ridge 求解重构、NCM 线性分数与直接距离等价、C2 在各向同性协方差下与 NCM 预测等价、标签/seen 列置换一致、矩汇总一次性与顺序累计一致、固定旧均值的 NCM 旧类两两分数差不变、掩码分解恒等式。

实物输入检查有限值、维度、正计数、类质量定义、对称性和协方差数值半正定性。允许数值舍入造成的微小负特征值：lambda_min(C) >= -1e-8 * max(||C||_2, 1e-12)；超过即判统计异常。若固定 Sigma 的 Cholesky 失败，标记 NUMERICAL_FAILURE，停止该臂，不提高 shrinkage 自动重试，不临时切换伪逆或裁剪特征值。

候选数值失败占用该候选名额；其他已锁定臂若输入没有共同异常可照原协议完成。共同 bank 或 C0 异常则全部停止。

## 8. 为什么本轮不做“换后续顺序”的确认

在同一个冻结 Task1 编码器下，三种头只依赖当前已见类的固定均值/二阶矩及确定性规则。拥有相同最终已见类时，最终读出在精确算术下与 T2—T4 到达次序无关；浮点误差和 tie-breaking 另作工程核验。

因此，仅排列 T2—T4 的任务顺序不能当作新的最终性能独立重复。它可改变阶段路径与标准遗忘，但不会自动提供新的最终 BA 证据。复用同一前缀、缓存或 bootstrap 都不能宣称“多 seed 确认”。

通过当前开发筛选后，下一周期才另立含独立 Task1 seed/匹配 R 和未参与开发的评价设计；不得沿用本轮资源余额自动启动。本协议不授权那一周期。
