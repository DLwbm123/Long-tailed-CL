## 能解释什么，不能解释什么

F1 同时冻结后续适配并取消旧bank运输，而 A 包含持续适配、FD及相应统计运输与任务末重建。该控制测量的是这组后续行为的总体效应，不能唯一归因于神经表示漂移、FD或共同平移。Task1 已精确复现，原先 Fibrosis 多1张由本侧 cuDNN TF32 设置偏差造成，不能再用于当前结果解释。

B 的82/300是另一冻结 CLS/patch 解析 learner，与 A/F1 的归一化双adapter特征、权重和推理不同；本分析不将 A/F1 与 B 的差值归因于冻结。反复使用的300图是开发评价，不是独立测试。
