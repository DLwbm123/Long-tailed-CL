# NIH比较协议核对：先建立绝对竞争力，不把静态结果冒充增量SOTA

核对日期：2026-10-20。当前未确认存在与本项目完全相同的NIH author20、六阶段10+2×5、相同顺序/骨干/回放权限的公开SOTA表。因此以下是**同数据任务的强参考**，不是可直接相减的同协议排行榜，也不是穷尽所有2026论文后的全局最高声明。

LT-Soups原文数据表中NIH总量/最大最小频数与其训练划分及本项目实际CSV部分数字不一致，需以实际数据加载代码与发布CSV核对；未核实前不声称精确复现39.3。其公开代码提供cxr8_lt配置、默认CLIP使用pre-projection 768维、CosineClassifier scale25与文本初始化；论文写AdamW lr3e-4，而默认yaml写lr.01/SGD分支，命令覆盖必须区分。本轮明确采用论文AdamW配方并完整记录差异，称强基线适配而非原论文精确复现。

原始基准使用最多60epoch并按验证早停；LT-Soups附录报NIH Full-FT约5320次更新、10epoch收敛。这里不把“60才充分”或“10必然收敛”当事实：固定训练30epoch，预先记录第10/30及验证最佳，完整学习曲线判断是否仍在改善。源论文与代码均使用val选checkpoint，本轮只按预定BA选最佳，不据此搜索新学习率；测试继续封存。

## 分层诊断与比较顺序

1. 同一预训练内部比较冻结骨干与Full-FT，在同一训练/验证、损失、分类头、增广、初始化与更新次数下量化适配作用。
2. ImageNet ViT-B/16和CLIP ViT-B/16分别做上述配对；跨预训练差值同时包含预训练目标、视觉结构细节、文本初始化和归一化差异，不能归因某一新模块。
3. 先完成静态joint20训练上界参照，确认表征/训练级竞争力；随后才设计同骨干、训练预算和回放权限明确的增量基线。静态joint可访问全20类，不是可直接对比的六阶段方法。
4. 若充分训练仍弱，优先审查表示、数据/目标适配与收敛，不再在19%冻结特征基线上扫选择器；若静态强而增量弱，再定位持续学习损失。
