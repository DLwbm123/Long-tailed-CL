# 保持原ridge旧记忆响应的正交补优化

q404在旧H空间内已充分约束收敛，ISIC Qfit仍损伤旧类2和3各一个预测，old宏下降1.167342pp，双片主门失败；HK通过开发门但新类正确数没有改善。q403事后投影则删除了大部分ISIC新收益。不能再将这些失败归结为q404未充分优化。

本轮是一个互补的几何约束对照：旧H的全部类别响应保持原ridge，在其正交补直接学习。它检验精确保留记忆响应能否改善query保留与新类学习；q402已发现空间外可以同时携带收益与伤害，因此不预设安全或成功。已有数据均是开发数据，不是新增独立证据。

## 固定操作与目标

旧H归一化特征做一次full-right SVD，使用与前轮相同的cutoff=max(H.shape)*float64eps*smax决定原H数值秩r。令N=Vh[r:].T，要求NᵀN≈I、HN≈0；旧空间Q=Vh[:r].T仍验证H重构。预计r=64/169、更新维数1472/1367，不选秩、不混合内外更新、不扫描阈值。

W=W0+NA从A=0开始，W0始终原class-balanced ridge。目标保持CE(8zW)+.064/2 Rnorm(W−W0)，p_i=1/(K*n_yi)，Rnorm=1536/(2∑p||z||²)∑_i p_i∑_j[z_i(Δw_yi−Δw_j)]²，仍使用所有H+newS与全部竞争列。正则scale仍由原z和1536决定，不归一化zN或用新维数改变目标。HN=0使旧H响应项按构造为零，新S仍约束更新；这不是完整H+newS目标的自由零空间。

沿用已有受限优化代码，以N替代旧空间Q；G=(zN)ᵀdiag(p)(zN)，L Lᵀ=G+.001I、V=LᵀA、Ztilde=zN L⁻ᵀ、固定offset=8zW0。该坐标正则不新增目标项。q404头仅在当前候选保存seal后作为次对照读取，不用于初始化或续跑。q404历史源码/结果保持。

## 预算与判定

两CPU任务，每组最多200外步、50CG/step、20Armijo回退；沿用初步长1、缩小.5、c1=1e−4，无阻尼。每组梯度目标+HVP+线搜索目标+曲率概率合计≤300，另2终点梯度。每组900秒、全轮3600秒、2线程、0GPU，无预算延长或自动重试。相同计数上限不代表与低维q404等FLOPs；报告实际CPU/RSS。

最终原W切空间梯度max|NNᵀ∇W|≤1e−6才约束收敛；内部变换梯度阈值1e−8不替代它。完整∇W另报，不宣称无约束收敛。原ridge唯一主对照，双query均BA_all严格提高且old/new各下降≤1pp，并需约束收敛才通过数据集开发主门。q404固定空间内头用于真实配对次对照，不切换主判定或剔除稀有类。

## 输入、封存与验证

同一合法支持ISIC2354/HK264，旧H原herding直接读、新S既有特征；禁止原旧S/E/teacher/raw/新增标签。centroid/ridge/q404 DELIVERY先验证；q404私有头与结果、query均在候选seal后才能访问，守卫主动测试。模型1536维double/finite/无bias/全零adapter一致，支持count和每类质量保持。

复用二维非零offset目标、解析HVP对autograd、固定二分标量根、默认offset0以及坐标恒等式自检；新增二维互补更新保持旧H响应的代数检查，不增加工程fit。正式验证N正交、HN与H重构；fit后全旧H全类别8H(W−W0)最大误差≤1e−10，更新位于N空间，原/变换目标与梯度链≤1e−10。若保持恒等式不满足即工程失败，不以小准确率差掩盖。

三头raw_ridge/frozen_constrained/constrained_response；其中frozen_constrained为q404空间内头，当前candidate为零空间头。ridge/q404逐类支持与query整数计数精确、CE在1e−10内匹配既有结果。输出所有旧新类别、margin/rank与全竞争者、两组真实配对、参考伤害修复/收益保留转换，含全部零事件；保留拟合trace/操作数/全梯度、来源与成本。

2正式fit+2二维工程fit、2次full-right SVD（不能记作thin）、2正式Cholesky/4三角solve和同数工程操作；支持特征2618/三头logit7854，query2155/三头logit6465，优化运算另计。2派生头共32256double/258048bytes；N只在内存，不新增推理模块。0encoder/adapter/teacher/memory更新、0GPU和新标签。

## 解释与停止边界

旧H响应保留是构造约束，不等于旧query保留或压缩充分性。若旧H恒等式成立而旧query受损，即为当前有限记忆响应保护不足的开发反例，不外推完整历史oracle或医学失败。若再次达到预算而未收敛，保持预算端点与失败标记，不盲换solver或延长；若没有不同且可检验的后续假设，应报告固定信息/读出路线瓶颈，不为持续运行做混合系数网格。当前会话不接管独立新方法会话。
