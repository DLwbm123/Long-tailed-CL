## 分阶段访问与封存

单个有界 CPU 队列按 unit、两次 build、两次 fit、两次 evaluate 顺序运行。每个角色独立进程，路径访问守卫先验证再读数据。

- build 唯一获准读取各自旧 S 缓存；按 A 的零适配器路径归一化，构建统计量并以新来源记录封存。禁止新 S、查询、E、原图或其他历史实验输入。统计量及构建成本记为本轮新增，不追溯记成旧阶段已保存。
- fit 禁止旧 S 和查询。只读取新统计量、同一新 S、A 头及 H；重建 A 的法方程检查相对残差<=1e-7但不重新求解。每数据集只进行一次 B 岭求解，残差同样<=1e-7，然后封存 B 头。
- evaluate 须确认两套 B 头都已封存；仅打开 Qfit/Qgate，复算 A/B 以获得配对结果。A 的逐类计数、正确数及错误方向必须与原公开聚合一致，CE误差<1e-10。查询不选头、不选参数，始终报告两臂。所有阶段禁止 E、test/reserved、旧图像、新标签和 GPU。
