类进入顺序[8, 6, 4, 3, 0, 1, 7, 2, 5]，任务3+2+2+2；尾类固定频率最后3类[3, 8, 1]，头/中/尾各3。按既有fit_split从所选train每类分20%为meta，其余fit；meta任务末进入拟合，绝不拿官方val做meta。原样本索引作为唯一identity，官方split不合并；不含患者/玻片ID，不能宣称患者隔离或临床泛化。
