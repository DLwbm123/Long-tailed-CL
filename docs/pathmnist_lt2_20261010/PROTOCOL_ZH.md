# PathMNIST分布对照：第二轮冻结协议

首轮IF100完整交付后，依用户批准的设计比较IF10、IF50与同IF100总量的平衡控制，每种分布原static_pc/local_transport新配对，共6条。保持已冻结候选，不按首轮val或CIFAR test改幅度、方法、seed或类别开关。每个分布同配对数据与预算，全部6条TRAINED、计数一致后才统一官方val评价。

复用已下载官方224 NPZ与全部val图片，不重新下载、不打开test数组。频率顺序[4,2,7,6,0,5,3,8,1]、进入顺序[8,6,4,3,0,1,7,2,5]、任务3+2+2+2、采样/训练/划分seed74002不变。IF10/50使用floor(5000*IF^(-rank/8))，相同每类随机排列前缀，无放回，因此IF100样本嵌套于IF50、IF50嵌套于IF10。平衡对照每类1262，总11358，严格等于首轮IF100总量，不是IF10/50等总量控制；必须明确该限制，IF变化同时改变总样本数。

平衡对照同一频率rank仅作为跨分布参考组：三类head/middle/tail标签分别[4,2,7]/[6,0,5]/[3,8,1]，平衡分布没有实际少样本尾类，不将参考组收益称尾类稀缺收益。所有分布val10004及每类分母原封保留；fit/meta为各所选train的80/20，meta任务末拟合，val不作meta。源仅样本索引，无患者/玻片分组证据。

主体、局部四区域先验/区域共同运输、原全局竞争头、FD10、AdamW、2epoch/batch64/workers4/lr.0003/WD.01/clip5/ridge.001/proximal.01均不改，无局部CE、附加读出、新学习头或旧影像/逐样本回放。每分布更新与训练数量精确见PROTOCOL_LOCK，更新差异由样本数与固定2epoch产生；不能称三个分布等更新预算。6个真实零更新预检全PASS再正式训练，只GPU0/1，GPU2/3禁止。无超参网格/重选seed/自动正式失败重跑。数据准备和排队计入独立24小时截止，历史成本不重置；6preflight+6train+6evaluate为18条正常GPU子进程费用，不按job/operation去重，CPU准备和并行墙钟另列。
