# PCRL2 结案报告：固定动作可复现旧 RL，改版未带来提升

四条新增正式轨迹及其评估于2026-10-07 21:37:03（上海）全部完成，无运行失败。唯一候选 RL_RESPONSE 初筛失败；本轮停止，未开启新种子、模块消融或 HyperKvasir 迁移。所有指标来自反复使用的开发 val，不是独立测试确认。

最直接的结论是：固定动作1与旧RL在四个阶段的所有预测完全一致；完整改版虽然有一次动作变化，最终却比固定动作多错一张。当前设置没有支持额外RL模块的收益。

完整改版与FIXED1在T1、T2预测一致；T3有一张不同但双方均答错；T4仅一张由正确变错误，class3召回由18/40变17/40，对8类macro BA恰为−0.3125pp。RESPONSE0在T3比固定动作多答对两张，平均BA +0.177581pp，但最终295张预测又全部相同；它更高的遗忘来自更高的历史召回，不是更低的最终召回。

## 为什么仍然偏向同一动作

旧RL的全局状态相似及重复采样确实存在，但本轮显示，仅将状态换成共享的动作响应仍不足：RL_SHARED仍16/16选动作1。不能继续将全部问题归因于旧的7×13动作专属参数。

|控制器|动作次数|额外策略更新|重复采样（共64）|
|---|---|---:|---:|
|RESPONSE0|1: 12, 0: 2, 4: 2|0|11|
|RL_SHARED|1: 16|32|11|
|RL_RESPONSE|1: 15, 4: 1|32|15|

可直接追溯的决策反例在第5、6次：解析预测均认为动作0最好（所有非零动作预测奖励为负）。纯解析RESPONSE0选择0；完整RL的历史学习残差压过这个基准，分别选择4、1。第5次选择的动作4未被真实分支抽到，不能补造其真实奖励。第6次动作0已在真实采样组内、奖励为0，而动作1奖励为−0.000449815，最终仍选1。

这说明当前“带历史参数的组相对更新 + 最终argmax”既不保证选择已评估最高奖励，也没有相对不动作的收益保障。旧轮第5/6次“负奖励仍正优势”是具体强化路径之一；本轮第6次即使采到动作0，历史参数与有限更新仍可保留较差的正式选择。此处是日志支持的机制诊断，不是全部因果来源已被唯一识别，也不是证明一般RL无效。
