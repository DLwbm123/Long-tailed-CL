# PCRL2：查明固定动作，并验证动作响应策略

用户于2026-10-07要求继续提升并解决“为什么会选同一个动作”。本轮为新授权周期；PCRL1与更早周期均已结案，旧结果和预算不变。本轮沿用上轮最大边界：24小时、32 GPU小时、20条正式轨迹、诊断3600秒、64 GiB；一次零optimizer更新真实预检，无自动重试、调参或追加机制修订。精确起止时间见PROTOCOL_LOCK.json。

## 已有证据与待检验原因

PCRL1的RL在16次决策中均选动作1，但最终概率只有0.685835，并未变成确定性概率1。64次有放回采样只覆盖44个不同的动作—决策组合，重复20次。第5、6次动作1实际代理奖励为−0.0002356/−0.0004549，但同组相对优势为+0.6301/+0.6341；组内其他动作更差，故动作1仍被强化。动作0参考奖励为0，但不作为独立样本参与策略更新，除非另被采到。第8、9次已评估动作4也优于被选动作1。

13维全局状态两两余弦相似度均值0.9275、最大0.999982；7×13动作专属线性参数容易把早期偏好带到后续阶段。以上是日志事实和可检验的机制解释，不是“GRPO公式错误”或改后必然更好的证明。CPU逐次重放旧策略的采样、前后概率与30次更新，另检查最终策略作用于全部历史状态的动作。

原始奖励可能真实偏爱同一方向；缺少固定动作对照时不能把其收益归因于状态自适应。新实验同时检验固定动作是否已足够，以及动作响应是否提供有用信息，不把动作数量或熵当成功标准。

## 最小机制改动

保留原训练、解析头、完整二阶矩、原型、FD10、beta0.5、gamma0、奖励、7个预算动作及四采样加一参考的真实分支预算。每次决策用同样的1或2个缓存增强minibatch，在当前冻结编码器上提取一次特征。对全部7个动作，仅递推同一解析近端头，不做适配器更新；在同一探针特征与平移旧统计上计算风险预测。这里的“冻结”只指这次预测，正式路径编码器持续训练。

预测相对动作0产生各类收益g。每动作四维u=[mean_all(g), mean_old(min(g,0)), mean_new(min(g,0)), mean_tail(min(g,0))]；空尾类为0。五列描述为[tanh(sum(u)/0.01), tanh(u/0.01)]。动作0描述严格为零。单一共享4参数theta零初始化，logit_a=tanh(sum(u_a)/0.01)+tanh(u_a/0.01)·(0.5*tanh(theta))。没有动作编号embedding或各动作专属偏置。0.01尺度与0.5残差界在读取本轮val前固定，不搜索。

策略仍按真实适配器分支收益，执行原组相对裁剪更新：Adam0.02、每决策最多2步、clip0.2、均匀KL0.01、梯度范数1；4次有放回采样，另加动作0参考。正式选择更新后argmax，平局最小动作号。未改变相对优势定义或探索采样，以隔离表示机制。解析预测不等于两步编码器更新后的风险，更不等于真实旧类召回；预测与真实分支误差必须报告。

每块从index0起每16步决策，16次决策、150次分支适配器更新；主路径T1后200次。全部解析求解与特征提取计GPU驻留成本，不能称免费。PCG仍为FP64、目标1e-9、最终≤1e-8、最多128次，无普通头回退。参数、buffer、Adam、模块模式、RNG与头完整恢复。任务末仍在全当前训练refit上应用最后动作。
