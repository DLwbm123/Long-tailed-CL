# 后续贡献协议尚未正式启动

CPU阶段只证伪：旧矩精确运输是否足够、逐点约束能否保持非公共logit作用、是否需Lagrangian项。未批准或接好任何新GPU轮，不额外GPU推理。

完整native生产CPU通过后，才前瞻冻结最小主四格（Core、LT、模块、组合）和唯一必要的“同运输提案但无逐点约束”贡献对照，复用匹配现有控制，不改data/seed/每臂原预算、不降低Core。现阶段不决定新增多少正式轨迹，不因本轮val挑类/阈值/步长，也不许直接把GPU-ready写为true。

任何正式协议必须同时报告：已观察训练约束可行/不活跃/只公共范数变化/判别identity的比例，dual/KKT/梯度与所有费用；独立val全部新旧类救回破坏与AIR差距。不能把训练约束成功当val无损或旧旧风险已识别。若所有可行变化在代表性非退化CPUfixture都退回判别identity，应如实报告NOT_READY，不能机械训练。
