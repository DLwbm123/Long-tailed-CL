## 下一步的机制假设（不改本轮）

不把未过门实现送到GPU，也不扩大节点数、query数、step数、种子或放宽门。下一候选仅检验“每个合成节点必须是当时本类训练支持的凸组合”这一结构约束：保持16节点和相同对抗查询/更新次数，但将自由单位球节点改为支持内的重心参数化。部署时只留合成节点和权重，构造阶段的支持/系数在当前任务结束时释放，不保存旧原图或原始特征回放。系数本身可能很大，需要独立实测内存/计算，合成不保证隐私。

该约束可能抑制对当前查询的离支持追逐，但也可能把记忆拉回均值、牺牲尾部信息或仍然对抗不稳定。是待证伪机制，不把已观察到的矩偏差当因果证明。新轮必须冻结相同初始化/参数/数据/预算的自由节点对照，并在共同查询上比较；增加的是一个结构候选而非强度网格。单独报告支持可行性、节点移动/权重、固定查询误差及全部成本。新轮只CPU，不读取医学val。若仍失败，不能机械重复该优化或强行制造医学效果。
