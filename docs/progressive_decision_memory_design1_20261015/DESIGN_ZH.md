# 稳定接口上的渐进判别记忆：第一轮前瞻 CPU 证伪

用户已授权立即验证、半小时监测、结果后自主分析与改进。本轮只验证最关键的记忆机制，不修改旧 Core/LT/PMT/guard，不运行医学训练。完整新方法计划为冻结预训练输入接口、可学习非线性适配器、渐进 ETF、面向未来判别损失的带权合成潜特征记忆。合成潜特征回放是此次新协议；不把它冒充原统计量无回放设置，也不声称隐私保证。

## 假设与证伪

主假设：相同节点/字节预算下，判别损失压缩在未用于更新记忆的查询上优于二阶矩匹配及随机记忆。只在已拟合查询变好不算通过。先检查相同均值/二阶矩但非线性风险不同的单位样本反例，ETF 扩容固定特征下消除公共项与尺度后的旧旧 logit 不变，以及合成节点梯度有限差分/排列/精确记忆。

三规模使用固定合成非高斯混合：32维512支持/4类；1536维9434支持/8类；1536维1038支持/23类。后两者仅N/K规模参考ISIC/HK，不是医学features或真实fit划分。类比例从公开train counts按带每类至少1的最大余数分配；每个case对所有类合成支持压缩，不冒充原医学task的当前类支持。固定seed是合成fixture标识，不是新增正式训练seed。无医学图像、医学checkpoint、val/test、旧NAS模型访问。

查询为 softplus(8 * normalize(z+tanh(3*z*B)*A^T) dot v)。A/B Frobenius范数<=2、rank8、v范数<=2，可表示有界类别差方向。合成节点在单位球中、每类16节点和softmax权重。未来方向不接触未来数据；当前工具未构建真实渐进训练，几何仅算术检查。四种记忆为均值重复16次（容量占位、唯一点只有1）、固定随机样本有放回16点（只有此合成检查使用，不能据此授权医学真实特征回放）、完整二阶矩匹配、判别损失压缩。moment/decision使用相同初始化、48次Adam节点更新，lr.02；decision每次先2次Adam查询最大化更新，lr.01；所有设置锁定，不网格。moment匹配均值误差平方加完整二阶矩Frobenius误差平方，成本不同完整报告。

判别目标为所有类及8查询的平均平方损失差；它是有限见证优化，不是原sup目标的精确解。评价使用4个独立随机adapter/方向组，加2个从其中初始化、固定12步、针对全部四种方法共同找大误差的stress组，共48查询；只评价、不能反向更新记忆。计算每类最大误差、总体均值/最大值，随机和stress分列。经验最大值只是全族sup下界，不输出伪造uniform bound。当前未检查旧压缩记忆再次压缩的误差累计、真实分类收益、完整训练/optimizer预算或真实图像流水线。

## 冻结判断

两个高维case均要求decision最大误差较moment和random各至少降低10%，平均绝对误差均不增加，且所有算术检查通过。此门只识别有限查询信号，不是医学效果门。失败/超时/部分完成不当0或identity，不放宽门。同seed不同方法配对，不能用少数正例替代整体。未通过先公开完整负结果并分析；持续授权允许下一轮独立假设与新源码协议，但不机械加节点/查询/epoch强度重跑。

## 资源、边界与后续

4独立CPU子进程，2线程、每case1800秒硬限、整体5500秒。按wait4实测每次wall/user/system/peak RSS，mode时间和operation嵌在子进程驻留内，不相加。超时先保留最近纯标量progress，private traceback不外传。所有矩阵/节点只内存，不发布。GPU0、新医学访问0、val/test0，既有GPU历史400036.74851310626秒不重计。

方法改进可持续，但每轮独立冻结、终态一次收集、全部正负与成本先公开交付再进入下一轮。通过此门后仍需完整序列CPU接线、重压缩/类别增长/关闭回归/预算与真实零更新预检；不得把第一轮CPU证伪当GPU-ready。后续GPU仅0/1，禁止2/3；不降低Core、不val调参、不增加正式seed或预算档位、不新增旧训练图像访问。test/reserved持续封存、RL暂停。未来新科学轨迹的架构/更新/曝光/内存比较必须另前瞻冻结，不能把新增记忆和模型变化的效果归给单独模块。
