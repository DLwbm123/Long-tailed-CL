# 原型与解析分类头：single-label 开发实验 PA1

2026-10-05 用户授权实施并在 single-label 数据上实验。新的开发实验，不续跑此前已停止的 NB-RL-A6，不使用 RL。

## 方法与比较

复用现有固定预训练 ViT 和 APART 双适配器（1536 维归一化拼接特征）。持久记忆为每类样本数 n、均值 μ，以及所有类别均衡原始二阶矩之和 S。无历史图像或逐样本特征回放。

解析头求解 J(W)=1/(2C) Σ_c E_c ||zW−e_c||² + 0.001/2 ||W||²；W=(S/C+0.001I)⁻¹[μ₁,…,μ_C]/C。无偏置项。该闭式解只对所存固定特征统计量的平方损失精确，不等价于 CE/BCE，也不保证漂移后的旧类统计量准确。

每个任务开始时以当前真实样本特征和旧类统计量初始化分类头。每轮训练后用规范变换重新提取当前样本；当前任务始末配对特征给出各新类平均位移 d_c。旧统计量始终从任务开始版本做一次映射，当前类统计量重新计算，避免重复计数。

三组共用数据、初始化、增强随机种子、优化器、全部规范提取/求解次数：

- `stage_global`：任务内固定开始时的头，任务末更新；旧类均使用新类位移的均值。
- `epoch_global`：每轮更新头；相同全局位移。
- `epoch_local`：每轮更新头；旧类位移为 0.5×全局位移 + 0.5×新类位移的软加权和。权重为旧原型与任务开始新类原型余弦相似度 / 0.1 的 softmax。

按类平移均值与原始二阶矩：μ′=μ+d，E[z′z′ᵀ]=E[zzᵀ]+μdᵀ+dμᵀ+ddᵀ。这一统计变换精确，但“新类漂移可外推到旧类”仅是假设，不能据此声称旧分布恢复。单原型和固定 0.5 混合系数是首轮简化，不根据验证结果调参。这不是 GRAPE 或 Closed-Form Last Layer Optimization 的完整复现。

适配器每轮使用当前类均衡平方损失（对输出维求和）及权重 10 的样本特征 L2 蒸馏，教师固定为任务开始模型；AdamW lr=0.0003、weight_decay=0.01，每任务 cosine 至 1e-5，梯度范数裁剪 5。旧类没有样本梯度，整个训练过程不是联合闭式优化。

## 冻结范围

- ISIC：全部 8 类，train=18718，val=295，每任务 2 类，共 4 任务。
- Hyper-Kvasir：全部 23 类，train=6821，val=1698，每任务 4 类，最后 3 类，共 6 任务。
- 原有 train/val 清单、original_label 语义不变；不访问 test。身份组件在训练/验证之间无交叉，训练组件不跨类别。组件并不自动等于已验证患者身份。
- 每个数据集使用 NumPy default_rng(1993).permutation(C) 生成一个类别顺序；训练 seed=74002。每任务 3 epochs，batch_size=32，完整训练集，无人工重采样。
- 共 2 数据集 × 3 条件 = 6 条完整轨迹；每条最多 3000 optimizer steps。总正式后台运行墙钟上限 8 小时，串行 GPU0；启动前小型工程验收单列，最多 12 steps，不计作效果结果。
- 不自动重试失败轨迹、不新增种子/顺序/条件、不据性能继续新轮。超时保留已完成阶段并记 INCOMPLETE。

## 指标与交付

各轨迹全部训练结束后再评估各阶段 checkpoint；验证不反馈给训练或选 checkpoint。报告平均增量 balanced accuracy、最终 balanced accuracy、按完整训练频数后半类定义的 tail recall、每类样本数/召回率、旧类遗忘（此前阶段最高召回减最终召回，可为负）、训练成本及解析残差。按相同数据集做 `epoch_global−stage_global` 和 `epoch_local−epoch_global` 配对差值，不只报告最优结果。

HK 极少数类验证仅 1–2 例，需要保留分母，不能将波动称为可靠尾类提升。本轮单种子单顺序、复用开发验证集，是机制开发证据，不是独立确认；不做显著性或 SOTA 声明。未经新授权不开展多标签或 RL 扩展。

代码/协议公开；实际结束后发布所有完成与失败结果、报告、成本和限制，验证 GitHub 远程提交及匿名可访问性。患者数据、私有路径配置、逐样本输出、checkpoint 和原始日志留在既定服务器。后台启动后仅短验收，不创建定时监测。
