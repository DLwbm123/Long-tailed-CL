# MARGINP1：当前类分类间隔保护的快速试验

用户于2026-10-06明确要求尽快检验。沿用B第3任务记忆与最终编码器，只重解最后任务解析头；零新增优化器更新，零新正式训练轨迹。GPU0预算1200秒，计入原16GPU小时总账；原截止和工程40/40不重置。

## 训练数据决定规则

最后任务当前类[2,1]的训练样本按identity_component分组，每类固定20%组作为解析头校准留出，seed74002+4*100003+类别ID*2003。其余80%用于簇构造、漂移估计与解析头拟合。校准样本原本已用于B编码器训练，所以这是解析统计留出，不是独立编码器训练留出。

三个强度预先固定为g=0、0.5、1，不能根据验证结果改点位。旧组件位移统一为global+g*(graph−global)，通过原组件平移同时更新一阶和二阶统计量，再加入当前类统计并重解解析头。不存在交叉拼接不一致统计量。

每个当前类单独计算真实类分数与最强旧类分数之间的负间隔平方均值；任一类损失不得高于g=0。再用g=0传输后的旧类均值作为三头共同代理输入，逐旧类计算真实类对其他已见类别的负间隔平方损失，任一旧类代理损失不得增加。数值容差1e-8。选择同时满足两组条件的最大g；g=0始终可行。旧类均值代理不是旧图像泛化/FN估计。

先保存选定g与全部训练校准损失，再使用完整当前训练数据重建对应头，然后提取既有295张开发验证图像计算最终指标。验证标签不参与g选择。公开三固定端点结果用于透明诊断，但不改已锁定选择，不挑验证最好点。完整图头应重建匹配B checkpoint并复核BA。

## 判定与边界

主要比较选定头和同B编码器的g=0/1端点，报告旧新类、逐类分母、BA与混淆矩阵；原完整A仅作历史路径不同的参考。若选定g=0或结果无净收益，保留负结果，不调整容差、alpha或训练切分。该快速试验只检验最后任务解析头保护规则，不代表全程持续学习方法效果，也不复现RLAP-CLIP。复用验证集、单种子与旧类代理局限保留。完成即公开发布源码/协议/聚合结果，不存或发布逐样本分数和私有数据。
