# R2：保持与适应的两项独立检验

R1 未达到筛选门槛，原因假设和全部结果见 [R1 报告](round1/REPORT_ZH.md)。本轮协议已在源码提交 `041c529edf9387ac4aaa3a61b9463a65aefcb0e8` 中冻结；完整参数见 [协议](R2_PROTOCOL_LOCK.json)。

- FD40：stage_global 的特征保持系数 10→40。
- READOUT1：stage_global 保持 FD10，加权重 1 的旧头输出保持项。旧头取前一任务最终解析头，在当前任务内固定。损失为当前特征与任务开始教师特征之差经旧头映射后的均方值，按 batch 和旧类数取平均。第一任务为零，教师和旧头均停止梯度。

沿用 ISIC 全 8 类、18718 张训练图像、295 张验证图像、原始顺序、seed74002、每任务两轮和 batch64；每个候选 588 次更新。两个独立队列各有 7200 秒硬超时，预留合计 4 GPU 小时，纳入原周期的 16 GPU 小时/24 小时边界。主要比较 PA2 stage_global，同时报告 R1 冻结、不校正及图对照。只有全部轨迹结束才做性能判断，不改变原筛选标准。

真实短验收已通过，两个条件各两阶段、4 次更新，共 8 次；旧头损失在第二任务实际非零，READOUT1 第一任务适配器与头均匹配基线。梯度检查验证旧头/教师无梯度。峰值分配显存约 12.65 GB，验收队列驻留 168.865 秒，累计工程验收 18/40 次更新。详见 [验收回执](R2_ADMISSION.json)。这些只证明工程机制有效，不证明性能提升。

准备时系统默认 python 指向旧解释器，已改用明确 Python 3；NFS 扩展属性复制失败，定位到 setxattr 后改用普通源码内容复制，读写探针正常。两项问题均发生在训练前，没有失败训练或额外更新。运行入口保持中性，私有路径、数据、checkpoint 和原始日志不公开。
