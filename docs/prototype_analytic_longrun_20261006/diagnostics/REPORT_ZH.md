# DIAG1–DIAG2：多原型图的分类分数与统计项定位

**结论：本次验证中的新类损失主要表现为旧类竞争；最后任务解析头是其中一个可干预因素，但尚不能定位为某一个统计项单独造成。** 不新增模型训练，未找到可据此声称胜出的新方法。

复用EF1 A/B最终checkpoint和既有295张开发验证图像，两模型逐类正确数与已发布结果完全一致。A BA=56.9508%，B=56.3868%。相对A，B共损伤5例、改善3例：新类损伤4例且无改善；旧类损伤1例、改善3例。

限制新类候选的77/83利用真实组别，只作诊断，不是可部署准确率。A/B在新类内部的正确数相同，不代表每个样本的分数或内部预测逐元素相同。类别2的平均真实类对最强旧类分数间隔从0.07072降至0.06184；类别1从0.16265降至0.15946。原始分数尺度受分类头影响，不能跨模型解释为校准概率。

以上支持本配置的新增新类错误主要来自旧／新类竞争；单靠该比较仍不能独立归因于编码器或统计量。

## 3. 对后续方法的判断

当前结果支持把下一机制的检验目标从“漂移拟合误差更小”改为“图校正是否损害当前类的判别间隔，同时保持历史类约束”。这只是待检验方向，不能只用新类训练正确率来放大新类分数，否则可能反过来损害旧类。

不支持简单删除某一个统计项，也不支持直接把本轮验证集上较好的混合头包装为方法。现阶段保留全局校正及READOUT1作为有效参照，图分支仍未证明总体收益。若开展新的完整训练，需要先固定可由当前训练数据校准、且一二阶统计一致的判别保护机制；原工程验收预算已40/40，不能默默重置或追加。
