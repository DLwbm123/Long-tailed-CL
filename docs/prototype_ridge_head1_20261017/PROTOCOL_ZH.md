# 固定类均值二阶矩：移除类内散布消融

依据[对角消融](../diagonal_ridge_head1_20261017/REPORT_ZH.md)，直接删除非对角二阶项未保留完整岭的分类表现，头尺度也显著改变。但该消融同时删除了类均值和类内散布的交叉项，不能区分二者。本轮只移除类内散布，保留所有类均值交叉项。

固定原始单位支持每类均值μ_c（不额外单位化），G=(1/K)Σ_c mean_i z_i z_iᵀ，G_between=(1/K)Σ_c μ_c μ_cᵀ，G_within=G−G_between。候选W=(G_between+0.001I)⁻¹μᵀ/K。它等价每类只用原始均值拟合岭读出，而不是在每个支持样本上拟合原目标；与原始单位均值余弦头也不同，因为保留了类均值间的联合逆矩阵作用。

唯一主要变化为G替换成G_between，RHS/λ=.001、BETA8、无bias无列归一化、raw冻结表示、H64/169新S2290/95、均匀类内与等类质量、seed74002/类序/划分全部不变。不搜索λ、混合比例、秩、温度或支持选择。G_between是未中心化均值外积，不把它直接称为去全局均值后的标准between-class covariance。

主要机制比较完整raw_ridge，同时报告raw_centroid及MM、HH、identity_ETF、teacher_centroid、teacher_ETF、coordinate_median、centered_centroid、raw_diagonal_ridge共十参考，全部类/组BA和完整seen CE、正负差值及描述性双查询门槛（总体严格提高且旧新各下降<=1pp）。不自动选择候选、不用弱参考通过代替完整岭比较。仅判断当前固定支持下保留均值结构是否足够，不证明普适必要性或独立医学机制。

报告原G中类内散布的trace比例tr(G_within)/tr(G)和Frobenius范数比||G_within||F/||G||F（不是平方能量比例），支持计数、候选头范数、对候选方程求解相对残差。仍构建原G用于上述诊断，不宣称当前实现已经省去完整Gram构建。CE依赖头尺度，BETA8相同不构成校准等价。

复用prototype_analytic.ridge，把本轮求解用S替换为μᵀμ，原始S保留仅用于诊断，不修改既有bank。run_raw_ridge_head.py隔离prototype_only_second_moment=true、diagonal_second_moment=false，二者不可同时开启。默认完整岭和既有对角分支保留。

先支持拟合封存头，再读查询/历史聚合（从对角轮全量结果复用）；只读teacher文件用于零残差形状、同一H和新S，禁止旧S/E/原图/新标签/GPU。finite、均匀权重、非空类、1536维、标签范围、头1536×6/15、读取守卫及既有残差<=1e−7保留，失败不回退完整头或改λ。合成每数据集3个二维求解：正交解析解、类内复制不变性、相同μ而加入类内散布时候选解不变且不满足完整原方程。合计6工程小型矩阵解；正式2矩阵解，0逐元素解、0梯度（含工程）/适配器教师编码器记忆更新。
