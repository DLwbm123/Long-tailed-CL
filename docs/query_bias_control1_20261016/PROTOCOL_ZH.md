# 同查询监督的类别偏置对照

前两轮节点权重实验尚不能分离具体记忆机制与额外查询监督的作用。本轮补充一个简单对照：在原始基线模型的 seen-class logits 上仅加可训练类别偏置 b；基线适配器、编码器、ETF frame 和记忆全部固定。ISIC/HK 原种子、顺序、首增量、Qfit/Qgate 划分保持一致。

该对照在推理时额外保存每个已见类别一个标量，即 ISIC 6 个、HK 15 个参数；不宣称与原方法参数量相同。

从 b=0 出发，最小化 Qfit 各类别等权 CE + 0.5·mean(b²)，固定 48 次梯度更新，学习率 1/16，每步减去偏置均值。两个数据集共 96 次偏置更新，没有适配器更新、节点权重优化、超梯度或特征提取。正则、步数和学习率在运行前固定，不扫描。用目标逐步非增、零偏置 CE 与既存基线复现误差、有限值与零均值断言做最小工程自检。

主要判定：相对原基线，Qgate 总体宏平均召回率严格提高，且旧/新类各自下降均不超过 1 个百分点。两数据集分别报告，不只保留通过者。它是开发筛选描述，不触发 E 推理。次要报告与原完整节点方向、固定半步方向的逐类 CE/BA 对照；这三个既有模型复用上一轮完整记录，不重训或重复推理。

Qfit 与 Qgate 已经暴露，所有结果只作开发机制证据。一个简单偏置控制通过时，只能说明额外查询监督存在低成本替代解释，不能据此归因全部节点收益；控制失败也不能证明节点机制不可替代。优化目标、容量和计算并不完全匹配，因此不称为完整公平消融。

只访问既存基线模型、Qfit/Qgate 特征和前轮去身份化结果。S、E、保留测试集、原图、教师和其他候选模型文件不读取；不新增标注。GPU 新增为零。两个 CPU 子任务各最多 900 秒，总上限 3600 秒，保留逐次成本、失败和全部结果。完成后公开交付，依据结果继续下一轮有明确依据的分类研究。
