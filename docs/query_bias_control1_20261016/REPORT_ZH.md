HK 总体 BA 从 44.41495% 到 44.52639%，增益很小。新类表现保持原基线，其中 3 张图像的类别仍为 1/3 正确，8 张图像的类别仍为 7/8；没有发生前两轮节点方向的新类预测损失。ISIC 则在新类小幅提升的同时损失旧类，超过 −1 个百分点门槛，不能用总体 CE 的下降覆盖这个失败。

## 机制读数

ISIC Qfit 旧/新类 CE 从 1.709940/1.625597 降至 1.686316/1.615986；HK 从 1.825911/1.325886 降至 1.811340/1.312285。两数据集都实际降低了 Qfit 两组 CE。Qgate 两组 CE 也都下降：ISIC 从 2.116497/1.670406 到 2.089368/1.669539，HK 从 1.891334/1.296512 到 1.875830/1.281918。ISIC 仍有旧类准确率下降，再次说明 CE 改善不是宏平均准确率安全的保证。

固定正则化目标在 48 步中逐步非增。ISIC 目标从 1.681825 到 1.666540，HK 从 1.759241 到 1.746106；这里含偏置正则，不能与不含正则的 CE 混用。零偏置 CE 复现误差分别为 2.22e−16 和 0。完整偏置向量、目标轨迹和类级计数均保留在 `RESULTS.json`。

这个结果说明，HK 上的轻微开发收益可以通过简单的额外查询监督获得，不能据此把查询收益专门归因于记忆节点机制。ISIC 上原节点方向有正向读数而偏置对照失败，也不足以证明节点机制必要；两者参数容量、优化目标和计算不同，且 Qgate 已用于多轮开发。

下一轮不按数据集分别挑选方法，也不继续调偏置强度或节点步长。固定交换原 Qfit/Qgate 的拟合与检查用途，对同一节点方向方法和同一偏置控制做反向划分检查，以观察方法排序与门槛结论是否依赖当前查询划分。这仍是已暴露开发数据上的稳健性诊断，不是新的独立验证。
