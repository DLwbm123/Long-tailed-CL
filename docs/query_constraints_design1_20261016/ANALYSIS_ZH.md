唯一正的非基线整体Q收益来自HK 100265的rho=2（+0.193333pp），但新组下降21.85pp。整体BA的类别等权性质允许13个旧类的获益抵消2个新类的重大损失；预定分组约束正确拒绝了这种候选。

Q上的组CE也呈相同方向：rho=.5旧组CE四场景全升、新组全降；rho=2旧组全降、新组全升。这支持该标量主要改变旧、新取舍的解释，但不是所有连续rho都不可行的证明。

## E零差值应如何解释

四个选择在SELECTION中全部为rho=1，实际选中模型就是原moment基线。E上的整体/旧组/新组差值全部为0，paired bootstrap区间均为[0,0]，救回/伤害均为0。旧新代价条件通过，整体正收益条件失败。

这是同一模型比较自身的结构性零差值，不能包装成新的有效性证据或独立发现“所有候选都无效”。E只评估了按Q锁定的最终策略，按协议没有查看八个被拒候选在E上的表现，因此没有这些候选的独立E结论。Q上的不可行性保留为开发结果。

## 对研究方向的更新

1. 本轮说明：固定候选族内，按更新后的真实旧新BA执行约束选择能够返回基线，避免采用已知Q代价超限的方案；尚未展示非平凡改进。

3. 这不证明整个连续rho范围或所有更细粒度优化都不可行：本轮只测.5、1、2。也不证明增加网格必然有效。没有进行插值、网格加密、保持系数扫描、双层梯度或新的memory构造。
4. 如未来重新讨论方法，应将候选族的表达能力与独立query资源分别列为待解决问题，不能把“换一个选择门”直接等同于能产生可行改进。当前轮次停止，不自动开展上述任何新方向。
