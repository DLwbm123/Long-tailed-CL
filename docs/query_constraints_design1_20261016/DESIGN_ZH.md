# 更新后旧新组约束选择：冻结协议

只复用ISIC 100264/200264、HK 100265/200265四个既有teacher、ETF和moment memory。每场景从同一teacher新增rho=.5和2各48步，共384次adapter更新、0次memory/teacher更新；rho=1复用已有moment终点。固定类内memory权重、16节点、学习率1/16及teacher-correct旧类中心化保持项系数1，不补训练种子、不扩网格、不提前停止、不科研重试。

设pi_old=K_old/K_seen、pi_new=K_new/K_seen，训练目标是(rho*pi_old*macroCE_old+pi_new*macroCE_new)/(rho*pi_old+pi_new)+retention。分母保持CE总权重1；保持项仍按旧类等权。rho=1的目标和梯度通过零更新算术检查与既有训练表达式一致；不通过新增训练复测基线。

阶段顺序：unit→8个独立训练worker并封存→一次Q选择worker→一次E评分worker。任何失败使后续阶段不运行。Q只在8条候选全部成功封存后生成；四个选择在一个完整manifest内独占写入并锁定后，supervisor才抽取E随机种子；E只在此前阶段成功退休后生成。E每个场景只评分selected和baseline，不评价未选候选，不回填Q、不重拟合、不根据E回选。

S为原确定性有限合成训练支持，仅训练worker读取。Q和E各场景每已见类1000个独立噪声样本，中心、低秩空间和混合结构不变，混合层固定20%/80%；不生成未见类样本。Q使用955100..955103四个预定独立种子。E种子仅在锁定全部选择后由secrets.randbits(62)抽取四个唯一值且>=10^9并排除训练/Q种子；排除规则与性能无关，抽样一次后封存，无结果驱动重抽。Q/E均打乱特征及标签对应顺序，预测器只接收特征；标签与混合层只交评分器。样本身份以角色/场景/不透明ID分区，不把增强或重复S当作独立query。Q总42000个、E总42000个已见类合成样本，属于额外带标签数据预算，不是实际医疗图像或原16节点预算下的独立query解决方案。

数据访问隔离在阶段入口与文件访问审计中执行：Q/E进程拒绝读取历史S状态路径；Q拒绝读取E文件；E拒绝读取Q结果及未选候选模型。训练进程结束后才创建Q，全部选择结束后才创建E；E种子不提前存在。用于Q/E的frame和baseline只导出模型，不导出S或memory。审计是程序执行边界，不宣称抵御拥有服务器root权限的恶意修改者。源代码和锁定规则公开后不修改结果驱动规则。

Q选择对全部三个终点计算seen单头BA，分别按all/old/new类别等权。相对同一更新后的moment终点，旧、新点估计差值各>=−.01−1e−12才可行；在可行项中最大化整体BA。非基线须整体收益>1e−12；若无则回退rho=1。收益差在1e−12内视为并列，优先baseline，再按abs(log(rho))、rho数值升序。Q区间不用于额外筛选；Q一经选择即为开发数据，不能当测试证据。

E沿用整体正收益、旧新各最多下降1pp及原条件区间门槛。分层paired multinomial bootstrap 10000次，类别内对混合层固定.2/.8加权，再对组内类别等权；bootstrap种子955200..955203，numpy线性双侧95分位数。区间只描述固定模型、固定混合设计的条件评估抽样不确定性，非训练seed总体/同时覆盖。SUPPORTED要求整体点正且区间下界正、旧新点及下界都>=−.01−1e−12；代价点超限COST_EXCEEDS_LIMIT，整体点非正NO_POSITIVE_GAIN，其余INCONCLUSIVE。baseline回退为零差，不能记成功。四场景全部SUPPORTED才记共同通过。

公开Q全部候选逐类、组指标及选择原因；E只公开选中与baseline的逐类正确数、CE/margin、四格配对、错向旧新类及分组区间。保留回退、零收益、失败、负结果和全部成本。单worker600秒，总1800秒，CPU两线程，GPU禁用。历史CPU8352.909403781872秒、历史GPU400036.74851310626秒；新增和历史分列，不重复相加，未测客户端耗时为null。完成后推送GitHub、保存NAS回执、分析并停止。
