## 数据与标签隔离

S只用于训练；Q使用四个新的预定随机流，每已见类1000，共42000样本。所有候选先封存后Q才生成，四个选择全部锁定后supervisor才抽E种子，随后E生成共42000样本。DATA_RECEIPTS和SELECTION保存顺序与种子；角色文件访问审计拒绝Q/E读取历史S状态、拒绝Q读取E、拒绝E读取Q结果和未选模型。模型推理只接收特征，标签只用于当前角色评分；不生成未见类样本。当前是程序级访问边界，不宣称抵御root恶意修改。

Q是额外开发标签，E是新评估标签；二者各42000，均不是memory免费资源。重复观察的旧bank未读取。本轮只验证合成分布上的有限候选机制；不能作为真实医疗数据、训练种子总体泛化或解决真实尾类独立query不足的证据。回退基线意味着未找到正收益，不算科学成功。
