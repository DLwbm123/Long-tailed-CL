# 固定反向查询划分检查

此前完整节点方向在 ISIC 原 Qgate 通过、HK 不通过；固定偏置对照则在 ISIC 不通过、HK 仅有 +0.1114 个百分点的微小通过。不能按数据集事后选一个赢家便宣称统一方法有效。本轮同时检查这两种已固定方法对查询角色划分是否敏感。

唯一改变是用原 Qgate 拟合方向/偏置，在原 Qfit 做开发检查。保留同一真实图像特征、类别顺序、种子、旧教师、记忆、S_new 和基线。节点方法仍使用全 48 步超梯度、原两组非增半空间投影、最大 log 权重改动 log(1.25)，恰好一个完整方向；偏置方法仍为零初始化、48 步、lr=1/16、宏平均 CE + 0.5 mean(b²)。不增加半步候选，不扫描参数，不新增查询数据。

主要判定在运行前固定：每个“数据集×方法”必须在正向和反向两次检查中都满足总体 BA 严格改善，且旧/新类 BA 各自下降不超过 1 个百分点，才标为双向通过。原正向判定已写入协议锁，不允许用反向结果替换。两数据集、两方法共四项全部报告；任何单项通过都不构成跨数据集一致结论。

新方向需要一次可微基线展开，逐参数与已保存的原基线核对，不能把它算作免费计算：两数据集共 96 次基线图重放、最多 96 次节点候选更新、96 次偏置更新及 4 次超梯度反传。不重新训练教师、记忆或编码器，也不将基线重放保存为新的对照结果。偏置推理额外参数仍分别为 6 和 15。

每个数据集内两候选完成保存后才读取反向检查特征；程序访问规则拒绝 E、旧类 S，以及封存前的检查特征。已保存的聚合基线计数用于比较，记录模型重放误差、零偏置 CE 误差、目标非增检查及全部类级 CE/召回率。两数据集是分开的分析单元，不用一个数据集结果修改另一个。

两查询集在历史开发中都已暴露，因此这里只是反向角色敏感性诊断，不是独立验证，也不是预先未见数据的交叉验证。E 和保留测试集不访问，患者隔离未知等既有限制保持。

两个顺序 CPU 子任务各最多 900 秒，总上限 3600 秒。新增 GPU、标注和特征提取均为零。记录完整逐阶段/历史累计成本与全部负结果，实际结束后公开交付，再依据证据推进下一轮分类研究。
