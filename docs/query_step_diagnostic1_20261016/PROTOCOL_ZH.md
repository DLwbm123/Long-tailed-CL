# 固定半步的有限变化机制诊断

前轮真实图像结果中，ISIC 有正向但不确定的开发 BA 信号；HK 的 Qgate 新类损失集中于一个预测翻转。Qfit 零点处的 CE 方向导数不能解释有限更新后的损失，也不能保证 Qgate 泛化。本轮只检验这一缺口，不进行新的性能确认。

复用前轮教师、基线、记忆、完整方向和特征。唯一新增训练改动是令节点 log 权重改变量从 d 变为 d/2；每个数据集恰好从同一教师训练 48 步，共 96 次下游适配器更新。节点、类别总质量和保留项不变，无超梯度重算、教师/基线重训、特征提取或新增标签。只运行 ISIC/HK 同一种子、同一首个增量，不扫描更多幅度。

主要读数是在 Qfit 上分别测量基线、已存在的完整步和新半步模型的旧/新类宏平均 CE，并与保存的局部预测 g·d、g·d/2 比较。两组 CE 变化都不大于 1e-10 时记为“实际共同下降”；同时报告变化量和非线性残差，不能只报是否通过。若完整步失效而半步兑现，支持有限步长非线性解释；若 Qfit 兑现但 Qgate 失效，说明跨查询集或 CE/准确率之间不一致，不能单凭本轮断言具体因果机制。

次要读数是已暴露开发 Qgate 的逐类 CE/召回率。基线与完整步复用已有计数，仅新增半步推理；原 −1 个百分点旧/新类门槛作为描述性检查，不用来挑选模型进入 E。E、原始图像和旧类 S 均不读取。两数据集的全部结果都报告，不追加训练或候选。

Qfit/Qgate 已因前轮结果分析暴露，本轮明确属于开发机制诊断。保持原样本资源和患者隔离未知的局限，不计算新的“独立”置信区间。无新的随机种子、样本、标注或保留测试集访问。

两个 CPU 子任务顺序执行，各最多 900 秒，总上限 3600 秒；记录每次尝试的 CPU 驻留、CPU user/system、峰值内存和父进程墙钟，GPU 新增为零。自动监测负责工程修复、实际结束后的完整公开交付与下一轮证据分析，不能修改本轮冻结判定。
