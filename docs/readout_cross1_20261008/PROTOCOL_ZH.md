# T2 四格受控读出重建：冻结协议

用户批准在 GPU 0、1、2 上进行，显存满足即运行。仅使用已完成 FIXED_DRIFT1 的共同 T1 编码器、两臂 T2 编码器及共同 T1 历史统计；不修改既有训练轨迹。SHIFT 与 AFFINE 原完整轨迹结论保持不变。

## 四格与数据

三张 GPU 分别提取共同 T1、SHIFT T2、AFFINE T2 编码器的当前任务特征；两路 T2 编码器另提取既有开发 val 特征。与原运行采用相同 canonical 顺序、预处理、种子、batch64；为匹配原提取批次会前向当前任务 canonical 样本，但仅永久 fit 的1057/22个样本进入搬运及分类头，254个meta样本不参与拟合或选择。旧类原图不重新提取，test封存。

每一行均从同一 T1 fit 统计起点出发，以共同 T1 与该行冻结 T2 编码器在相同 fit 样本上的配对特征重新拟合两种搬运；加入该行新类统计，调用原生 head(strength=0) 重新求解。四格为 SHIFT_SHIFT、SHIFT_AFFINE、AFFINE_SHIFT、AFFINE_AFFINE。第二个名称是搬运规则。affine及head岭系数均0.001，竞争及原型度量项为0。

## 先复现，再解释

对角线比较既有私有T2分数、head及bank。分数绝对/相对容差为1e-5/1e-4，head为1e-5/1e-4，均值及二阶矩为1e-6/1e-5；全部逐样本预测必须一致。任一对角线不通过则停止归因，保存失败；不放宽容差或自动重跑。

通过后报告四格 BA、旧类BA、新类BA、逐类分母、混淆矩阵，两行 AFFINE−SHIFT 差值和交互（AFFINE行差值减SHIFT行差值）。报告配对正确性迁移，以及新类内部正确但输给旧类的新增/恢复计数。所有效果为描述性开发诊断，没有成功阈值选择或显著性主张。

同时记录各类均值范数、二阶矩迹、中心协方差最小/最大特征值和共享G谱。对固定编码器，验证完整恒等式 dW=Ga^-1*dH−Ga^-1*dG*Ws。针对真实新类，与SHIFT读出下同一个最强旧类竞争者比较margin，分别报告均值右端项和共享二阶矩项的代数贡献；不将其冒充独立因果效应。公开聚合量，不公开均值、矩、头、特征、逐样本分数或身份。
