# T4 局部读出：冻结协议

用户批准在GPU0、1、2上继续实验。本波定位完整训练终点的直接读出效应，复用FIXED_DRIFT1两条已完成轨迹，不重新训练编码器。

## 两条轨迹各自的二读出

SHIFT行固定SHIFT的T4编码器、SHIFT的T3历史统计及T3编码器；AFFINE行固定AFFINE的T4编码器、AFFINE的T3历史统计及T3编码器。每行使用同一批当前任务fit样本、同一份T3起点，分别重新拟合SHIFT/AFFINE搬运，再加入该行T4新类统计、重建原生head(strength=0)。岭系数均0.001，竞争及原型度量项0。

两行历史统计不同，不交换bank，不将跨行差异当成纯编码器效应，也不将四格当成共享起点的完整因果析因实验。主读出为每行AFFINE−SHIFT的BA、旧六类BA、新两类BA及配对错误；两行效应差仅描述不同编码器与历史状态下的差异，不据此恢复RL。

当前T4两个fit类为原始类2/1，样本2310/2710，共5020。沿用原canonical顺序和batch64前向6098个当前任务样本，但1078个永久meta不参与映射、统计或选择。只重访当前训练类，不读取旧类训练图像。评价沿用已反复使用的295个开发val样本，包括212个旧类及83个新类；test一直封存。类顺序4/0/3/7/5/6/2/1，验证分母41/44/40/24/37/26/46/37。

## 复现与诊断

对角线必须复现原始T4分数、head、bank和逐样本预测。容差与T2相同：分数与head绝对1e-5、相对1e-4；均值及二阶矩绝对1e-6、相对1e-5；所有预测必须一致。失败即停止归因，保留结果，不放宽阈值、不自动重跑。

通过后报告四格完整混淆矩阵、类别分母、组内与组间错误、行内配对变化。沿用预先定义的完整head差分解：dW=Ga^-1*dH−Ga^-1*dG*Ws；对真实新类，固定SHIFT读出下的最强旧类竞争者，报告得分差的均值右端项与二阶矩项贡献，不视为独立因果干预。记录各类二阶矩迹、均值范数、中心协方差谱极值和G谱，不通过这些诊断选择新方法。

## 运行边界

四个特征进程并行：GPU0提取SHIFT T3与AFFINE T4，GPU1提取AFFINE T3，GPU2提取SHIFT T4。前轮相同冻结提取实现的PyTorch分配峰值为1.23GiB；本轮启动前每进程要求至少4GiB可用显存，GPU0双进程合计至少8GiB。允许共享GPU，不更改其他进程。

每进程上限1200秒，按进程GPU驻留求和最多4800秒（1.3333GPU小时）；GPU0并行进程的重叠时间仍各自计入，属于保守进程驻留账本。CPU审计墙钟上限600秒，输出2GiB。此前所列三阶段6663.981284856796GPU秒另账保留，不冒充整个项目历史成本；仍受原48GPU小时上限和2026-10-09 16:52:27.912北京时间绝对截止约束。

零新增优化器、策略或试探分支更新。无自动重试、FD调整、偏置扫描、额外种子、其他任务阶段或RL。全部进程使用中性入口和stdin配置。完成后公开源代码、协议、聚合结果、预算及中文报告并核验GitHub远端与匿名访问；私有身份、图像、特征、矩、head、逐样本预测和checkpoint不发布。

本波最多定位T4最后一次搬运的直接读出效应；历史统计误差和训练反馈已积累在各自T3起点与T4编码器中，不能由此独立拆解整个训练过程。
