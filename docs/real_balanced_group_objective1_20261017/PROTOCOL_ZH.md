# 最高分组间目标的旧新等质量对照

依据已交付[最高分组间目标结果](../real_max_group_objective1_20261017/REPORT_ZH.md)（`75df10d`），原 max 目标在两数据集的两个查询均因新类退化未通过，HK Qgate 新类下降 54.17pp。旧类改善不能抵消新类失败。该目标沿用每类质量 1/K，因此旧/新组的总质量分别为 ISIC 4/6 与 2/6、HK 13/15 与 2/15。本轮只检验这种组质量差异是否解释 max 目标的旧类偏向，不预设成功。

## 唯一改变与固定公式

令 p_i 为原 class-uniform 支持权重（各类总质量 1/K），g_i 为样本真实旧/新组，P_g=该组 p_i 之和，m_i=max(新 logits)−max(旧 logits)。组内 CE 保持 sum_i p_i within_CE_i；只将组间项由 sum_i p_i softplus(sign_i m_i) 改为 sum_i [p_i/(2P_g_i)] softplus(sign_i m_i)。旧样本 sign=+1、新样本 sign=−1，两组总质量各 0.5；单个旧类质量 1/(2K_old)，单个新类质量 1/(2K_new)。这不是完整 CE，也不是在查询上选择系数。

从与原 HH 相同的冻结旧教师初始化重新训练 48 步、步长 1/16，不继续已有 HH 或 max 模型。复用已封存 H（ISIC 64、HK 169 个节点）、原新 S、ETF、种子 74002、类别顺序、划分与未缩放 H 保留项。组内 CE 类质量仍为 1/K，不改变保留项权重，不加入新参数、偏置、温度或混合系数，不扫描权重或种子。两项相加后加原保留项；日志分别记录标准完整 CE、实际分类代理损失和保留项。

## 固定判定与必要对照

主要候选仍相对原 MM：每数据集在 Qfit 与 Qgate 均须总体 BA 严格改善，旧、新 BA 各下降不超过 1pp。所有失败和逐类损害均保留，不事后换主要指标。

原完整 CE 的未缩放 HH，以及上一轮未平衡 max 目标，是两个已冻结的次要对照，完整报告组别与逐类 BA/CE 差值。相对 MM 的继承 H 收益不能算作新目标收益；相对未平衡 max 的恢复也不能冒充超越原 HH。关注提高新类是否牺牲旧类，不预先推断改善。

两个查询已暴露并用于方法设计，只是开发/机制证据。患者分组未知；不声称独立医学验证、跨种子稳健性或完整持续学习优越性。

## 预算与访问边界

两个串行 CPU 任务 ISIC_balanced、HK_balanced，各 48 步，共 96 个适配器更新；每任务 900 秒，总限 3600 秒。每任务沿用 3 次工程 logit 梯度自检，两任务共 6 次，零工程适配器更新。新增解析值自检只做前向：三个支持样本、logits 均为 [0,0,2]、标签 0/1/2、旧类 2 个时，平衡目标为 (2/3)log2 + [softplus(2)+softplus(-2)]/2，未平衡目标比它大 1/3。实际训练断言两组质量各 0.5、原各类质量 1/K、模型数值有限，并继续验证角色访问边界。保留原分解值/梯度及 max 梯度有限性和平移不变自检。
