# 对称冲突梯度移除：固定更新规则对照

依据[支持梯度诊断](../support_gradient_audit1_20261017/REPORT_ZH.md)（`3b4fa3c`），原HH旧新梯度余弦约−0.924/−0.909，但原总方向仍可同时下降两个支持CE。因此本轮不声称无共同下降空间，也不假定投影必然更好；检验固定冲突移除规则对完整训练轨迹的效果。

## 唯一改变及公式

从相同原旧教师初始化，复用H64/169、新S、ETF、种子74002、顺序/划分、48步和步长1/16。完整CE、原每类质量1/K、未缩放H保留项不变，不增加参数或组权重选择。

每步计算组内按类均匀归一化的完整CE梯度a=g_old、b=g_new和原保留项r。令c=a·b。若c<0，同时用原a、b计算a'=a−c b/||b||²、b'=b−c a/||a||²；否则a'=a、b'=b。负内积时两范数必非零，代码显式断言；零向量或非负内积不投影。没有温度、容差超参数、随机顺序或系数扫描。

最终更新梯度d=(K_old/K)a'+(K_new/K)b'+r，参数减d/16。保留项梯度原样加入；不投影保留项、不事后选择方向、不增加线搜索或回退。这个更新不再是原标量总损失的普通梯度下降，记录的标准CE仍只是损失值。

逐步保留48条记录：是否投影、原旧新内积、原加权总方向与新方向分别对应的旧CE/新CE/保留项方向导数。负梯度方向导数为−g·d，正值表示局部损害。对称移除保证仅CE合成部分与两组非负内积，但保留项及有限步长可能破坏共同下降；不能把几何性质当作实际BA保证。

## 判定与对照

主要候选相对原MM，每数据集Qfit/Qgate都须总体BA严格改善，旧/新各下降不超过1pp。未修改原HH是完整次要对照，报告全部组别/逐类BA/CE、原完整CE与保留项、投影次数及每步方向导数。继承H收益不能算投影增益；记录全部失败与旧类损害，不切换主要指标。

查询已暴露并用于方案设计，但训练不读取查询。只有保存固定48步模型后才评价两个查询，无早停、选步数或选模型。患者分组未知，单种子首增量，结果仅作开发证据。

## 预算与工程检查

两个串行CPU任务ISIC_project/HK_project，各48步，共96次参数更新。每步旧CE、新CE、保留项各一次反向，共288次训练梯度计算；相比原普通梯度下降反向开销增大，必须单列。各任务900秒、总3600秒，不因超时重置预算或自动重跑。

工程自检只做向量运算，无反向或模型更新：a=[1,0]、b=[−1,1]时投影结果[0.5,0.5]、[0,1]；验证它们均与原两向量非负内积，并检查非冲突和零向量原样返回。正式训练保留类质量、有限参数与访问边界检查。

只使用冻结教师、H、新S，禁止旧S、E、原图、新标签、GPU、教师/编码器/记忆更新。H历史构造不重复计成本。通过代理封存源码与协议并验证匿名可读后启动；全部父子退出后公开完整正负结果、逐类数据、方向记录和每轮/累计成本，私有模型、特征、身份与路径不发布。
