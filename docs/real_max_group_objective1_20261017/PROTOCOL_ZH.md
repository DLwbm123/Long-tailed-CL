# 固定 H 记忆的最高分组间目标对照

依据已交付[支持组间标定](../support_group_bias1_20261017/REPORT_ZH.md)（`7dad7d5`），HK 支持 CE 的最优新类偏置接近零，两个查询预测不变；此前新类诊断却显示其错误落入旧类。本轮检验训练目标中“组概率总量”与“组最高分竞争”的区别，不继续试系数。

## 唯一改变及公式

复用 H 记忆，从与原 HH 相同的冻结旧教师初始化，重新进行同样 48 步、步长 1/16 的适配器训练；不从已有 HH 继续增加步数。保持类内概率、各类质量 1/K、新 S、ETF、种子、顺序和未缩放 H 保留项完全相同，不加入标量偏置或任何新参数。

对于标签所在组（旧/新），标准完整 CE 可精确拆成：组内 CE + 两组 logsumexp 的二元 logistic CE。唯一改动是后项的组代表分数由 logsumexp 改为 max。令 m=max(新类 logits)−max(旧类 logits)，旧类样本的组间损失为 softplus(m)，新类样本为 softplus(−m)。组内 CE 不变，两项系数均为 1，按原类质量加权，之后加原 H 保留项。

该目标是一个不同于完整 CE 的代理损失，不声称与原概率模型等价或必然提高 BA。组内最大值与真实类可能不同，组内 CE 仍负责类内区分；max 的梯度采用 PyTorch 默认规则，同分时按固定索引规则，不另做平滑、温度或系数选择。日志同时保留标准 CE、新分类目标和保留项，不能把新目标数值冒充完整 CE。

## 固定判定和对照

主要候选相对原 MM，在 Qfit 与 Qgate 都必须总体 BA 严格改善、旧/新 BA 各不下降超过 1pp。两数据集独立报告，保留旧类损害与所有失败。未修改 HH 的既有结果是次要对照，必须报告新目标相对 HH 的完整组别/逐类变化；仅继承 H 原收益不能宣称目标有增量改进。禁止事后换主要对照或辅助指标。

两个查询都早已暴露，且参与本轮设计，只作开发判定。患者分组未知；不形成独立临床验证、跨种子稳健性或完整持续学习结论。

## 边界、预算与工程检查

两个串行 CPU 任务 ISIC_max/HK_max，各 48 步，共 96 个适配器更新；每任务 900 秒，总限 3600 秒。H 直接复用，旧构造成本保留在历史，不重计。无教师、编码器、可学习记忆更新，无 GPU、新标签、E、旧 S、原图像、参数/种子扫描或自动重试。

每任务先执行一个微型工程自检：logsumexp 分解与直接 CE 的值和梯度一致；零 logits 的 max 组目标等于解析值 (5/3)log 2；新目标梯度有限、对全 logit 平移不变。每任务 3 次 logit 梯度计算，两任务共 6 次，单列为工程检查，不计成模型训练。正式训练继续检查类质量、模型有限性及角色访问边界。

只读冻结教师、H 和新 S 来训练；保存模型后才允许查询与旧基线聚合进入评价，不用查询拟合、早停或挑配置。两任务和全部父子进程退出后，公开代码、协议、完整正负结果、逐类指标及每轮/累计成本；不公开模型、特征、身份或私有路径。
