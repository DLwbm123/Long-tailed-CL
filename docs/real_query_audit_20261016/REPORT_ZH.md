## 标签预算应怎样计账

Qfit 用于拟合干预，Qgate 用于候选选择，两者均为额外开发监督；E 仅用于锁定后的评分。即使图像已有标注，重新获得访问权仍须计入可用标签资源，不能因无需付标注费就记作零监督。

账本至少记录：按类独立患者/检查数、图像/帧数、标签来源、历史暴露、进入教师/记忆/更新/选择的阶段、保存的图像或特征字节数、每轮标签访问次数。全部方法使用相同的许可池、分组划分和曝光上限；记录实际消耗差异。旧类 query 若跨阶段保存图像或逐样本特征，会改变原 no-old-image/no-per-sample-feature 资源设定，必须在新协议中明确列出，不能藏在选择器外。

当前可认证为满足“患者独立、未进入既有教师、未作为开发选择证据”的完整 Qfit/Qgate 池：未建立。未采购或申请新标签，新增标注预算为 0；现有资源能否支持所需统计精度未知。不能将先前合成实验每类 1000 的规模直接当作医学数据要求或可用预算。

## 解除前置阻塞的最小条件

1. 获得与当前图像可靠连接、可解释命名空间的患者/检查分组，或获得来源明确的新独立队列；病灶或图像 ID 不自动替代患者 ID。
2. 在任何新教师、记忆构建和超参数选择前，按患者固定互斥 S、Qfit、Qgate、E。若从原 train 重新预留，需重建受影响教师和对照；不能复用已见这些样本的旧模型并声称独立。
3. 根据逐类独立组支持量明确标签上限、历史访问和存储成本；在不读取 E 效果的前提下，前瞻评估原 1 pp 代价门槛的可辨识性。数量不足时报告不足，不放宽门槛或把帧/像素当独立病例增加样本量。
4. 这些条件满足后，再冻结具体细粒度干预与完整预算，启动医学实验。当前不扩 rho 网格、不借用封存 E、不自动更换数据集。
