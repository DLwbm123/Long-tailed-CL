## 观察与解释

两数据集都产生了非零方向，每个旧类内的权重重新分配，类别 CE 总质量、节点位置和保留项原始权重均保持固定。ISIC 的局部旧类 CE 方向导数近零、新类为 −0.06698；HK 分别为 −0.01372 和 −0.00427。这些是 Qfit 上、零改动处的局部预测，不能保证有限更新后 CE 或准确率改善。

ISIC Qgate 新类增益主要来自一个新类：正确数 24/287 增至 61/287；另一个新类保持 2/3。其 Qgate 旧类宏平均 CE 从 2.11650 增至 2.17175，新类从 1.67041 增至 1.90493。准确率与 CE 的变化不一致，不能把局部 CE 约束称作准确率保证。

HK Qgate 新类损失完全来自仅有 3 张图像的类别：正确数从 1/3 降至 0/3，另一个新类保持 7/8；一个预测翻转即产生 −16.6667 个百分点的新类宏平均下降。新类 CE 只从 1.296512 增至 1.296939。尾类查询样本稀少使准确率筛选非常离散；此观察不是放宽门槛的理由。

下一项可检验问题是：方向的局部 CE 改善能否在有限步长下兑现，还是主要在 Qfit 与 Qgate 之间失去一致性。下一轮将单独冻结一次半步机制对照，复用已有基线、完整方向和特征，不重训教师、不扩大查询集、不再读取 E。该对照属于开发机制诊断，不能补成独立确认。

## 数据边界与成本

原训练集先按已知身份组件划为 S、Qfit、Qgate，教师只见旧类 S。Qfit 共 1076 张、Qgate 共 1079 张，是额外有标签资源；E 共 1226 张。新人工标注为零。全部候选先封存，随后访问 Qgate；两次选择均锁定后才提取 E 特征。锁定时间及分角色访问记录保留在结果文件。这里的组件不是已验证的患者分组。

仅使用一个种子、固定顺序、首个增量。图像编码器及其初始化适配器池冻结，仅训练下游 rank-8 非线性适配器；这不是端到端全协议复现。总适配器更新 288 次，记忆构造更新 96 次，另有工程自检前向更新 192 次、超梯度反传 4 次。完整分阶段耗时、CPU/GPU 历史累计与特征缓存大小见 `COSTS.json`、`RESULTS.json`；GPU 进程驻留时间不是 GPU kernel 忙碌时间，父进程墙钟不重复计入。

E 是历史复用的开发验证集，患者隔离未知；区间只反映固定模型和已知组件内的条件性不确定性，不覆盖训练种子和患者泛化。HK 极小尾类的自举可能退化。基线可用相同资源，但不优化查询权重，因此尚未分离“额外查询监督”与具体权重机制的收益。
