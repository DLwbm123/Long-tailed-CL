# 同容量固定随机真实记忆对照

上一轮[真实代表 2×2](../real_herding_factorial1_20261017/REPORT_ZH.md)已交付：ISIC 的 HH 在两个开发查询通过，HK 失败（提交 `541cdb3`）。本轮只检验 ISIC 的收益是否依赖 herding 选样；不以新方法寻找查询赢家。

## 唯一改变

将 HH 的 herding 选择替换为一次固定类内均匀不放回随机选样，得到 RR。每旧类仍取 min(16, 类内 S_old 数量)，与 HH 各类数量完全一致（ISIC 共 64、HK 共 169）。CPU PyTorch `randperm` 使用 `Generator.manual_seed(74002+class_index)`，截取前 min(16,n) 项并按源索引排序，保存原 float64 特征，类内概率均匀；两个数据集使用同一冻结种子规则。不追加抽样、不扫描或挑选种子，不增加容量。

RR 的 CE 与保留项共用同一套随机记忆。其余保持 HH 完全相同：教师、固定 ETF、适配器初始化、新类支持、类别顺序、数据划分、48 步和步长 1/16；CE 每已见类质量 1/K、保留项每旧类质量 1/old。教师正确掩码与旧类中心化目标在 R 上依原规则计算。真实样本的变化会改变掩码有效质量，须单独报告，不宣称仅有几何变化。

## 判定与比较

唯一主要判定是每个数据集 RR 相对原 MM，在 Qfit 和 Qgate **均**总体 BA 严格改善，且旧/新 BA 各不下降超过 1pp。两数据集单列，旧类收益不能覆盖新类失败；不事后用 HH 或某个查询替换主要指标。

次要报告 RR−HH 的全部组别/逐类 BA 与 CE、teacher-correct 质量和记忆资源。HH/MM 指标直接复用已交付结果，不重复训练或推理。若 RR 也通过，说明本次 ISIC 开发信号不要求特定 herding 选择；若 RR 未通过，只能说明这一个固定抽样未复现，不能由一次随机抽样证明 herding 普遍优越。不得宣称跨抽样稳健性。

## 数据访问与预算

一次构造任务只读原 S_old，保存两数据集 R，不读查询、E 或新标签。两个拟合任务只读教师、S_new 与封存 R，禁止读取 S_old。模型保存后才读 Qfit/Qgate 与原基线汇总；查询不用于选样、梯度或早停。所有查询已被历史分析和本轮设计暴露，仅开发证据；患者分组未知。禁止 E、保留测试、原图像、新标注、GPU 或其他项目。

三个串行 CPU 任务（banks、ISIC_random、HK_random），两次适配器拟合各 48 步，共 96 步；每任务 900 秒，总限 3600 秒。无教师/编码器/可学习记忆更新，无超梯度、无自动重试。复用已验证的分离 CE/保留训练与角色访问守卫；新增随机选择执行一个小型确定性、不放回、索引范围及稀少类自检，正式记忆继续断言上限与唯一性。没有新增实验训练自检。

保存所有失败、缺失、逐类正负结果和每阶段 CPU 驻留/user/system/峰值 RSS；监督器墙钟单列，累计成本延续上一轮，不重置预算。全部进程退出后公开结果与报告并验证交付。私有特征、模型、样本身份与运行路径留在既定私有存储。
