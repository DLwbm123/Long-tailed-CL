# 固定 H 支持的保留总质量匹配对照

依据已交付的 [H 记忆 2×2](../real_herding_factorial1_20261017/REPORT_ZH.md) 和 [固定随机记忆](../real_random_memory_control1_20261017/REPORT_ZH.md)（最新交付 `b472604`），H 在 ISIC 双查询通过、HK 失败，随机 R 均未通过。H 的 teacher-correct 概率质量明显小于原 M；本轮检验 ISIC 的 H 信号是否依赖这一总权重差异。所有既有结果都是开发依据。

## 唯一改变

直接复用已经封存的 H，不重新选样、不读旧 S。令 m_M 和 m_H 为同一冻结教师在 M/H 上的正确概率质量：各旧类总质量 1/old，类内使用各记忆原概率，正确条件为旧类 logits argmax 等于标签。定义唯一固定系数 s=m_M/m_H，训练目标为原 CE + s×原 H 保留项。

该比值只依赖冻结教师和记忆，训练前一次计算；不使用查询，不优化或搜索系数。运行断言 m_M、m_H 在 (0,1]、s 有限且为正、s×m_H=m_M（误差小于 1e−12）；为零或非法则失败停止，不替换公式。保留项仍使用 H 上的原 teacher-correct 掩码、旧类中心化教师目标和类内概率；CE 同样使用 H。教师、ETF、初始化、新 S、48 步、步长 1/16、种子/类别顺序/数据划分均保持不变。

总质量匹配只控制全局权重总量，不匹配逐类正确覆盖、支持几何、梯度范数或方向。因此若效果改变，只支持对这一固定缩放敏感；若通过，只说明收益不完全依赖较小的全局正确质量，不能证明完整机制。

M 只用于确定一个标量，其节点不进入本轮训练损失。此为有额外 M 统计信息的机制控制，不能宣称与纯 H 方法信息预算完全相同；不提升为新的正式方法结果。

## 预先固定判定

每数据集的质量匹配 HH 相对原 MM，Qfit 和 Qgate 都必须总体 BA 严格改善，旧/新 BA 分别不下降超过 1pp。沿用原 select 函数。未缩放 HH 只复用历史公开指标作次要描述性比较，报告逐类 BA/CE、所有失败、缩放值和匹配前后总质量；不重训基线，不事后挑选缩放版本。

ISIC/HK 单列，不用辅助 CE 改善替代 BA 门槛。全部查询早已暴露且参与研究设计，不是独立验证。患者分组未知、只有首个增量和单种子小适配器；不声称临床泛化或完整持续学习结果。

## 访问与预算

启动时复制已有 H 银行及其构造收据，原构造成本已在历史累计中，不再次计入本轮。两个串行 CPU 拟合任务 ISIC_mass/HK_mass，各 48 步，共 96 步；每任务 900 秒、总队列 3600 秒。无额外代表构造任务，无自动重试、参数或种子扫描，无编码器/教师/可学习记忆/超梯度/GPU 更新。

拟合任务只读教师状态（含原 M）、封存 H、新 S；旧 S、E、保留测试集、原图像和新增标注禁止。当前模型先保存，再读取两个开发查询和原基线汇总；查询不参与训练、比值计算或早停。保留原类质量、有限数值和访问守卫断言，并增加总质量匹配断言；不新增训练自检。

全部任务结束且父子进程退出后，公开源码、协议、完整正负结果、逐类指标、每轮及累计成本；CPU 驻留/user/system/RSS 与监督器墙钟分列。复用构造不冒充零历史成本，失败/缺失也报告。特征、模型、身份与私有运行路径不公开。
