# 真实旧类完整 CE 支持参考：保持原记忆保留项

查询方向与偏置控制的四项双向门槛均未通过，尚不能认为微调查询权重已经解决主要问题。本轮先检验旧类 CE 的压缩支持是否存在可观察损失，暂停查询参数优化。

唯一训练变化：旧类 CE 从每类 16 个原合成节点替换为该类全部原 S_old 特征，并在类内均匀加权。旧/新类别各自仍占 1/K 的总 CE 质量；新类 S_new、教师初始化、ETF frame、48 步、lr=1/16 全部保持原设置。

保留项仍只在原合成记忆节点上计算，使用原类内概率、原教师旧类中心化 logits、原 teacher-correct 掩码和原总系数。不能把保留项也换成真实支持，否则会同时改变覆盖和约束。新实现用分开的 CE 与保留项前向；一个小型三步断言用原记忆同时作为两种支持，核对其与原训练器的参数一致性，并确保保留掩码非空。

这会重新访问既有旧类 S：ISIC 3236 张、HK 3140 张对应的缓存特征。不读取原图或新增标签。完整旧类支持是额外资源参考，明确不满足原记忆预算，也不是优化意义上的上界；其作用是定位压缩 CE 支持的影响，不能将其准确率当作可部署方案。

候选训练完成保存后才读取 Qfit/Qgate，两者仅作开发检查，不参与本轮拟合。主要判定：对每个数据集，在两组查询上均需总体 BA 严格改善，且旧/新类 BA 下降各不超过 1 个百分点。报告全部类级 CE、召回率、失败与资源成本，不把其中较好的一组替换为主要结果。历史查询数据已暴露，患者隔离未知，结论不作独立医学验证。

一个 CPU 工程自检和两个顺序数据集任务，各最多 900 秒，总上限 3600 秒。实际适配器更新 96 次，另有工程自检 6 次；无教师/编码器/记忆构造或超梯度更新，无新增 GPU、特征提取、标注和 E/保留测试集访问。记录旧支持特征数量/字节和原记忆数量，实际结束后完整公开交付，再据证据继续分类研究。
