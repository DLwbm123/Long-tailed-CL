# 最高分错误类分类间隔：固定损失对照

依据[支持CE/BA诊断](../support_metric_audit1_20261017/REPORT_ZH.md)（`4204291`），投影相对原HH在HK旧支持CE下降0.040866，BA却下降4.3269pp；ISIC旧支持CE和BA同时变差。本轮从原HH设置出发检验单一分类损失改变，不继续调整投影。

## 唯一改变

对于已见类logits s和真实标签y，分类项由完整CE改为 softplus(max_{j≠y} s_j−s_y)，仍按原样本权重p_i加权（各类总质量1/K）。错误竞争者覆盖全部已见类，不分旧新组、不含未见预留类。没有温度、额外间隔、系数选择；ties采用现有PyTorch固定索引max规则。它是不同的代理目标，不等于多类完整CE，也不保证BA改善。

从相同原冻结旧教师初始化48步、步长1/16，普通梯度下降；复用H64/169、新S、ETF、seed74002、顺序/划分，原未缩放H保留项不变。无投影、组等权、新参数、模型续训或旧S。相对原HH只改分类项；相对此前投影模型同时改变分类项和更新规则，后者只是背景对照，不能据此作单因素因果解释。

这也不同于此前“组内CE+旧新两组max logistic”：本轮直接比较真实类和最强错误类，错误类可来自同组或异组。日志分别记录原完整CE、实际新分类损失、保留项，不能用新目标数值冒充CE。

## 冻结判定与对照

主要候选vs原MM，每数据集Qfit/Qgate均须总体BA严格改善，旧/新各下降不超过1pp。原HH是完整次要对照，投影模型作完整背景对照；报告组别/逐类BA与CE、全部旧类损害和失败，不事后选择有利对照或指标。继承H收益不能称为新损失增益。
