# NIH 长尾持续学习：前12小时研究报告

**报告窗口：北京时间2026-10-20 22:03:28—2026-10-21 10:03:28。** 截止时刻取开始撰写本报告的时间；正文依据已经封存、独立核验并交付的记录汇总，本次不重训、不重提取、不重复评分。

## 1. 主要结论

过去12小时没有获得通过预定继续门的原方法改进。原强联合`df_matched_joint`仍是本路线有效的同协议参照：最终82/300＝27.3333%，六阶段平均34.0053%，尾7为20/105，后来10类38/150。

固定Spatial Moment使最终多对2张、尾类多对5张，但六阶段平均下降，未通过整体及阶段门。原生MLP分支、固定类别数容量调度和CLS×patch交叉特征均未通过各自完整门，已关闭固定假说，未用扫参或事后更换主臂补救。

额外全历史特征权限下的离线CE得到94/300＝31.3333%，说明同一表示上的某个读出终点能增加整体正确数；但500次迭代后未收敛，尾类19/105又低于原强联合。因此它不构成合法同记忆CIL提升、最优CE或严格性能上界。

原方法27.33%与这次静态ImageNet冻结26.67%、full所达best31%的分数量级接近，没有本次证据支持“原方法明显异常低效”的判断；但静态训练和增量解析读出的增强、目标及访问不同，不能据此认证实现完全正确或差距已经消除。full最后仅18%，尤其不能将偶发best称为稳定收敛上界。

### Spatial Moment：局部改善不等于通过整体门

单个固定signed-p3、同1536维，p1只作小样本资格。最终相对强联合+0.6667pp、阶段平均−0.7712pp；尾7多5张、后来10多3张，头7却少3张。预定final>=86/300及阶段平均>=参照+1pp两门失败；尾>=22、后来不差通过。关闭该固定迁移，**不启动附条件ProtoTail B**，不扫p/温度/M/seed/融合/白化。

已完成归因：基阶段就少对3张，第2—4阶段另有新类竞争损害，不能只归因增量漂移。第一次32图p1舍入资格失败永久归档；只修复p1端点，不改变p3科学候选。独立验收重解保存统计六头/重算保存query分数，没有重新图像提取。

证据：[结果](../spatial_moment1_20261020/REPORT_ZH.md)、[归因](../spatial_moment1_20261020/ATTRIBUTION_ZH.md)。该运行21:59:13已开始，早于窗口约4分钟，属于跨窗续行；其全程费用不能全部冒称本窗新增。

### 原生MLP与类别数容量规则：不支持替换原强联合

native_pre用最终CLS加末block MLP激活中仅基类Fisher选定的768坐标，post用同CLS加该MLP投影后768维。同一编码pass、同维配对。pre相对强联合救9害15，基阶段66→60；最终虽胜post2张，阶段平均反低于post。最终、阶段平均、基阶段保持及pre平均不低post四门失败，不推广为全部InnerCIL被否定，也不扫层/维数/Fisher规则。

classmean固定CLS alpha=K/10、联合匹配其训练df。主联合阶段平均仅+0.1133pp，最终少3张、尾类持平；最终、阶段平均+1pp、尾类三门失败。控制CLS尾类较好不能事后改为主候选。关闭固定调度，不扫K指数/alpha/阶段/seed。

证据：[native](../native_hidden1_20261021/REPORT_ZH.md)、[classmean](../classmean_df1_20261021/REPORT_ZH.md)。

### 交叉特征：明显退步，保留负结果与惩罚解释

固定aligned中心化同通道CLS×patch乘积，对照固定偏移384通道；都保留原线性块。aligned最终比强联合少29张、救19害48，七门仅“平均不低于shifted”通过。原线性块仍在，不代表其惩罚保持：相同总df下final alpha由1.5374增到27.9215，原坐标CLS块显式罚由3.0747增到55.8429。因此这是该固定函数/尺度/惩罚几何组合的负结果，不能证明一切乘积信息无用，也不据此再扫尺度补救。

所有20类CLS/patch边际Gram及300val特征与旧对照误差0，独立显式矩阵/Cholesky核验通过。证据：[报告](../crossview_product1_20261021/REPORT_ZH.md)、[读出审计](../crossview_product1_20261021/READOUT_AUDIT.json)。
