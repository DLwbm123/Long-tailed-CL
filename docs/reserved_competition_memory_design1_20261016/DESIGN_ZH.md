# 稳定接口、预留类别竞争与判别记忆：快速 2×2 合成验证

本轮仅执行一个前瞻合成 CPU 试验，不恢复无限自主实验、不进入医学 GPU。test/reserved 封存。科学参数以 DESIGN_LOCK.json 为准。

四臂为 fixed_moment / fixed_decision / assigned_moment / assigned_decision。全臂共享不可变合成输入、固定全局 ETF、同初始化的 rank8 非线性残差适配器、48 步全 batch SGD（1/16）、class-balanced CE 和系数1的旧正确记忆中心化 logits 保持。不再使用 .125 局部头域。初始 U 正态、V 零；未运行真实冻结 ViT，不能称验证了医学稳定接口。

固定输入 -> 可学习归一化残差适配器 -> 固定容量 ETF。类别逐步激活，旧类别 slot 永不换位；新增类采用固定空位或 Hungarian 分配，代价为当前类对方向的负平均 score 加旧记忆上新方向超过旧正确方向的 softplus 风险。只使用当前训练支持和已有合成记忆；已知总类别数用于容量，不使用未来支持。

两种记忆均每类16合成节点和16权重，当前任务结束压缩48 Adam步、lr .02。原 mean/second-moment 目标保留；新判别目标匹配实际任务前后两个模型的 seen/reserved 最强竞争间隔联合响应与 CE 参数梯度。联合响应采用8个固定投影的 sliced-W1；这是有限投影近似，不是完整联合运输距离，更没有任意未来查询保证。梯度项为两个快照相对平方误差均值，分母下限1e-12。无对抗查询优化、无未来模型查询。最后阶段 reserve 为空时该坐标显式为零。

所有臂从当前类均值加固定 .1 高斯扰动初始化合成节点，非挑选原特征行；不提供隐私保证。与旧轮初始化/架构不同，不称旧轨迹复现或跨轮严格贡献。moment 两臂共享一次构造；decision 两条轨迹分别构造，实际总记忆更新1728，不把每臂逻辑预算当总计算。

数据沿用冻结的低秩非高斯 unit 合成分布 r=2K，small/ISIC-scale/HK-scale，原 counts、seed、信号噪声、任务顺序不变。只有公开规模参考，没有医学特征/图像/checkpoint/val/test。每规模四臂全部阶段训练封存后才生成独立同分布合成评价集；旧真实合成支持仅在封存后用于记忆 CE/gradient/margin 误差审计，不反馈训练。

主门要求两个高维每一个阶段完整臂的 BA、oldBA、newBA 均不低于三个同架构对照，并分别至少一次 BA 严格收益；单位与不可变性检查通过。首阶段 oldBA=null。报告所有阶段、类别 recall、救回/破坏/错换错、错误流向、交互项、全正零负。该新门不修改旧失败结论。无 GPU-ready 声明。

每独立 CPU case 1800秒，整体5500秒，仅资源停止上限。4子进程分别计驻留/user/system/RSS，内部训练/压缩/评价已包含，父wall另列。新GPU为0，历史闭合GPU400036.74851310626秒保持。先前20轮CPU5862.192477149423秒仅加本次一次。失败保留，不同轮健康源上修复/重启。

贡献边界：本轮分离分配与记忆及交互；固定接口和教师保持是共同条件，不单独声称它们有分类收益。没有生产 checkpoint、预训练 encoder 或原医学 Core/LT 同架构验证。完成本轮后停下分析，不自动扩预算或启动下一科学轮。
