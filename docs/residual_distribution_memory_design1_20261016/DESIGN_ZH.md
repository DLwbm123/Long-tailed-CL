# 随机残差分布记忆：前瞻CPU验证

上一容量审计05c845d已完整交付。它给出某各向同性参考、固定16单位原子的广泛查询误差下界，不解释所有医学失败，也不允许降低旧门。本轮改变记忆表示：保存原矩匹配中心/概率，并补一个由当前支持确定的随机残差分布；不再永久只使用同16个离散点。尚未接生产，不是医学方法有效性验证。

## 构造、控制与计算账

只执行一次原ball moment48 Adam节点+logits构造，原16nodes/class、lr .02/48步、seed263/264/265、原fixture与类比例不变。random/moment对照保持原实现。另加normalized_moment必要机制控制，区分仅归一化中心与真正随机残差的作用，不增加其优化。candidate与moment共享完全相同中心权重，不重复计费。

对每类计算rho=max(0,trace(Q_current)-sum_i p_i||n_i||²)。仅存额外一个float64标量，无可调强度。每次调用独立生成16个Rademacher向量xi_i，各坐标±1/sqrt(d)，取raw_i=n_i+sqrt(rho)*xi_i后单位归一化。raw范数<=1e-12拒绝并保留失败，不发明方向。rho=0原样返回中心以保证关闭精确。节点/权重冻结；不新增记忆优化或判别查询训练。

噪声原空间均值0、协方差I/d，因此归一化前的解码二阶矩为Q_memory+rho I/d，rho>0时残差满秩。但真实Q_current-Q_memory未必PSD或各向同性；归一化又改变均值/矩，不能宣称精确分布恢复。记录原trace、rho、各向同性残差Fro误差、每批归一化trace/均值误差。每类存储从16(d+1)个数增为16(d+1)+1个数，明确不是字节完全相同；每次仍仅16合成点，生成与归一化计算非零，单独记录临时batch逻辑bytes与实际RSS。

## 查询时序与统计范围

本轮明确研究“查询先固定，随后使用新的合成批次”的估计，不研究“看到该次随机样本后再挑任意最坏查询”的uniform误差。后者每次仍是16原子，旧容量反例不因采样而消失。对生成分布的条件期望/梯度估计不等对真实旧类分布无偏，拟合偏差和采样方差必须分开。

评价仍48查询=4随机组+2共同stress组各8，rank8/beta8/lr .01/每stress12步，A/B Fro<=2、v norm<=2，不扩大查询族或更新步数。stress对四种方法共同找困难方向，candidate每步使用新的16点噪声批估计梯度；这只是评价查询构造，不能更新任何记忆。所有查询最终冻结后，预声明8个新独立PRNG批次做方差审计（固定seed+7000+batch索引），这些是随机解码算法的审计重复，不是新增正式训练seed/轨迹或部署累积128节点。

主门仍要求两个高维都通过10%最大改善且均值不增：具体要求每一个新16点审计批次都满足max<=.9各原moment/random的max、mean<=各基线，另算术通过。不得仅挑好批次，不允许把8批平均预测拿来过主门。8批平均仅独立标记的诊断，可分解模型偏差与采样波动，不当部署表现或概率保证。normalized_moment全正负另报，不替换主控制。该新时序协议不能倒改旧失败结果或称通过旧uniform要求。
