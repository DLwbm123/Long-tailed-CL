# 冻结响应头的旧 H 空间投影消融

两组诊断完成并退休，工程恒等式与来源引用通过。硬投影没有给出跨数据集稳定提升：ISIC Qgate 宏平均准确率下降；HK 两片描述性指标过门，但新类正确数没有改善。本轮无拟合、不检验新头梯度，不宣称完整方法成功。q401 的预算内未收敛与主门失败保持不变。

唯一操作为 `Wprojected=W0+Q Qᵀ(Wfull−W0)`，Q 来自旧 H 的固定数值秩 SVD，Wfull 为 q401 冻结预算端点，W0 为原 class-balanced ridge。没有系数或秩扫描，完整旧 H 的全类别响应保持到数值误差；新 S 与 query 响应重新计算。所有 query 已用于开发，不是独立验证。

## 后续依据与边界

这次消融否定“直接删除空间外更新即可兼顾学习和保护”的简单解释；空间外更新同时携带伤害与收益。它没有证明压缩损失、旧 H 空间不可学习，或约束内最优头必定失败，因为投影头未在受限空间重新优化。

下一项有区别的最小问题是：保持旧 H 空间外为原 ridge，在同一合法 H+newS 上直接优化相同 CE+响应保护目标，能否恢复新类拟合同时保留旧类表现。若启动，应固定同一数值秩和正则、从原 ridge 开始、沿用联合300次运算及时间预算；单独报告约束切空间梯度，不冒充全空间收敛。不得从本轮结果选择投影系数或调整历史判定。所有结果仍仅为开发证据。
