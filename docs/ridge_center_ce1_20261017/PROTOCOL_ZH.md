# 固定强度、原 ridge 为中心的 CE 控制

## 假设与唯一改动

q396/q397 均收敛却未通过双查询标准。q397 向零的 .064 罚项使 ISIC/HK 头范数从 10.678/10.878 降到 3.021/3.849，支持 CE 上升，HK Qgate 小类单例贡献超过总体净增且旧类保护失败。这些是已曝光开发依据，不是独立验证或收缩导致错误的因果证明。

本轮只把罚项中心由零换为封存的完整原 ridge 头 W0：L=类平衡 CE(8zW,y)+.064/2||W−W0||F²，等价 U=8W 下 CE(zU,y)+.001/2||U−8W0||F²。不叠加另一个向零罚项，不调强度、温度、初始化或插值。所有权重列都受约束；W0 是原同 H+新 S 的岭头，不是之前任一 CE 头，也不是旧任务 teacher。假设是保护已学判别头附近的 CE 修正可能减轻向零收缩的损伤；失败同样保留。该标准二次锚定是机制对照，不宣称方法创新。

## 输入、优化和判定

沿用 q397 全部合法输入与绑定：原 H+新 S，ISIC 64+2290=2354、HK 169+95=264；零 adapter、1536 维归一化 feature、类质量1/K且类内均匀。三份 DELIVERY 绑定、有限值/DT/count/零adapter检查、完整均值重构 maxabs<1e−12、原岭正规方程 residual≤1e−7。禁原旧 S/teacher/E/原图/新标签；拟合时不读 query/ref。保存候选头后 seal，才读取 Qfit/Qgate 与历史参考。

W 从同一封存 ridge 初始化，只优化无偏置 W，无列归一化；中心固定且无梯度。L-BFGS lr1、max_iter200、max_eval250、history20、strong_wolfe、tolgrad1e−8、tolchange1e−14，closure 硬上限300/fit；终点梯度∞≤1e−6为收敛，不延长/重试。不用 query 早停、选择参数或罚项中心。

主要参考仍为原 raw_ridge：收敛且每片 BA_all 严格提高、BA_old/new 各下降≤1pp，两个查询都通过才记数据集通过；均值次要，q397只是额外历史汇总比较，不切主、不部署、不改阈值。所有查询早已曝光开发，患者分组未知。完整逐类/组/CE/错误去向、rank/margin/top2/3/ties/竞争者、ridge与mean→candidate配对救回伤害，完整目标梯度轨迹、初末支持 CE/W范数及距中心范数全保存。原两头整数聚合精确复现、CE容差1e−10。交付时全部42逐类和12组汇总对照q397，不重跑、不访问其头，不推导两候选间的逐样本配对。
