# 训练留出统一收缩与按类风险受限修正：冻结一次实验

用户授权两个候选、对比两个强联合头、尽量复用数据、控制缓存、每30分钟监测、保留成本负结果。不得添加其他模块、独立病例、种子、数据或新科学轮次。

## 固定基础

保持NIH author20单标签开发协议、68058训练/300验证、768维CLS与patch均值、seed74002、六阶段和原预处理/骨干不变，不访问E/test。原CLS alpha1为参照，尺度校准联合头为候选主干，df匹配头仍为同等强比较对象。各类总权重1，患者等权、患者内图像等权；风险按类别及输出平均。

## 三折训练内部交叉拟合

同一训练患者始终同折：SHA256('risk-shrink-v1:74002:'+规范患者ID)前8字节little-endian整数mod3。此散列仅为稳定算法分折，不是文件校验；不扫分折/seed、不基于结果重排。验证患者完全不参与。
每阶段只拟合当时已见类；两折训练一折出预测。各折每类重新归一总权重1，使用原CLS ridge alpha1。折内尺度联合使用折内基类训练能量计算s，输入[C/sqrt2,sM/sqrt2,1]，ridge alpha1和单个受罚截距。所有尺度均不使用留出折，不使用验证结果。
若某类折内训练没有病例，保留零贡献/零目标列，公开缺失计数，且该输出的按类收缩系数固定0；不补数据或换折。统一系数仍按全部OOF风险定义并报告缺失限制。

一次全训练编码，缓存float32 CLS+patchmean，仅1536维，不存patch token。缓存约398.8MiB；训练身份/索引仅私有。旧训练Gram用于新缓存边际/交叉一致性检查，旧验证query和11臂分数直接复用，新增验证编码0。
折内Gram仅在内存中构造，不把约1GiB临时矩阵写盘；保留小型折内头、OOF分数和风险二次型供核验。缓存为本轮可再生成中间产物，完成独立核验和交付后才能考虑清理；失败或未核验时保留，不自动删证据。

## 两个候选

令C为类中心化CLS分数，D=(S_joint−S_CLS)H，H=I−11^T/K。候选输出F=(C+D*alpha)H；alpha是输出类别系数，不知道推理真值，不是样本门控。alpha全0回CLS、全1回尺度联合（argmax等效）。D包含联合估计改变CLS的部分，不称为纯patch信息。
OOF标签目标为onehot*H，平方分数损失作为Brier型代理（分数不是概率，不称概率Brier校准）。归一为每类/患者及输出平均。
1. uniform_shrink：全局alpha∈[0,1]，直接解析最小化全部OOF代理风险；无验证选参。
2. risk_limited_shrink：每输出一个alpha_c∈[0,1]，最小化相同总OOF风险。对每个非空“折×真实类”的风险设不高于其CLS OOF基线；对其中CLS OOF正确且至少2名患者的子集也设同样约束。少于2患者的正确子集不加约束但显式记录，不能声称已保护；空类风险不计算。约束对所有类一视同仁，不按验证尾组或频次手调。使用原患者权重在子集上条件归一。
风险为alpha的PSD二次型（输出中心化纳入Q）。alpha0可行；SLSQP从0单次求解，maxiter1000/ftol1e-10，约束按各自基线风险max(R0,1e-8)归一；成功标志、系数界限和归一约束违反<=1e-7均须通过。失败保留全部信息并停止，无换solver/盲目重试。数值求解不宣称严格全局最优；常数解0是有效负结果，不事后放松保护。
这不是“不伤害CLS正确率”的理论保证：代理风险、OOF正确子集及折间估计均有限；独立评价上仍可能损害。

## 资源与封存

单次主程序含退出最多3小时、GPU1 reserved<=6GiB、CPU4线程、主进程峰值RSS<=8GiB、输出<=768MiB；新增训练编码<=68058，验证0，骨干优化0。36个折内ridge头（6stage×3fold×2），6个统一闭式系数与6次受限数值求解；保留迭代数/耗时，不能把系数求解说成零优化。
全六阶段OOF预测与收缩系数求解并封存后，才打开验证分数；不根据验证结果重新选择规则/候选。
小矩阵验证折权重、代理二次型/梯度/约束、解析统一最优、受限已知解、端点不变性。启动一次健康检查后后台运行；每30分钟按身份和状态检查，正常不重复启动。
