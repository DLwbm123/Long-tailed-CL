# 训练留出风险收缩：六阶段完成与独立核验报告

## 结论

本轮已完成六阶段并独立核验通过。**两种收缩都未超过两个强联合头。** 统一收缩最终78/300（26.000%），低于两个联合头的82/300（27.333%）；受限收缩最终74/300（24.667%），也低于CLS的76/300（25.333%）。受限方案减少了CLS正确样本的损害、尾类正确数恢复到CLS水平，但丢失的救回更多，没有实现保留联合增益并降低代价的共同目标。

第三、四阶段被原保护约束严格强制为零；第五、六阶段则得到通过原容差验收的非零数值解。不能将后三阶段概括为都归零，也不能把本次负结果归因于“实验没算完”。三个历史失败均保留，完成不追溯改变失败状态。

## 为什么训练约束通过，验证却不占优

所有受限OOF风险约束均通过，独立重算最大归一违反约1.71e-11，低于1e-7；但OOF代理风险约束不等于验证0/1正确率或尾类不伤害保证。第三、四阶段的精确保护结构直接排除了所有非零修正；前两阶段也只保留统一方案代理风险收益的约6%–7%。第五、六阶段有非零空间，最终OOF风险仍由CLS0.04928861降至受限0.04894479，却没有转化为验证正确率收益。

因此当前问题至少包含保护结构过强和代理目标与分类评价不一致；现有证据不能把相对贡献精确量化，也不能宣称所有风险控制/收缩机制无效。本轮仅否定这两个固定规则实现共同目标的效果，不否定patch相对CLS在既有强联合头中的增益。

后续应保留两个强联合头作为主比较对象，收缩作为完整负结果及机制诊断。若要研究另一种训练侧原则，应另行明确协议并授权，不能依验证结果放松本轮约束、扫描权重或添门控追分。本次不启动新实验。
