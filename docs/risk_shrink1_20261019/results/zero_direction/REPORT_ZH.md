# 零点可行下降方向分析：第三阶段的保护约束强制零解

## 结论与适用范围

只复用已有problem_0/1/2、已保存收缩系数和匿名约束元数据，没有训练、重编码、科学收缩求解重试、验证评分或续跑。第三阶段（stage 2，14类）的结论现已从数值猜测升级为代数证书：**对保存的float64二次型按其精确有理数值解释，原非负盒约束下，精确满足全部原保护不等式的点只有alpha=0。因此不存在非零可行方向，更不存在非零可行下降方向，零点是原精确问题的唯一可行解和全局最优解。**

这个证书适用于当前冻结分折、表示、统计和风险约束，不是对其他分折、数据或泛化风险的普遍定理。不把已有float64统计称为无限精度原始样本风险；本次直接证明的是实际交给求解器的保存矩阵。证书有明显正裕量，不依赖近零特征值符号或HiGHS的不可行状态。

## 分析路径与可复核证书

每个保护约束记为

    g_i(a) = (a' Q_i a + 2 b_i' a) / s_i <= 0,
    s_i = max(OOF_CLS_subset_risk_i, 1e-8),  a >= 0.

在零点，任何非零可行方向d都必须满足d>=0和2b_i'd/s_i<=0。利用齐次性可附加sum(d)=1进行方向诊断。一个小型线性规划报告该系统不可行；第二个线性规划只用于搜索证书权重。这两次都是已存矩阵上的数学诊断，不是训练、头拟合或原科学收缩问题重试，其状态本身不作为证明。

搜索得到81条约束中12条的非负组合。将组合权重舍入为8位小数后以精确分数归一，得到lambda_i>=0、sum(lambda_i)=1。舍入仅作用于证明所用的辅助权重，原问题矩阵、目标、约束和容差完全未改。

从原矩阵以Fraction精确有理数运算重新计算：

    Qbar = sum_i lambda_i Q_i / s_i,
    v    = sum_i lambda_i (2 b_i) / s_i.

精确LDL分解的14个主元全部严格为正，并逐元素精确重建Qbar，证明Qbar正定。v的14个分量全部严格不小于367/2500000，即0.0001468；实际最小分量约0.000146855704。公开证书保存12条约束索引、匿名折/类别/子集计数、精确分数权重、组合向量和LDL主元摘要，脚本可在私有原矩阵上重建并核验，不公开逐样本证据或原二次型。

于是对任意合法非负a：

    sum_i lambda_i g_i(a)
      = a' Qbar a + v' a
      >= 0.0001468 * ||a||_1.

若a非零，右侧严格为正；但所有g_i(a)<=0又要求左侧非正，矛盾。因此只有a=0可行。这个证明覆盖整个盒约束可行域，不只是零点邻域，也不依赖原目标函数的梯度。

## 原容差下也只能接近零

科学约束的右侧仍是0，原数值验收允许每条归一违反不超过epsilon=1e-7。若使用这一个原验收容差，则上述组合给出

    0.0001468 * ||a||_1 <= epsilon * sum(lambda_i) = 1e-7,
    ||a||_1 <= 0.0006811989100817438.

这是对合法非负系数的上界，不是新增或放宽约束，也不是建议把验收容差当作可以利用的科学收益。任何单个系数也不能超过该上界，因此不能期望在原规则下恢复0.1量级的联合修正。原Clarabel约2.38e-12的返回系数与这个结论兼容，但其AlmostSolved仍是失败，不能追溯改判。

## 哪些保护共同造成阻断

这份充分证书只需要12条保护：10条来自“折×真实类中的CLS OOF正确子集”，另外2条是class15在fold0和fold1的完整类风险保护（分别2张/2名患者和4张/4名患者）。正确子集涉及class13、6、17、1、8、12、18、14、9等，个别子集只有3或6名患者。

这是多个不同人群要求修正绝不增加其代理风险时的联合冲突。它表明当前保护系统足以阻断所有非负输出修正，不能把结果主要归咎于求解器错失一个明显可行下降方向。证书不是最小约束集；未删除约束做消融，不能说某一条、某个类别或“CLS正确保护单独”就是唯一原因，也不能把稀有类本身当作错误来源。

前两阶段作为现成检查：使用已验收非零alpha的方向归一后，所有保护约束在零点的方向导数均严格为负，最大归一方向导数分别约-5.45e-5和-5.04e-5，目标方向导数分别约-2.69e-4和-1.31e-4。因此这些阶段确实有非零可行下降方向；并非分析过程把所有阶段都判为零。其已接受最大系数0.07043和0.18175及风险下降仍沿用原记录。

## 如何解释两次求解失败

第三阶段精确可行域是单点，没有严格可行内点。全零起步时所有保护约束和系数下界同时活跃，SLSQP的局部步骤与锥内点法的数值终止在这种退化问题上容易遇到困难，这与两次记录兼容。不过本次没有证明求解器内部每个失败分支的具体成因。

应区分两件事：保护约束在数学上确实迫使本阶段零修正；求解器仍没有按冻结终止标准给出成功状态。前者现在有精确证据，后者不能用改标签或放宽容差抹去。此前“还不能确定是否只有零解”的不确定性由本次证书解除，但历史失败状态和成本全部保留。
