# SCARCITY-FACTOR1：固定规则、竞争强度与类内分配

用户授权根据分析继续实验、尝试改善效果。本轮在读取新结果之前冻结以下方法、预算与报告口径。此前开发结果促成此设计，因此本轮仍为开发实验，不是独立确认。

## 方法与最小比较

复用上轮五个固定编码器状态与 fit-only bank：ISIC/HK 缓存任务2（一 epoch）、ISIC任务3和HK任务4/6（完整两 epoch 轨迹）。只使用样本量差异描述符的正负单位系数；两方向对所有数据集都报告，不根据数据集名称选择方向。每状态7个唯一头：零头、原full正/负、row正/负、within正/负。

设原竞争矩阵为 B，行和为 r，总和为 M。对正/负稀缺度倾斜后，未与原矩阵混合的全局softmax分配为 C，行和为 s。三种机制定义如下，保持相同的原矩阵50%下限：

- full = 0.5 B + 0.5 C：原全局调整，同时改变类别竞争强度和类内分配。
- row = 0.5 B + 0.5 diag(s/r) B：只改变每类总强度，行内比例保持原值。
- within = 0.5 B + 0.5 diag(r/s) C：保持每类原总强度，只改变行内比例。

所有方案保持全局总量、非负性、零对角与原支持集，每条边至少为原权重一半。分解在自适应的50%分量上完成，避免直接归一化full破坏共同下限。验证自适应分量的行强度×行内分配可精确重构C。full两方向必须重建原edge_13/14，零头重建原edge_00；float头allclose阈值atol=1e-6、rtol=1e-5，求解残差≤1e-8，不放宽。

这是终端读出修改，不是已训练的完整新持续学习轨迹，也不干预编码器强度。row/within效果之差只能在此定义下解释，不能据一个状态宣称普遍因果规律。

## 训练侧选择与主要候选

每个机制分别在零、正、负三个头中选择，保持相同候选数。复用冻结的分类效用：旧类来自fit bank一二阶矩联合高斯；当前类使用不参与当前bank/平移/头拟合的原meta经验召回。积分为8批×4096，同一状态原seed+offset，同候选共用标准正态；不扩大预算或调协方差。历史meta可能已进入旧bank，不重新命名为独立留出集。

point选择沿用总体改善>max(1e-8,2×配对积分SE)，旧/当前/尾组点估计均不下降，最大总体改善，平局索引小者优先，未通过则零头。

stable选择先执行同一个point规则，再逐一删除一个当前meta身份的全部图像、重算该类经验召回，保持旧类高斯、分类头、类别权重和候选不变。只有所有删除都得到同一point赢家才执行，否则回退零头。若某次删除使类别无meta样本，视为支持不足并回退。删除不重新训练或求头。当前类经验分量在积分批次间是常量，删除只改变均值、不改变积分SE；快速计算须与显式重算合成校验一致。

唯一主要候选为 within_stable。full_stable提供匹配稳定性规则的原机制对照，within_point区分稳定性门贡献，row_point/row_stable及full_point用于机制解释。所有固定正负头也报告，不能只与零动作比较。没有合并七头后再搜索机制，没有根据开发结果切换主要候选或重新选阈值。

删除稳定性仅针对当前meta身份，不覆盖旧类统计或总体抽样误差；它不是置信区间、安全保证或独立泛化证据。即使全部回退，也不能宣布方法有效。分别报告实际收益、回退率、保护违反与相对固定规则的增量。

## 数据屏障与评价

复用旧缓存的当前任务before/after特征、原身份划分和上轮A/B索引；无新影像读取，无旧训练影像、医学测试或CIFAR访问。训练侧选择只接触当前train/meta与旧bank；所有五状态选择保存、三个屏障回执齐全后，才读取开发特征并计算full/A/B指标。读取manifest可能包含开发元数据，不能声称文件从未接触；明确禁止用开发指标选择。

full包括全部已见类别，是主要开发读出；A/B是固定覆盖类别的次级诊断，本轮两边均不参与选择。HK A/B仍缺5/6/19，不填零、不视为保护通过。每状态7头×3分区，共105评价块。缓存一epoch与完整两epoch状态分开报告。

主要可行性信号：三个完整轨迹状态上within_stable的full总体/旧/当前/尾增量均非负，ISIC与HK各至少一个完整状态有正总体增量，并在两数据集各至少一个完整状态超过匹配full_stable。正增量按>1e-8、非负按≥-1e-12判定，仅为本轮描述性门，不是统计显著性。另行列出对所有固定规则的比较；满足此门也不能替代固定规则对照或独立确认。失败、零变化、收益集中于少数身份、few类未改善均保留。
