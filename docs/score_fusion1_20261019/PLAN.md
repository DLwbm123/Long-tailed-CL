# 独立头分数融合与救回重叠：冻结最小对照

用户授权复用现有统计和预测，补等权及训练侧尺度归一化融合，分析同块CLS与联合头救回样本重叠；不加门控/其他模块、不扩病例/数据/种子、不调DENO、不恢复监测。

沿用NIH author20固定单标签开发协议、768维CLS和patch均值、seed74002、六阶段、原患者/类权重及固定ridge1。独立头直接复用joint_heads1中已封存的cls与patch头，不重新拟合；历史九臂分数直接复用joint_origin1。

新增两臂，每阶段固定：
1. score_equal=(S_C+S_M)/2，直接平均原独立ridge分数，不softmax、不调温度/权重。
2. score_train_rms：令H=I−11^T/K，sigma_C^2=tr[(W_C H)^T G_C(W_C H)]/K^2，patch同理；G为已见K类加权训练Gram（总权重K），包含原单个截距，sigma是训练样本与类别两维平均的类中心化分数RMS。
S_norm=(S_C H/sigma_C+S_M H/sigma_M)/2。
按每个样本在类别维去共同分数偏移，不做特征中心化，不改变单头argmax；该操作避免训练分数中对argmax无效的公共偏移主导sigma。所有sigma在读取验证分数前计算封存，仅用已见类统计，不用验证分数定尺度，不选择最佳融合权重。
这是训练内RMS归一化的固定简单基线，不是交叉拟合可靠性估计、概率校准或最优组合；若失败只否定这两个固定基线。

全部11臂报告六阶段mean/final、old/new、类正确数/混淆；融合对CLS、scale_joint、df_matched_joint及彼此报告救回/损害/改变。最终按上一轮固定尾7/中6/头7分组报告，不能挑一个联合头作为方便比较对象。
救回重叠：相对同一个原CLS基线，分别构造same-block与scale_joint/df_matched_joint的救回集合、损害集合；报告共同、仅A、仅J、Jaccard，按原CLS/patch四组和逐类拆解。尤其报告原共同错误205张内same-block与联合纠错的交集，不能从聚合差1张推断patch独有贡献。只公开聚合，不公开样本索引/身份。

CPU四线程一次运行，硬限5分钟、输出<=128MiB，新增图像编码/优化/GPU/头部拟合均0，无自动重试或新科学轮次。
