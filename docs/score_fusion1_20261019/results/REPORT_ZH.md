# 独立头分数融合与同块CLS救回重叠：完成报告

## 主要结论

固定等权分数融合最终25.333%，与CLS持平；训练侧RMS归一化融合25.667%，仅比CLS多1/300张。尺度联合和df匹配联合均27.333%，本轮两个简单分数融合没有复现强联合头收益；六阶段二者均低于两个强联合头。仅支持这两个固定分数基线不足，不能否定所有分数融合或宣布联合特征分类器不可替代。
同块CLS与df联合的全部救回集合分别8、16张，交集5；在205张两单头共同错误样本上分别纠正6、7张，交集3，即联合独有4、同块CLS独有3。不能把总计差1张说成只有1张新增纠错，也不能把联合独有4张直接视为严格条件独有信息。

## 冻结设置与训练尺度

沿用NIH author20单标签开发协议、原768维CLS/patch均值、seed74002、六阶段、患者/类权重、独立ridge alpha1及原300张验证。新增图像编码、GPU、优化和头部拟合均0。原九臂分数逐元素复用。
等权：score_equal=(SC+SM)/2，无softmax或调温。
归一化：每阶段仅用已见K类训练Gram和既有独立头，令H=I−11^T/K，sigma²=tr[(WH)^T G (WH)]/K²；G总权重K，包含截距。分数为(SC H/sigmaC+SM H/sigmaM)/2。先计算全六阶段尺度并封存，再打开验证分数。
类别维共同偏移不影响argmax，去掉它是为避免训练RMS被无效公共分数主导；没有特征中心化。尺度来自训练内分数而非交叉拟合，不是可靠性或概率校准，不使用验证分数选权重、温度或尺度。

## 解释边界与后续（未执行）

当前证据支持保留两个强联合头作为主比较对象；不能用普通分数平均替代它们，也不能把硬预测oracle当特征融合上限。这个结果尚未说明如何从训练侧识别有利/有害修正，更没有成立门控、尾类收缩或新增量机制。
RMS只是一种固定的训练内归一化，失败不排除其他训练侧组合原则；不能继续用验证集扫描系数直到分数融合追平，也不能凭当前差值宣布特征级融合原则上不可替代。
