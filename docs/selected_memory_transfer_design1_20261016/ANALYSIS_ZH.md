## 2. 成对样本揭示了平均值下的变化

ISIC旧类救回38个、伤害26个，净+12；新类救回18个、伤害31个，净−13。总BA从57.064947%升到58.400422%，但总体正确数量净少1个。这些指标并不矛盾：BA给每个类别同等权重，而总体正确数量按样本计。

ISIC回退旧类1仅14个样本，从4个正确变5个，recall增加7.142857pp；它对四个旧类平均增益贡献1.785714pp，占总+2.230645pp的大部分。三个接纳旧类的平均增益为0.593240pp。样本稀少的尾类一条翻转会显著影响BA，不能据此声称稳定收益。

HK旧类救回6个、伤害2个，净+4；新类救回/伤害均为0。接纳旧类均值+0.711675pp，回退旧类均值−0.454545pp。即使某个类的记忆没有变化，它也共享更新后的适配器，所以预测仍可能改善或受损。ISIC回退类获益、HK回退类受损，直接说明不能只检查11个接纳类的后续表现。

每类净recall不下降也不等于每个样本没有损失。例如ISIC所有旧类净recall均不下降，但仍有26个原本正确的旧类样本变错。冻结门槛是逐类净效果，样本级rescued/harmed单独公开，不混用两种“无损”含义。

## 3. 对当前接纳准则的解释

前一轮证明了固定共同教师处，接纳后的旧类梯度/响应满足约束。当前验证进一步显示：这套局部条件不足以保证48步联合训练之后的逐类分类无损。ISIC的新类风险，以及HK回退旧类的风险，都没有被前一轮终点记忆接纳门槛排除。

分类竞争方向也有可见变化：ISIC旧样本错向新类由658降到635，新样本错向旧类由363升到378。这与旧类保持改善伴随新类受损的结果一致；这些终点计数不能唯一证明某个梯度方向或保持项就是原因。没有额外梯度干预或消融，因此不补充因果断言。

ISIC两组起点教师正确记忆质量均为98.395181%，所以本次旧BA增益不能简单解释为“教师正确质量提高”；HK该质量从90.764874%降至90.268609%，旧BA仍小幅上升。标量覆盖不是下游效果的充分替代。训练中权重同时影响replay CE和保持项，二者贡献未被本轮拆分。

本轮保留“存在平均旧类收益”的正结果，同时将“逐类严格无损”明确记为失败。没有自动提出或实施新的权重、保持范围、训练长度或候选选择。
