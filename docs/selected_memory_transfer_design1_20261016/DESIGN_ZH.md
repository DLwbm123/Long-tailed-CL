# selected记忆下一阶段成对验证：冻结协议

## 问题与范围

仅验证保存的selected记忆相对原moment是否改善下一阶段旧类保持且不伤新类。ISIC从4到6类、HK从13到15类，各moment/selected两组，每组48步，总192适配器更新；记忆优化0。small仅确认保存的selected与原moment完全相同，0更新，不算效果场景。不重建教师/moment/selected，不重新接纳，不调参，不补步数，不增加种子或阶段。

教师/ETF/moment来自第一阶段保存状态（结果8e668e03），selected及接纳类来自固定节点权重修正（结果f09e548c）。ISIC接纳[0,2,3]；HK接纳[0,1,2,5,6,7,11,12]。保存的selected必须与各类接纳来源相符，所有节点与moment相同；原状态只读。

## 唯一组间差异

两组从完全相同的共同教师出发，使用相同新类合成训练样本、ETF、类别顺序、联合slots和更新规则。唯一差异为已接纳类别的旧记忆权重，回退类保留原moment。沿用check_fullslot_retention_memory.train(full=False)：类别均衡CE；旧slots中心化logits保持，旧类argmax教师正确掩码，系数1，不对筛选后质量重新归一；全批量SGD学习率1/16，固定48步。既有rank8、beta8、float64和两线程保持不变。

合成训练fixture按既有seed/count规则重建，但训练只取当前新增的两类样本；旧类训练仅取保存记忆。第二阶段结束不构造新记忆，不启动第三阶段。

## 全部封存后独立评估

监督器顺序运行零更新单元检查、ISIC两组训练、HK两组训练、独立评估。评估进程先确认两个训练进程完成且四条终点轨迹已保存，再生成原seed+20000的合成样本，即20264/20265。生成规则、总n及类别分配不变，仅评第二阶段已见类别；不使用此前已查看的seed+10000样本作为确认性主评估。

共同起点和两组48步终点均在旧+新联合slots分类。另报共同起点旧slots-only旧BA，以区分静态扩展竞争与训练变化。共同起点扩展slots旧BA减终点旧BA定义本轮forgetting；两组起点相同，所以旧BA提升对应forgetting减少。没有中间点选优。

报告全体、旧、新、接纳旧类、回退旧类的BA/Accuracy；逐类计数与recall；逐类both-correct/rescued/harmed/both-wrong及错向旧/新类计数。所有旧类都纳入主门槛，不能只看接纳类。

## 冻结的严格判定

每规模须同时满足：selected旧BA−moment旧BA>1e-12；每一个旧类及新类selected正确数量均>=moment。成对样本完全相同，逐类条件用整数正确数量比较，0允许下降；1e-12仅用于旧BA严格改善的数值判定。两个规模都满足才整体通过；单规模通过记部分结果，不改变主门槛。零改善、只改善梯度、只提高总BA均不算通过。

零优化更新单元检查验证正例、零收益拒绝、新类受损拒绝、旧类受损拒绝，以及small保存状态原样回退。报告器独立从逐类计数重算主门槛并验证配对计数、分组指标和192更新。未完成项为缺失/NA，不能填0或补跑。
