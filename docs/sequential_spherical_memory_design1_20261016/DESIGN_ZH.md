# 稳定输入接口下的序列球面合成记忆：前瞻 CPU 协议

本轮是上一轮完整交付 78223da 后的新假说。上一轮主候选 sphere_weight 两高维门失败；sphere48 仅为次要机制控制，其有限查询优势不能回写为上一轮成功。本轮明确以 sphere 为新候选，停用未来判别查询训练和权重校准，检验较简单的球面矩匹配能否在类别增长时保持优势。不把这一步称完整新方法或医学贡献。

## 候选、控制与固定资源

每类16个节点，当前新类批次48次原矩目标 Adam（节点与概率logits，lr .02），候选每步单位球面归一化，原moment控制仍单位球投影，random与两者共享逐类初始化。球面零范数<=1e-12明确失败。每类seed=原规模seed+1000+类号；原规模seed263/264/265不增加随机重复。新初始化规则事前固定；当前批次目标按当前类均值，Adam epsilon带来可能的批次规模差异，因此不声称逐步复现上一轮全类联合构造。三个方法在本轮配对一致，原Core/LT生产代码不变。

small序列2+1+1类、ISIC规模4+2+2类、HK规模13+2+2+2+2+2类。d/N/K分别32/512/4、1536/9434/8、1536/1038/23。使用既有非高斯单位合成fixture和公开比例最大余数分配；这些总支持数与分配不是实际医学任务fit数。各类总共只构造一次。记忆总量为16×已见类数，随类增长，各控制相同；不是固定全局容量实验。random只作为合成oracle点控制，不代表授权保存医学原始特征。

## 访问、持久化和时序契约

稳定z仅为本轮合成坐标，尚未接入ViT/生产分类训练。compressor只接收当前类support副本和当前标签范围，拒绝范围不一致；不接收oracle、旧支持或旧记忆。旧记忆只在外部append，逐tensor精确不变。完整合成oracle单独保留供评价，允许在CPU诊断中评估旧支持误差，绝不传入压缩器；这不是许可未来医学实验回访旧图或原始特征。

每stage检查旧节点/权重精确不变、相同四组固定查询下旧记忆loss精确不变。使用事前随机正交基，容量按公开总类数固定，随seen构造ETF；固定probe下校验缩放后的旧旧logit差不变。该恒等不保护encoder更新或新类竞争，未训练classifier或渐进adapter。checkpoint私有NAS roundtrip检查tensor、source/task及schema/frame/seen/dimension，非法元信息拒绝；checkpoint不公开。原样追加不发生旧记忆重压缩，不宣称验证过损失性重压缩或其累计误差。

## 查询与主门

构造中不使用任何判别查询。每stage四组相同seed的独立初始化查询，加两组共同stress，每组8方向/rank8/beta8；stress对三个已冻结方法共同做12次Adam .01，只用于审计、不更新记忆。约束A/B Frobenius<=2、v norm<=2。不同stage stress会变化，因此不能把stage最大误差变化全归为旧记忆退化。报告固定随机与stress、old/new及所有class误差。

预声明主门：两个高维序列的每一个stage都必须 sphere最大误差<=.9×各moment/random最大误差，且平均误差不高于各基线，并且接口检查全部通过。small完整报告但不替代高维门。缺失失败不得补0，不选择某stage/类改门。有限查询和共同stress不是population独立测试或sup证书。方法集合和构造时序已变，不能和旧轮max直接配对。
