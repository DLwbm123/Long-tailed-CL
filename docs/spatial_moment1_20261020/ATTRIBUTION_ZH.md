# 已保存阶段结果的损害分解

这是已完成实验的事后描述性分析，不是新候选、参数选择或新增对照。仅使用RESULTS.json和DIAGNOSTICS.json；0图像编码、0模型拟合，A的继续门和失败结论不变。机器可读汇总见POSTHOC_ATTRIBUTION.json。

损害不能全归于新增类竞争：初始10类阶段尚未发生增量扩类，signed-p3已比df_matched_joint少对3张（63 vs 66）。因此只保护旧类logit或增加漂移惩罚，不能解释或保证修复基阶段的表示损害；冻结表示下SADP仍恒零，不据此重做decision_anchor。

后续阶段可以把候选与参照在同一批旧类验证图上的正确数差，精确分成“限制只在旧类中预测时的差”减去“允许新类竞争后额外丢失的正确图数”。各列是同一阶段的比较；不同阶段图像重复，不相加冒充独立样本。

这比“后来类改善，所以应该加共享query”更严格：第2—4阶段的主要额外损害发生在旧类样本，新加入的类别自身没有明显退化；到第5—6阶段额外竞争损失消失。固定聚合的判别结构与竞争效应均随已见类别集合变化，不能用最终一行选择一个全局融合系数。

最终20类中，8类正确数增加、4类减少、8类不变；增加的每类均为1张，减少的4类分别为1、1、3、1张。头7类总体损失3张并不代表每个头类都退步；其中类别9减少3张，头组另有相互抵消变化。尾7类的+5张分布在5个类别，各+1张，其余2类不变。不能把105张尾组汇总改善称为所有尾类已解决。

基于当前证据的下一步约束：后继机制必须同时检验“基阶段是否保住强参照”和“第2—4阶段是否避免额外竞争损失”，不能只挑最终/尾类端点；分类器或表示目标若要改变，需作为不同的新假说冻结协议，不得追改本轮、启动受门控的ProtoTail B、调聚合阶数或重做已有融合/锚点。现有统计只支持诊断描述，尚未证明一个新的可部署算法有效。
