# 固定 signed-p3 聚合：尾类改善，但未通过继续门

本轮已完成68058张训练图统计、300张验证图编码和六阶段独立验收。一个固定p=3候选最终84/300=28.0000%，相对原df匹配强联合82/300=27.3333%增加2张、0.6667个百分点；六阶段平均从34.0053%降至33.2341%。预先要求四项同时满足，最终正确数和平均阶段增益两项失败，因此不启动附条件的ProtoTail共享query实验，不扫描p、温度、M、种子或后验融合补救。

这是Spatial Moment聚合机制在带符号ViT token上的一次明确适配，不是原CNN多专家方法复现，也不能据此否定原论文或所有query方法。300图验证集已反复用于开发，实用继续门不等于显著性检验，不是独立测试或同协议SOTA证据。

## 继续门与机制判读

|预登记条件|实际|结果|
|---|---:|---|
|最终至少86/300|84/300|失败|
|平均阶段相对A0至少+1pp|−0.7712pp|失败|
|尾7至少22/105|25/105|通过|
|后来10类不低于A0的38/150|41/150|通过|

最终相对A0救回9张、损害7张、改变55张预测，净增2张；并非整体一致改善。前四阶段均退步，最后两阶段改善，说明固定峰值聚合的收益受类别集合影响。尾类+5张伴随头类−3张，不能用尾类进步替代全门判断。相对scale_joint救回13张、损害11张，也仅净增2张。

最后一次新增类竞争损失为旧类270图中的1张，两方法相同；各次转移的竞争丢失分别为A0的[5,2,4,8,1]张、候选的[8,4,7,8,1]张。此为各阶段事件数，不能累加当独立患者或最终遗忘量。早期候选也更容易受新类竞争影响，单独最终端点掩盖了这部分损害。

正/负有效通道的训练加权前、逐有效通道平均有效patch数分别约31.7376和32.0243（原196个patch）。这只刻画通道激活集中度；聚合对patch排列不变，不能解释为病灶定位或证明空间连续性。

接下来先基于本轮已保存统计与阶段诊断追查早期损害和类别竞争，形成另一独立且可证伪的机制假说。当前不把失败的A接入B，不启动另一个p/M/融合搜索，不复活已关闭的弱头、DENO、病例、decision_anchor或CLIP路线；持续研究入口保留，后继新实验仍须先冻结协议和硬预算。

## 实现、核验与成本

仅变更最终post-norm patch聚合：正负分解立方均值根之差；保持CLS768+patch768、受罚偏置、原编码器/变换/FP16、float64统计和求解、基类能量缩放、逐阶段匹配CLS自由度。六头在第一次验证编码前封存。原始图只读，不重建pack，不缓存全量逐图训练特征或token。

独立进程从20类充分统计重建六头，用Cholesky核对worker一般线性求解，重算保存的300图各阶段指标；验收PASS。核验训练覆盖68058、验证每类15图、患者隔离、df匹配、全部20类CLS训练Gram与历史最大误差0；worker的20类验证CLS检查均通过2e-5门。独立验收没有再次编码影像，不称独立重提取300图或作者代码复现。三个相关进程均已退出，run/verify返回码均0。
