# 严格阶段访问下的目标可实现性与旧机制边界

这是实现和代数审查，不是新性能实验。原输入为冻结CLS/patch mean加偏置；G_c=Σw_i x_i x_iᵀ、μ_c=Σw_i x_i，每类质量1，患者权重沿用原协议。历史只保留这些充分统计，当前阶段可读取当前类训练特征；不能把最终20类离线缓存或头偷偷带入早期CIL。

| 目标/操作 | 历史G/μ能否精确计算 | 还需什么 | 本路线决定 |
|---|---|---|---|
| 平方风险与类/患者固定权重ridge | 能：tr(WᵀGW)−2tr(WᵀT)+常数 | 历史类质量/固定目标 | 已有原强联合，不重做 |
| 线性旧教师A的平方响应保持 | 能：tr((W−A)ᵀG(W−A)) | 已封存A | 代数可行不等于旧query保护；不换名重做响应项 |
| 类条件有向平方间隔 | 能：每类G_c和μ_c足够，联合输出耦合二次型 | 预定边权/目标，不能用query选边 | EDGE-BUDGET已有相关平方竞争机制，不换名重做 |
| 完整历史softmax CE | 一般不能 | 每个样本在当前W的softmax或等价完整信息 | 离线final20已关闭，不称同记忆CIL |
| 非零anchor处CE梯度/Hessian | 一般不能 | x相关的p_i(A)、p_i(A)p_i(A)ᵀ加权矩 | 旧未加权Gram不足；不以μ代替逐样本softmax |
| 当前阶段CE＋旧平方风险 | 可精确计算这一个混合目标 | 仅当前阶段逐样本特征＋旧G/μ | 权限上可行，但历次旧类CE切换为平方风险，目标不一致；尚无独立训练证据支持，暂不启动 |
| 原均值/协方差构造Gaussian或伪样本CE | 只能精确计算所假设分布的目标 | 新分布假设、采样/近似误差 | 不是历史真实CE；不能直接接续为新实验 |
| 逐样本top-1、最大错类margin、repair/keep标签 | 一般不能 | 逐样本特征/预测及标签 | 原矩不能重建，不添加隐性记忆 |

对CE，令p_i=softmax(βx_iᵀW)。梯度涉及Σw_i x_i(p_i−e_y)ᵀ，Hessian涉及Σw_i (x_i x_iᵀ)⊗(diag(p_i)−p_i p_iᵀ)。W=0时p为常数，退化到G/μ；非零A的权重随x变化，不能用旧Gram精确推出。围绕A做二阶展开也不自动解决，因为其梯度和Hessian首先就缺输入。完整风险的一二阶矩反例已在final20的AUDIT中保存，不重复运行该反例。

## 与已有实验的真实差别

NIH correction20_nested是最终20类三折训练内嵌套：普通CE残差及repair/keep保护，访问对应外层训练的全部逐样本缓存。普通BA18.8287%、保护18.9944%，尾8.7603%→8.5014%，均低于df联合尾14.8826%；保护失败。数字不能与300val的27.33%相减。

NIH correction20_subspace仍是同外层完整训练的CE残差，只比较原头张成空间与同维PCA基；限制空间不改变其额外历史样本需求，也不变成充分统计CIL。它不是一个尚未做过的“响应保护”空白。

ISIC/HK linear_ce与full_support_linear_ce分别访问旧H+新S和完整旧S+新S，单位归一特征、无偏置、β8/λ.001，不同于NIH患者等权。其双查询负结果保留，不冒充NIH；full-support格本来就是额外历史访问。nullspace_response严格保持有限H响应，在正交补做CE，仍不能保证旧query无损；不能把“记忆响应完全相同”当泛化保证。old_covariance固定2×2旧/新来源相关性是ridge统计消融，不是Gaussian CE回放；不能将该负结果写成未做过的Gaussian CE已失败，也不据此自动启动它。

NIH final20完整头CE则是额外全历史、一次固定零中心范数罚的离线终点：94/300但未收敛、tail19/105，两门失败已关闭。已有证据只支持“读出终点存在整体空间且尾类风险仍未解决”；不支持立即叠新项或换后验主臂。

此外，旧EDGE-BUDGET已实现原型驱动有向类对平方间隔、类别矩和PCG耦合求解；ISIC/HK的细动作未过门。这不证明NIH任意平方margin无效，但简单把平方间隔包装成“统计记忆可用的新CE替代”会重复已有机制，当前不启动该方向。其CIFAR测试不用于本次方法选择。

## 本轮具体推进

本轮已完成只读训练充分统计诊断：固定比较原最终df联合列中心头和已封存离线CE头，以原患者/类权重计算每类centered-onehot平方风险、真类对平均错类分数差的均值/方差。不能从这些矩声称top-1、最大竞争margin或精确CE；CE头含全历史权限，诊断只最终20类，禁止作为早期初始化。

这是不同于已有val配对/阶段归因的训练风险诊断，不做新模型、重提取、重复query评分或重拟合；先明确训练风险变化是否集中于频率/初始类，再决定不同机制。若只发现目标间正常折中，不据此扫类权重/温度/正则。没有新的训练证据前不启动混合CE、Gaussian回放或响应保护实验。
