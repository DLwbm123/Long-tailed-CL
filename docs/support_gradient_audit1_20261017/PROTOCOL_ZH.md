# 支持集梯度冲突诊断：四个冻结状态、零参数更新

[四格目标实验](../real_balanced_lse_objective1_20261017/REPORT_ZH.md)（`8b13988`）未解决两数据集的旧新约束。改变组质量主要移动旧新取舍，平衡 LSE 在 HK 不比平衡 max 提高新类 BA，反而加重旧类损害。下一步不搜索权重，改为检查共享适配器中的局部梯度冲突。

## 唯一问题与固定判定

主要机制假设：在原 HH 冻结模型上，旧组完整 CE 梯度与新组完整 CE 梯度夹角余弦在 ISIC、HK 均小于 −1e−12。容差仅处理数值零；零范数导致余弦未定义时记 null，不算冲突证据。两数据集分别及联合报告，不筛选有利状态代替原 HH。

四个固定状态为原旧教师、原 HH、平衡 max、平衡 LSE。全部既有模型只读，不重新训练或续训；未平衡 max 不在本次预先指定状态内。后面三个已依据历史查询构造，诊断结果仍是开发证据。

用相同已封存 H（ISIC64、HK169）与新 S。完整 CE 的 logits 范围为全部已见类。旧、新两组的完整 CE 分别按组内各类均匀归一化，得到 g_old、g_new；第三个梯度 g_ret 来自原未缩放 H 保留项（冻结旧教师旧类中心化得分，只计教师预测正确的 H 权重）。保留项公式和原 HH 一致。

每个状态报告三个损失值、梯度范数、3×3 Gram 与余弦矩阵，以及沿 −g_new 和 −g_full 的三个方向导数，其中 g_full=(K_old/K)g_old+(K_new/K)g_new+g_ret。方向导数正值表示无穷小更新使对应支持损失上升。此处在所有状态上计算同一原 HH 目标的梯度，不把它误称为平衡代理目标的训练梯度。

这些量不是实际一步更新后的变化，不计算有限步探针、不评估 BA，不证明旧新冲突是全部退化的原因，也不保证投影梯度能改善查询结果。即使主要机制条件成立，也只支持后续提出可检验的局部更新假设。

## 访问、预算与自检

两个串行 CPU 任务 ISIC_gradient/HK_gradient，每任务4状态×3项=12次适配器参数梯度计算，共24次诊断梯度计算；参数更新、工程梯度、教师/编码器/记忆更新全部为0。每任务900秒、总3600秒，不扫描种子、权重或模型状态，不自动重试或重置预算。

只读原冻结教师、上述三个模型、已封存H、新S；禁止旧S、Qfit、Qgate、E、原图、新标签与GPU。用文件访问边界逐项拒绝旧S和两查询/E，统计脚本不加载历史查询结果。原教师初始化、特征、ETF、种子、顺序不改变。不会保存新模型或梯度向量，仅输出去身份化标量矩阵与成本。

微型工程自检不做反向传播：g_old=[1,0]、g_new=[−1,1]、g_ret=[0,0] 时，余弦=−1/√2，零梯度余弦为null；沿−g_new的导数为[1,−2,0]，等类质量g_full下为[0,−0.5,0]。正式计算检查梯度有限、各类质量与旧组质量，沿用可靠队列记录全部退出码/失败/缺失。
