原 HH 状态下沿原负总梯度，两个支持 CE 都下降。单独沿负新类梯度却会使旧 CE 上升，ISIC/HK 导数分别 +5.185890/+4.913914。这表明单独强化新类确有局部冲突，但“负余弦”不能推导出无共同改善空间，也不能单凭它解释全部查询退化。平衡模型状态上，回到原总方向会降低旧 CE、提高新 CE，符合已观察到的取舍。
