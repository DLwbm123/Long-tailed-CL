# 仅训练支持拟合的新旧组标量标定

依据[固定端点诊断](../new_class_competition_audit1_20261017/REPORT_ZH.md)（交付 `9b91293`），HK 的 HH 在新类内部可完全区分这些支持/查询样本，但全类错误落入旧类。本轮检查一个从训练支持拟合的组间偏置能否缓解该现象，以及是否损害旧类；不使用 oracle 归属进行推理。

## 唯一改变

冻结未缩放 HH 的适配器和 ETF，只增加一个实数 b，对所有新类 logits 加 b、旧类 logits 不变。对每个查询样本都执行同一规则，不知道其真实新旧归属；各组内部 logits 排序保持不变。

拟合数据仅为原 H 和原 S_new，沿用每已见类 1/K、类内均匀的 CE 权重。H 数量 ISIC64/HK169；新支持 ISIC2290/HK95。不读旧 S、不重新选记忆、不使用 Qfit/Qgate 来拟合或选择 b。增加一个标量参数，不能宣称与未标定 HH 等容量。

## 无搜索的确定性解

在冻结支持 logits 上最小化完整 K 类加权交叉熵，不添加正则、温度或其他自由参数。令 t_i=logsumexp(新类 logits)−logsumexp(旧类 logits)，pi 为权重下的新类标签质量（等于 new/K）。最优点满足 sum_i p_i sigmoid(t_i+b)=pi。

因为两组质量均非零、logits 有限，此目标对 b 严格凸且有唯一有限解。初始区间固定为 [logit(pi)−max(t), logit(pi)−min(t)]；严格执行 64 次二分，取最后中点，不扫描候选、不检查查询、不根据结果挑偏置。运行断言类质量正确、区间夹住根、根残差小于 1e−12、标量有限、支持 CE 不增。常数 logits 的解析例子验证 b=−3；每任务执行一次 64 步微型自检，单独计量迭代数。

## 冻结主要判定

标定后的 HH 相对原 MM，Qfit 和 Qgate 均须总体 BA 严格提高、旧/新各不下降超过 1pp。ISIC/HK 分别报告，不能以新类收益掩盖旧类失败。次要完整报告相对未标定 HH 的同样门槛及组别/逐类 BA、CE，并报告 b、拟合支持数量、支持 CE 前后和根残差。MM/HH 旧结果直接复用，不重训或重推理。

若主判定通过但相对 HH 没有收益，必须明确标定的增益未成立；不把原 H 已有的收益归功于标定。不事后改用 oracle 指标、单个查询或换主要对照。

## 预算和访问

两个 CPU 任务 ISIC_group/HK_group，每任务 900 秒、全队列 3600 秒。正式二分共 128 次，工程解析自检二分另 128 次；两数据集各拟合一个标量。适配器、教师、编码器、记忆和梯度更新均为零，无 GPU、E、新标签、旧 S、原始图像、额外抽样或自动重试。

标量与模型先保存，之后才允许两个开发查询和历史汇总进入评价；支持拟合不能访问查询。所有既有查询已用于研究设计，患者分组未知，只能产生开发证据，不形成独立医学验证。

确认父子进程全部退出后公开全部正负结果、逐类指标、偏置及每轮/累计成本；CPU 驻留/user/system/RSS、监督器墙钟分列。私有特征、模型、身份和运行路径不发布。
