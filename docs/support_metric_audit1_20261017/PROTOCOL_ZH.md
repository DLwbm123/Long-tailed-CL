# 投影模型的支持 CE/BA 对齐诊断

[投影结果](../real_conflict_projection1_20261017/REPORT_ZH.md)（`040c60d`）在四个查询判定上均未通过旧类约束。HK全48步旧新支持CE均具有局部下降方向，查询旧类BA仍下降，且查询旧类CE相对原HH反而改善。因此下一步不改更新规则，只读检查最终支持CE和BA是否一致。

## 主要分类规则

固定主要比较为投影模型减原HH的旧类支持组指标。若ΔCE<−1e−12且ΔBA<−1e−12，标为“支持CE/BA不一致”；若ΔCE<−1e−12且ΔBA≥−1e−12，标为“支持CE改善且BA不差”，结合已公开的查询旧BA损害讨论支持到查询的差距；若CE未改善，明确标为“支持CE未改善”，不强行归入前两种解释。容差只处理数值零，不是性能放宽。分别报告两数据集，不把类别解释当新方法通过。

固定三个只读状态：原旧教师、原HH、投影模型。每状态在同一H+新S上评价全部已见类别，报告逐类样本数、正确数、recall、完整CE、错误落入旧/新组数量；汇总all/old/new宏平均BA/CE，并提供投影相对教师及原HH的全部组别变化。原教师也按全部已见类竞争评价，不能与仅旧类教师准确率混淆。

H节点权重必须为类内均匀；用断言检查后复用现有metrics的类内平均，组间按类均匀汇总。H来自历史herding选择，不是独立旧类验证样本；新S同为训练支持。支持与查询差异不能单独证明患者域偏移，也不能量化独立泛化。
