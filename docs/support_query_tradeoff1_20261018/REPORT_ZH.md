class4是三个头都拟合过的相同新S，取舍并非只来自C_H未见过的大量旧S。其支持端救回7个、伤害368个；误判旧组从78增至441，误判另一个新类从5降至3。class3则救回819个、伤害20个，误判新组832→123。这是大样本类别上的实际决策交换，并非极小尾类制造的宏BA符号变化。

完整支持相同的R_F→C_F另有不同结果：支持class3增加173个正确（+6.577947pp），class4增加444个（+19.698314pp）；两片查询也同时改善这两类（class3均+17，class4 +56/+51）。支持上全部6类净召回不下降，但仍有66个个体伤害，不能把类别净改善说成每个样本均获益。由此不能将C_H→C_F的交换称作所有线性读出或当前表示必然要求的取舍。

泛化问题仍单独存在：R_F→C_F在支持class0/2分别+48/+50个正确，Qfit却−3/−1；class1支持两头均23/23，Qfit从2/2降到1/2，给原总体BA贡献−8.333333pp。该极小类会放大总体失败，但不改变class3/class4上数百个支持样本的取舍证据。C_H→C_F的支持与查询取舍同向，不等于三个域的幅度相同或已经解释全部查询误差。

结论限于已冻结配方：历史支持信息变化已在支持域改变分类错误分配；它不完全是查询迁移现象。同时，目标/正则配方与跨域泛化仍共同影响结果，本轮不能证明表示不足、线性不可分或存在一个全类最优头，也不提出后续方法。
