# 完整支持参照后的判断

本轮完成了授权的四条参照训练，全部各48步、共192次adapter更新，无记忆更新、训练重试或新种子。工程运行完整，科学判据全部未通过：full_support相对moment、selected、candidate的12组比较都为COST_EXCEEDS_LIMIT。不能因整体BA或CE改善而越过新组代价门槛。

## 最关键的结果

相对moment，完整回放的整体/旧组/新组BA差值（pp）：

|场景|整体|旧组|新组|新组条件95%区间|
|---|---:|---:|---:|---|
|ISIC 100264|+1.450000|+8.350000|−12.350000|[−13.90, −10.80]|
|ISIC 200264|−0.100000|+4.000000|−8.300000|[−9.60, −7.00]|
|HK 100265|+2.220000|+3.023077|−3.000000|[−4.00, −2.00]|
|HK 200265|+1.153333|+2.423077|−7.100000|[−8.35, −5.90]|

四个旧组区间均完全大于零；三个整体区间完全大于零，ISIC 200264整体区间跨零。所有新组区间完全低于−1pp，且相对另外两个基线也如此。这比上一轮candidate只有两组新组点估计超限更明确；仍只是在固定训练状态下的pointwise评估抽样结论，不是训练种子总体或同时覆盖保证。

整体BA按类别平均：ISIC旧/新权重为4/6与2/6，HK为13/15与2/15。因此整体改善可以伴随新组明显受损，尤其HK。这是预先指定指标的性质，不能事后改成旧、新各半或降低新组限制。

## CE降低，并未解决受约束分类目标

相对moment，整体宏CE四个场景均下降，分别为−0.07902793、−0.01359876、−0.07277831、−0.04343594；相对selected和candidate也四场景全降。但新组宏CE分别上升+0.20613706、+0.14987690、+0.05854677、+0.14841244，旧组全部下降。

所以，这次不只是“CE改善但argmax没变化”的小幅指标错位：总平均目标改善伴随新组损失和分类同时恶化。即便未来外层只优化无约束的整体query CE，也不能据此保证旧、新组1pp限制。CE可以作为可微代理，仍需要显式对应旧新代价约束和最终BA判定。

平均margin也不提供统一保证：新组平均真类减最大其他类margin四场景均下降，分别−0.731401、−0.399089、−0.085241、−0.145946。ISIC第二状态整体平均margin甚至下降，虽然宏CE下降；不要把单个平均分数量解释成整个分布普遍改善。

## 新类受到的主要伤害是被判为旧类

相对moment，新组真实配对翻转如下（每场景2000个新类评估样本）：

|场景|错误→正确|正确→错误|其中正确→旧类错误|新类错向旧类：moment→full_support|新类错向新类：moment→full_support|
|---|---:|---:|---:|---|---|
|ISIC 100264|15|262|258|501→797|124→75|
|ISIC 200264|12|178|178|715→929|122→74|
|HK 100265|24|84|84|1006→1074|37→29|
|HK 200265|14|156|143|986→1168|157→117|

新增错误中的绝大多数正确样本翻到旧类；边际错向旧类数量也全增，而新类内部错误全减。两个统计描述不同对象，不能把边际增量当作正确→错误人数。每个场景两种新类各自BA都下降，并非只有一个罕见新类驱动所有组结果。

新类真类减最大旧类分数的平均margin四场景分别下降0.815304、0.466018、0.089266、0.251946；新类样本上的max_old−max_new平均差全上升。配对翻转与分数诊断共同支持“新类相对旧类竞争变差”。这不证明一个全局标量偏置能修复：HK第二状态全部样本平均max_old−max_new反而下降，旧类内部错误也发生变化，且本轮没有做偏置拟合或干预。

## 如何更新前两轮的解释

前轮candidate在teacher和moment终点上更接近完整支持总梯度，但四场景相对moment的整体BA点估计都下降。这轮完整支持在三个场景改善整体BA、四个场景改善旧组BA和宏CE，同时新组严重受损。两轮合在一起说明：

1. 原有限支持包含压缩表示未保留的有效信息，尤其表现为旧组恢复；不能说“完整支持毫无用处”。
2. 梯度更接近完整支持，并不保证压缩轨迹或分类结果接近它；本轮也未证明轨迹梯度误差始终较小。
3. 即使直接使用完整支持，当前48步训练方案也不能通过用户的旧新代价约束。因而仅取消gate、扩展联合selector或更精确拟合原总梯度，不足以成为下一步成功依据。
4. 完整支持不是最优性能上界，也不构成“所有memory方法都不可能成功”的证明；压缩可能带来不同的正则化和轨迹。

本轮保持目标表达式相同，但旧类样本分布和teacher-correct保持项的有效覆盖也随支持一起变化。full_support的平均teacher-correct覆盖四场景为83.013986%、78.141137%、60.353937%、59.403359%。没有分离CE、保持项、步数或支持覆盖的干预，不能将失败唯一归因于某一个系数、保持项或ETF几何。

## 下一步应先改研究目标，当前不再运行

建议停止把“更忠实复现完整支持梯度”当作充分目标。若后续继续，应先设计**更新后的类别均衡query表现与旧新组代价约束直接对齐**的目标和验证协议，再判断是否值得实现新的memory权重或selector。单独换成整体query CE仍不充分，这次数据已给出反例。

这需要一套未参与memory构造/更新、也未用于选择方案的query和明确的标签隔离。当前评估bank与四个训练状态已反复观察，不能直接拿来选权重、调偏置、调保持系数后再宣称独立确认。HK原训练支持中新组仅19个样本，旧尾类存在1–2样本，简单切分并不能自动形成可信独立query。若要解决这一资源边界，需另行冻结数据与实验范围；本轮没有自行新增样本、种子、外层优化、偏置校正或消融扫描。

本轮原旧类完整支持：ISIC各2020个样本（压缩为4×16节点），HK各597个样本（压缩为13×16节点）；新类支持分别1452和19个。完整支持属于不等存储/计算预算的有限参照，以上均为合成特征，不是实际ISIC/HK影像实验。下一项科学动作目前停止，等待用户另行决定。
