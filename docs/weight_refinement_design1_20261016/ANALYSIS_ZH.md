# 结果分析与停止结论

本轮得到有限的正结果：固定moment节点、只修正权重并执行终点接纳，19类中11类满足全部冻结条件；另8类保留原moment。ISIC与HK均有实际接纳收益，small全部回退，故“每规模至少一个可用修正”标记为false。接纳后的无退化部分由回退机制保证，不能把8个原样保留类当作修正成功。

## 1. 梯度修正确实发生，但不能跳过响应检查

原始候选相对moment的57个类×查询比较，56个严格改善，1个退化，无平局。small的2类和ISIC的4类均同时改善旧/新增竞争/扩展梯度；HK有12/13类同时改善。HK匿名类10的新增竞争绝对误差从0.10378928695346408升到0.10528098812327749，被按规则回退；旧与扩展改善不能覆盖这项退化。

响应条件使small 2类全部回退、ISIC匿名类1回退、HK匿名类3/4/8/9回退。HK类3只有旧/扩展覆盖绝对偏差退化；类10只有新增竞争梯度退化。其余完整拒绝项见ACCEPTANCE，无事后豁免。接纳类为ISIC [0,2,3]、HK [0,1,2,5,6,7,11,12]；每个接纳类的三个梯度实际上都严格改善，所以接纳后57项比较是33项改善、24项原样保留、0项退化。

small旧查询的候选seen-W1从0.470556升到0.555546；扩展查询从0.322687升到0.469979。旧教师正确质量从87.568262%升到91.462406%，但完整支持仅82.720588%，因此更高覆盖在这里反而更不保真。两个类别均发生旧/扩展覆盖偏差退化。只看更低梯度误差或更高覆盖会得出错误接纳。

## 3. 目标的变化与可识别边界

原moment的归一目标约为1。候选终点均值small/ISIC/HK分别为0.283172/0.688386/0.697020，接纳后为1.000000/0.832527/0.788907。均值优化并不保证每个查询无损；HK类10就是反例。终点门槛有效挡住它，但并未证明候选目标达到最优。

本轮同时改为moment暖启动、固定节点、逐查询原误差归一和均值聚合。可确认的是这套组合在既定48步下使56/57项梯度误差改善；不能把收益唯一归因于其中某个因素，也不能由本轮排除进一步冲突。与上轮不同起点、可优化变量和目标的耗时不应解释为严格匹配的算法加速比。

固定教师/固定节点时，记忆梯度是节点梯度按权重的线性组合，因此无需移动节点也可能修正梯度；但同一组权重也会改变响应分布。这解释了为什么节点位置保持不变并不自动保证响应不退化。没有新增优化实验来验证更强的因果结论。
