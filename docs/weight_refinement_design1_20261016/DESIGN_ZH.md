# 固定 moment 节点的权重修正：冻结协议

本轮仅复用第一阶段审计保存的共同教师、ETF与moment；不重建教师/moment，不更新适配器，不做第二阶段训练。每规模一个候选，CPU两线程、float64、48步Adam(lr=.02)，每case硬上限900秒、整体2400秒；不重试、不增加种子、参数、步数或预算。规模、合成支持和种子与DESIGN_LOCK一致，医学影像、val、test均不读取。

## 唯一改动

每类16个moment节点完全固定，仅优化16个权重logits。以原moment权重的log值初始化，减去最大与最小log值的中点，保持softmax概率且位于原[-8,8]范围；Adam状态重新初始化，每步后仍夹至[-8,8]。不增加额外残差参数，不做moment节点再优化。

固定教师的旧slots与下一阶段扩展slots各给一个CE梯度；新增竞争梯度为扩展减旧。三查询各自平方残差E，以原moment的平方残差B（step0复用计算）归一：L=mean_class mean_query E/max(B,1e-12)。三个查询均参与，无max分支，无响应训练项；不访问新类样本。完整支持只取已见合成训练样本，不能称作独立测试。

## 唯一终点接纳

只评估第48步终点；不挑中间最优点，不回溯、不重启。逐类要求：旧/新增竞争/扩展三个梯度的绝对L2误差均不超过moment+1e-12；旧和扩展两个查询的seen-W1、reserved-W1、sliced-W1，以及相对完整支持的教师正确质量绝对偏差、近零seen间隔质量绝对偏差，均不超过moment+1e-12；并且至少一个梯度误差改善超过1e-12。共13项不退化检查加严格改善条件。任一不满足，该类原样保留moment，保存候选及全部失败项。全回退就是没有得到可用修正，不能算方法成功。

## 输出和检查

19个旧类，四种表示full_support/moment/candidate/selected，共228梯度记录、152响应记录、228 CE记录；响应保留完整加权经验原子、分位数与固定abs(seen margin)<=.25质量；逐类和宏梯度分开报告。selected按接纳决定复制候选或moment记录，宏梯度由已有向量汇总，不额外调用模型。保存候选权重、最终权重及接纳选择的私有状态。

单元检查：权重logits roundtrip、权重目标有限差分、相同结果拒绝/严格改善接纳/响应或梯度退化拒绝，0优化更新。运行中确认教师、原moment、固定节点均未改变。报告器检查记录数、权重分布、与已发表基线一致性及接纳规则；无新增科学训练。
