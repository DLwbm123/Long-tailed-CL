# 保留每维类内方差、移除类内跨维协方差

## 假设与证据

原型岭删除全部类内散布后，四切片总体BA均低于完整岭；随后同trace各向同性散布仍低于完整岭9.5144/3.9148/3.5064/8.9215pp，相对原型岭仅−0.0124/−0.2386/0/+0.0183pp。总trace本身不足以恢复表现。本轮只检验：各维边际方差差异是否已足够，或完整岭的优势还依赖当前特征坐标中的类内跨维协方差。不扩大分类研究范围。

## 唯一主要改动

固定G=(1/K)Σ_c mean_i z_ci z_ciᵀ，G_between=μᵀμ/K，G_within=G−G_between，μ不额外单位化。候选G_wdiag=G_between+diag(diag(G_within))；W=(G_wdiag+0.001I)^−1(μᵀ/K)，评分8zW，无bias、无列归一化。

G_wdiag保留完整G的每个对角项和trace，保留类均值外积的全部交叉项，只删类内散布非对角项。它不同于此前对整个G对角化的方案；不是把类内方差平均化，也不改变原均值。原始坐标系固定，不旋转、排序或选择特征，无λ/强度/秩/温度扫描。

复用analytic.ridge，在新的μᵀμ矩阵上用原S对角覆盖，原bank不改。run_raw_ridge_head.py增加diagonal_within_second_moment=true，与全G对角、原型、各向同性标志互斥；旧默认分支保留。候选不等价于原逐样本最小二乘解，不包装为新方法。对角消融依赖坐标系，不能外推为所有表示的协方差必要性。
