# D48: local visual label structure, TRAIN only

Frozen before first execution. Source audit: native HASTEN trains image-text paired contrast and entailment, text hierarchy, and mapping geometry; it lacks a directly supervised image-image relational objective (official models/hasten.py training loss block). R22/R23 add text-logit CE; R24 independent head does not backpropagate into core; R35 changes replay inputs without a visual relational objective. R46/D47 fail fixed covariance/semantic mean changes. Thus local visual class structure, rather than a better single class mean or text prototype, is an untested mechanism relevant to mainline representation design. This does not establish that it is a bottleneck.

Question: does frozen pretrained TRAIN representation retain useful local label structure that class-mean compression loses? NIH/ISIC/HK stage-zero original TRAIN exact IDs, unit image features, per-class odd/even exchanged folds. Use first min(64,n_fit) support rows and first min(64,n_holdout) query rows in original manifest order; query/support strictly disjoint. Both readouts use identical support: cosine nearest class mean versus fixed cosine 1-nearest-neighbor labels. Deterministic first-index tie breaking. All 54 class×fold counts, full TRAIN counts and macro/tail deltas published. Tail uses original TRAIN count<250. No support size/k/distance/subset/seed/threshold/fusion scan.

Support requires NIH both folds tail>=+1pp and macro>=0pp; ISIC/HK each two-fold mean macro/tail drop<=1pp. Failure rejects this fixed local-neighborhood rationale at this scope. Success supports a further disjoint TRAIN gradient test of visual relational learning, not direct full training or an inference/memory replacement. No classifier/comparator optimization, learned model forward, optimizer, image encoding, VAL or TEST. TRAIN statistical estimation and label lookup occur; repeated medical rows are not independent patients. Stage-zero bounded support may miss later-class structure and full-density neighborhoods; do not generalize a failed diagnostic to all visual objectives.
