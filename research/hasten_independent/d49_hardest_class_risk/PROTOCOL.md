# D49: hardest-class binary risk, disjoint TRAIN gradient feasibility

Frozen before execution. Source audit: native training class logits are computed but paired diagonal image/text contrast supplies the principal discriminative objective. R08 tested ordinary all-class CE replacement; R22/R23 added CE; R38 changed text positive pooling; D44 only changed reduction. None tested a principal objective that compares each row's true class only against its strongest wrong class. Hypothesis: explicitly training the decision against its dominant competitor avoids spending risk on duplicate paired prompts and redundant easy negatives. This is a changed task loss, not an inference/fusion correction or a rescue of D44 class weights. Hard-negative noise, nonsmooth competitor switches and lost global calibration are material risks.

Candidate replaces paired contrast with mean softplus(max_{j!=y} z_j-z_y), where z is the existing exp(logit_scale) times negative hyperbolic class distance over all arrived classes. No margin/temperature/coefficient fit, class reweighting, teacher, new classifier, input/statistics or geometry change. Original entailment/hierarchy/map regularization remain with original coefficients. Actual future training would apply to real and original Gaussian generating-label rows; this diagnostic uses real initial TRAIN only, so replay and incremental effectiveness remain unproven.

A: remaining TRAIN rows, fixed natural shuffle from D44; earliest 64-row batch containing each initial tail class, deduplicate batches. A/B strictly disjoint. Unlike D44, the common reference target is all-seen-class CE balanced across B classes, separately macro/tail, rather than the old paired loss. Compare parameter-gradient cosine of original total loss and candidate total loss against common B CE gradient. No optimizer/parameter change, no image/backbone encoding, VAL/TEST or checkpoint refit. The fixed A selection is conditional on tail presence and is not an actual natural training trajectory.
