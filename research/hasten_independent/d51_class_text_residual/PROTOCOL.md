# D51: fresh TRAIN learning pilot of class-specific text residuals

Frozen before first execution. Existing shared affine Text adapters couple changes across all class prompts; R37 froze birth-task text routes without introducing class-specific adaptation. R24 added an independent detached linear logit head without changing core text prototypes; R42 changed initial matrices only. New architecture here adds a zero-initialized trainable 512-vector per class to that class's native Text_encode output, before the existing shared mapping. Existing Text/Image adapters and original losses remain trainable; virtual parent prompts receive no class residual. This changes representational degrees of freedom inside the native class prototypes and paired/hierarchy losses, not readout fusion, teacher, initialization amplitude or an auxiliary visual/CE coefficient. Risks include overfitting rare class residuals, disrupting hierarchy, and no incremental stability.
