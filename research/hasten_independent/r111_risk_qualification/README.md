# R111 risk qualification

See [REPORT_ZH.md](REPORT_ZH.md) for the saved-only A1–A4 analysis and conditional P1b admission status.

`audit.py` recomputes archived integer outcomes without a model. Set Q_SAVED to the R110 private receipt directory, Q_METADATA to its private label metadata, and Q_OUTPUT to an empty result directory. No private data are distributed here.

`readiness.py` imports the pinned sibling R110 implementation. `readiness_control.py` supplies independent original-clock, RAM, disk and CPU guards. Private configuration supplies read-only TRAIN/encoder resources and output locations. The neutral main wrapper receives source/config through environment variables.

[READINESS_PROTOCOL.md](READINESS_PROTOCOL.md) and [READINESS_FREEZE.json](READINESS_FREEZE.json) were frozen before fresh input encoding. [A_FREEZE.json](A_FREEZE.json) seals the completed A analysis code and fixed selection settings. All new donor seeds use the same previously observed TRAIN population; independent clinical patients remain unverified.

Tables in `results/` report all predefined roots. The empirical gate uses complete real-seen old-tail coverage, while original R110 rewards retain their original shadow-tail definition. NA never denotes zero harm. Per-component events and per-candidate/class integer outcomes stay private.
