## One charged evidence mechanism

At each real class birth, retain one distinct component from each original
S/FIT/AUDIT partition. Within each partition choose ascending
SHA256("r112-evidence-v1:" + identity_component), independent of scores and
geometry. Each fixed package is one global token. S core globals, FIT globals
and AUDIT globals remain pinned thereafter. Optional S local views remain
optional. The original centroid-nearest S coverage globals are also mandatory;
their union with S cores is measured, not assumed to have exactly C elements.

The canonical feature record remains 2064 bytes: 2048 float32 feature bytes,
8 parent-key bytes, 2 class bytes, 1 view byte, 1 role/core byte and 4 padding
bytes. The role byte reuses original padding (0 S, 1 FIT, 2 AUDIT, 4 S-core global).
Twenty-three 8-byte statistics records use count:uint32, birth:int16 and
birth_total:uint16; the latter reuses the original statistics padding. No
precision reduction or new uncharged role/decoder table is allowed. Previous
roles and core keys are decoded from retained records only. Birth counts must
fit uint16, otherwise stop before truncation. Model/optimizer scope is unchanged;
actual tensor/container overhead is charged to the RAM/GPU guard.

All active history together is <=256 tokens and <=528568 bytes including 184
statistics bytes. Query evidence costs 2C tokens; B_S=256-2C, reaching 210 support
tokens for 23 classes. Fixed S cores are within this support allocation. Optional
S uses the original uniform-next-action ZERO or BAL transitions, extended only
to require the union of original coverage and S cores. Feasibility counts use
the actual size of this mandatory union. Each current evidence checkpoint is
serialized and restored from its charged bytes, overwriting only this new run's
CURRENT checkpoint; previous features are not accumulated as a decoder/cache.
Aggregate retention traces remain. All original project artifacts are protected.
