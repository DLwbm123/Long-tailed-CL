# Source review and mechanism choice

TARS: Extending Reinforcement Learning Gains to the Long Tail under Limited Data for Domain-Specific Visual Recognition, anonymous ICLR2027 submission [me8ReG9Qh4](https://openreview.net/forum?id=me8ReG9Qh4). Existing locally supplied original PDF read: main method sections3.1-3.3 and experimental setup4.1. No author code inspected; web forum access failed in this session, so identity is grounded in the cached original PDF and existing metadata, not a current acceptance claim.

Original rarity-times-SFT-error exponent.75 and median normalization amplify the clipped normalized GRPO surrogate only. Class exposure remains natural; fixedweights reduce effective KL strength for high-tailness queries. Thus total-strength-matched RL is needed to separate allocation from merely larger gradients. Scaling raw rewards before within-query normalization largely cancels. Zero reward diversity remains zero PG.

Prior adaptations differ materially: R67 uses CLIP categorical recognition with visual LoRA; R105 uses a three-expert selector and its TARS_GRPO predictions coincide with weighted exact-reward optimization; R113 controls memory with a scalar multi-stage return and tiny fixed probes, with zero-information argmax numerical drift. None is a direct generative-recognition replication. Repeating their names or weights is insufficient.

R114 returns to free-form autoregressive recognition with a shared generic Qwen2.5-VL-3B checkpoint. It deliberately tests the mechanism before claiming a new continual method. LoRA instead of full language updates, fixed224 resolution, static medical data and one development seed differ from the original four-H100 experiment. CE_CONT and TARS_CE are query-matched controls, not compute-matched or independent method tuning. The larger research question remains how to integrate reliable tailness-aware RL with evolving classes and old-class protection; a static positive result alone will not resolve that.
