## Source and mechanism

TARS scales post-normalization advantages from rarity times SFT error; retain exactly the R114 generative objective. A-GEM (Chaudhry et al., ICLR2019; https://arxiv.org/html/1812.00420v2 section4 and appendixC) uses an average reference gradient and halfspace projection to limit past-data loss to first order. The present adaptation constrains the actual AdamW parameter proposal, not just its raw gradient, because momentum/preconditioning can change the applied direction. A fixed interior cone and a TRAIN-only finite-step loss guard address curvature. These geometric ideas are borrowed, not claimed as a novel algorithm or as guarantees on unseen/head accuracy.

Let h be the gradient of class-balanced head-label tokenCE at the current parameters, d the actual AdamW proposal after the existingRL gradient clipping. For normalized u=h/||h||, write d=a*u+v, b=||v||. Main PROJECTED_TARS projects d to {z: h dot z <= -.1*||h||*||z||}; fixed k=.1/sqrt(1-.1^2). If a<=-k*b keep d. Else if b-k*a<=0 return0. Else b'=(b-k*a)/(1+k^2), a'=-k*b', and z=a'*u+(b'/b)*v. Zero h leaves d unchanged and is reported. This is a Euclidean cone projection; no validation-derived angle selection.

Evaluate candidate parameter states before+alpha*z for fixed alpha=[1,.5,.25,.125,.0625,0], all six every update. Choose largest alpha whose head minibatch CE is <= alpha0 CE, with no performance tolerance. Raw AdamW state/moments advance on the originalRL gradient; only the applied parameter displacement is constrained. Record moments policy and zero accepted steps. The guard concerns this TRAIN minibatch only, not an independent population or per-class guarantee. FP32 parameter rounding means measured displacement/dot are recorded rather than claiming exact symbolic feasibility.
