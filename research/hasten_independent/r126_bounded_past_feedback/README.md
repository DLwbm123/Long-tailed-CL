# R126 bounded past-task feedback qualification

Frozen five-stage generative continual policy experiment. The main causal contrast holds four current plus four bounded-old input slots and rollout/update budgets fixed while masking old correctness before advantage and CTAN in OLD_PROXY. See PROTOCOL.md for exact access, reward, controls, costs and gates. The fixed buffer has at most two TRAIN components per arrived class; old full-TRAIN cache access is denied.

This is a mechanism qualification of known replay and RaPO/TARS ingredients, not a claimed novel final method or independent clinical confirmation. The shared first-task supervised contribution is separate from RL. Native engineering updates are discarded.

Only source and aggregate receipts are published; data, selected indices, features, predictions, weights and private runtime configuration are excluded.
