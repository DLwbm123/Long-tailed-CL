## Mechanism and distinction

Use existing same-encoder Biomed512 unit image caches, no new backbone/patch/multilayer extraction and no text classifier. Learn a visual residual once on the complete initial TRAIN task, then freeze its entire coordinate map permanently. Jointly solve all seen-class boundaries from true class-labelled TRAIN sufficient statistics as new classes arrive; no synthetic replay, old raw-feature reread, teacher, hierarchy, shared hyperbolic mapping, adapter merge, task routing, or fitted score fusion. VIS motivates learn-then-freeze and analytic updates, but this is not its multi-layer CLS implementation. R16 changed a raw linear readout inside old fusion; R24 detached a head while core representation continued changing. R55 jointly changes representation, global decision, and historical evidence retention.

Residual u(x)=normalize(x+W2 GELU(W1 x+b1)+b2), bottleneck64; W2,b2 initially zero; W1 ordinary PyTorch initialization. Temporary initial-task cosine head initialized using initial TRAIN raw class means, fixed scale20. Entire residual and temporary head trained20 full epochs, batch64 original natural shuffle, AdamW lr.001 weight_decay.001 cosine schedule, no early stopping. Loss minibatch mean[N0/(C0*n_y)*CE] + .01*mean||raw_residual(x)||^2. Unlike averaging only present classes, the CE estimator targets the global equal-class risk. All initial rows retained, no64cap. No independent optimization convergence claim merely from20epochs. Save epoch0..20 full objective and fixed classprobe metrics; always use epoch20.

Freeze u and a single Gaussian random projection R[512,2048] drawn with a separate seeded generator(seed+550000), same for both analytic arms. phi(x)=[sqrt(2/2048)*ReLU(u(x)R);1], intercept penalized too. Projected features not L2-normalized again. No random map/dimension/seed search. Random expansion adds capacity but no generalization guarantee.

At arrival of class c all its TRAIN rows are available exactly once, n_c is its exact arrived count. Balanced arm G=sum_c sum_i(phi_i phi_i^T)/n_c; Q[:,c]=sum_i phi_i/n_c. Thus each class contributes total sample mass1, including old rare classes, independent of new head counts. At each stage ridge lambda=.01*trace(G)/2049, W=solve(G+lambda I,Q), FP64 accumulation/solve. Compare matched same-u/R sample-weighted ablation: G=(C/N)*sum_i phi_i phi_i^T; Q=(C/N)*sum_i phi_i e_y^T, lambda same trace rule. Its total sample mass alsoC but per-class contribution proportional n_c. One shared learned map; no extra optimizer for ablation. Labels onehot; no claim +-1 targets outperform equivalent onehot argmax. Plain standalone W logits, no prototype/text fusion.

All parameters/R remain exact unchanged after initial training. New classes append Q columns; old columns unchanged. Fixed-class arrival permits exact additive weighted G without per-class scatters or replay. At a given stage accumulation equals batch normal equations for that same stage objective, up to floating arithmetic; this optimization identity does not prove perfect memory/generalization. Global lambda trace rule changes with arrived statistics, specified in advance. Need stored matrices O(D^2), not zero memory; save both G variants per boundary for recovery and expose cost.
