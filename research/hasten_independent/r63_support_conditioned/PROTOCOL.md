Use original TRAIN identity_component metadata, not assumed universally patient identity. Across all3manifests no component spans labels; each class>=2components. Within a class, sort groups by descending row count then lexical group key; greedily assign to fold with fewer current rows (tie0). Preserve old assignment exactly, no future features used, assignment of old class unaffected by future classes. Every seen class has nonzero support/query in each direction. Full metadata can define schedule; features/images only read after arrival.

For each stage,10completeepochs. Each epoch qfold0then1: use current encoder/eval/no_grad to encode ALL opposite-fold real support into prototypes, detach and hold them fixed during this query pass; train ALL qfold rows once in natural seeded shuffle. Then refresh support with updated encoder for the other pass. This is an alternating detached-support/semi-gradient procedure, explicitly not full joint differentiation through support. Every arrived real row is a query once per epoch and support once per epoch; no query shares a metadata component with that pass's support. Not independent patient holdout: all rows eventually query-label train, components may be image/content/lesion identities. This construction may still overfit.
