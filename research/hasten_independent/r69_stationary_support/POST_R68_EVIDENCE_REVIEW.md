# Post-R68 evidence review and frozen R69 decision

R67 and R68 are complete, verified and publicly delivered. This review uses only saved aggregate counts, TRAIN curves and diagnostics; no new model scores or validation selection. R68 primary raw_tars_grpo mean/final/tail65.295557/63.727152/43.586882 vs original natural66.115954/63.655574/44.737644 and common SFT66.840041/64.876782/44.924938. Raw reduced zero-advantage groups74.76% to66.55% yet reduced tail performance. Exact expectation did not consistently improve validation. Atstage5 natural sampled TRAIN macro/tail88.506/83.221→81.596/72.194; natural exact→86.868/80.691; raw sampled→88.342/83.549; raw exact→90.879/88.184 while its validation final/tail fell. Thus neither group sparsity nor estimator variance nor policy prior alone explains the failure. TRAINcrossfold observation is not independent holdout.

Code inspection identifies an untested coordinate feedback mechanism: support prototypes are detached from query gradients but recomputed from the changing model each epoch/fold. Correctness reward, behavior likelihood and query gradient then operate against changing class coordinates. Hypothesis: anchoring TRAIN support coordinates to the fixed SFT opposite-fold prototypes may stabilize posttraining while final inference still uses adapted full-history prototypes. This is a hypothesis, not causal proof; frozen support might also harm adaptation or create a new train/inference gap. Test both sampled and exact estimators with original count policy; do not select raw merely because one endpoint improved.

R69 preregisters dynamic_tars_grpo, fixed_tars_grpo(primary), dynamic_tars_exact, fixed_tars_exact; no LR/epoch/gamma/weightcap sweep or rescue. Use all six stages and same seed, matched SFT heads, identical query orders and matched support-forward exposures. Dynamic and fixed arms both encode current support; fixed arms deliberately use immutable SFT prototypes for training and old behavior, while query model updates normally. All arms recompute adapted full-history prototypes for inference. Record selected-support equality and current-to-SFT shift per fold. No validation lookup to alter training. Follow all prior resource, privacy and delivery constraints.
