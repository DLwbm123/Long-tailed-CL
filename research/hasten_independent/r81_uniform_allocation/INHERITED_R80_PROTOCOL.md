# R80 frozen training-trajectory allocation experiment

Frozen before software/native execution or data probes, 2026-10-29. User explicitly authorized completing the proposal, freezing controls/budget, implementing and launching. Supersedes waiting-for-Pro instructions, not historical protocols. No R79 or low-LR launch.

## Hypothesis and interpretation
A state-conditioned category allocation policy, trained with GRPO on actual supervised update consequences, can improve class-balanced recognition while limiting old/tail damage relative to fixed balanced allocation. This is a GRPO controller of a supervised learner, not categorical-label GRPO or generative reasoning. Dynamic replay scheduling/meta-learning are known antecedents; no novelty/effectiveness claim before evidence. R72/R73/R75 negative results and R77 small same-readout positive increments plus original-SFT final/tail losses remain.

## Fixed contexts and trajectories
8 contexts per stage, alternating folds, 3 actual updates/trajectory, batch256/micro64. First two updates contain 192 shared natural-frequency unique S rows and 64 controlled rows. The last update is a shared natural-frequency unique256 batch testing immediate retention. Shared streams seeded by 74002+10000*stage+100*context+h. No image repeats within a batch. Across updates repeated replay is allowed and counted, not new independent observations.

Action0 fills the64 slots by balanced cycling through randomly ordered classes with nonempty unique pools, without replacement within batch. Action(c+1) first adds up to64 remaining unique class-c rows, then uses the same balanced unique fill. Common192 rows are excluded from controlled pools. A class action is masked if no row remains after the common batch; action0 always legal. Small classes cannot consume64 slots by repeating one image. Log priority availability/allocation and realized class counts, including zero influence for already-covered classes. This deliberately caps possible small-class exposure; it is not guaranteed to make every tail action large. Batch fill randomness is shared across branches/arms; action uniforms have a separate fixed stream.

All nine branches start from the same visual parameters AND AdamW state, except the explicitly identified long-supervised control below. Eight sampled action sequences (2 decisions each) plus one balanced reference. Evaluate all9 endpoints on full Q; use full class counts, including tiny denominators. Retained branch index=(stage*8+context)%8 is fixed before rewards. Never select by reward. Branch8 is reference only for learned/short controls. Commit the chosen branch's visual parameters AND optimizer state; discard alternative updates after logging. No exact resume from a partial optimizer/context.

## State and controller
Per arrived class: log full real TRAIN count/log1000, log S unique count/log1000, age/5, new-class indicator, pre-context Q mean Brier, Q mean probability margin, change since previous same-fold margin (zero if unavailable), last retained exposure fraction. At second decision replace exposure fraction with first-step exposure fraction. Initial SFT feedback and cross-context Q reuse disclosed. No class-ID embeddings, future-class signals or VAL inputs.
Shared MLP 8->64 tanh->64 tanh. Mean set pooling. Class scorer concatenates own64+pooled64 -> scalar; balanced scorer pooled64->scalar. Both output heads initialize zero (uniform over legal actions). Controller AdamW lr .0003 wd0, persistent moments, four full-batch GRPO gradient steps per context, no additional entropy/gradient clipping/tuning. Snapshot old log probability at sampling. Replay stored states/masks/actions. Per-decision ratio, clip[.8,1.2], shared trajectory advantage populationstd+1e-8, uniform-over-legal-actions fixed reference KL coefficient .04. This KL regularizes controller behavior, not visual knowledge. No tail factor after normalization. No claim that clipped standardized GRPO is an unbiased gradient of raw utility.

## Reward
Q raw-prototype softmax, Brier(x)=.5 sum_k(p_k-onehot_k)^2 in[0,1]. Lc is full Q class mean. Macro=mean over all arrived classes. P=old classes union classes with original full arrived TRAIN count<250. Old anchors: previous-stage final model on same context Q and S restricted to previously arrived classes, padded new probabilities with zero (Brier unchanged). New-tail anchor: current context start model on same full class space. Stage0 has no old classes. Protected damage=mean_P max(Lc-Lc_anchor,0), no double counting union. U=-macro-damage, coefficients1, fixed. Macro-only ablation U=-macro. Rg=Ug-U_balanced; common baseline cancels during group normalization, not a new source of gradient information or safety guarantee. Log absolute retained R, positive/negative advantages, all-eight-negative cases, class risks and realized exposure. Relative positive advantage may accompany a negative absolute return.

## Frozen arms and comparisons
A balanced_short: all9 branches balanced, restart each from identical snapshot, commit prespecified index. No controller learning. Same 3 committed updates/context.
B macro_controller: GRPO controller with macro-only utility.
C protected_controller: **sole primary**, macro plus protected damage.
D shuffled_controller: same as C but rotate eight rewards by one before controller advantage assignment (fixed derangement), correct rewards still logged. Same branch index commit; tests reward/action credit assignment.
E balanced_long: all9 balanced branches execute sequentially without resetting visual/AdamW, committing all27 updates/context. No controller. This spends the same number of inner backward updates on one supervised trajectory.

All5 perform the same18 full-S prototype encodes/context (one pre plus8 branch starts plus9 endpoints) and10 full-Q evaluations (pre plus9 endpoints), same9*3*256 query exposures and4 micros/update. Learned controller overhead, previous-model anchor and end computations are measured; equal primitive visual work does NOT imply exact equal wall/GPU seconds. A controls committed updates and otherwise wasted rollout cost; E controls major visual compute by spending updates on learning. C-A allocation increment, C-B damage penalty increment, C-D credit assignment, C-E compute efficiency. E is a resource-matched causal control, not an optimization campaign of a paper baseline.

Zero additional training reference: same stage0 SFT encoder carried unchanged, full arrived prototypes each stage. Existing original stagewise SFT six endpoints retained as historical strong reference, not causally matched to new carry protocol. No extra historical SFT model scoring; use its sealed counts. All five arms truly carry state; six independent SFT restarts are prohibited.
