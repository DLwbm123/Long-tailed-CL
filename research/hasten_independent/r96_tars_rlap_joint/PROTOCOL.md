## Stagewise supervised anchor and main posttraining
At each stage the supervised carry model adds its new branch and trains exactly10epochs. AdamW lr1e-4/wd.01, batch16/micro2, R95 difficulty-weighted CE + micro2 symmetric contrastive + .01 routing balance. Prototype bank refresh once/epoch, detached encodings; no RLPO. Shared AdamW moments carry between supervised stages; new branch moments fresh. Save SFT stage checkpoint, optimizer, bank/text/IDs before posttraining. It is the necessary fixed KL reference and internal before/after readout, not an additional independently trained comparison arm.

Make a main model copy from that SFT stage, then exactly2epochs categorical TARS-GRPO, AdamW lr1e-5/wd.01 fresh per stage. Two optimizer updates per natural batch16; same sampled actions, behavior probabilities and advantages fixed across both updates. Group G8 independent class actions/query sampled with replacement. Reward binary correct class. Population group std+1e-8; constant-reward groups retain zero advantage and remain in denominators, no resampling. Old logits are detached from the first pre-update forward for the whole optimizer group; they are **not** overwritten by current logits on update2. Per-action PPO min(ratio*A,clip(ratio,.8,1.2)*A), mean over8. Genuine sampling/ratio/clipping; no exact surrogate substituted.

Tailness fixed per stage: w_c=max(1, [((mean raw TRAIN count)/raw count_c)*(1-SFT TRAIN recall_c)]^.75 / max(midpoint median across arrived classes,1e-8)). Recall uses a fixed SFT pass over exactly this stage's legal natural training IDs. This changes R67's crossfold source and is explicitly disclosed, not an independent audit. No F/VAL labels in weights or training. Weight multiplies only GRPO surrogate. Exact forward categorical KL beta.04 to fixed SFT query logits, plus .01 routing balance; no additional CE or contrast in GRPO. KL is an anchor intended to limit drift, not a guarantee of no forgetting. Record all constant groups, action rewards, clipping/KL and per-class weights privately, with safe aggregates public.

During RL bank refresh each epoch uses the current main model/retained memory. The reference logits and weights remain those of original stage SFT. Old branch caches remain immutable. RL delta does not carry into later SFT stages; next stage starts from the supervised carry model. This preserves stagewise posttraining interpretation and prevents unknown RL drift from redefining later reference checkpoints.
