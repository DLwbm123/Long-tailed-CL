# 残差耦合的等价性核对：撤回一个候选创新，不启动等价实验

## 本次结论

固定额外子空间U时，C中的“减去全局可预测部分”没有新增线性可表达信息；它是可逆坐标变换。配合原标量RMS归一化与各向同性ridge，它等价于直接坐标下一个带交叉块的广义ridge。若再做惩罚同余变换，所有样本上的得分可完全一致。因此不把“残差解耦/坐标不变惩罚”作为独立新方法，也不再花GPU重新证明代数等价。

这只是固定U、相同输入归一化、相同支持/权重/目标与相应惩罚下的条件性结论。C和PCA估计出的U不同，不能据此说二者全部等价，或宣称已解释PCA在读出支持诊断中更稳定。

## 从实际源码推导

现有core_depth.project令全局核心为G，额外特征Q=H U，残差特征E=Q−G V。G/H已经过各自训练支持上的输入归一化。令输出训练均值为[m_g,m_e]，norm_fit返回单个RMS标量s>0，并保留不受罚截距。于是

```
X = [G, Q, 1]
Z = [(G−m_g)/s, (Q−GV−m_e)/s, 1] = X T

T = [[ I/s,  −V/s, 0 ],
     [  0,    I/s, 0 ],
     [−m_g/s,−m_e/s,1]]
```

T可逆。若残差系数为W、直接坐标系数为β，则β=T W，Xβ=ZW。类/组平衡矩阵Ω在两问题中相同，D=diag(I,0)表示截距不罚：

```
min_W  ||Ω^(1/2)(Z W−Y)||_F² + λ tr(Wᵀ D W)
=
min_β  ||Ω^(1/2)(X β−Y)||_F² + λ tr(βᵀ T^(−ᵀ) D T^(−1) β)
```

目标的公共类数除数可并入Ω，不影响等价关系。写β=[a;b;c]，原各向同性残差惩罚变为

```
λ s² ( ||a+Vb||_F² + ||b||_F² ).
```

因此残差耦合实际上偏好某些全局/额外系数组合。输出均值只改变自由截距；RMS标量改变有效惩罚尺度；V带来交叉块。不能把相同数值alpha误称相同统计先验。

反过来，若直接坐标原本采用D，则残差坐标必须用Tᵀ D T，才能保持同一惩罚。仅将lambda改成另一个标量通常不能消去V引入的交叉项；但改成同余惩罚只是恢复坐标不变性，仍不是新的判别信息。

源码core_depth.coordinate_check已经转换系数核对得分，selfcheck已经包含同余惩罚的合成数据恒等式。本次只审读代码和推导，没有重跑该检查或访问服务器数据；旧检查存在不等于本次新增独立实证。

1. birth_geometry_recovery的D_G=D_N=0，只表示本次16组query的0/1差向量为零；并非几何参数或margin不变，更非总体无害。

3. 固定U等价说明：从残差C变成“不残差但匹配惩罚”不可能在精确算术下修复风险；“不残差且仍用普通ridge”改变了先验，可以改变预测，但它就是现有广义ridge机制的另一种设定，不能因产生收益就主张新信息。
4. P/C子空间、输出尺度及诱导度量同时不同。当前没有把差异唯一归因于哪项，不能根据PCA的有利结果去扫描子空间或正则强度。
