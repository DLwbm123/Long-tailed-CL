# Frozen B plus local shrink, single fixed fusion

Authorized scope: ISIC 4+2 and HyperKvasir 13+2 first transition, same Qfit/Qgate rows. Historical B and previous local_shrink scores are immutable. No model fit, feature extraction, new labels, E/test access, lambda scan, retry for performance, or seed expansion. Lambda is exactly 0.5.

Before opening cached query scores, compute both scales using the exact previous base-support calibration sample: seed 74002, up to 32 known groups per base class, one lexicographic image per selected group, equal class weight. B is the FULL frozen historical B head, not a refitted base head. Both branches score ALL currently seen classes on these base images. Scale = square root of the mean across base classes of mean squared within-image class-centered scores. This deliberately uses the current frozen class set; it differs from the previous base-head/base-class calibration and avoids reusing the 768-D ridge scale. It is training-support calibration, not held-out calibration, and uses new-class model state through scoring columns. Local covariance shrinkage and every density parameter stay unchanged. Seal both dataset scales before reading either query. Prediction: argmax(B/scale_B + 0.5 * local/scale_local).

Exact per-class metrics and confusion matrices of B and local_shrink must reproduce the stored previous results. Record all/old/new BA, CE, micro accuracy, rescue/harm and changed predictions. Per class record branch disagreement, B-only-correct, local-only-correct, both-wrong, rescue and harm. On every branch-disagreement OR fusion-changed row, privately record row index, label, predictions, each branch's normalized top1-top2 gap, true-class-minus-best-other margin, and signed score difference between B's winner and local's winner; also record raw B/local top2 gaps. Fusion margins use the final fused scale. Local normalized margins exclude the lambda factor (multiply by 0.5 for its fusion contribution). Public files contain aggregate counts and margin quantiles only; no row identifiers, per-row scores, images, or model state.

Report all four conditions with no winner selection. Descriptive success criterion per dataset: both queries strictly improve overall BA vs B and neither old nor new BA loses more than 1 percentage point on either query. Already-inspected development queries cannot establish independent generalization. Tiny class denominators remain unchanged. This is a full-old-statistics B diagnostic, not proof of compressed-memory deployment.

Implementation reuses run_transfer aggregation and run_v2 scoring. Cached calibration patches must align with base support row order. No GPU is needed: only cached CPU scoring and scalar calibration. Stop on failed input/reference assertions and preserve artifacts. Expected duration under 10 minutes; resource budget one CPU process with four torch threads and small result files.
