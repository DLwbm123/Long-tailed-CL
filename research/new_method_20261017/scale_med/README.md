# SCALE-Med minimal v1

Implements the linked Pro proposal's first rung: frozen final-layer patches, fixed orthonormal random projection (128), one Gaussian per class, patient-equal statistics, base-only fixed Gaussian reference, support-adaptive covariance shrinkage, fixed uniform local aggregation, and fixed global/local fusion. No inner-layer MLP feature selection or multi-component mixture is implemented in this rung.

Seven paired scoring arms reuse identical features: `uniform`, `entropy` (PatchBELL Appendix A4 weighting), `reference`, `reference_shrink`, `global`, `global_local`, and full 768-D CLS `ridge`. This is a controlled adaptation, not an exact reproduction of PatchBELL's original representation. Uniform and entropy use the same unshrunk Gaussians; reference_shrink changes covariance only. Beta = patients/(patients+20), eta=.5, lambda=.5. Covariance floor is .001 times the base reference's average diagonal variance. Reference is a single Gaussian moment match of equal-weight base class distributions. Scores divide by 128; no validation rescaling. Ridge uses class-balanced, patient-balanced sufficient statistics and alpha=1 with an intercept (also regularized).

Frozen ImageNet pretrained timm `vit_base_patch16_224`, 224x224 RGB bicubic resize and mean/std .5. No gradient training, no network downloads, no test split. The NIH author20 single-label setup has 68,058 training and 300 balanced validation images. Subject IDs are cross-checked against image identifiers and train/val subjects must be disjoint. Support means patients within each class. Validation metrics are image-level, not patient-level. Base statistics may pool base classes; incremental class statistics are computed only when that class arrives. Validation features are never used to fit models or select parameters.

`config.json` is the frozen public parameter set. A private runtime config additionally requires `manifest`, `author_labels` (train.csv/val.csv folders), `images`, `weight`, and `output`. Launch with `RUN_CONFIG` in the environment. Data CSV schema is validated by `read_rows`. `python check.py` runs focused math checks; `python run.py` runs the experiment; `python report.py OUTPUT` creates aggregate reporting after all six stages finish. Runtime: Python with torch 2.6.0+cu124, timm 1.0.15, torchvision, Pillow, safetensors.

Completed class statistics and validation features are atomic checkpoints. Resume requires the identical private configuration and retains the original 12-hour wall deadline. A partially processed class is not checkpointed; engineering restarts must record that repeated work and preserve prior status/logs. Failed or low-scoring runs do not authorize parameter sweeps. Outputs are expected below 1 GB; no full training patch cache is retained.

Diagnostics record fixed-old-score drift, old-class restricted rank flips, harm/rescue, and new-class wins separately. Fixed scores do not imply zero forgetting. One order/seed on a previously used development split provides exploratory evidence only.

Public delivery allowlist: these source files, public config, aggregate `support.json`, `results.json`, `summary.csv`, and `REPORT.md`. Never publish private configs, subject identities, paths, images, features, logits, checkpoints, or raw runtime logs. Existing experiments and their automations remain separate.
