## Identifiable contrast and differences
Freeze original native features and F mapper. Initialize three trainable linear heads from the explicitly allowed frozen F reference, not old T/P/C/D endpoints. R learns real support only; M learns real plus curated synthetic support; T learns real plus the same bounded M-guided proposal pool without virtual-risk admission. Thus M–T isolates admission conditional on M's adaptive proposal trajectory, not an independently generated T trajectory. Unchanged F and native cosine mean P also reported. Primary must beat F/R/T; no best-control promotion.

Paper uses trained Stage-I CNN/GAP and BCE3S classifier; ours uses existing normalized1536 native descriptors and original affine mapper, with class/group-balanced CE. Whole-channel grafting commutes with GAP for a fixed mask, but these descriptors are not original CNN maps; this is a pooled coordinate-grafting transfer only. No new encoder or Stage-I fit. Original paper/code MaxNorm for its classifier is not imposed on the arbitrary-scale F ridge head; same unconstrained architecture and real optimizer for all three trainable heads. This omission and full-batch schedule limit reproduction claims. No calibration/EMA/test-selected epoch or original-code optional adapter/BN/portfolio modes.

## Fixed algorithm
20 full-support weighted real-gradient epochs, SGD momentum.9, initial LR1e-4 cosine to epoch20, weight decay0, free intercept; 1 real update per epoch per head. Selection uses only current fold support. Class frequency stable-sort partitions top ceil(K/3) head, next floor(K/3) medium, rest tail. All support retained, no requirement for patient identifiers.

Detector uses average M/R logits, true-vs-largest-other margin, tail quantile.35 with minimum.001. Per tail choose at most2 most-negative errors and2 smallest positive margins below threshold. Unlike code's parity image split, all available support may be proposed and judged: ISIC known groups are never described as independent judge validation, and singleton classes are not discarded. Query groups remain excluded from every stage.

Generator: donor rival if head, else nearest head prototype (official default head mode); random donor image. Four random masks per anchor, floor(.15*d) coordinates, strength.5 for errors and.375 for positives (code defaults, not paper shorthand alpha.15). Both M/R must improve erroneous-anchor margin >.001; low-positive anchors must instead decrease margin by>.001 but stay>=.001, preserving near-boundary enrichment. Select closest desired margin .05 for errors or max(.001,.7*oldmargin) for positives. Cosine-to-anchor>=.90, relative drift<=.35, true-minus-other prototype margin>=-.05. Fixed seed74420+support index, no searches.

Curator merges old memory and proposals; each tail at most8, order by distance to pair margin.25, deduplicate cosine>=.995. Synthetic class-balanced softplus pair loss uses temperature.1 and goal max(.25,detached margin+.25). Greedily admit class groups only if one virtual R gradient step reduces whole class-balanced support CE, strictly reduces every included target class CE, and head/medium mean CE increase<=1e-4. No claim that reused training support estimates generalization. M receives admitted memory; T receives the same bounded pre-admission pool, each one plain gradient step with current real LR and no momentum. R remains real only. Re-evaluate memory every epoch. No stochastic head selection or reuse of observed query answers.
