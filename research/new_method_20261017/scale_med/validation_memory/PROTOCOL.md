# Historical validation memory: minimal falsification, v1

Authorized 2026-10-18. One existing ISIC 4+2 transition and one HK 13+2 transition; no additional orders, seeds, features, penalties, or compression experiments. Reused exposed evaluation is exploratory, not blind confirmation. Known identity groups do not establish patient isolation.

## Eligibility and split

Use the existing frozen normalized 1536-dimensional global feature caches, existing support/test manifests and audited support/test separation. Recheck cache labels/group ordering, support counts and manifest path/group disjointness. No historical heads or historical test predictions are inputs. Split each class by existing holdout(seed74006): max(1,floor(.2*n_groups)) validation groups when n_groups>=2; singleton remains training. Permanent holdout for every selector, no validation-to-training refit. ISIC has full six-class validation coverage and is primary. HK class1 has one support group: its 14/15-class validation is auxiliary only, never all-class validation. HK evaluates all15 output competitors, including the uncovered class. No extra data to repair coverage.

Freeze base-train weighted mean and scalar RMS normalization; intercept unpenalized. Training weights equal per class, per group and per image within group, as existing core_attribution. Solve three ridge heads alpha=[.0001,.01,1] at base and joint stages; divide training objective by number of seen classes. No extra grid even if an endpoint wins. Ties favor larger alpha. Cache extraction/backbone costs are inherited and excluded explicitly.

## Six selectors, identical candidate heads

FIRST: base validation BA winner, fixed afterward. CURRENT: new-class validation BA of current all-class heads. BIRTH: class-count-weighted average of base heads' old-class birth BA and current heads' new-class BA. This is a scalar-archive control, not a literal SLARC reproduction. FULL_BA: privileged independent auditor recomputes current heads' BA on all covered historical/current validation classes. FULL_MSE: privileged auditor directly computes class-balanced one-hot squared loss on the same rows and full output dimension. MOMENT: learner computes that loss from validation G=sum_c mean(zz'), H[:,c]=mean(z), constant Ccovered; average by covered class count. New label columns are zero-padded. These are standard quadratic sufficient statistics, not a new theorem or privacy guarantee.

Learner can access per-example inputs only in their birth stage. Old rows/cache and auditor files are denied after retirement; guard probe must reject access. Old train and validation tensors leave scope before new cache is opened. Retain only train/validation aggregate statistics, normalization, base scalar scores, candidate heads, counts and selector choices. Privileged auditor data are separate files and consumed by a separate process only after all learner choices and heads for both datasets are sealed. Test process runs only after auditor choices seal. Never use audit/test to alter learner choices, splits, normalization or candidates. All selectors use the same permanent training exclusions.

## Measurements and stopping rules fixed before execution

Report alpha, full covered-validation BA/MSE per candidate, old/new validation BA, selection regret r=max_candidate BA-BA(selected), all/old/new test BA, per-class test counts/recall, paired group-bootstrap10000(seed74003) intervals versus FIRST and the strongest simple control. Strongest simple control is selected by full validation BA among FIRST/CURRENT/BIRTH, ties in that order, before test access. This diagnostic comparator is privileged and cannot be deployed without full validation access. Candidate BA spread and test best-candidate BA are descriptive only, never selections.

Gate1 (need): on primary ISIC the strongest simple control's validation regret must exceed .5pp. Otherwise STOP_NO_SELECTION_HEADROOM. Gate2 (surrogate): MOMENT regret<=.5pp and <=50% of that control's regret; otherwise STOP_SURROGATE_MISMATCH. Direct FULL_MSE and MOMENT losses must agree within1e-8 absolute, rankings/alpha identical; violation is engineering failure, not a scientific negative. Gate3 (exploratory transfer): MOMENT test BA gain over the prespecified strongest control has positive lower95% paired interval and old/new point losses no worse than .5pp; otherwise STOP_TRANSFER_UNCERTAIN. Gate3 cannot certify blind generalization on exposed data. HK cannot pass or fail primary gates because validation coverage is incomplete. All six diagnostics are completed and reported even when a scientific gate fails; no compression/follow-up automatically starts even if gates pass.

Record wall time by phase, solve/selection time, actual float64 dense train/validation tensor bytes, packed-symmetric theoretical bytes separately, head bytes, normalization bytes, privileged auditor storage bytes and raw-feature equivalent. Include private payload sizes and peak RSS/GPU allocation. No assumption that moments save bytes. No original-image read or encoder extraction in this diagnostic. Engineering self-check: split isolation, additive stats/direct solve parity, quadratic-loss equality including added competitors, retired-read rejection, finite scores and seals-before-test. Preserve partial failure and cumulative costs; no rerun based on scores. Publish source/protocol/aggregate results/Chinese mechanism report through the required proxy, excluding raw rows/features/predictions/heads/private paths/logs.
